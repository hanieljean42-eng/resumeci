SIXIEME
FRANÇAIS CÔTE D’IVOIRE – ÉCOLE NUMÉRIQUE
GRAMMAIRE : LECON 6 : LES ADVERBES
SITUATION D’APPRENTISSAGE
Un concours de rédaction en expression écrite est organisé par le club littéraire du collège
moderne koonan. Les élèves de la 6eme de ladite école voulant réussir à ce concoure décident
d’étudier les adverbes. Aidés de leur professeur de français, ils s’organisent pour étudier les
adverbes de temps connaitre leur emploi afin de mieux les utiliser correctement en contexte à
travers le corpus suivant :
P1 :j’irai demain au champ.
P2 : Elle vient me voir souvent.
P3 : Le rat est rentré dans ce trou hier.
P4 : Papa je ne veux plus être dans cette maison. Je pars d’ici aujourd’hui.
P5 : Pourquoi ne pas aller tout de suite voir le marchand de vêtements ?
SEANCE 1 : LES ADVERBES DE TEMPS
DEFINITION
L’adverbe de temps est un mot ou un groupe de mots qui indique le moment ou se déroule
l’action exprimée par le verbe.
EX : Je mangeais souvent les légumes.
I. LES FORMES DE L’ADVERBE DE TEMPS
Les adverbes de temps se présentent sous deux formes :
-La forme simple : demain ; hier ; maintenant ; souvent ; bientôt.
EX : Mon chien viendra bientôt.
-La forme composée : Ils sont formés de plusieurs mots.
Ce sont ; plus tard ; aujourd’hui ; après demain ; tout de suite ; avant-hier.
EX : Ils iront à la rizière après-demain.
II. L’EMPLOI DE L’ADVERBE DE TEMPS
L’adverbe de temps s’emploie pour designer :
-Une date
EX : demain, nous laverons la moto.

-Une durée.
EX : Mon grand-père vécut longtemps avant de mourir.
-Une période.
EX : Avant j’étais pauvre, maintenant je suis devenu riche.
EXERCICES
1- Remplace les pointillés par les adverbes de lieu suivants : ici ; souvent ;maintenant
;demain ; avant.
Je suis viens…… pour qu’on parle de mon avenir. Papa dit de laver les chiots …de
vaquer à nos occupations. Il dit de ne pas le laisser sortir car…son propriétaire viendra le
prendre. Il se cachait ………..sous le canapé.
2- Construis une phrase avec chacun de ces adverbes de temps suivant : souvent ;
maintenant; demain; avant.
