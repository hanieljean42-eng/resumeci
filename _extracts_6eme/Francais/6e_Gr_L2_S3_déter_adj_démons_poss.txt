Séance 3 : Les déterminants du nom : Les adjectifs démonstratifs et possessifs.
Situation d’apprentissage
Les élèves de la 6ème 2 de ton établissement avouent rencontrer d’énormes difficultés,
notamment dans l’identification de certaines classes grammaticales. En vue de
résoudre leurs difficultés, ils s’appuient sur le corpus ci-dessous.
P1 :Cette école est belle.
P2 : Ces élèves sont les meilleurs de leur classe.
P3 : Mon sac d’école est neuf.
P4 : Notre bibliothèque est bien fournie.
Ils se proposent alors d’identifier le groupe nominal, de le définir, de connaître ses
constituants et de l’utiliser en contexte.
Séance 3 : Les déterminants du nom : Les adjectifs démonstratifs et possessifs.
Définition
Le déterminant est un constituant obligatoire du groupe nominal. Il est toujours placé
devant le nom et s’accorde en genre et en nombre avec ce nom. On distingue plusieurs
catégories de déterminants dont les adjectifs démonstratifs et les adjectifs possessifs.
I-Les adjectifs démonstratifs.
1-Emplois des adjectifs démonstratifs
Dans l’emploi, les adjectifs démonstratifs servent à montrer, à désigner les êtres ou les
choses dont on parle.
Exemples : CeMonsieur est mon père. (On désigne le monsieur)
Cet élève est mon meilleur ami.
2-Formes des adjectifs démonstratifs :
Les adjectifs démonstratifs varient selon le genre et le nombre du nom qu’ils
accompagnent :

 Devant un nom au masculin singulier, on emploie :
- Ce devant un nom commençant par une consonne
Exemple : Ce garçon est mon voisin
- cet devant un nom commençant une voyelle ou un ‘’h’’ muet.
Exemple 1 : Cet arbre est petit.
Exemple 2 :Cet homme est beau.
 Devant un nom au féminin singulier, on emploie cette
Exemples : Cette école est belle.
Cette statue est imposante.
 Devant un nom au masculin pluriel ou féminin pluriel, on emploie
« ces »
Exemples : Ces garçons / Ces filles
II -Les adjectifs possessifs
1-Emploi des adjectifs possessifs
Dans l’emploi, les adjectifs possessifs établissent généralement une relation de
possession et d’appartenance.
Exemple : Ma maison (la maison qui m’appartient)
Mais ils peuvent établir d’autres relations.
Exemple : Mon professeur de français (relation professionnelle)
2-Formes des adjectifs possessifs :
Les adjectifs possessifs varient en genre et en nombre avec l’objet possédé mais
aussi avec la personnedu possesseur (celui à qui appartient l’objet) :
 Le nom de l’objet possédé est aumasculin singulier : mon, ton, son,
notre, votre, leur.
Exemple : Son véhicule est encore neuf.
 Le nom de l’objet possédé est auféminin singulier : ma, ta, sa, notre,
votre, leur.
Exemples : Ma maison a été détruite (ma : possesseur, 1èrepers du sing ; maison :
objet possédé, féminin sing)
Notre maison a été détruite. (Notre : possesseur : 1ère pers du pluriel ;
maison : objet possédé : féminin singulier)

 Le nom de l’objet possédé est aumasculin ou au féminin pluriel :
mes, tes, ses, nos, vos, vos, leurs.
Exemples : vos cahiers sont propres
Tes (robes sont cousues
NB : On emploie mon, ton et son devant un nom féminin commençant par une
voyelle ou un « h » muet.
Exemples : Mon école / mon affaire / mon histoire / mon habitation.

Exercice1 :

P1 : …………..oiseau m’a réveillé.
P2 : …………..usine va donner du travail à de nombreux ouvriers.
Exercice 2
Remplace les pointillés par l’adjectif possessif qui convient :
P1 : J’ai fêté……anniversaire hier.
P2 : Elle habitait loin de…école.
P3 : Je préfère … robe rouge.
Exercice 3
Complète les phrases suivantes avec l’adjectif « ses », « ces », « cet »,
P1 : je voudrais ….biscuits- là ; mon amie dit que ….enfants en raffolent.
P2 : ………...terres appartenaient au père Jacquot qui préféra les vendre à
…………..étranger plutôt que de les léguer à …enfants.
Exercice 4
Souligne dans les phrases suivantes ‘’Leur’’ quand il est employé comme adjectif
possessif.
P1 : vous leur donnerez leur note quand leurs camarades seront revenus.
P2 : Il leur faut leurs bottes et leur imperméable.
