2. Parallélogrammes particuliers
a. Le rectangle
❖ Définition
Un rectangle est un quadrilatère qui a ses quatre angles droits.
Exemple
ABCD est un rectangle. Les angles A ̂ ; B ̂ ; Ĉ 𝑒𝑡 D ̂ sont droits.
Remarques :
• Un rectangle est un parallélogramme particulier.
• Un rectangle a toutes les propriétés du parallélogramme.
❖ Propriété
Si un quadrilatère est un rectangle, alors ses diagonales ont la même longueur.
Exemple
ABCD est un rectangle.
Donc AC= BD.
Exercice de fixation

a) Un quadrilatère qui a ses quatre angles droits est un rectangle ;
b) Un rectangle a les supports de ses côtés opposés parallèles ;
c) Un rectangle n’est pas un parallélogramme ;
d) Les diagonales d’un rectangle ont le même milieu ;
e) Un rectangle est un quadrilatère qui a ses diagonales de même longueur.
Corrigé de l’exercice de fixation
a) Un quadrilatère qui a ses quatre angles droits est un rectangle ;
b) Un rectangle a les supports de ses côtés opposés parallèles ;
d) Les diagonales d’un rectangle ont le même milieu ;
