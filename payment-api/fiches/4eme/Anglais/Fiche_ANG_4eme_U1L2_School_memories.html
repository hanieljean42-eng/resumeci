II. Expressing past habits — used to

Affirmative : sujet + used to + BV → At primary school, I used to eat in the classroom.
Négative : sujet + didn't use to + BV → I didn't use to cheat in the classroom.
Used to exprime une habitude passée qui n'existe plus. Ex : In form one, the big boys used to beat small boys.

III. Things we don't do any more

  • Today, I don't steal pens any more.
  • Now, I no longer weep at school.
  • My friend is no longer a bad-tempered boy.
Transformation : I used to cheat → I don't cheat any more = I no longer cheat.
⚠️ Pièges classiques :
  • Négation : didn't use to (sans d final) — pas « didn't used to ».
  • any more va en fin de phrase ; no longer avant le verbe.
  • used to = habitude terminée — ne pas utiliser pour des habitudes présentes.
