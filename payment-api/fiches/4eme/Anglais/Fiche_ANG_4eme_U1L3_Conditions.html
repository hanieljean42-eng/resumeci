II. Expressing conditions — if

If + present → will + BV
If Koffi works harder, he will improve his results.
If you don't study, you will fail.
La condition peut se placer au début ou en fin :
Konaté won't obtain good results if he doesn't work harder.
⚠️ Virgule si if commence la phrase ; pas de virgule sinon.

III. Unless = if … not

You will fail this year unless you catch up. = You will fail if you don't catch up.
unless = « à moins que » → remplace if + négation. Le verbe après unless reste affirmatif.
⚠️ Pièges classiques :
  • Après if (condition) : présent, jamais « if + will ».
  • unless contient déjà la négation — ne pas écrire « unless you don't ».
  • will not = won't.
