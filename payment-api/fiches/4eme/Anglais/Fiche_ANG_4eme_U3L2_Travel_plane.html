II. Expressing necessity — need to

When you travel by plane, you need to go to the airport.
When you travel by car, you don't need to go to the airport.
Adama needs to take a car. / He doesn't need to have a passport.
need to = avoir besoin de / devoir ; négation : don't/doesn't need to.

III. Expressing preferences

I like to travel abroad by plane.
I prefer travelling by plane. / I prefer airways to railroad.
I'd rather travel by waterway.
like to + BV · prefer + V-ing ou « prefer X to Y » · would rather + BV (je préférerais).
⚠️ Pièges classiques :
  • 3ᵉ pers. : he/she needs to / doesn't need to.
  • would rather + base verbale (jamais -ing) : I'd rather go…
  • prefer X to Y (pas « than »).
  • Documents pour l'avion : passport + boarding pass ; bus = ticket seulement.
