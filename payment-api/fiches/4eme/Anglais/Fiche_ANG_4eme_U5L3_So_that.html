📝 FICHE DE RÉSUMÉ

📖 Anglais🏫 4èmeUnit 5 Lesson 3 : Zoko leaves his village — so … that

I. Vocabulary — Rural exodus

rural exodus (exode rural : quitter le village pour la ville) · employment (emploi) · juvenile delinquency (délinquance juvénile) · tiring work (travail fatigant) · youngsters (jeunes) · attractive places · overcrowded (surpeuplé) · depopulation · drug addiction · poverty · bad living conditions · temptations

II. Expressing consequence — so + adjective + that

Farm work is so difficult that many young people prefer city life.
Rain is so rare that all the plants die.
Cities are so attractive that many young villagers are tempted.
Structure : sujet + verbe + so + adjectif + that + conséquence.
Transformation : John is tired. He sleeps on the chair. → John is so tired that he sleeps on the chair.

III. so + adverb + that

He worked so well that he passed his exam.
Population grows so quickly that the planet will be overcrowded soon.
Adjectif (après be) : so bad that… · Adverbe (après un verbe d'action) : so quickly / loudly / dangerously / comfortably that…
⚠️ Pièges classiques :
  • Après be → adjectif (so bad) ; après un verbe d'action → adverbe (so dangerously).
  • so … that — ne pas oublier that.
  • Conséquences de l'exode rural : villes surpeuplées + villages dépeuplés + délinquance juvénile.
