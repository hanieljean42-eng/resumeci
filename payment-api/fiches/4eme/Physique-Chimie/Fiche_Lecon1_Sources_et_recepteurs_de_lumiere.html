📖 Physique-Chimie🏫 4èmeLeçon 1 : Sources et récepteurs de lumière

I. Sources de lumière

Définition : Une source de lumière est un corps qui émet de la lumière. Ex. : soleil, lune, flamme, lampe allumée, luciole, écran de télévision.

1. Sources primaires

Définition : Une source primaire est un corps qui émet la lumière qu'il produit lui-même. Deux types :
  • Naturelles (non créées par l'homme) : soleil, étoiles, lucioles.
  • Artificielles (fabriquées par l'homme) : lampe à incandescence, lampe au néon, écran de télévision allumé, lampe torche.

2. Sources secondaires

Définition : Une source secondaire (ou objet éclairé) est un corps qui émet ou diffuse la lumière qu'il reçoit. Ex. : la lune, un mur éclairé, un caillou éclairé, un tableau éclairé.
Exemple de tri : Sources primaires = soleil, luciole, étoile ; Sources secondaires = lune, arbre éclairé, nuage.

II. Récepteurs de lumière

Définition : Un récepteur de lumière est un corps sensible à la lumière ou qui réagit à la lumière.
  • Naturels : l'œil, la chlorophylle, la peau.
  • Artificiels : pellicule photographique, photorésistance (LDR), photopiles/piles solaires, chlorure d'argent.

Deux récepteurs étudiés

① Chlorure d'argent : précipité blanc qui noircit à la lumière (il reste blanc dans l'obscurité). C'est un récepteur photochimique.
② Photorésistance (LDR) : dipôle électrique dont la résistance varie avec l'éclairement — éclairée = conducteur ; dans l'obscurité = isolant. C'est un récepteur photoélectrique.
Applications : appareils photographiques, éclairage public automatique, panneaux solaires, calculatrices solaires.

III. Cas particulier : un corps peut être les deux

Exemple : les feuilles d'un manguier sont à la fois source secondaire (elles diffusent la lumière reçue, donc visibles) et récepteur (la chlorophylle capte la lumière). Tout objet visible est une source de lumière (au moins secondaire).
⚠️ Pièges classiques :
  • La lune n'est PAS une source primaire : elle diffuse la lumière du soleil → source secondaire.
  • Une source secondaire ne peut éclairer sans être elle-même éclairée.
  • LDR : lumière → conducteur ; obscurité → isolant (ne pas inverser).
