📖 Espagnol🏫 4èmeLeçon 19 : Exprimer ses préférences

I. Vocabulaire

preferir = préférer · la preferencia = la préférence · favorito/a = favori · elegir = choisir · la elección = le choix · más = (le) plus.

II. Les expressions pour dire ses préférences

Entre el fútbol y el boxeo, prefiero el fútbol.
Mi plato favorito es el garba.
Entre las frutas, me gusta más la manzana.
Elijo el liceo clásico. / Mi preferencia es la manzana.
Prefiero estudiar que jugar.
4 structures :
  • prefiero + nom ou prefiero + infinitivo — entre deux options : prefiero X que Y (ou X a Y)
  • mi + nom + favorito es…
  • me gusta más + nom (comparatif)
  • elijo… / mi preferencia es…

III. preferir — le verbe à botte (e → ie)

PersonneForme

La chaussure : e→ie partout sauf nosotros et vosotros.

IV. Dialogue type

— ¿Qué asignatura prefieres?
— Prefiero el español. Me gusta más que las matemáticas. ¿Y tú?
— Mi favorita es el inglés.
⚠️ Pièges classiques :
  • preferir : prefiero, pas « preforo » (e→ie).
  • favorito s'accorde : mi asignatura favorita.
  • Comparaison : me gusta más el cine que la tele.
