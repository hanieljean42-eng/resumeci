📖 Espagnol🏫 4èmeLeçon 9 : Décrire

I. Vocabulaire

redondo/a = rond (el balón es redondo) · limpio/a = propre (≠ sucio) · el nieto = le petit-fils (el hijo de mi hijo) · abuelo = grand-père · patio = cour · paja = paille · adobe = adobe (brique de terre).

II. Décrire avec les adjectifs

AspectAdjectifs
la forma (forme)redondo/a, cuadrado/a
el tamaño (taille)alto/a, bajo/a
el colorblanco/a, azul, negro…
qualitélimpio/sucio, bonito, antiguo, fantástico…
El patio está siempre limpio. · La casa tiene una forma redonda. · Los muchachos altos juegan al baloncesto. · Ayer vimos una película fantástica.
Accord : l'adjectif s'accorde en genre et nombre avec le nom : las chicas bonitas · los muchachos altos · una película fantástica.
Contraires : limpio ↔ sucio · blanco ↔ negro · alto ↔ bajo.

III. Texte modèle — la casa del abuelo

En mi pueblo, las antiguas casas son redondas, están construidas con adobe roja y cubiertas de paja. Las montañas son altas con rocas duras.
Maison traditionnelle Senoufo : construite avec des éléments naturels (adobe + paja). Le patio sert à descansar, tomar aire, charlar, jugar y beber.
⚠️ Pièges classiques :
  • L'adjectif s'accorde : casas redondas (fém. pluriel).
  • estar + limpio/sucio (état) ; ser/tener pour les caractéristiques.
  • Description de lieu : forme + matériaux + couleurs + taille.
