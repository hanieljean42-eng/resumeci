📝 FICHE DE RÉSUMÉ

📖 Espagnol🏫 4èmeLeçon 4 : Saluer

I. Vocabulaire

saludar = saluer (el profesor saluda a los alumnos) · ¡Hola! = salut (entre amis, à tout moment).

II. Les expressions de saludo

MomentExpressionExemple
Le matin¡Buenos días!Buenos días, señor (8h30, au professeur)
L'après-midi¡Buenas tardes!Buenas tardes, señor director (14h30)
Le soir / la nuit¡Buenas noches!Buenas noches, señor (20h45)
À tout moment (familier)¡Hola!¡Hola Tanoh! — ¡Hola Lea!
Règle : ¡Buenos días! le matin · ¡Buenas tardes! l'après-midi · ¡Buenas noches! le soir/nuit · ¡Hola! entre amis à n'importe quelle heure. Pour une personne importante (directeur, professeur), on préfère les formules complètes + señor/señora.

III. Mini-dialogue type

Lea : ¡Hola Tanoh! · Tanoh : ¡Hola Lea!
Profesor : ¡Buenos días alumnos y alumnas! · Alumnos : ¡Buenos días, señor profesor!
⚠️ Pièges classiques :
  • On ne salue pas le directeur avec « ¡Hola! » (trop familier).
  • Le soir → buenas noches, pas « buenas tardes ».
  • día est masculin : « buenos días » ; tarde/noche féminins : « buenas ».
