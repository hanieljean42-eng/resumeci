📖 Espagnol🏫 4èmeLeçon 27 : Déconseiller

I. Vocabulaire

desaconsejar = déconseiller = disuadir (el profesor desaconseja beber alcohol) · la velocidad = la vitesse (rapidez) — la velocidad provoca accidentes de tráfico.

II. Les 3 structures pour déconseiller

No le aconsejo hacerlo. (no aconsejar + infinitivo)
No debéis beber alcohol. (no deber + infinitivo)
Lo mejor es que no fuméis. (lo mejor es que no + subjuntivo)
Autres formes : no os aconsejo viajar de noche · les desaconsejamos consumir alcohol · no debéis tomar drogas.

III. Conseiller ≠ déconseiller ≠ interdire

IntentionStructureExemple
Conseillerdeber / aconsejar + inf.Debes estudiar.
Déconseillerno aconsejar/deber + inf. · lo mejor es que no + subj.No debes beber alcohol.
Interdire¡no + subjuntivo!¡No bebas alcohol!
⚠️ Pièges classiques :
  • no te felicito n'est PAS un déconseil (c'est l'absence de félicitation).
  • desaconsejar = disuadir (synonyme des quiz).
  • Après lo mejor es que no… → subjonctif : no bebas.
