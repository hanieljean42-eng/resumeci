📖 Espagnol🏫 4èmeLeçon 22 : Demander et accepter des excuses

I. Vocabulaire

disculparse = pedir perdón = s'excuser (él se disculpa) = excusarse · enfadarse = se fâcher (ponerse nervioso) · lesionar(se) = se blesser (herir) · aceptar la disculpa = accepter l'excuse.

II. Demander pardon

¡Discúlpame! · ¡Perdóname! · Perdón. · Lo siento. · De verdad, lo lamento. · Perdóname por el retraso.
lo siento / lo lamento = je suis désolé · discúlpame / perdóname = impératif + pronom.

III. Accepter des excuses

No pasa nada. · No te preocupes. · De acuerdo. · Vale.
Équivalences : ¡Perdóname! ≈ ¡Discúlpame! · No pasa nada ≈ No te preocupes.

IV. Dialogue type

El presidente : ¡Perdóname por el retraso!
La asamblea : No pasa nada, Presidente. ¡Bienvenido!
Sié (qui a blessé Yao au front avec une pierre) : ¡Discúlpame! · Yao : No te preocupes.
⚠️ Pièges classiques :
  • Distinguer demander pardon (discúlpame, lo siento) d'accepter (no pasa nada).
  • disculparse por + nom : te pido perdón por el retraso.
  • Synonymes : enfadarse = ponerse nervioso ; lesionar = herir.
