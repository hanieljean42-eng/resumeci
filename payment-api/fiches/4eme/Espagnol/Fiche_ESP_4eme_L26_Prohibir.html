📖 Espagnol🏫 4èmeLeçon 26 : Interdire

I. Vocabulaire

una prohibición = une interdiction (« ¡No fumes! » es una prohibición) · prohibir / prohibido = interdire / interdit (« está prohibido fumar ») · contaminar = contaminer · una enfermedad = une maladie · un letrero = un panneau · hacer ruido = faire du bruit.

II. La prohibition — NO + subjonctif présent

Règle : pour interdire, on utilise ¡No + verbe au présent de subjuntivo!
Verbe¡No + tú!¡No + vosotros!
fumar (-ar)¡No fumes!¡No fuméis!
charlar (-ar)¡No charles en clase!
escribir (-ir)¡No escribas con errores!
poner (irrég.)¡No pongas el desorden!¡No pongáis…!
hacer (irrég.)¡No hagas ruido!¡No hagáis ruido!
contaminar¡No contamines!¡No contaminéis!
ser¡No seas perezoso!¡No seáis perezosos!
Astuce : au subjonctif, les verbes -ar prennent e (no fumes) et les verbes -er/-ir prennent a (no bebas, no hagas).

III. Formule impersonnelle

Está prohibido fumar / hacer ruido. · Aquí está prohibido fumar.
⚠️ Pièges classiques :
  • ¡Escucha! / ¡Aprende! = ordre positif (impératif) ; ¡No fumes! = interdiction → subjonctif.
  • Verbes irréguliers au subjonctif : hacer→haga, poner→ponga, ser→sea, ir→vaya, tener→tenga.
  • Panneau : está prohibido + infinitivo.
