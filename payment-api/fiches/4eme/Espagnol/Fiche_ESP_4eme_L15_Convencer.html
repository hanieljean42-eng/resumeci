📖 Espagnol🏫 4èmeLeçon 15 : Convaincre quelqu'un

I. Vocabulaire

convencer = convaincre (el que tiene buenas ideas convence a los demás) · un esfuerzo = un effort (hacer un esfuerzo para mejorar) · perdonar = pardonner · reconocer la culpa / pedir perdón = reconnaître sa faute / demander pardon.

II. Grammaire — tener que + infinitivo

Règle : pour convaincre quelqu'un, on utilise tener que + infinitif (= il faut que tu/vous…) ou deber + infinitif.
Tienes que perdonar. · Tenéis que llegar a la hora para no perder el tren. · Tienes que escuchar al profesor para comprender. · Tenemos que hacer los ejercicios para evitar malas notas. · Debéis lavaros para tener buena salud.
tener que conjugué : tengo que · tienes que · tiene que · tenemos que · tenéis que · tienen que.

III. Convaincre + argument (pour + infinitif)

Amigo, tienes que estudiar para tener buenos resultados.
Vecino, tienes que dejar de charlar durante la clase.
Compañero, tienes que perdonar a los demás.
Vecino, haces trampa, no está bien. Tienes que dejar de hacer trampa porque puedes tener problemas.
Structure gagnante : interpellation (Amigo/Vecino) + tener que + infinitivo + justification (para… / porque…).
⚠️ Pièges classiques :
  • Après tener que → infinitif, jamais un verbe conjugué.
  • Au quiz, seules les phrases avec tener que / deber « convainquent » ; « Tengo dos libros para ti » n'est pas une persuasion.
  • dejar de + infinitivo = arrêter de.
