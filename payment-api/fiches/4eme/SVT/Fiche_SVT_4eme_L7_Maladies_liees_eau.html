📖 SVT🏫 4èmeLeçon 7 : Les maladies liées à l'eau

I. Transmission par les produits souillés : les maladies du péril fécal

Les maladies transmises par la consommation ou le contact d'eau souillée ou d'aliments souillés par les urines et les selles sont des maladies du péril fécal.
MaladieAgent pathogèneMode de contaminationSymptômes
Dracunculose (ver de Guinée)Filaire de MédineEau non traitée contenant des Cyclops (petits crustacés)Plaies sur la peau ; vers sous la peau et dans les selles
Bilharziose (schistosomiase)Bilharzie (schistosome)Contact avec eau souillée par urines/selles — le parasite pénètre par la peauForte fièvre ; sang dans les selles et les urines
AmibiaseAmibeEau et aliments souillésSang dans les selles ; déshydratation
CholéraVibrion cholériqueEau et aliments souillésDiarrhées ; vomissements ; déshydratation

II. Transmission par des êtres vivants : les maladies à vecteurs

MaladieAgent pathogèneVecteurSymptômes
Paludisme (malaria)Plasmodium falciparumPiqûre de l'anophèle femelleForte fièvre, vomissements, céphalées, grelottements, courbatures, douleurs musculaires, manque d'appétit
OnchocercoseOnchocerca volvulusPi qûre de la simulieLésions et dépigmentation de la peau ; troubles de la vue
Les maladies transmises par la piqûre d'êtres vivants infectés sont des maladies à vecteurs.

III. Cycles de développement des agents pathogènes

1. Cycle de la bilharziose (Homme + mollusques)

Chez l'Homme : cercaires pénètrent la peau → schistosomes migrent dans les vaisseaux de l'intestin/vessie → accouplement → œufs rejetés dans selles/urines
Dans l'eau : éclosion des œufs → miracidiums → pénètrent les mollusques (hôtes intermédiaires : bulin, planorbe, oncomelania) → cercaires libérées → le cycle recommence

2. Cycle du paludisme (Homme + anophèle)

Chez le moustique : piqûre d'un malade → plasmodiums → gamètes → union → œuf → nouveaux plasmodiums migrent dans les glandes salivaires
Chez l'Homme : piqûre → plasmodium → cellules du foie (hématozoaires) → infestation et éclatement des globules rouges → infection d'autres globules
Conclusion générale : les maladies liées à l'eau se transmettent soit par contact avec des produits souillés (péril fécal), soit par l'intermédiaire de vecteurs. Chacune s'identifie par des symptômes caractéristiques.
⚠️ Pièges classiques :
  • Agent pathogène ≠ vecteur : le plasmodium est l'agent, l'anophèle le vecteur.
  • Bilharziose : péril fécal MAIS transmise par pénétration de la peau (pas seulement consommation).
  • Dracunculose ↔ filaire de Médine ; bilharziose ↔ bilharzie ; amibiase ↔ amibe ; paludisme ↔ plasmodium.
  • Hôtes intermédiaires de la bilharziose = les mollusques.
