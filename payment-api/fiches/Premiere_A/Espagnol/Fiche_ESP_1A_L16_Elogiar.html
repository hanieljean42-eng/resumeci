Première A Espagnol L16 — Elogiar (Faire des éloges)

I. L'acte de parole : rendre hommage

Vocabulaire : elogiar = alabar · un homenaje (cérémonie d'hommage) · el testigo (témoin).
Texte-support : Dadié : el padre de las letras africanas — hommage à Bernard Binlin Dadié : écrivain prolífico, activiste de l'indépendance, ancien ministre, ex-viceprésident du Conseil exécutif de l'UNESCO ; hommage national en 2016.
Verbes d'éloge : rendir homenaje · glorificar · engrandecer · alabar.

II. Grammaire : les deux types d'adjectifs

TypeDéfinitionExemple
Epítetoadjectif avant le nom, embellit le message en soulignant une qualitéUn caluroso homenaje a Dadié.
Atributoadjectif après un verbe copulatif (ser, estar, parecer)El homenaje a Dadié es caluroso.

III. Expressions pour rendre hommage

  • ser socio de la justicia · ser simpático · ser atento a las preocupaciones de los demás ;
  • tener una generosidad legendaria · ser un hombre bondadoso · ser una persona excepcional ;
  • merecer alabanzas · merecer un caluroso homenaje.
⚠️ Points d'attention :
  • L'epíteto précède le nom pour mettre en valeur (« un caluroso homenaje ») ;
  • L'atributo suit ser/estar (« el homenaje es caluroso ») ;
  • En español, la plupart des adjectifs se placent après le nom — l'antéposition a valeur stylistique ;
  • Un bon hommage : présenter la personne → raconter ses actions → utiliser des adjectifs laudatifs.
