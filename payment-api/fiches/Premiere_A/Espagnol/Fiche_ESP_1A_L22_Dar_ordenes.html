Première A Espagnol L22 — Dar órdenes

I. L'acte de parole : donner un ordre

Vocabulaire : una vida sana/saludable · una dieta (régime : « una dieta sin sal ») · vigilar = controlar.
Texte-support : Llevar una vida saludable — recommandations pour une vie saine : dieta equilibrada (frutas, verduras, granos enteros, carnes magras), beber dos litros de agua al día, evitar el tabaco, mantener un peso equilibrado.

II. Les formes de l'ordre

FormeExemple
deber + infinitivoDebes ser honesto en la vida. · Debes mantener un peso equilibrado.
imperativoPresta atención a tu alimentación. · Lleva una vida activa.
Impératif — formes : tú : sé, escucha, obedece · vosotros : escuchad, obedeced, consumid · nosotros : hagamos, protejámonos.

III. Transformations types

  • « Es importante llevar una vida sana » → « Debes llevar / Lleva una vida saludable » ;
  • « Hace falta protegernos » → « Protejámonos / Debemos protegernos » ;
  • « Es necesario cuidar tu alimentación » → « Cuida / Debes cuidar tu alimentación ».
⚠️ Points d'attention :
  • Impératif vosotros = radical + -d (escuchad, obedeced, consumid) ;
  • Impératif affirmatif pronominal : -d tombe avant « os » (protejámosnos → protejámonos) ;
  • deber + inf. = ordre attenué (recommandation) ; impératif = ordre direct.
