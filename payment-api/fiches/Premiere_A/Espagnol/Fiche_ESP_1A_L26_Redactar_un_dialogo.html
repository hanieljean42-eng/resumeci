Première A Espagnol L26 — Redactar un diálogo

I. Les éléments du dialogue

Vocabulaire : un diálogo · la ubicación = situación spatiale · un negocio.
Texte-support : El teléfono — Don Rodolfo dialogue avec sa femme sur l'ubicación idéale du nouveau téléphone fixe : ni dans son gabinete ni dans la biblioteca → installé dans une habitación.
Composants : los hablantes/interlocutores · la raya/guión · el estilo directo.

II. La technique du dialogue

  • La raya (—) ou le guión indique qui parle et chaque changement d'interlocuteur ;
  • El estilo directo reproduit mot pour mot les paroles ;
  • El estilo indirecto rapporte les paroles (transformations de temps, pronoms, marqueurs temporels).
Exemple :
— Hola vecino. ¿Qué tal estás?
— Hola Andrés. Estoy muy bien. Gracias.

⚠️ Points d'attention :
  • Indirect → direct : restaurer personnes, temps et déictiques (aquí, hoy, mañana) ;
  • Chaque nouvelle réplique = nouvelle raya + retour à la ligne ;
  • Les verbes de parole (decir, preguntar, contestar) encadrent le discours rapporté.
