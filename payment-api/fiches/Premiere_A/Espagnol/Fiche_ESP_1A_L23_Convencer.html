Première A Espagnol L23 — Convencer

I. L'acte de parole : convaincre

Vocabulaire : una pandemia · una contaminación = un contagio · un aislamiento (isolement/quarantena).
Texte-support : España, la pandemia del coronavirus — convaincre les gens du danger du coronavirus : observer las medidas barreras ; si fiebre/cansancio/dificultad respiratoria → llamar urgencias, test, aislarse 14 días.

II. Les expressions pour convaincre

StructureModeExemple
creo que / estoy convencido(a) de que / tengo la convicción de que+ indicativoEstoy convencido de que sigue circulando la viruela.
es bueno / importante / malo / urgente / una buena idea / interesante que+ subjuntivoEs bueno que observemos las medidas barreras. · Es urgente que llames a urgencias.
expressions coloquiales—¡anímate! · ¡venga! · ¡vamos! · no te lo pienses · convéncete
Transformations types :
  • « mantén distancia » → « Es bueno que mantengas un metro de distancia » ;
  • « sé distinguir el bien » → « Estoy convencido de que sabes distinguir » (indicatif car affirmation) ;
  • « no seas flojo » → « ¡Venga! El esfuerzo siempre recompensa. »
⚠️ Points d'attention :
  • Conviction personnelle → indicatif ; jugement/nécessité → subjonctif ;
  • Familles de mots : persuadir→persuasión · convencer→convicción · contagiar→contagio · prevenir→prevención · recomendar→recomendación ;
  • « es menester que + subj. » = « il faut que ».
