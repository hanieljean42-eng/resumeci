II. Grammaire : l'expression de l'obligation personnelle

StructureExemple
deber + infinitivoEl gobierno deberá estudiar el papel de los impuestos verdes.
tener que + infinitivoEl gobierno tiene que abordar una reforma completa.
ser preciso / menester / necesario / obligatorio · hacer falta + que + subjuntivoHace falta que el gobierno aborde las reformas.
Autre forme : haber de + inf. — « Sánchez ha de enfrentarse con el desafío energético. »
⚠️ Points d'attention :
  • Après hace falta que / es necesario que → subjonctif (aborde, cuiden, enseñen) ;
  • deber + inf. = obligation personnelle ; deber de + inf. = probabilité ;
  • tener que + inf. est la forme la plus courante à l'oral.
