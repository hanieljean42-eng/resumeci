Première A Espagnol L19 — Dar consignas

I. L'acte de parole : donner une consigne

Vocabulaire : dar consignas (donner des instructions avant une tâche) · cuidar de (prendre soin de) · el medio ambiente.
Texte-support : Acciones para cuidar el medio ambiente — consignes simples et pratiques pour protéger l'environnement : apagar las luces, cerrar los grifos, plantar árboles, usar el transporte público, aprovechar la luz natural.

II. Les formes de la consigne

FormeExemple
Imperativo (affirmatif ou négatif)Evita dejar los aparatos enchufados. · No tires las basuras en el patio.
Obligación impersonal : hay que + inf.Hay que salvar a los animales.
Obligación personal : tener que + inf.Tenemos que preservar el medio ambiente.
Imperativo — formes clés : tú : evita / no evites · usted : evite / no evite · vosotros : evitad / no evitéis · nosotros : evitemos / no evitemos.

III. Exemples corrigés

  • No juegues tú aquí la pelota (imp. nég. = subjonctif) ;
  • No se meta usted en mis asuntos ;
  • Es probable que mañana nosotros tengamos tiempo ;
  • Niños, no os tiréis al suelo ;
  • Callaos vosotros cuando habla el profesor (imp. affirmatif : -d → -os pour les pronominaux : callar + os = callaos).
⚠️ Points d'attention :
  • L'impératif négatif = présent du subjonctif (no juegues, no se meta) ;
  • Verbes pronominaux à l'impératif affirmatif vosotros : -d tombe (callad → callaos) ;
  • hay que = consigne générale ; tenéis que = consigne ciblée ;
  • Les pronoms se placent après l'impératif affirmatif (lávate), avant au négatif (no te laves).
