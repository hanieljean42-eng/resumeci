Première A Espagnol L24 — Comentar una imagen o un texto

I. L'acte de parole : commenter

Vocabulaire : una imagen (foto/dibujo) · la piña (ananas) · una viñeta (une image d'une série).
Texte-support : Piña de Costa de Marfil — photo d'une plantation d'ananas ivoirienne.
Synonymes de comentar : explicar · desarrollar · ilustrar · interpretar · glosar.

II. La méthode en 4 étapes

  1. Describir — ce qu'on voit (éléments concrets, couleurs, personnages, lieux) ;
  2. Analizar — les actions, les relations entre les éléments ;
  3. Interpretar — le sens par rapport au contexte/intention de l'auteur ;
  4. Transposición — le lien avec sa propre réalité/expérience.

III. Exemple modèle (plantation de piñas)

  1. Description : « La imagen es una plantación de piñas. »
  2. Analyse : « Las piñas son de color amarillo, es decir que están maduras. »
  3. Interprétation : « La piña tiene muchas propiedades, es buena para la salud. »
  4. Transposition : « En mi pueblo, en Bonoua, se producen muchas piñas. »
⚠️ Points d'attention :
  • Toujours commencer par « La imagen / El documento muestra/es… » ;
  • Ne pas seulement décrire : les 4 étapes sont obligatoires à l'oral du bac ;
  • La transposition = ramener à son pays / son vécu (« En Costa de Marfil, nosotros también… ») ;
  • Utile : « es decir que… » pour analyser ce qu'on voit.
