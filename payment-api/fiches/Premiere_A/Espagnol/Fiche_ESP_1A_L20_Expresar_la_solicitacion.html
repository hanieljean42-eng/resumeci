Première A Espagnol L20 — Expresar la solicitación

I. L'acte de parole : solliciter

Vocabulaire : solicitar (demander de l'aide) · una virtud = un valor (« el respeto es una virtud ») · fortalecer (renforcer : « leer mucho fortalece la memoria »).
Texte-support : Los padres, debemos educar en valores — un spécialiste de l'éducation solicita la participation des parents pour inculquer des valeurs aux enfants : diferenciar lo bueno de lo malo, respeto, honestidad.

II. Les formes de la sollicitation

FormeExemple
deber + infinitivoLos padres deben animar a sus niños a trabajar.
haber de + infinitivoLos padres han de fortalecer el desarrollo moral de los niños.
imperativo¡Padres! Animad a vuestros niños a trabajar.
verbos : solicitar, rogar, pedir, necesitarSolicito su ayuda para el concurso.
Transformations types :
  • « Aprender las lecciones es una necesidad » → « Vosotros debéis aprender las lecciones » ;
  • « Es una obligación ser padre modelo » → « Usted ha de ser un padre modelo » ;
  • « Tiene la obligación de educar » → « Padre, tienes la obligación de educar a tu progenitura ».
⚠️ Points d'attention :
  • deber + inf. = obligation morale/conseil ; haber de + inf. = nécessité formelle ;
  • solicitar / rogar / pedir peuvent prendre que + subjonctif : « le solicito que nos facilite el viaje » ;
  • En lettre formelle : « Le escribo para solicitarle… / le ruego que… ».
