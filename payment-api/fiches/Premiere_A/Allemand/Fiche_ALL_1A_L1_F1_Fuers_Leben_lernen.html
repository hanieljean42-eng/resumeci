Première A Allemand Leçon 1 — Fürs Leben lernen (Fiche 1)

I. Thème : das deutsche Schulsystem

Vocabulaire clé :
  • Schultypen : die Grundschule (primaire), das Gymnasium, die Realschule, die Hauptschule, die Berufsschule ;
  • Schulabschlüsse : das Abitur, der Realschulabschluss, der Hauptschulabschluss ;
  • Ausbildungsmöglichkeiten : die Universität, die Berufsausbildung, die Fachhochschule ;
  • Points de vue : « nach Klasse 4 wird sortiert » — certains trouvent le tri zu früh (man weiß noch nicht, was man werden will), d'autres le jugent positif (schnell mit der Schule fertig sein).

II. Grammaire : Konjunktiv II au passé

Formation : radical du prétérit de haben/sein au Konj. II (hätte / wäre) + Partizip II.
IndicatifKonjunktiv II passé
Ich hatte frei. / Ich habe frei gehabt.Ich hätte frei gehabt.
Ich blieb im Bett. / Ich bin im Bett geblieben.Ich wäre im Bett geblieben.
L'auxiliaire suit le verbe : haben pour la plupart des verbes, sein pour les verbes de mouvement/changement.
Avec les verbes de modalité : hätte + infinitif + infinitif du modal (double infinitif).
IndicatifKonjunktiv II passé
Ich konnte im Bett bleiben. / Ich habe im Bett bleiben können.Ich hätte im Bett bleiben können.
Exemple : « Vielleicht hätte er weniger von Moon fordern können. »

III. Wortbildung : noms en -schaft

Règle : les noms en -schaft sont toujours féminins (die). Ils dérivent de :
  • Nom + schaft : der Partner → die Partnerschaft ; der Freund → die Freundschaft ;
  • Adjectif + schaft : schwanger → die Schwangerschaft ; eigen → die Eigenschaft ;
  • Verbe + schaft : wandern → die Wanderschaft ; wissen → die Wissenschaft.
⚠️ Points d'attention :
  • Konj. II passé : choisir hätte ou wäre selon l'auxiliaire du parfait (haben/sein) ;
  • Avec un modal : deux infinitifs en fin de phrase (bleiben können) ;
  • Tout nom en -schaft prend die, quel que soit le genre du mot de base ;
  • Sens du Konj. II passé : action irréelle / regret (« j'aurais dû/pu… »).
