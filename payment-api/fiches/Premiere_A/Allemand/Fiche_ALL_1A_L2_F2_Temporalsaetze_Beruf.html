Première A Allemand Leçon 2 — (K)ein bisschen erwachsen (Fiche 2)

I. Thème : Mein Wunschberuf (le métier de mes rêves)

Objectif : parler de son futur métier, exprimer la surprise, donner des raisons et mener un entretien.
Vocabulaire : das Praktikum (stage), der Praktikumsbericht, das Berufspraktikum, die Ausbildung, die Arbeitsstelle, die Prüfung, sich bewerben, einen Beruf ausüben, Geld verdienen, die Firma.
Ex. : « Wenn man Bäcker werden will, braucht man Realschulabschluss oder Hauptschulabschluss. »

II. Grammaire : les subordonnées temporelles (Temporalsätze)

1. wenn / als (« quand »)
ConjonctionEmploiExemple
wennaction répétée (présent/passé) ou futureWenn Schüler in der 9. Klasse sind, machen sie ein Praktikum. · Wenn die Schüler Probleme hatten, informierten sie den Lehrer.
alsaction unique dans le passéAls ein Schüler krank war, konnte er zwei Tage nicht in die Firma gehen.
2. während / bevor / nachdem
ConjonctionSensExemple
währendpendant — actions simultanéesWährend die Schüler das Praktikum machen, gelten gesetzliche Regeln.
bevoravant (que) — antérioritéBevor man sich anmeldet, sucht man eine Firma aus.
nachdemaprès (que) — postérioritéNachdem die Schüler das Praktikum beendet haben, schreiben sie einen Bericht.
Autres : bis (jusqu'à ce que), seit/seitdem (depuis que).

III. Équivalents avec prépositions

SubordonnéePréposition + casExemple
während + phrasewährend + GénitifWährend des Praktikums gelten gesetzliche Regeln.
bevor + phrasevor + DatifVor der Anmeldung sucht man eine Firma aus.
nachdem + phrasenach + DatifNach dem Praktikum schreiben sie einen Bericht.
⚠️ Points d'attention :
  • als = une seule fois au passé ; wenn = répétition ou futur — le grand classique du bac ;
  • Verbe conjugé en fin de subordonnée ;
  • nachdem impose souvent un changement de temps (PC → présent après le parfait : beendet haben → schreiben) ;
  • Ne pas confondre während conjonction (fin de phrase : machen) et während + Genitiv (nom).
