Première A SVT Transmission d'un caractère lié aux autosomes

I. Vocabulaire génétique

  • Gène : portion d'ADN sur un chromosome, unité de l'hérédité qui contrôle un caractère ;
  • Allèle : une des formes possibles d'un gène ; locus = son emplacement sur le chromosome ;
  • Génotype : ensemble des gènes d'un individu ; phénotype : caractères observables déterminés par le génotype ;
  • Homozygote (allèles identiques) / hétérozygote (allèles différents : l'un dominant s'exprime, l'autre récessif est masqué) ;
  • Codominance / semi-dominance : les deux allèles s'expriment (ex. drépanocytose : génotype A//S → phénotype [AS]).
Maladies héréditaires : trisomie 21, mucoviscidose, Huntington, myopathie de Duchenne, drépanocytose, hémophilie, thalassémie, X fragile, albinisme. (Paludisme, typhoïde, COVID = pas héréditaires.)

II. Méthode d'analyse d'un pédigrée (arbre généalogique)

  1. Dominant ou récessif ? Parents d'apparence saine avec enfant malade → ils portent l'allèle masqué (hétérozygotes) → allèle récessif ;
  2. Choix des symboles : majuscule = dominant, minuscule = récessif (A/a) ;
  3. Autosomal ou lié au sexe ? Poser l'hypothèse « gène porté par X » → calculer les phénotypes attendus par échiquier de croisement → comparer au pédigrée :
Cas test : couple [A] × [A] hétérozygotes, hypothèse « gène sur X » → seuls les garçons pourraient être malades (Xᵃ/Y). Or la fille malade existe → contradiction → le gène est porté par un autosome.

III. Cas de l'albinisme (récessif autosomal)

  • Maladie absente dans certaines générations (saute des générations) ;
  • Parents sains II1 × II2 (A//a × A//a) → enfants : 3/4 [A], 1/4 [a] albinos ;
  • Affecte les deux sexes indifféremment ;
  • Conclusion : allèle récessif, gène autosomal.

IV. Cas de la drépanocytose (codominance apparente)

  • A//A → sain [A] ; S//S → malade grave [S] ; A//S → [AS] apparemment sain mais transmetteur (deux hémoglobines A et S) ;
  • Transmission « mode récessif » apparent : test de liaison à X par hypothèse + échiquier → gène autosomal ;
  • Les hétérozygotes [AS] sont des porteurs sains — dépistage important avant mariage.
⚠️ Pièges fréquents :
  • Maladie qui « saute » une génération = récessif ; présente à chaque génération = souvent dominant ;
  • Test de liaison au sexe : raisonner par l'absurde — supposer X, montrer la contradiction avec le pédigrée ;
  • Affectant les deux sexes ≠ preuve d'autosomalité à elle seule : c'est la fille malade de père sain qui écarte X ;
  • [AS] est un phénotype sain-transmetteur, ni malade ni totalement normal génétiquement ;
  • Un individu diploïde ne porte que 2 allèles d'un gène, même s'il en existe plus dans la population (ex. ABO).
