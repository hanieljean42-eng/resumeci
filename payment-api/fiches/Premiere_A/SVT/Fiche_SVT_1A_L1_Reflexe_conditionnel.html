Première A SVT Le réflexe conditionnel

I. Définitions

Réflexe : mouvement involontaire, inconscient, brusque et automatique provoqué par une stimulation appropriée.
Réflexe inné : présent dès la naissance (voies nerveuses préexistantes) — ex. salivation à la vue de la viande.
Réflexe conditionnel (acquis) : résulte d'un apprentissage, varie d'un individu à l'autre — ex. salivation au son du métronome.

II. L'expérience de Pavlov (apprentissage)

  • Viande seule → salivation (stimulus absolu/inconditionnel → réflexe inné) ;
  • Son seul → pas de salivation (stimulus neutre) ;
  • Son + viande répétés → association : le son devient stimulus conditionnel → salivation seule au son (réflexe conditionnel) ;
  • Son seul répété sans viande → disparition progressive : extinction du réflexe.

III. Le mécanisme nerveux

Circuit inné : récepteur (langue) → fibre afférente (sensitive) → centre bulbaire (bulbe rachidien) → fibre efférente (motrice) → effecteur (glande salivaire).
Circuit conditionnel : nécessite le cerveau — l'apprentissage établit au cortex une nouvelle liaison entre l'aire auditive et l'aire gustative (neurone d'association).
Conditions d'obtention et de maintien :
  • Le stimulus neutre doit être associé au stimulus absolu ;
  • Le stimulus neutre précède le stimulus absolu ;
  • Répétitions multiples dans le même sens ;
  • Le réflexe acquis doit être entretenu sinon → extinction.

IV. Les avantages des réflexes conditionnels

  • Adaptation de l'individu à son milieu ;
  • Automatismes : marche, écriture, lecture, natation, conduite ;
  • Éducation : langage, signaux sociaux, communication ;
  • Dressage des animaux : chiens de police/d'aveugles/de chasse, détection de drogues.
⚠️ Pièges fréquents :
  • Stimulus absolu (viande) ≠ stimulus neutre (son, avant apprentissage) ≠ stimulus conditionnel (son, après apprentissage) ;
  • L'ordre compte : le neutre avant l'absolu, pas l'inverse ;
  • Le réflexe inné utilise le bulbe rachidien ; le conditionnel exige le cortex cérébral ;
  • Un réflexe acquis non entretenu s'éteint — il n'est pas définitif ;
  • Afférent = sensitif (vers le centre) ; efférent = moteur (vers l'effecteur).
