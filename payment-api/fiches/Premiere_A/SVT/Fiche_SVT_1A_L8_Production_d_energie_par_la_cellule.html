Première A SVT La production d'énergie par la cellule

I. Les deux voies de production d'énergie

Expérience des levures : même quantité de levures + glucose :
• Milieu oxygéné : fort développement, 2815 kJ/g glucose → voie aérobie = respiration (dégradation totale) ;
• Milieu non oxygéné : faible développement, 167 kJ/g + alcool + CO₂ → voie anaérobie = fermentation (dégradation partielle).
Sources d'énergie (valeurs énergétiques) :
NutrimentProduit de dégradationÉnergie / g
GlucidesGlucose17 kJ (4 kcal)
ProtidesAcides aminés17 kJ (4 kcal)
LipidesAcides gras + glycérol38 kJ (9 kcal)
L'énergie libérée est stockée sous forme d'ATP (adénosine triphosphate).

II. Les zones de production

• Cytoplasme (hyaloplasme) : le glucose → acide pyruvique (glycolyse) ;
• Mitochondrie : l'acide pyruvique, les acides gras et les acides aminés y sont dégradés.
Fermentation : hyaloplasme seul ; respiration : hyaloplasme puis mitochondrie.

III. Le mécanisme de la respiration

  1. Glycolyse (hyaloplasme) : glucose → 2 acide pyruvique + 2 ATP ;
  2. Cycle de Krebs (matrice mitochondriale) : décarboxylations oxydatives de l'acide pyruvique (via l'acétylcoenzyme A) → CO₂ + composés réduits + ATP ;
  3. Phosphorylation oxydative (crêtes de la membrane interne) : les composés réduits sont oxydés par le dioxygène (accepteur final des électrons) → production massive d'ATP.
C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 38 ATP
2 ATP de la glycolyse + 36 ATP des oxydations respiratoires.

IV. La fermentation alcoolique

En absence d'O₂, l'acide pyruvique se dégrade en éthanol :
C₆H₁₂O₆ → 2 C₂H₅OH + 2 CO₂ + 2 ATP
Réaction incomplète : seulement 2 ATP par glucose (rendement faible — d'où le moindre développement des levures en anaérobie).
Comparaison :

OxygèneNécessaire (aérobie)Absente (anaérobie)
LieuHyaloplasme + mitochondrieHyaloplasme seul

⚠️ Pièges fréquents :
  • La glycolyse est commune aux deux voies — c'est le devenir de l'acide pyruvique qui diffère ;
  • Le CO₂ de la respiration vient du cycle de Krebs, pas de la glycolyse ;
  • L'O₂ intervient seulement à la phosphorylation oxydative (accepteur final), pas au cycle de Krebs directement ;
  • 38 ATP total ≠ 38 dans la mitochondrie : la glycolyse n'en produit que 2 ;
  • Les lipides sont la source la plus énergétique (38 kJ/g), pas les glucides.
