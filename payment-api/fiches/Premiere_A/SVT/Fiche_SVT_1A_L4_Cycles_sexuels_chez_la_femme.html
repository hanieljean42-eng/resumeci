Première A SVT Les cycles sexuels chez la femme

I. Les trois cycles synchronisés (cycle de 28 jours)

Phase folliculaire (J1–J14)Phase lutéinique (J15–J28)
Cycle ovarienCroissance des follicules ; 1 seul arrive à maturité → ovulation au J14 (rupture du follicule mûr, expulsion de l'ovocyte II)Follicule rompu → corps jaune ; sans fécondation → dégénère en corps blanc ; avec fécondation → persiste
Cycle utérinMenstrues (desquamation, J1–J5) puis épaississement progressif de l'endomètre, glandes en doigts de gantEndomètre maximal, vaisseaux spiralés, glandes tortueuses → dentelle utérine ; sans fécondation → desquamation au J28
Cycle hormonalPic d'œstradiol J12 ; pics FSH J10–J13 et LH J13 (LH > FSH)2ᵉ pic d'œstradiol + pic de progestérone ~J21 ; FSH et LH faibles

II. Les hormones en jeu

  • GnRH (hypothalamus) → stimule l'antéhypophyse ;
  • FSH (antéhypophyse) → croissance et maturation des follicules ;
  • LH (antéhypophyse) → son pic déclenche l'ovulation + transformation en corps jaune ;
  • Œstradiol (ovaires/follicules) → épaississement de l'endomètre, glandes ;
  • Progestérone (corps jaune) → dentelle utérine (avec l'œstradiol).

III. Le mécanisme de régulation

Axe hypothalamo-hypophyso-ovarien :
Hypothalamus —(GnRH)→ Antéhypophyse —(FSH + LH)→ Ovaires —(œstradiol + progestérone)→ Utérus.
Preuves expérimentales : ablation de l'antéhypophyse → atrophie ovarienne (reprise après greffe) ; ablation des ovaires → arrêt du cycle utérin (reprise après injection d'extraits) → contrôle par voie sanguine.
Rétrocontrôle (feed-back) des ovaires sur le complexe hypothalamo-hypophysaire :
  • Œstradiol + progestérone en forte quantité → baisse de FSH/LH = feed-back négatif ;
  • Œstradiol seul en forte quantité → augmentation de FSH/LH = feed-back positif (provoque le pic ovulatoire).

IV. Anomalies de reproduction

Insuffisance hormonale (ex. Madame E) :
• Pas de pic de FSH → pas de maturation folliculaire ;
• Pas de pic de LH → pas d'ovulation ;
• Œstradiol faible → endomètre insuffisant ;
• Pas de pic de progestérone → pas de dentelle utérine → pas de nidation.
→ Conséquences : stérilité, avortements spontanés.
⚠️ Pièges fréquents :
  • FSH et LH = hormones hypophysaires ; œstradiol et progestérone = ovariennes ;
  • C'est le pic de LH (pas FSH) qui déclenche l'ovulation ;
  • La progestérone est faible en phase folliculaire, élevée en phase lutéinique ;
  • Menstrues = desquamation de l'endomètre (début du cycle), pas une maladie ;
  • La GnRH commande la FSH/LH — pas l'inverse ;
  • Sans fécondation → corps jaune dégénère (corps blanc) ; avec fécondation → il persiste.
