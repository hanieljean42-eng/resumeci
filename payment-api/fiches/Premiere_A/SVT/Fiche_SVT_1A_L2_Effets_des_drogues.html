Première A SVT Les effets des drogues sur le comportement

I. Définitions et classification

Drogue : substance chimique ou naturelle dont la consommation modifie les fonctions de l'organisme.
Toxicomanie : intoxication chronique entraînant dépendance (physique et/ou psychique) et accoutumance.
FamilleExemplesEffets
Psychostimulants (excitants)Cocaïne, crack, amphétamines, caféineRecul de la fatigue, bien-être, hyperactivité motrice/intellectuelle, forte dépendance physique
Psycho-dépresseurs (inhibiteurs)Opium, morphine, héroïne, barbituriques, alcool, solvantsTorpeur, quiétude, baisse d'activité, forte dépendance psychique
Perturbateurs (effets mixtes)Cannabis, LSD, mescalineEuphorie puis confusion mentale, dépression, sommeil avec hallucinations

II. Les organes cibles (encéphale)

  • Cortex cérébral (réflexion, mémoire, langage) → sédatifs ;
  • Système limbique (émotions, plaisir, récompense) → tranquillisants (opiacées) ;
  • Mésencéphale → antidépresseurs ;
  • Thalamus et substance réticulée → sédatifs, tranquillisants, antidépresseurs, stimulants ;
  • Cervelet (équilibre, coordination motrice) → cannabis, alcool → démarche titubante.
Le message né dans ces zones est véhiculé par les neurones via la moelle épinière jusqu'aux effecteurs. Les zones de contact entre neurones = synapses.

III. Le mécanisme d'action : la synapse

Drogues excitatrices — deux mécanismes :
  • Libération massive de neurotransmetteurs dans la fente synaptique (ex. amphétamine → dopamine, noradrénaline) → excitation intense ;
  • Inhibition de la recapture par le neurone pré-synaptique (ex. cocaïne) → forte concentration durable → membrane post-synaptique continuellement excitée.
Drogues inhibitrices — deux mécanismes :
  • Blocage de la libération du neuromédiateur au niveau pré-synaptique (ex. opiacées bloquent la substance P → suppression de la douleur = effet analgésique) ;
  • Occupation des récepteurs post-synaptiques empêchant la fixation du neuromédiateur → non-transmission de l'influx → état dépressif, voire dégénérescence des neurones (perte de mémoire, folie).
⚠️ Pièges fréquents :
  • Cocaïne = empêche la recapture ; amphétamine = libère les neuromédiateurs ;
  • Effet analgésique = blocage pré-synaptique, pas récepteurs post-synaptiques ;
  • L'alcool est un psycho-dépresseur, pas un excitant ;
  • Dépendance physique (excitants) vs dépendance psychique (dépresseurs) — distinction fréquente aux examens ;
  • Caféine = drogue excitante (même si légale) ; lait, thé, jus = pas des drogues.
