Première A Mathématiques Généralités sur les fonctions

I. Fonctions paires et impaires

f paire ⟺ pour tout x ∈ Df : −x ∈ Df et f(−x) = f(x).
⟺ l'axe des ordonnées (OJ) est axe de symétrie de (Cf).
f impaire ⟺ pour tout x ∈ Df : −x ∈ Df et f(−x) = −f(x).
⟺ l'origine O est centre de symétrie de (Cf).
Méthode d'étude de la parité :
  1. Déterminer Df et vérifier qu'il est symétrique par rapport à 0 (si −x ∉ Df, f n'est ni paire ni impaire) ;
  2. Calculer f(−x) et comparer à f(x) et −f(x) ;
  3. Conclure : paire, impaire, ou ni paire ni impaire (cas fréquent !).
Contre-exemple suffit : si f(1) ≠ f(−1) alors f non paire ; si f(1) ≠ −f(−1) alors f non impaire.

II. Axe et centre de symétrie quelconques

Axe de symétrie (Δ) : x = a
(Δ) axe de symétrie de (Cf) ⟺ pour tout h avec a+h ∈ Df : a−h ∈ Df et
f(a + h) = f(a − h)
Cas particulier a = 0 → fonction paire.
Centre de symétrie Ω(a ; b)
Ω centre de symétrie de (Cf) ⟺ pour tout h avec a+h ∈ Df : a−h ∈ Df et
(f(a+h) + f(a−h)) / 2 = b
Cas particulier Ω = O(0 ; 0) → fonction impaire.
Ex. : f(x) = 3x/(x−1) + … → on vérifie [f(1+h) + f(1−h)]/2 = 3 donc A(1 ; 3) centre de symétrie.

III. Applications graphiques

  • Courbe incomplète + fonction paire → compléter par symétrie par rapport à (OJ) ;
  • Courbe incomplète + fonction impaire → compléter par symétrie par rapport à O ;
  • Lecture graphique : axe de symétrie ≠ (OJ) ou centre ≠ O → la fonction est ni paire ni impaire même si la courbe a un élément de symétrie.
⚠️ Pièges fréquents :
  • Une fonction peut être ni paire ni impaire — ne pas forcer une des deux réponses ;
  • La parité exige que Df soit symétrique par rapport à 0 : vérifier Df avant de calculer ;
  • (x−1)² n'est ni paire ni impaire : son axe de symétrie est x = 1, pas x = 0 ;
  • Symétrie par rapport à (OJ) ≠ symétrie par rapport à un axe vertical quelconque ;
  • Pour un centre Ω(a ; b) : c'est la demi-somme [f(a+h)+f(a−h)]/2 qui vaut b, pas f(a+h) seul.
