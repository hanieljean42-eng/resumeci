Première A Mathématiques Statistiques (séries en classes)

I. Classes : amplitude, centre, densité

  • Amplitude de [x₁ ; x₂[ = x₂ − x₁ ;
  • Centre c₁ = (x₁ + x₂)/2 ;
  • Densité = effectif de la classe / amplitude de la classe.

II. Caractéristiques de position

Classe modale : classe de densité maximale (si amplitudes égales → effectif maximal).
Moyenne :
x̄ = (1/N)(n₁c₁ + n₂c₂ + … + npcp) = f₁c₁ + f₂c₂ + … + fpcp
Médiane : nombre séparant la série ordonnée en deux moitiés (≥ 50 % des valeurs de part et d'autre).
• Graphiquement : abscisse du point de la courbe cumulative d'ordonnée N/2 (ou 0,5 en fréquences) ;
• Par interpolation linéaire : si N/2 ∈ classe [a ; b[ avec ECC de A à B :
(Me − a)/(b − a) = (N/2 − ECC_a) / (ECC_b − ECC_a)
Quartiles : Q₁ (25 % des valeurs en dessous), Q₂ = médiane (50 %), Q₃ (75 %) — même méthode d'interpolation avec N×25/100 et N×75/100.

III. Représentations graphiques

  • Histogramme : rectangles juxtaposés ; aire ∝ effectif ; largeur ∝ amplitude ; hauteur ∝ densité ;
  • Polygone des effectifs/fréquences : on joint les milieux des sommets des rectangles ;
  • Courbe cumulative : fonction affine par morceaux joignant les effectifs (ou fréquences) cumulés croissants aux bornes des classes ; sert à lire Me, Q₁, Q₃.

IV. Caractéristiques de dispersion

Variance :
V = (1/N) Σ nᵢ(cᵢ − x̄)² = (1/N) Σ nᵢcᵢ² − x̄²
Écart-type : σ = √V — mesure la dispersion autour de la moyenne.
⚠️ Pièges fréquents :
  • La classe modale est déterminée par la densité, pas par l'effectif — sauf si les amplitudes sont égales ;
  • La moyenne utilise les centres des classes, pas les bornes ;
  • Médiane ≠ moyenne : la médiane coupe l'effectif en deux, la moyenne pondère par les centres ;
  • Dans l'interpolation, repérer d'abord la classe contenant le rang (ex. N/2 = 52 entre ECC 40 et 72 → classe [8 ; 13[) ;
  • Histogramme : c'est l'aire qui est proportionnelle à l'effectif, pas la hauteur (hauteur = densité) ;
  • Écart-type = racine de la variance, pas la variance elle-même.
