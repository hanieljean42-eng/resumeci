I. La ponctuation : signes syntaxiques

La ponctuation : ensemble de signes qui mettent en valeur les divisions d'un texte — séparer les idées, préciser leur substance ; à l'oral, ils marquent pauses et changements de registre.
SigneEmploi
. (point)Isole les phrases (pause forte) ; abréviations et sigles (C.-à-d., cf.). ⚠️ Jamais après un titre, nom propre ou en-tête de lettre.
, (virgule)Pause faible ; isole les groupes mobiles, sépare les termes d'énumération, lève les ambiguïtés (« Le poète chante, la nuit. »).
; (point-virgule)Sépare deux énoncés liés par une résolution logique (pause moyenne).
? !Phrase interrogative / exclamative (sentiment, interjection). Majuscule après, sauf série de questions complémentaires.
… (suspension)Énoncé interrompu ou laissé en suspens. ⚠️ Pas de points après etc. (pléonasme).
: (deux-points)Annonce un terme ou une énumération ; rapport de cause/conséquence ; introduit le discours direct avec guillemets.
( ) — [ ]Parenthèses et tirets : information non indispensable ; crochets : indication à l'intérieur de parenthèses.
« » (guillemets)Paroles citées, citation (emprunt), expression familière ou technique.
Paragraphe / alinéaCellule de base du raisonnement écrit : 5 à 25 lignes, un aspect = un paragraphe.

II. L'accord du participe passé

Le participe passé exprime un fait passé ; il peut aussi servir d'adjectif (et s'accorde alors avec son nom : « des fautes avouées »).
AuxiliaireRègleExemples
AVOIRS'accorde avec le COD placé avant ; jamais avec le sujet ni le COI ; invariable si le COD subit l'action sans la faire, si « l' » = pronom neutre (« cela ») ou en tournure impersonnelle (« les deux jours qu'il a plu »).« les outils qu'il m'a prêtés » — « les paroles que j'ai entendu prononcer »
ÊTRES'accorde avec le sujet. Verbes pronominaux : accord avec le sujet si « se » = COD ou verbe essentiellement pronominal (s'évanouir, se moquer…) ; accord avec le COD si placé avant.« Akissi est arrivée » — « elle s'est blessée » — « la bonne épouse qu'il s'est trouvée »
Cas figésInvariable devant le nom (« vu la situation », « ci-joint notre facture ») ; accord quand placé après (« notre facture ci-jointe »). Locutions : « lu et approuvé », « vu ».« Veuillez trouver ci-joint… »

III. La sémantique : le sens des mots

La sémantique : étude du sens des mots dans le contexte — partie de la linguistique au service de la compréhension des textes.
  • Notions fondamentales : synonymes (sens proches — distingués par intensité et expressivité : sale/crasseux/dégoûtant) ; antonymes (sens opposés) ; homonymes (même son, orthographe et sens différents : maire/mère/mer) ; paronymes (orthographe/sens proches : adapter/adopter, compréhensif/compréhensible).
  • Construction du sens : champ lexical = mots différents renvoyant à un même thème (tourisme : voyage, hôtel, visite…) ; champ sémantique = ensemble des sens possibles d'un même mot (« corps humain » ≠ « corps de métier »).
  • Dénotation : sens premier, conventionnel, de dictionnaire ; connotation : sens secondaires conférés par le contexte.
  • Explicite : ce qui est dit (premier plan) ; implicite : ce qui est supposé, à déduire (second plan).

IV. ⚠️ Pièges d'examen & méthode

⚠️ Erreurs fréquentes :
  • Accorder le participe passé d'AVOIR avec le sujet : jamais — seulement avec le COD placé avant ;
  • Accorder « vu » ou « ci-joint » placés avant le nom : ils restent invariables ;
  • Mettre des points de suspension après etc. ;
  • Confondre homonyme (même son) et paronyme (formes proches) ;
  • S'arrêter au sens dénoté : un mot prend des sens connotés selon le contexte — capital pour interpréter un texte juridique.
💡 Réflexe : ponctuer pour lever l'ambiguïté ; vérifier COD-avant pour l'accord ; lire le sens en contexte (champ sémantique), pas seulement en dictionnaire.
