📝 FICHE DE RÉSUMÉ

📖 Techniques d'expression française 🏫 Licence 1 Droit — Semestre 1 Leçon 4 : Le résumé de texte, le vocabulaire et la discussion

I. Le résumé de texte

Le résumé de texte : exercice de synthèse consistant à condenser un texte argumentatif en un nombre de mots précis, en n'en retenant que l'essentiel — exige lecture rapide, compréhension et fidélité sans contresens.
  • Les exigences — 3 maîtres-mots : fidélité, clarté, brièveté :
    • Respecter le nombre de mots (tolérance ≈ ±10 %) ;
    • Suivre l'ordre des idées du texte et conserver son système d'énonciation (pas de « l'auteur montre que… ») ;
    • N'en garder que la substance : idées essentielles rendues dans son style propre — ni montage de citations, ni paraphrase ;
    • Aucun commentaire personnel, aucune idée étrangère ; pas d'introduction ni de conclusion propres ; le résumé tient en un seul paragraphe.
  • Travail préliminaire : 3 lectures (découvrir → s'imprégner → articulations) ; dégager thème → idée générale → thèse ; noter les arguments et leurs articulations (explicites ou implicites) ; sélectionner et reformuler (synonymie, nominalisation, pronominalisation, changement de nature des mots). 💡 Les idées-forces se trouvent le plus souvent en début d'introduction, début de paragraphe et conclusion.
  • La rédaction : relier les idées par les connecteurs logiques ; « se débarrasser » du texte original ; relire en comparant au texte ; compter les mots. Mots-clés sans synonyme : reprises permises, mais phrases propres obligatoires ; éviter les longues phrases.

II. L'explication de vocabulaire

  • Un mot a un sens dénoté (dictionnaire) mais prend des significations selon son contexte — le contexte lève la polysémie.
  • Expliquer = dégager le sens conféré par l'environnement contextuel — réponse rédigée, précise, introduite par « selon le texte… », « selon le contexte… », « du point de vue de l'auteur… » ; s'aider de la racine/du radical du mot.

III. La discussion

La discussion : développer une réflexion personnelle argumentée à partir d'une question issue du texte — « petite dissertation » évaluant la capacité à entrer dans le débat.
  • Principe fondamental : aucune affirmation gratuite — chaque idée/argument est soutenu par un exemple précis, cohérent et concret.
  • Discuter ≠ s'opposer systématiquement : c'est analyser le pour et le contre, mesurer la pertinence et les limites de la thèse — la controverse est souhaitable, pas obligatoire.
  • Interdits : répéter, commenter ou paraphraser le texte.
  • Démarche : analyser le sujet jusqu'à compréhension totale → rechercher les idées → classer par grands axes → rédiger (introduction, développement par axe, conclusion).

IV. ⚠️ Pièges d'examen & méthode

⚠️ Erreurs fréquentes :
  • Résumé = collage de citations ou paraphrase : faute éliminatoire d'esprit — reformuler dans son style ;
  • Ajouter ses opinions dans le résumé ou écrire « l'auteur pense que… » (rupture de l'énonciation) ;
  • Dépasser le nombre de mots sans compter ;
  • Dans la discussion, reprendre le texte au lieu d'argumenter — ou croire qu'il faut obligatoirement contredire l'auteur ;
  • Expliquer un mot hors contexte par son seul sens de dictionnaire.
💡 Réflexe : résumé = fidélité + clarté + brièveté en un paragraphe ; vocabulaire = contexte ; discussion = arguments + exemples, jamais d'affirmation gratuite.
