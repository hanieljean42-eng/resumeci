📜 FICHE DE RÉSUMÉ

📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 4 : Séries de données — la recopie incrémentée
La création d’une série évite de saisir une à une les données : elle est plus rapide et plus fiable. On crée une série dans tous les sens (bas, haut, droite, gauche) grâce à la poignée de recopie (cliqué-glissé, pointeur en croix noire), au menu de la balise active ou à la fenêtre « Série de données » (Accueil → Édition → Remplissage → Série).

I. Série numérique

  • Série linéaire : chaque terme s’obtient en ajoutant un nombre fixe (le pas ou incrément) au précédent. Ex. : 5, 8, 11, 14… → pas de 3.
    • Saisir les deux premiers éléments sur deux cellules adjacentes → Excel déduit le pas → sélectionner les deux cellules → cliqué-glissé sur la poignée.
    • Une seule cellule sélectionnée = pas nul (recopie de la valeur constante).
  • Série géométrique : chaque terme s’obtient en multipliant par un nombre fixe. Ex. : 4, 8, 16, 32 → pas de 2.
    • Saisir le 1er élément → sélectionner les cellules à remplir (ou uniquement la cellule en indiquant la dernière valeur) → fenêtre « Série de données » → type Géométrique + valeur du pas.

II. Série chronologique

  • Suite de dates où chaque terme s’obtient en ajoutant la même durée (le pas). Ex. : 10/05/2011, 17/05/2011, 24/05/2011 → pas de 7 jours ;
  • Saisir la 1ère date → cliqué-glissé : incrémentation par défaut de pas un jour ;
  • Affiner via la balise active (ex. : « Incrémenter les mois ») ou la fenêtre « Série de données » (pas et unité de temps au choix : jour, jour ouvré, mois, année) ;
  • La balise est plus rapide ; la fenêtre offre davantage de possibilités.

III. Série alphanumérique

  • Valeurs composées d’un texte fixe + un nombre incrémentable ;
  • Saisir le 1er élément (couleur 1) ou les deux premiers (forme 5, forme 7) → cliqué-glissé : couleur 2, couleur 3… / forme 9, forme 11… ;
  • ⚠️ La fenêtre « Série de données » n’est pas utilisable pour ce type ;
  • Excel n’incrémente que le nombre situé le plus à droite (la dernière décimale) : hauteur 1,84 → hauteur 1,85 ; 1,86…

IV. Série à partir d’une liste personnalisée

  1. Créer la liste : Fichier → Options → Options avancées → rubrique Général → « Modifier les listes personnalisées » → Nouvelle liste → saisir chaque élément (Entrée entre chacun) ou importer une plage → Ajouter ;
  2. Créer la série : saisir un élément de la liste → valider → cliqué-glissé sur la poignée ; les éléments s’enchaînent et la liste se répète si on dépasse son nombre d’éléments ;
  3. Exemple intégré : les listes prédéfinies d’Excel (jours, mois) fonctionnent déjà ainsi : saisir « lundi » → tirer la poignée → mardi, mercredi…

Points importants à retenir

  • Excel crée automatiquement des séries à partir de nombres, mois et dates ;
  • La série dépend du contenu initial des cellules sources ;
  • L’incrément positif = série croissante ; négatif = décroissante ;
  • Le cliqué-glissé en sens inverse réduit la série.

V. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Tirer la poignée sur une seule valeur numérique en espérant une suite : Excel recopie (pas nul) — il faut saisir deux premiers termes pour définir le pas ;
  • Chercher la série géométrique par la seule poignée : elle exige la fenêtre « Série de données » ;
  • Croire que le texte avant le nombre bloque l’incrément : seul compte le nombre le plus à droite ;
  • Oublier qu’une liste personnalisée boucle (elle recommence au 1er élément).
💡 Axe de synthèse : la poignée de recopie automatise les suites — linéaire et chronologique directement, géométrique par la fenêtre Série, alphanumérique par incrément du dernier nombre.
