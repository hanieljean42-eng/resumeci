📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 6 : Formules et fonctions
L’objectif d’un tableur est d’effectuer des calculs et des simulations. Toute formule commence par le signe = et peut contenir des constantes, des références de cellules, des opérateurs et des fonctions (Excel 2013 : plus de 300). Excel ne distingue pas la casse.

I. Les formules

  • Signe = obligatoire : « 5 + 2 » reste du texte ; « = 5 + 2 » affiche 7 ;
  • Affichage : le résultat est dans la cellule, la formule dans la barre de formule ; tout afficher : « Afficher les formules » (groupe Audit) ou Ctrl + " ; saut de ligne dans une longue formule : Alt + Entrée ;
  • Indépendante : n’utilise aucune autre cellule (=8*5-6) ; dépendante : utilise des cellules (=A3+B1) ;
  • Opérateurs de calcul par ordre de priorité : * et / puis + et − ; les parenthèses forcent la priorité (autant d’ouvrantes que de fermantes) ;
  • Opérateur alphanumérique : l’esperluette & concatène : =A1&" habite à "&B1.

II. Les références : relatives, absolues, mixtes

TypeÉcritureComportement à la recopie
Relative (défaut)E1S’ajuste automatiquement à la nouvelle position
Absolue$E$1Le $ fige : la valeur reste celle de la cellule d’origine
Mixte$A8 ou A$8Une dimension figée (colonne ou ligne), l’autre relative
  • Touche F4 : fait défiler les types dans la formule en cours : A4 → $A$4 → A$4 → $A4 → A4 ;
  • Exemple-clé : en F2, =E1 recopié en G2 donne la valeur de F1 ; en F3, =$E$1 recopié en G3 donne toujours la valeur de E1 ;
  • Autre feuille : =Feuil1!T9 (apostrophes si le nom contient un espace : ='Feuille une'!T9) ;
  • Référence 3D : =SOMME(Feuil1:Feuil3!G2:H8) additionne la même plage sur plusieurs feuilles ;
  • Autre classeur : =[Classeur1]Feuil5!A2 — référence externe (proposition de mise à jour des liaisons à l’ouverture).

III. Nommer cellules et plages

  • Un nom peut désigner une cellule, une plage, un ensemble de plages, une formule ou une constante ; c’est une référence absolue utilisable dans tout le classeur ;
  • Règles : pas de ressemblance avec une référence ligne/colonne ; 1er caractère = lettre ou « _ » ; pas d’espace (point ou « _ » à la place) ; pas de distinction de casse ;
  • Attribution : saisie dans la Zone Nom + Entrée, ou « Gestionnaire de noms » (Ctrl + F3, onglet Formules → Noms définis) ;
  • « Depuis sélection » : attribue les intitulés des lignes/colonnes comme noms — l’espace devient l’opérateur d’intersection : =salamandres juillet renvoie la cellule au croisement ;
  • Usage : plus lisible — =D6*(1+TauxTVA), =SOMME(Totalité) ; « Appliquer les noms » remplace les références déjà saisies.

IV. Dates, heures et audit

  • Date = numéro de série depuis le 01/01/1900 (12/09/2008 → 39703) ; heure = fraction de journée (12:00 → 0,5 ; 18:00 → 0,75) ;
  • Audit de formules (onglet Formules) : antécédents/dépendants, évaluation du calcul ;
  • Erreurs : affichées avec un # — #VALEUR!, #NOM?, #REF!, #N/A ; « Vérification des erreurs » parcourt et aide à corriger.

V. Les fonctions

  • Syntaxe : = + nom + arguments entre parenthèses, séparés par des points-virgules ; argument = constante, référence, plage, nom ou autre fonction ;
  • Sans argument : =AUJOURDHUI(), =MAINTENANT() ; fonctions imbriquées : =ENT(SOMME(E6:G8)) ;
  • SOMME : 1 à 30 arguments — =SOMME(5;B1:B6;C3) ; bouton Σ (Somme automatique) propose aussi Moyenne, NB, Max, Min ;
  • NB : compte les cellules à valeurs numériques de ses arguments (+ les arguments eux-mêmes numériques) ;
  • Insertion : bouton fx (recherche par description ou catégorie → fenêtre « Arguments de la fonction ») ou saisie directe (info-bulle des arguments ; [argument] = facultatif) ;
  • Fonction SI — formule conditionnelle :
    SI(Test ; Résultat_si_vrai ; Résultat_si_faux) — le Test contient un opérateur logique (=, >, >=, <, <=). Ex. : =SI(E6="Jaune";"la couleur est jaune") → le texte si vrai, FAUX sinon.

VI. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Oublier le = : « 5 + 2 » reste du texte, jamais calculé ;
  • Oublier le $ : une référence qui ne doit pas bouger doit être absolue (F4) ;
  • Séparer les arguments par des virgules : le séparateur est le point-virgule ;
  • Confondre NB (compte les nombres) et une somme de cellules ;
  • Oublier que sans le 3e argument, SI renvoie FAUX quand le test est faux.
💡 Axe de synthèse : formule = « = » + opérateurs + références (relatives/absolues/mixtes/nommées, mono- ou multi-feuilles) ; fonction = nom + arguments ; les erreurs commencent par # et s’auditer via le groupe Audit de formules.
