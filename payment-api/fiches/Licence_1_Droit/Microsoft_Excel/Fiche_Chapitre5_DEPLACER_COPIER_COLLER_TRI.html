📜 FICHE DE RÉSUMÉ

📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 5 : Déplacer, copier, coller et tri rapide
Déplacer, copier ou coller porte sur les valeurs des cellules. Sans insertion concomitante, ces actions ne changent pas les références des cellules et n’entraînent aucun décalage de cellules.

I. Le volet Presse-papiers

  • Stocke 24 éléments coupés ou copiés ; affichage : lanceur du groupe Presse-papiers (onglet Accueil) ;
  • « Coller tout » : insère tous les éléments d’un bloc, dans l’ordre inverse de leur affichage ;
  • Si le volet n’est pas affiché, seul le dernier élément est conservé (bordure clignotante ; disparaît dès qu’il ne peut plus être collé).

II. Déplacer les valeurs

  • À la souris : sélection → pointer le contour (pointeur en croix fléchée) → cliqué-glissé ;
  • Couper/Coller : clic droit → Couper (Ctrl + X) → sélectionner la 1ère cellule de destination → Coller (Ctrl + V) ;
  • Vers une autre feuille : Alt + cliqué-glissé du contour jusqu’à l’onglet cible ;
  • Vers un autre classeur : disposer les deux fenêtres (« Réorganiser tout ») puis appliquer une méthode classique ;
  • Déplacer + insérer (avec décalage de cellules) : Maj + cliqué-glissé, ou Couper → clic droit sur la destination → « Insérer les cellules coupées » → choisir le sens du décalage.

III. Copier

  • Copier/Coller : clic droit → Copier (Ctrl + C) → Coller ; la bordure clignotante permet de recoller à volonté (Échap pour y mettre fin) ;
  • À la souris : Ctrl + cliqué-glissé sur le contour (signe + près du pointeur) ;
  • Copier + insérer : Copier → clic droit sur la destination → « Insérer les cellules copiées » → option de décalage.

IV. Les options de collage

OptionEffet
CollerCopie conforme (tout, sauf les largeurs de colonnes)
FormulesLes formules seules, sans mise en forme
ValeursLes résultats, pas les formules
TransposerInversion des colonnes et des lignes
Aucune bordureTout sauf les bordures
Conserver les largeurs de colonnesMise en forme + largeurs sources
Mise en formeSeule la mise en forme, pas les données
Coller avec liaisonColle les références : la copie suit toute modification de l’original
Image / Image liéeColle une image figée / une image mise à jour avec les données

Fenêtre « Collage spécial » : rubrique « Coller » (Tout, Formules, Valeurs, Formats, Commentaires, Validation, Largeurs des colonnes) + rubrique « Opération » (addition, soustraction, multiplication, division entre données collées et destination : destination − données collées, destination / données collées) + option « Blancs non compris » (les cellules vides copiées n’effacent pas la destination).

V. Tri rapide

  • Trier une colonne : clic sur une cellule de la colonne (le tri s’arrête à la 1ère cellule vide) ou sélection complète → Accueil → « Trier et filtrer » (ou onglet Données → « Trier de A à Z » / « de Z à A ») ;
  • En ordre croissant : les chiffres avant les lettres, les cellules vides en dernier ;
  • Fenêtre « Tri » (« Tri personnalisé ») : plusieurs niveaux de critères (ex. : nom puis prénom), case « Mes données ont des en-têtes » pour exclure l’en-tête ; pour trier une ligne : bouton Options → « De la gauche vers la droite » ;
  • Dates : « Du plus ancien au plus récent » ou l’inverse.

VI. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Croire que couper/coller décale les cellules : sans insertion, aucun décalage ;
  • Compter sur le presse-papiers sans l’avoir affiché : seul le dernier élément est alors gardé ;
  • Confondre « Coller avec liaison » (copie vivante, liée à l’original) et collage simple (copie figée) ;
  • Cliquer dans une colonne contenant des vides avant de trier : le tri s’arrête à la première cellule vide.
💡 Axe de synthèse : déplacer = couper + coller (ou croix fléchée) ; copier = Ctrl + cliqué-glissé ; insertion = Maj (ou « Insérer les cellules ») ; le collage spécial affine ce qui est collé (formules, valeurs, formats, liaison, opérations).
