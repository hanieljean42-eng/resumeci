📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 1 : Introduction — le tableur et son interface
Microsoft Excel est un tableur : une application conçue pour créer et utiliser des feuilles de calcul, effectuer des suites de calculs et visualiser les données sous forme de graphiques. Dans Word on travaille sur un document ; dans Excel, sur un classeur (extension .xlsx).

I. Démarrage et fenêtre principale

  • Lancement : menu Démarrer → chemin vers EXCEL.EXE ; ou raccourci Bureau (clic droit → Envoyer vers → Bureau) ; ou recherche « Excel » sous Windows 10 → Nouveau classeur.
  • Info-bulle : rectangle d’aide qui s’affiche quand on pointe un bouton.
  • Barre de titre : nom du classeur (par défaut Classeur1) + nom de l’application ; boutons réduire / agrandir / fermer à droite.
  • Ruban : onglets regroupant les fonctionnalités — communs (Fichier, Accueil, Insertion, Mise en page, Révision, Affichage) et propres à Excel (Formule, Données) ; chaque onglet = groupes de commandes ; le lanceur de groupe ouvre une boîte de dialogue ; ruban rétractable et personnalisable (Fichier → Options → Personnaliser le ruban).
  • Barre d’outils Accès rapide : petites commandes fréquentes (enregistrer, impression rapide…), personnalisable.

II. Enregistrer, protéger, imprimer

  • Enregistrer : bouton disquette de l’Accès rapide ou Fichier → Enregistrer ; au 1er enregistrement : dossier, nom (pas de signes de ponctuation), type de fichier.
  • Export PDF/XPS : Fichier → Enregistrer sous → type « PDF » ; diffusion sans modification (le destinataire lit mais ne modifie pas).
  • Enregistrement automatique : Fichier → Options → Enregistrement (fréquence et dossier par défaut).
  • Mot de passe : Fichier → Informations → Protéger le classeur ; minimum 8 caractères (idéal 14+, majuscules/minuscules/chiffres/symboles) ; ⚠️ irrécupérable si perdu.
  • Impression : Fichier → Imprimer (paramètres, mise en page) ou bouton Impression rapide.

III. Le classeur et la feuille de calcul

  • Classeur : ensemble de feuilles à onglets ; 3 feuilles par défaut, 255 maximum ; l’onglet blanc = feuille active ; clic droit sur les flèches de défilement = liste de toutes les feuilles.
  • Feuille de calcul : 16 384 colonnes (A → XFD) × 1 048 576 lignes = plus de 17 milliards de cellules.
  • Référence d’une cellule : lettre(s) de colonne + numéro de ligne, sans espace (ex. : F5) ; Excel ignore la casse.
  • Cellule active : celle qui recevra la saisie (cadre plus marqué, une seule à la fois, A1 à l’ouverture) ; son nom s’affiche dans la Zone Nom.
  • Plage : rectangle de cellules noté B7:E12 (première cellule : dernière cellule) ; zone active = plus petite plage depuis A1 contenant toutes les données.
  • Zone Nom + barre de formule : on saisit dans la cellule ou dans la barre de formule ; bouton fx = Insérer une fonction ; ✗ = annuler (Échap) ; ✓ = valider (Entrée).

IV. Barre d’état et deux fenêtres

  • Barre d’état (clic droit pour personnaliser) : calculs instantanés sur la sélection (moyenne, nombre, somme, min, max) + 3 modes d’affichage (Normal, Mise en page, Aperçu des sauts de page).
  • Deux fenêtres : la fenêtre du programme (ruban + barres) et la fenêtre du classeur (onglets + défilement), chacune avec ses boutons de dimension.
  • Paramétrage : Fichier → Options → 10 catégories (ex. : changer le nombre de feuilles par classeur, le sens de déplacement après Entrée).

V. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Confondre document (Word) et classeur (Excel, .xlsx) ;
  • Dire qu’un classeur est limité à 3 feuilles : c’est le défaut, le maximum est 255 ;
  • Citer un faux nombre de cellules : 16 384 colonnes × 1 048 576 lignes ;
  • Oublier que le mot de passe perdu est définitivement irrécupérable.
💡 Axe de synthèse : Excel = classeur → feuilles → cellules ; toute l’interface (ruban, Zone Nom, barre de formule, barre d’état) sert à lire et manipuler ces cellules.
