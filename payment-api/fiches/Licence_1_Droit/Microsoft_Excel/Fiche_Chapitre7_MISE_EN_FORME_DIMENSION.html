📜 FICHE DE RÉSUMÉ

📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 7 : Mise en forme et dimension
La mise en forme d’une cellule concerne six éléments : le format d’affichage de la valeur (« nombre »), l’alignement, la police, la bordure, le remplissage et le format. On agit par le ruban (onglet Accueil), la mini-barre d’outils ou la fenêtre « Format de cellule » (clic droit → Format de cellule, ou lanceur du groupe Nombre) dont les cinq premiers éléments ont chacun un onglet.

I. Les formats d’affichage (groupe Nombre)

FormatParticularités
StandardFormat par défaut : nombre/date à droite, texte à gauche
Nombre2 décimales par défaut, sans séparateur de milliers (ajoutable)
Monétaire2 décimales + séparateur + devise contre le bord droit
ComptabilitéDevise avec retrait du bord droit ; zéro affiché « – » centré ; signe moins aligné seul à gauche
Date / Heure« Date courte » ou « Date longue » (avec le jour) selon paramètre régional
Pourcentage0,055 → 5,5 % ; bouton %
Fraction3,5 → 3 ½ ; Excel affiche la fraction la plus proche (dénominateur 1 à 3 chiffres)
TexteMême un nombre devient du texte : exclu des formules ; une formule saisie reste du texte
SpécialCode postal, Sécurité sociale, Téléphone — selon le paramètre régional
Personnalisé1 à 4 parties séparées par des points-virgules ; partir d’un type prédéfini à modifier
  • Décimales : boutons « Ajouter/Réduire une décimale » ; séparateur de milliers : espace par défaut (modifiable dans Options → Options avancées) ;
  • ⚠️ Le bouton d’icône « 000 » applique le format Comptabilité, pas le séparateur du format Nombre.

II. Alignement et orientation

  • Horizontal : gauche / centré / droite ; retraits possibles (boutons « Augmenter/Diminuer le retrait ») ; options spéciales : Recopié (répète le contenu), Distribué (retraits égaux des deux côtés) ;
  • Vertical : haut / centré / bas ;
  • Orientation : bouton Orientation ou zone « degrés » de Format de cellule ;
  • Texte et dimensions :
    • « Renvoyer à la ligne automatiquement » : le texte reste dans la cellule, la hauteur de ligne augmente ;
    • « Ajuster » : la taille des caractères diminue, la cellule garde ses dimensions ;
    • « Fusionner et centrer » : combine plusieurs cellules (souvent pour un titre) — ⚠️ seule la valeur de la cellule supérieure gauche est conservée.

III. Police, bordure, remplissage, dimensions

  • Police : groupe Police (type, taille, couleur, gras G / italique I / souligné S ; boutons A+/A− par point) ; onglet Police de Format de cellule : types de soulignement, couleurs, Barré, Exposant, Indice ;
  • Bordure : bouton bordures du groupe Police (menu déroulant : contours, styles, couleurs) ;
  • Remplissage : couleur de fond des cellules ;
  • Dimensions : largeur de colonne / hauteur de ligne par cliqué-glissé sur les bordures des en-têtes, ou double-clic pour l’ajustement automatique au contenu.

IV. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Confondre Monétaire (devise contre le bord) et Comptabilité (devise en retrait, zéro en tiret centré) ;
  • Sélectionner le contenu de la cellule au lieu de la cellule : seul l’onglet Police est alors accessible ;
  • Croire que la fusion conserve toutes les valeurs : seule celle du haut à gauche subsiste ;
  • Confondre « Renvoyer à la ligne » (hauteur ↑) et « Ajuster » (taille des caractères ↓) ;
  • Appliquer le format Texte à des nombres destinés aux calculs.
💡 Axe de synthèse : sélectionner d’abord le maximum de cellules, puis appliquer format d’affichage → alignement → police → bordure → remplissage ; tout se centralise dans la fenêtre « Format de cellule ».
