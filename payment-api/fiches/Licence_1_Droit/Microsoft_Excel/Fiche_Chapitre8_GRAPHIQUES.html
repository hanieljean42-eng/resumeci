📜 FICHE DE RÉSUMÉ

📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 8 : Les graphiques
Un graphique sert à représenter et « faire parler » des données chiffrées. Ce qu’on appelle couramment « graphique » est en fait la zone de graphique, qui comprend tous ses éléments : le graphique lui-même, les axes, les étiquettes, la légende…

I. Création et outils

  1. Sélectionner la plage de données y compris les intitulés (étiquettes) des lignes et colonnes — Ctrl si éléments non adjacents ;
  2. Onglet Insertion → groupe Graphiques : choisir la catégorie (souvent Colonne, Ligne ou Secteurs), puis le type dans la galerie ;
  3. La zone de graphique apparaît sélectionnée (cadre bleuté épais) → onglets contextuels « Outils de graphique » : Création, Disposition, Mise en forme ;
  4. Clic droit sur un élément de la zone = menu propre à cet élément ; la zone se déplace par cliqué-glissé (croix fléchée) et se redimensionne par ses poignées ;
  5. Plusieurs graphiques différents peuvent représenter les mêmes données sur une feuille.

II. Emplacement, type, axe secondaire

  • Emplacement : par défaut sur la feuille des données ; « Déplacer le graphique » (Création → Emplacement) le déplace sur une autre feuille — déplacement, pas copie ; le graphique reste lié aux données sources et se met à jour ;
  • Changer de type : « Modifier le type de graphique » (onglet Création ou clic droit) ;
  • Axe secondaire : nécessaire quand une série a un ordre de grandeur très différent (ex. : dizaines vs milliers) — clic droit sur la série → « Mettre en forme une série de données » → Options des séries → cocher « Axe secondaire » (axe vertical à droite).

III. Les données sources

  • Redimensionner la plage : cliqué-glissé sur un angle du cadre bleu entourant les données sources (réduire, ou étendre aux données adjacentes) ;
  • Intervertir lignes/colonnes : par défaut, les étiquettes de colonnes sont sur l’axe horizontal ; Création → Données → « Intervertir les lignes/colonnes » les remplace par celles des lignes ;
  • Ajouter une série non adjacente (même ou autre feuille) :
    • Copier/Coller directement dans la zone de graphique ; ou
    • « Sélectionner des données » (Création → Données ou clic droit) → Ajouter → « Nom de la série » + « Valeurs de la série » (garder le « = » et sélectionner les cellules).
  • Copier en image : clic droit sur la zone → Copier → collage « Image » : éléments non modifiables (« Image liée » se met à jour).

IV. Présentation de la zone de graphique

  • Dispositions prédéfinies : Création → « Dispositions du graphique » (galerie selon le type) ;
  • Disposition individuelle : onglet Disposition (groupes Étiquettes, Axes, Arrière-plan) : afficher/masquer ou positionner titre, légende, axes ;
  • Rotation 3D : groupe Arrière-plan → « Rotation 3D » pour améliorer la lisibilité (aperçu instantané) ;
  • Excentration de secteurs (graphique en secteurs) : tous les secteurs → clic droit → « Mettre en forme une série de données » → « explosion » ; un seul secteur → sélectionner puis cliqué-glissé.

V. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Oublier de sélectionner les étiquettes avec les données : le graphique perd ses intitulés ;
  • Croire que déplacer un graphique vers une autre feuille le délie : il reste lié aux données sources ;
  • Superposer deux échelles incompatibles : prévoir un axe secondaire ;
  • Confondre les onglets Outils de graphique (Création / Disposition / Mise en forme), qui n’apparaissent que si la zone est sélectionnée.
💡 Axe de synthèse : sélection données + étiquettes → Insertion → type → zone de graphique liée aux sources, modifiable par les onglets Outils de graphique (type, emplacement, séries, axes, disposition).
