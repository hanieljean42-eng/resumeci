📖 Microsoft Excel 🏫 Licence 1 Droit — Semestre 2 Chapitre 2 : Gestion des feuilles et des classeurs
La gestion des feuilles passe par leurs onglets : nommer, sélectionner, insérer, supprimer, copier ou déplacer s’opèrent sur les onglets ; celle des classeurs passe par la fenêtre et l’onglet Affichage.

I. Gestion des feuilles de calcul

  • Renommer : clic droit sur l’onglet → Renommer (ou double-clic sur l’onglet), saisir le nom, valider par Entrée ;
  • Couleur d’onglet : clic droit → Couleur d’onglet (souligné si feuille active, fond coloré sinon) ;
  • Sélectionner des feuilles :
    • une feuille : clic sur l’onglet ;
    • feuilles adjacentes : clic sur la 1ère + Maj + clic sur la dernière ;
    • feuilles non adjacentes : Ctrl + clic sur chaque onglet ;
    • toutes : clic droit → Sélectionner toutes les feuilles.
  • Groupe de travail : plusieurs feuilles sélectionnées ([Groupe de travail] dans la barre de titre) → les saisies sur la feuille active se répercutent sur les autres ;
  • Insérer : bouton « Insérer une feuille » (groupe Cellules) ou onglet « Insérer une feuille de calcul » ou clic droit → Insérer ;
  • Supprimer : clic droit sur l’onglet → Supprimer — suppression définitive ;
  • Déplacer / copier : cliqué-glissé sur l’onglet pour déplacer ; Ctrl + cliqué-glissé pour copier (la copie prend le nom suivi d’un numéro : Feuil1 (2)) ; ou clic droit → « Déplacer ou copier ».

II. Affichage d’une feuille de calcul

  • Zoom : 100 % par défaut (barre d’état ou onglet Affichage → Zoom) ; « Zoom sur la sélection » pour une plage ;
  • Plein écran : Affichage → Plein écran (ruban, barre de formule et barre d’état masqués ; Échap pour quitter) ;
  • Figer les volets : garder visibles les intitulés de lignes/colonnes — sélectionner la cellule au-dessus de laquelle les lignes restent figées et à gauche de laquelle les colonnes restent figées → Affichage → Figer les volets ; « Libérer les volets » pour annuler.

III. Travailler sur plusieurs classeurs

  • Ouvrir plusieurs classeurs : Fichier → Ouvrir → Ctrl + clic sur chaque nom ;
  • Basculer : clic sur le nom dans la barre des tâches, ou Affichage → « Changement de fenêtre » ;
  • Même classeur dans plusieurs fenêtres : Affichage → « Nouvelle fenêtre » (nom suivi de « :2 » ; toute modification s’applique au classeur) ;
  • Disposer les fenêtres : « Réorganiser tout » → Mosaïque, Horizontal, Vertical ou Cascade ;
  • Comparer côte à côte : ouvrir les deux classeurs → « Afficher côte à côte » + défilement synchrone ; « Rétablir la position de la fenêtre » pour rééquilibrer.

IV. ⚠️ Pièges d’examen & méthode

⚠️ Erreurs fréquentes :
  • Confondre Maj (feuilles adjacentes) et Ctrl (feuilles non adjacentes) ;
  • Croire qu’on peut annuler une suppression de feuille : elle est définitive ;
  • Oublier que dans un groupe de travail, la saisie se reproduit sur toutes les feuilles ;
  • Confondre « Déplacer » (cliqué-glissé) et « Copier » (Ctrl + cliqué-glissé) un onglet ;
  • « Figer les volets » fige les lignes au-dessus et les colonnes à gauche de la cellule active — pas l’inverse.
💡 Axe de synthèse : onglets = gestion des feuilles ; Affichage = gestion de l’écran (zoom, volets, fenêtres multiples et comparaison).
