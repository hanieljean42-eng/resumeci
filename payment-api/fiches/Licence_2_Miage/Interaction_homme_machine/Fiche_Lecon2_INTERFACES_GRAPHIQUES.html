I. Les deux types d'interface

TypePrincipeUsage
Interface texte (ligne de commande)L'utilisateur saisit des commandes avec syntaxe et vocabulaireSurtout pour les informaticiens (installation, configuration) — ex. DOS, Unix
Interface graphique (mode fenêtré)Objets manipulés sous forme de pictogrammes à l'écran via un dispositif de pointage (souris)Dispositif courant : ordinateurs, DAB, téléphones, GPS
GUI (Graphical User Interface) : créée par les ingénieurs du Xerox PARC fin des années 1970, popularisée par Apple Macintosh (1984). Les IG intègrent des éléments graphiques → acronyme WIMP : Windows, Icons, Menus, Pointers (ou Rubans).

II. Composants habituels d'une IG

  1. Éléments d'affichage simple : étiquette (Label), icône (Icons) ;
  2. Boutons : poussoir (button), case à cocher (Check box), bouton radio (Radio button) ;
  3. Menus : de commande (Command menu), contextuel (Context menu), circulaire (Pie menu), onglets, ruban (Microsoft Office 2007 : regroupe toutes les fonctionnalités en un seul endroit, moins de clics) ;
  4. Listes : liste (contenu ordonné permanent, 3-8 éléments), liste déroulante (faible encombrement, contenu visible après clic), liste arborescente (hiérarchisé, encombrement modulable) ;
  5. Fenêtres : modales (fermeture obligatoire avant de revenir), boîte de dialogue, flottante (palette/barre d'outils), jaillissante pop-up (infobulle), informations textuelles ;
  6. Champs de saisie : mono-ligne (une unité d'information) et multi-lignes (redimensionnable, barre de défilement) — adapter type, dimensions et contraintes (format, nb caractères max).

III. Multifenêtrage

ModeAvantages / Inconvénients
Avec superposition❌ À éviter : informations masquées, temps d'accès à la fenêtre masquée via la barre des tâches
Sans superposition : mosaïqueHiérarchique : fenêtre d'application + fenêtres filles — ex. MDI (Multiple Document Interface) : fenêtre principale = espace de travail, fenêtres filles = documents

IV. Développement des IG

3 visions : utilisateur (l'utiliser), programmeur (la programmer via une bibliothèque de fonctions), concepteur (créer cette bibliothèque).

Questions préalables : système d'exploitation (Linux/Windows/deux) ? matériel (PC, SUN, Mac) ? Si l'indépendance est clé → bibliothèques multiplateformes ; tenir compte des coûts de portage.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Croire que l'interface texte est « dépassée » partout → elle reste pour les informaticiens (config, système).
  • Confondre fenêtre modale (bloquante) et fenêtre flottante (palette d'outils).
  • Recommander le multifenêtrage avec superposition → le cours dit explicitement « à éviter ».
  • Oublier que le ruban remplace menus + barres d'outils + volets (Office 2007).
