I. Principe

Algorithme du simplexe : méthode itérative qui parcourt les sommets du polyèdre des solutions réalisables pour trouver l'optimum d'un programme linéaire. On part d'une base réalisable de départ B ; I = indices des variables de base, J = indices des variables hors base.

Forme standard

Min Z = cx
    Ax = b
    x ≥ 0

Les inégalités sont transformées en égalités via les variables d'écart.

II. Algorithme primal (minimisation)

Étape 1 — Test d'arrêt

  • Si tous les ĉⱼ ≥ 0 → stop : « La base B est optimale » ;
  • Si ∃ k ∈ J avec ĉₖ < 0 et colonne Âₖ ≤ 0 → stop : « Le problème est non borné » (valeur optimale = −∞) ;
  • Sinon → changement de base.

Étape 2 — Changement de base

a) Test d'entrée : la variable entrante xₖ est celle avec le plus petit ĉₖ < 0 (pour min) :

ĉₖ = min { ĉⱼ : j ∈ J, ĉⱼ < 0 }

b) Test de sortie : la variable sortante xₗ est celle qui limite le plus le rapport :

b̂ₗ = min { b̂ᵢ / âᵢₖ : i ∈ I, âᵢₖ > 0 }

c) Nouvelle base : I := I − l + k ; J := J − k + l. Retour à l'étape 1.

Cas de la maximisation

Pas besoin de transformer en minimisation — inverser les inégalités :

  • Arrêt optimal : tous les cⱼ ≤ 0 ;
  • Non borné : ∃ k ∈ J avec cₖ > 0 et Aₖ ≤ 0 ;
  • Test d'entrée : ĉₖ = max { ĉⱼ : ĉⱼ > 0 }.

III. Méthode des tableaux

Mise en œuvre manuelle : on écrit les tableaux simplexes relatifs aux bases rencontrées. Dans le tableau :

  • Le pivot = élément à l'intersection de la ligne du pivot et de la colonne du pivot ;
  • La ligne du pivot et la colonne du pivot en découlent.

Règles de pivotage

  1. Remplacer le pivot par son inverse (1/pivot) ;
  2. Diviser les autres éléments de la ligne du pivot par le pivot ;
  3. Diviser les autres éléments de la colonne du pivot par le pivot et changer leur signe ;
  4. Mettre à jour les autres lignes par combinaison linéaire.

Cas particuliers : si une ligne intersecte la colonne du pivot par un zéro, la ligne est inchangée ; si une colonne intersecte la ligne du pivot par un zéro, la colonne reste inchangée.

IV. Lecture du résultat

  • Optimum atteint : tous les coefficients de la fonction objectif sont négatifs ou nuls (en min) ;
  • Solution optimale : les valeurs des variables de base dans la dernière colonne ;
  • Non borné : une colonne de la fonction objectif a des coefficients tous négatifs sans pivot possible → valeur optimale = −∞.

Exemple du cours : max Z = 3x₁ + 2x₂ → solution optimale x = (3/2, 2)ᵀ, Z = 17/2. Exemple non borné : min Z = −3x₁ + 5x₂ avec colonne x₂ toute négative → optimum = −∞.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre variable entrante (entre dans la base, choisie par le test d'entrée) et sortante (sort de la base, choisie par le test de sortie).
  • Pour une maximisation, inverser les signes : arrêt quand cⱼ ≤ 0, entrée par le max des ĉⱼ > 0.
  • Oublier que le test de sortie ne considère que les âᵢₖ > 0.
  • Confondre « non borné » (pas d'optimum fini) et « pas de solution » (incompatible).
  • Dans le pivotage : le pivot devient 1/pivot, la ligne est divisée, la colonne est divisée + signe changé.
  • Solution optimale lue dans la dernière colonne du tableau final.
