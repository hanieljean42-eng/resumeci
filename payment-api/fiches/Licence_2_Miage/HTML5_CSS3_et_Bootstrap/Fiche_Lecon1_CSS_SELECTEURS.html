I. Qu'est-ce que CSS ?

CSS (Cascading Style Sheets) : langage décrivant la présentation (apparence et disposition) d'un document HTML — séparé du contenu.

Avantages de la feuille de style externe :

  • Tout changer rapidement via 1 fichier ;
  • Fichiers moins volumineux → chargement plus rapide ;
  • Réutilisable sur plusieurs pages.

Liens vers CSS :

<link href="style.css" rel="stylesheet" type="text/css" media="all">
<link href="style-2.css" rel="stylesheet" type="text/css" media="print">

L'attribut media cible le support (all, print, screen…).

II. Structure d'une règle CSS

sélecteur {
  propriété: valeur;
}
  • Le sélecteur détermine les parties du document concernées ;
  • Le bloc de déclaration (entre accolades) contient propriété + valeur, séparées par : ;
  • Ex. color: red; → couleur des textes en rouge.

III. Les sélecteurs

1. Sélecteur de type

Le plus simple : on applique un style à une balise HTML — ex. p { color: green; } colore tous les paragraphes.

2. Les classes (.)

  • Nom de classe toujours précédé d'un point : .vert, .rouge ;
  • Appliquée via l'attribut HTML class="vert" ;
  • On peut omettre le nom de la balise : .vert { } s'applique à tout élément ayant cette classe ;
  • Intérêt : regrouper des propriétés dans une classe et les appliquer à différents éléments/endroits — noms significatifs et mémorisables (ex. .remarque).

3. L'ID (#)

  • Contrairement à la classe, un id s'applique à un objet unique — un élément ne peut avoir qu'un seul id, non réutilisable ;
  • Utilisé pour placer des blocs dans une page et créer des ancres/liens internes (retour en haut) ;
  • Priorité plus forte que la classe dans la cascade.

4. Groupement de sélecteurs

Plusieurs sélecteurs séparés par une virgule partagent le même bloc de déclaration.

IV. Héritage et cascade

Héritage

  • Les balises HTML s'emboîtent → un élément peut hériter du style de son parent (ex. un <p> dans <body> hérite de body) ;
  • L'héritage s'applique à certaines propriétés (couleur, police…) mais pas toutes — les marges ne se transmettent pas aux éléments en-ligne ;
  • Une propriété définie directement sur l'élément remplace celle héritée.

Cascade

  • Quand plusieurs règles s'appliquent au même élément, la dernière/plus spécifique gagne ;
  • Priorité : id > classe > type ;
  • Ex. : un paragraphe avec classe .pspecial écrase le style de base ; id « l'emporte » sur la classe.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier le point devant le nom de classe (.vert) ou le # devant l'id.
  • Penser qu'un id est réutilisable → il est unique par page.
  • Confondre classe (réutilisable, plusieurs par élément) et id (unique, un seul par élément).
  • Oublier que l'héritage ne s'applique pas à toutes les propriétés (marges non héritées par les en-lignes).
  • Ordre de priorité : id > classe > type.
