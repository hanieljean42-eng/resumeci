I. Propriétés de police et de texte

PropriétéRôle / valeurs
font-familyPolice : "Times new roman", arial, verdana, sans-serif (liste de recours)
font-sizeTaille : 10pt, 15pt, small, medium, large, px…
font-weightGraisse : bold, 900…
font-styleStyle : italic…
colorCouleur du texte
text-alignAlignement : left, center, right, justify
background-colorCouleur de fond : yellow, #FFFFFF…
vertical-alignAlignement vertical d'un texte par rapport à un élément en-ligne : baseline (défaut), top, middle, bottom…

Style en ligne : <p style="font-size: 15pt;"> — possible mais déconseillé (mélange contenu/présentation).

II. Unités en CSS

  • Unités absolues : pt (points), px (pixels) ;
  • Unités relatives : em (relatif à la taille de police parente), ex (relatif à la hauteur du « x » minuscules), % ;
  • Ex. : font-size: 10pt ; marges/paddings en px, em, %.

III. Listes (list-style)

list-style-position: inside;   /* ou outside */
list-style-type: ...;          /* type de puce */
  • list-style-position : emplacement de la puce par rapport à la bordure et au texte — inside (décalé à droite) ou outside (défaut, hors du texte) ;
  • Ex. : .bordure { border: medium double red; }.

IV. Arrière-plan (background)

background: url("image.png") no-repeat;
background-position: 40px 50px;   /* ou top right, etc. */
  • background-color : couleur de fond ;
  • background-image + no-repeat ;
  • background-position : position de l'image par rapport au coin supérieur gauche — en pixels (40px 50px) ou mots-clés (top right).

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre font-family (police), font-size (taille), font-weight (graisse), font-style (italique).
  • Confondre list-style-position: inside (puce dans le texte) et outside (puce hors texte, défaut).
  • Confondre text-align (texte) et vertical-align (alignement vertical en-ligne).
  • Oublier que background-position se réfère au coin supérieur gauche de l'élément.
  • Utiliser un style en ligne style="..." partout → à éviter, préférer la feuille externe.
