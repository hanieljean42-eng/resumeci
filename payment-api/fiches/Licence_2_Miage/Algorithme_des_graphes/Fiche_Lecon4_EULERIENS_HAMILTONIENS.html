I. Graphes eulériens

Chaîne eulérienne : chaîne composée de Toutes les arêtes du graphe, prises une seule fois.
Cycle eulérien : cycle composé de toutes les arêtes du graphe prises une seule fois.
Graphe eulérien : graphe possédant un cycle eulérien.

Théorème d'Euler (1739)

Un graphe connexe possède :
  • une chaîne eulérienne ⟺ tous ses sommets sont de degré pair, sauf deux (qui seront les extrémités de la chaîne) ;
  • un cycle eulérien ⟺ tous ses sommets sont de degré pair.
Méthode : pour savoir si un graphe est eulérien → vérifier la connexité puis compter les degrés des sommets.

Interprétation pratique : un graphe possédant une chaîne ou un cycle eulérien peut être « dessiné en une seule fois, sans jamais lever le crayon ».

Exemples du cours :

  • Chaîne eulérienne « A − C − E − D − B − C − D − A − B » mais pas de cycle → pas eulérien ;
  • Aucun sommet impair → plusieurs cycles eulériens → graphe eulérien.

II. Graphes hamiltoniens

Chemin hamiltonien : chemin qui passe par tous les sommets une et une seule fois.
Cycle hamiltonien : chemin hamiltonien fermé (une arête relie le sommet de départ au sommet d'arrivée).
Graphe hamiltonien : graphe possédant un cycle hamiltonien.

Théorème de Dirac (1952)

Soit G un graphe simple avec n ≥ 3 sommets. Si deg(x) ≥ n/2 pour chaque sommet x, alors G est hamiltonien.

Exemple : chemin hamiltonien « d − e − c − b − a » ; cycle hamiltonien « d − e − b − a − c ».

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre eulérien (arêtes) et hamiltonien (sommets) — question favorite !
  • Oublier l'hypothèse de connexité dans le théorème d'Euler.
  • Pour une chaîne eulérienne : exactement deux sommets de degré impair (les extrémités) — pas zéro, pas quatre.
  • Le théorème de Dirac donne une condition large : un graphe peut être hamiltonien sans vérifier deg ≥ n/2.
