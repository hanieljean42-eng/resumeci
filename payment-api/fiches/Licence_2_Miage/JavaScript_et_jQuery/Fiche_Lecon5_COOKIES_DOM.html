II. Les cookies

Cookie : petit fichier au format texte (.txt) stocké par le navigateur sur le poste de l'utilisateur, permettant de conserver des informations entre les visites (préférences, identifiants de session…).

1. Principe et utilisation

Un cookie est créé côté client ou serveur ; il est envoyé automatiquement au serveur lors des requêtes suivantes vers le même domaine.

2. Paramétrage des navigateurs

  • Les navigateurs permettent d'autoriser, bloquer ou supprimer les cookies (paramètres de confidentialité) ;
  • Certains bloqueurs de publicité/tracking les filtrent.

3. Limites d'utilisation

  • Taille limitée (~4 Ko par cookie) ;
  • Nombre limité par domaine ;
  • Date d'expiration à gérer ;
  • Ne pas y stocker de données sensibles (visibles côté client).

4. Application et gestion

  • Ajout d'informations optionnelles au cookie (attributs : expiration, chemin, domaine…) ;
  • Mise à jour d'un cookie : le réécrire avec les nouvelles valeurs ;
  • Lecture via document.cookie ; suppression en expirant la date.

III. Le DOM — Document Object Model

DOM (Document Object Model) : représentation arborescente du document HTML sous forme d'objets — chaque balise, attribut et nœud de texte devient un nœud accessible et modifiable par JavaScript.

Notions essentielles

  • Nœuds : éléments, attributs, textes ;
  • Arbre hiérarchique : parent / enfant / frère — parcours (childNodes, parentNode…) ;
  • Manipulation : créer, lire, modifier, supprimer des nœuds (createElement, appendChild, innerHTML…) ;
  • Événements : attacher des gestionnaires aux nœuds.

Mise en forme

JavaScript + CSS permettent de mettre en forme dynamiquement une page web : modifier styles, classes, contenu en réponse aux interactions.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre cookie (fichier texte côté client) et cache ou session serveur.
  • Oublier que document.cookie ne permet pas de tout lire : les cookies HttpOnly sont invisibles en JS.
  • Confondre DOM (représentation objet du document) et HTML (code source) : le DOM est dynamique, le HTML est statique.
  • Confondre nœud élément, nœud texte et attribut dans l'arbre DOM.
  • Penser qu'un cookie est « côté serveur » → il est stocké chez le client, envoyé au serveur.
