I. Les fonctions

Fonction : bloc de code réutilisable exécuté à la demande — élément fondamental avec les méthodes. Syntaxe : function nomFonction(paramètres) { instructions }. Appelée par un événement ou directement.

II. Programmation évènementielle

Programmation évènementielle : le code s'exécute en réponse à un événement (clic, saisie, chargement…) plutôt que de façon linéaire.
  • Syntaxe : nommer l'événement, suivi de =, puis la fonction — ex. attribut HTML onClick="maFonction()" ;
  • Événements courants : onClick, onChange, onSubmit, onLoad, onFocus, onBlur… ;
  • Fonctions et évènements sont largement employés avec les formulaires.

III. Manipulation des formulaires

Correspondance HTML ↔ JavaScript : chaque élément de formulaire HTML est un objet JavaScript accessible par la syntaxe pointée : document.formulaire.champ. Les contrôles se font via des fonctions placées dans le <head>.

A. Champ text (monoligne)

  • Reçoit des valeurs saisies par l'utilisateur et affiche des résultats ;
  • Monoligne → insuffisant pour une longue chaîne (utiliser textarea) ;
  • Accès à la valeur : syntaxe pointée document.form.nom.value.

B. Champ textarea (multiligne)

Identique à text mais pour les chaînes longues ; redimensionnable avec barre de défilement.

C. Cases à cocher (checkbox)

  • Teste si la case est cochée ou non → oriente le déroulement ;
  • Plusieurs cases cochées pour une même question possibles → combiner par le ET logique && ;
  • 4 possibilités pour 2 cases : aucune, 1re seule, 2e seule, les deux.

D. Boutons radio (radio)

Une seule réponse possible dans un groupe — tester la valeur sélectionnée.

E. Listes à sélection

  • Liste simple : une valeur sélectionnée ;
  • Sélection multiple : plusieurs valeurs via la touche [Alt] — le script fait une boucle sur les éléments pour contrôler chacun.

F. Envoi de fichier

Un formulaire peut permettre à l'utilisateur d'envoyer un fichier (champ de type fichier).

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre fonction (bloc réutilisable) et méthode (fonction d'un objet).
  • Oublier que les événements HTML s'écrivent onClick, onChange… (attributs de balise).
  • Confondre checkbox (plusieurs réponses possibles) et radio (une seule réponse par groupe).
  • Oublier la valeur d'un champ : document.form.champ renvoie l'objet, il faut .value pour le contenu.
  • Pour une liste à sélection multiple, oublier la boucle sur les éléments avec [Alt].
