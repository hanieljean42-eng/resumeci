I. Objets du navigateur et de la page

ObjetRôle / propriétés-méthodes clés
navigatorInformations sur le navigateur et l'environnement : nom, version, langue, plugins…
documentLa page : document.write(), document.title, accès aux formulaires/liens…
screenCaractéristiques de l'écran : résolution, profondeur de couleur…
locationURL courante ; méthode open() avec paramètres (URL, cible, dimensions…)

II. L'objet String

Méthodes de manipulation de chaînes : longueur, sous-chaînes (substring/slice), recherche (indexOf), remplacement (replace), majuscules/minuscules (toUpperCase/toLowerCase), concaténation.

III. L'objet Date et les minuteries

  • Date : date et heure courantes — création, lecture, formatage ;
  • Minuteries (timers) : 4 méthodes particulières pour gérer le temps :
MéthodeRôle
setTimeout(fonction, délai)Exécute la fonction une fois après le délai (ms)
clearTimeout(id)Annule un setTimeout
setInterval(fonction, délai)Exécute la fonction à intervalle régulier
clearInterval(id)Annule un setInterval

IV. L'objet Array (tableaux)

  • Tableau = objet permettant de stocker plusieurs valeurs ;
  • Création : new Array() ou littéral [v1, v2, v3] ;
  • Accès par indice (0, 1, 2…) ; propriété length ;
  • Méthodes : ajout (push), suppression (pop, splice), tri (sort), itération (forEach, boucles for)…
  • Tableaux par compréhension et fonctions génératrices (versions récentes).

V. L'objet RegExp (expressions régulières)

Manipule les expressions régulières (motifs de recherche/remplacement dans le texte). Deux créations :

var exp = new RegExp("motif","option");
var exp = /motif/option;

Le masque combine caractères classiques et métacaractères (classes de caractères, quantificateurs, alternatives…).

VI. L'objet Math

Opérations mathématiques : constantes (PI, E) et méthodes (abs, round, floor, ceil, random, pow, sqrt, sin, cos, max, min…).

VII. Objets window, frame, event

  • frame : très proche de window — gère les cadres (frames) d'une page ; accès par numéro d'indice ou par nom (recommandé) ;
  • event : objet lié aux événements — capture les infos de l'événement déclencheur.

VIII. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre setTimeout (une fois) et setInterval (répété) — et leurs clear* respectifs.
  • Oublier que les délais sont en millisecondes.
  • Confondre index (à partir de 0) et position (à partir de 1) pour un tableau.
  • Oublier length pour la taille d'un tableau/chaîne.
  • RegExp : ne pas oublier les options (g = global, i = insensible à la casse) ni le délimiteur /.
  • Math.random() retourne [0,1[ — pas [0,1].
