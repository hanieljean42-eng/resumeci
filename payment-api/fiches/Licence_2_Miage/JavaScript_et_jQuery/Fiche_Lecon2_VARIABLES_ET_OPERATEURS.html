I. Les constantes

  • Valeur fixe tout au long du script ;
  • Types : arithmétiques (nombres), chaînes de caractères (texte, y compris chaîne vide), booléennes (vrai/faux) ;
  • Constantes prédéfinies : Infinity, NaN, undefined ;
  • Moins employées que les variables.

II. Les variables

JavaScript est « faiblement typé » : les variables n'ont pas besoin de correspondre à un type déclaré (texte, numérique, booléen) — le type est déduit de la valeur affectée.

Étapes d'utilisation

  1. Portée (scope) : déterminer où la variable est visible ;
  2. Déclaration : mot clé var (plusieurs variables sur une ligne séparées par des virgules). Sans valeur → statut undefined ;
  3. Affectation : = ; il est possible d'utiliser des variables sans var (déconseillé) ;
  4. Affichage : via alert(), confirm() ou document.write().

Nommage des variables

  • Pas d'espaces → utiliser l'underscore « _ » ;
  • Majuscules/minuscules distinctes : Nom ≠ nom — deux variables différentes ;
  • Interdiction des mots clés réservés ;
  • Préférer des noms explicites (ce que la variable représente).

III. Types et conversion

  • Opérateur typeof : affiche le type d'une variable (number, string, boolean…) ;
  • Transfert de valeurs entre variables (ex. nom/prénom saisis via prompt() puis affichés avec \r pour saut de ligne) ;
  • Conversion de type : transformer une chaîne en nombre pour calculer (ex. saisie utilisateur → nombre → calcul).

IV. Les opérateurs

Les opérateurs + variables forment une expression. Catégories :

  • Affectation : = ;
  • Arithmétiques : + (addition et concaténation), -, *, /, % ;
  • Comparaison : ==, !=, >, <, >=, <= ;
  • Logiques : && (ET), || (OU), ! (NON) ;
  • Incrément/décrément : ++, -- ;
  • Concaténation : + entre chaînes ou nombre+chaîne ;
  • typeof : retourne le type d'une valeur.

Exemple du cours : un script affiche le résultat d'une multiplication document.write("le résultat de la multiplication est : "+produit) — concaténation texte + variable.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Penser que JS exige une déclaration de type → faiblement typé, le type suit la valeur.
  • Confondre = (affectation) et == (comparaison).
  • Oublier que + fait aussi la concaténation de chaînes — "5"+3 peut donner "53".
  • Utiliser des espaces dans un nom de variable ou un mot réservé → erreur de syntaxe.
  • Variable sans var → fonctionne mais crée une variable globale implicite (mauvaise pratique).
  • NaN = « Not a Number » (résultat d'un calcul invalide) ; undefined = variable déclarée sans valeur.
