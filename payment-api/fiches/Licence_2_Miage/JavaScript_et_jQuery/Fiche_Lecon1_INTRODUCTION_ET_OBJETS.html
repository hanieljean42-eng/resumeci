I. Historique et versions

ÉvénementDétail
Milieu des années 1990Besoin de pages plus conviviales ; Brendan Eich (Netscape) développe un langage de script — d'abord nommé LiveScript — complément de Java côté client
1995 — JS 1.0Implémenté nativement dans Netscape Navigator 2.0 et Internet Explorer 3.0
1996Microsoft sort Jscript (IE) ; Navigator 3.0 apporte corrections
StandardisationSuivi de la norme ECMA (ECMAScript) ; mais IE et Firefox implémentent différemment → un script peut marcher sur un navigateur et échouer sur un autre
Versions clés1.3 (Navigator 4.5), 1.4, 1.5, 1.6 (Firefox 1.0), 1.7 (Firefox 2.0), 1.8 (Firefox 3.0)
Réhabilitation : JavaScript a été déprécié à cause de l'abus des popups (fenêtres surgissantes) ; les bloqueurs de popup intégrés aux navigateurs ont redonné ses lettres de noblesse au langage.

II. Placement et exécution des scripts

  • Le script s'insère dans le <head> ou le <body> du document HTML ;
  • La partie body construit les objets de la page ; la partie head contient les fonctions et le code événementiel ;
  • Affichage dans la page : document.write("texte") ;
  • Boîtes de dialogue : alert() (message), confirm() (OK/Annuler → booléen), prompt() (saisie).

III. Débogage

  • Boîtes de dialogue (alert/confirm) : simples, adaptées aux petits scripts ;
  • Console du navigateur (F12) : adaptée aux scripts complexes — afficher variables et objets ;
  • Débogueur intégré : points d'arrêt, inspection pas à pas des variables.

IV. Objets, méthodes et propriétés

Programmation Orientée Objet (POO) : JavaScript manipule des objets (éléments de la page : fenêtres, formulaires, champs, boutons) dotés de propriétés (caractéristiques) et de méthodes (actions).

Hiérarchie des objets prédéfinis

window (fenêtre — objet le plus élevé)
 └── document (page)
      ├── formu (formulaire)
      │    └── nom (champ)
      └── ...
  • Syntaxe pointée : document.formu.nom accède à la propriété/méthode d'un objet imbriqué ;
  • window est implicite : inutile de le nommer → print() = window.print(), document.title lit le titre de la page ;
  • Deux catégories : objets prédéfinis (hiérarchie) et objets créés par le développeur ;
  • La version de JS détermine les objets/méthodes disponibles — un script peut renvoyer une erreur sur un navigateur plus ancien.

Méthodes utiles de window : alert(), confirm(), prompt(), print().

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre Java et JavaScript : noms quasi identiques mais langages différents, peu de points communs.
  • Attribuer JavaScript à Java ou à un autre langage → créé par Brendan Eich chez Netscape (LiveScript → JavaScript, 1995).
  • Oublier que window est l'objet racine implicite (on écrit alert(), pas window.alert() — les deux marchent).
  • Confondre propriété (valeur/caractéristique) et méthode (action/fonction de l'objet).
  • Penser que JS est « mort » à cause des popups → les bloqueurs ont réhabilité le langage.
