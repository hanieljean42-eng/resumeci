I. SELECT : ordre d'écriture vs ordre d'évaluation

Ordre d'écriture123456
ClauseSELECTFROMWHEREGROUP BYHAVINGORDER BY
Ordre d'évaluation512346
Conséquence : le SGBD évalue FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY. Un alias défini dans SELECT n'est pas utilisable dans WHERE (mais il l'est dans ORDER BY et, selon le SGBD, dans HAVING/GROUP BY).

II. Syntaxe et projection

SELECT [DISTINCT] { * | expr [[AS] alias] [, ...] }
FROM nom_table [alias]
[WHERE condition]
[ORDER BY expr [ASC|DESC] [NULLS {FIRST|LAST}] [, ...]]
[LIMIT n [OFFSET m]]                          -- MySQL, PostgreSQL
[OFFSET m ROWS] [FETCH FIRST n ROWS ONLY];    -- norme / Oracle
  • DISTINCT : supprime les doublons ;
  • AS alias : renomme une colonne dans le résultat ;
  • * : toutes les colonnes.

III. Filtrer avec WHERE

SELECT nom, prenom FROM etudiant
WHERE filiere_id = 1
  AND date_naissance >= DATE '2004-01-01'
  AND nom LIKE 'K%'          -- % : n caractères, _ : 1 caractère
  AND email IS NOT NULL;

IV. Trier, limiter, expressions

SELECT etudiant_id, note FROM inscription
WHERE cours_id = 10
ORDER BY note DESC, etudiant_id ASC
FETCH FIRST 5 ROWS ONLY;

CASE (expression conditionnelle)

SELECT etudiant_id, note,
  CASE
    WHEN note >= 16 THEN 'Très bien'
    WHEN note >= 14 THEN 'Bien'
    WHEN note >= 10 THEN 'Admis'
    ELSE 'Ajourné'
  END AS mention
FROM inscription;

V. Agrégats, GROUP BY, HAVING

FonctionRésultatNULL
COUNT(*)Nombre de lignesComptées
COUNT(col)Valeurs non nulles de la colonneIgnorées
COUNT(DISTINCT col)Valeurs distinctes non nullesIgnorées
SUM(col)SommeIgnorées
AVG(col)MoyenneIgnorées
MIN / MAX(col)Min / maxIgnorées
SELECT cours_id, COUNT(*) AS nb, ROUND(AVG(note),2) AS moyenne
FROM inscription
GROUP BY cours_id;

Règles

  • Toute colonne du SELECT hors fonction d'agrégation doit figurer dans le GROUP BY (sinon erreur) ;
  • WHERE filtre les lignes (avant regroupement) ;
  • HAVING filtre les groupes (après calcul des agrégats) ;
  • Sous-totaux : GROUP BY ROLLUP(a,b), CUBE, GROUPING SETS.
SELECT cours_id, AVG(note) AS moyenne
FROM inscription
WHERE note IS NOT NULL          -- filtre lignes
GROUP BY cours_id
HAVING AVG(note) < 10         -- filtre groupes
ORDER BY moyenne;

VII. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Utiliser un alias SELECT dans WHERE → impossible (ordre d'évaluation).
  • Oublier une colonne dans le GROUP BY → erreur « colonne hors GROUP BY ».
  • Mettre une condition sur un agrégat dans WHERE → WHERE filtre les lignes AVANT calcul ; pour filtrer sur l'agrégat → HAVING.
  • COUNT(*) compte les lignes, COUNT(col) ignore les NULL — différence cruciale.
  • note = NULL n'est jamais vrai → IS NULL.
  • Confondre LIKE '%x' (finit par x) et LIKE 'x%' (commence par x).
