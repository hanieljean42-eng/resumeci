I. Les documents de saisie

  • Bon de commande : le client donne l'ordre au fournisseur de livrer une quantité à un prix déterminé ;
  • Bon de livraison : remis avec la marchandise (3 exemplaires, l'un signé = bon de réception) — le prix n'y figure pas ;
  • Facture : écrit dressé par un commerçant constatant les conditions de vente/livraison/prestation — document principal.

Frais accessoires d'achat : transport, douane… → dans le compte d'achat concerné ou en 6015/6025/6045/6085. Contrepartie recommandée : toujours 401 pour les biens/services, 481/404 pour les immobilisations (facilite le tableau de flux de trésorerie).
Ex. facture : caisse enregistreuse 300 (immobilisation 2443) + ordinateurs 2 000 (marchandises 6011) + papier 500 (dont 50 non stockable 6055) + transport 280 (frais sur achats) + TVA récupérable 308 → D comptes achats/immobilisations/445 / C 4812 + 4011.

IV. Factures avec effets commerciaux et financiers

Éléments soustractifs

ÉlémentDéfinitionComptabilisation
RetourMarchandises/matières retournées → facture d'avoirClient : D 401 / C 60… ; Fournisseur : D 70… / C 411
RabaisRéduction pour défaut de qualité/conformité → le bienContre-passé comme un retour
RemiseRéduction pour importance de l'opération ou profession du client → la personneIdem ; si ventilation impossible : 6019-6089 (achats)
RistourneRéduction sur un ensemble d'opérations d'une période → fidélitéIdem ; pas de compte « RRR accordés »
Escompte de règlementRéduction pour paiement anticipé, en % simple du netEn 673 (accordé) / 773 (obtenu), au moment du règlement

Éléments additifs

  • Ports et emballages facturés : fournisseur → produits accessoires en 7071 ; client → majoration du coût d'achat (compte 2 ou 60) ;
  • Emballages consignés : fournisseur → 4194 (dette) ; client → 4094 (créance) ; retour = contre-passation ; boni fournisseur en 7074 / mali client en 6224 ; non retourné = vendu (7074) ou acheté (6082) ;
  • Taxes non récupérables + TVA (supposée récupérable).
Calcul complet (ex. d'application 20) : Brut 28 500 000 → rabais 4 % → remise 5 % → escompte 2,5 % sur le net → base taxable 25 342 200 → TVA 18 % = 4 561 596 → TTC 29 903 796 F.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre remise (personne), rabais (bien) et ristourne (période/fidélité).
  • Oublier que l'escompte de règlement s'enregistre au moment du paiement (673/773), pas sur la facture.
  • Mettre les réductions dans un compte « RRR » → le SYSCOHADA impose la contre-passation directe sur les comptes d'achats/ventes.
  • Inverser 4194 (fournisseur, dette) et 4094 (client, créance) pour les emballages consignés.
  • Oublier la TVA dans le calcul du prix : la base taxable = HT après rabais/remise/escompte.
