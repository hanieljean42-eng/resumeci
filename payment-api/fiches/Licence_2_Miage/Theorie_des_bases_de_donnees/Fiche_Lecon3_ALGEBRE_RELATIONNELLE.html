I. Qu'est-ce que l'algèbre relationnelle ?

Ensemble d'opérateurs permettant d'interroger une base relationnelle — c'est le fondement du langage SQL. Deux familles : les opérateurs ensemblistes et les opérateurs relationnels.

II. Opérateurs ensemblistes

OpérateurFormalismeSignificationLogique
UnionR = R1 ∪ R2Occurrences dans R1 ou R2 ou les deuxOU
IntersectionR = R1 ∩ R2Occurrences présentes dans les deuxET
DifférenceR = R1 − R2Occurrences de R1 sans appartenir à R2—
Produit cartésienR = R1 × R2Chaque ligne de R1 concaténée à chaque ligne de R2—
  • Union : pas de duplication des n-uplets ;
  • Différence : NON commutative — R1−R2 ≠ R2−R1 ;
  • Produit cartésien : toutes les combinaisons possibles d'association.

III. Opérateurs relationnels

1. Sélection

Extrait d'une relation les occurrences satisfaisant des critères — filtre les lignes.
R2 = SELECTION(R1, critère(s))   -- ex. Ville = 'Rissani'

Opérateurs : comparaison (=, ≠, <, >…), ET, OU, NON. Correspond au WHERE de SQL.

2. Projection

Met en place une nouvelle relation en ne retenant que certaines colonnes (attributs) — conserve les lignes mais élimine les doublons.
R2 = PROJECTION(R1, attributs)   -- ex. Nom, Prénom

Correspond au SELECT de SQL.

3. Jointure

Crée une nouvelle table à partir de deux tables ayant un champ commun (attribut) vérifiant un critère de jointure.
R = JOINTURE(R1, R2, R1.attr_jointure op_comparaison R2.attr_jointure)
  = R1 ⋈ R2 (R1.attr_jointure = R2.attr_jointure)

Ex du cours : Nom, Prénom, Libellé ← jointure ETUDIANT ⋈ FILIERE sur IdFilière.

4. Division

Trouve les occurrences d'une table associées à toutes les occurrences d'une autre table (souvent le résultat d'une sélection).
R = DIVISION(R1, R2)   -- ex. étudiants inscrits à TOUS les cours

IV. Application — exercices corrigés

Schéma de base : ETUDIANT(IdEtu, Nom, Prenom, Ville, IdFiliere), FILIERE(IdFiliere, Libelle), COURS(IdCours, Intitule, Credit, IdFiliere), INSCRIPTION(IdEtu, IdCours, Annee, Note).

ExerciceRequête algébrique
Étudiants d'Abidjan (Nom, Prénom, Ville)Nom,Prenom,Ville ( Ville='Abidjan' (ETUDIANT) )
Filière 3 à BouakéNom,Prenom ( IdFiliere=3 ∧ Ville='Bouaké' (ETUDIANT) )
Nom + filière de chaque étudiantNom,Prenom,Libelle ( ETUDIANT ⋈ ETUDIANT.IdFiliere=FILIERE.IdFiliere FILIERE )
Étudiants inscrits au cours 10Nom,Prenom ( ETUDIANT ⋈ ETUDIANT.IdEtu=INSCRIPTION.IdEtu IdCours=10(INSCRIPTION) )

Méthode : filtrer d'abord (sélection), puis joindre, puis projeter — l'ordre des opérations compte.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre sélection (filtre les lignes) et projection (filtre les colonnes).
  • Confondre intersection (ET, dans les deux) et union (OU, dans l'une ou l'autre).
  • Oublier que la différence est non commutative.
  • Confondre produit cartésien (toutes les combinaisons) et jointure (selon un critère).
  • Dans une requête composée : appliquer la sélection sur la bonne table avant la jointure.
  • Projection : le résultat élimine les doublons.
