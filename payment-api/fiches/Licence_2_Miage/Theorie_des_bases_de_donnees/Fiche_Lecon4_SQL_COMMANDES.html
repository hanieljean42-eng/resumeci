I. Qu'est-ce que SQL ?

SQL = Structured Query Language (Langage de Requête Structurée). Langage permettant d'administrer la base de données et de gérer les contrôles d'accès. Fondement : l'algèbre relationnelle.

Les 5 catégories de commandes

CatégorieNom completRôleCommandes
DDLData Definition LanguageManipuler les structures (tables, index…)CREATE, ALTER, DROP
DQLData Query LanguageRécupérer les donnéesSELECT
DMLData Manipulation LanguageManipuler les donnéesINSERT, UPDATE, DELETE
DCLData Control LanguageContrôler les accès aux donnéesGRANT, REVOKE

(Une 5e catégorie — TCL, transactions : COMMIT, ROLLBACK — est aussi citée dans le cours.)

II. DDL — Définir la structure

  • CREATE TABLE nom (colonne TYPE [contrainte], ...) ;
  • ALTER TABLE : modifier une table ; DROP TABLE : supprimer ;
  • PRIMARY KEY : indique la clé primaire ;
  • FOREIGN KEY ... REFERENCES : clé étrangère ;
  • CREATE INDEX : accélérer les recherches.

III. DQL — Interroger

SELECT Nom FROM Etudiant;          -- une colonne
SELECT * FROM Etudiant;            -- toutes les colonnes

La requête SELECT peut avoir des sous-commandes : WHERE (filtre), GROUP BY, ORDER BY, et opérateurs ensemblistes UNION | INTERSECT | EXCEPT.

IV. DML — Manipuler les données

  • INSERT INTO table (col) VALUES (...) — insérer ;
  • UPDATE table SET col = val WHERE ... — modifier ;
  • DELETE FROM table WHERE ... — supprimer ;
  • Sans WHERE, UPDATE/DELETE agissent sur toutes les lignes.

V. DCL — Contrôler les accès

GRANT SELECT ON Etudiant TO User1;   -- accorder un privilège
GRANT SELECT ON Etudiant TO User1 WITH GRANT OPTION;  -- peut retransmettre
REVOKE SELECT ON Etudiant FROM User1;  -- retirer le privilège

GRANT accorde une autorisation ; REVOKE l'annule. WITH GRANT OPTION permet au bénéficiaire de répercuter le privilège.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre DQL (SELECT = interroger) et DML (INSERT/UPDATE/DELETE = manipuler) et DDL (structure).
  • Oublier que SQL est fondé sur l'algèbre relationnelle.
  • Confondre GRANT (donner) et REVOKE (retirer).
  • SELECT * = toutes les colonnes ; SELECT col = une colonne.
  • Oublier le WHERE sur UPDATE/DELETE → effet global.
