Première C Mathématiques Équations et inéquations du second degré dans ℝ

I. Discriminant d'un polynôme du second degré

Discriminant : Pour le polynôme P(x) = ax² + bx + c (a ≠ 0), le discriminant est le réel noté Δ défini par : Δ = b² − 4ac.
Les trois cas selon le signe de Δ :
  • Δ > 0 : P admet deux zéros distincts x₁ = (−b−√Δ)/2a et x₂ = (−b+√Δ)/2a → P(x) = a(x−x₁)(x−x₂)
  • Δ = 0 : P admet un zéro double x₀ = −b/2a → P(x) = a(x−x₀)²
  • Δ < 0 : P n'admet pas de zéro → P n'est pas factorisable dans ℝ

II. Équations du second degré

Équation du second degré : Toute équation de la forme x ∈ ℝ, ax² + bx + c = 0, où a, b, c sont des réels et a ≠ 0.
Méthode de résolution : Résoudre ax² + bx + c = 0 revient à déterminer les zéros du polynôme P(x) = ax² + bx + c grâce au discriminant Δ.
⚠️ Astuce rapide : Si a et c sont de signes contraires, alors Δ = b² − 4ac > 0 automatiquement : l'équation admet forcément deux solutions distinctes.
Résolution graphique : Les solutions de f(x) = 0 sont les abscisses des points d'intersection de la courbe (Cf) avec l'axe des abscisses.

III. Signe d'un polynôme du second degré

Règle des signes :
  • Δ > 0 : P(x) est du signe de a à l'extérieur des racines, et du signe contraire de a entre les racines.
  • Δ = 0 : P(x) est du signe de a partout, et s'annule en x₀.
  • Δ < 0 : P(x) est du signe de a pour tout x ∈ ℝ.

IV. Inéquations du second degré

Inéquation du second degré : Toute inéquation de l'un des types : P(x) > 0 ; P(x) ≥ 0 ; P(x) < 0 ; P(x) ≤ 0, avec P(x) = ax² + bx + c (a ≠ 0).
Méthode : Calculer Δ → trouver les zéros → dresser le tableau de signes → lire l'intervalle correspondant à l'inéquation. Exemple : 2x² − 5x + 3 < 0 (Δ = 1, zéros 1 et 3/2) → S = ]1 ; 3/2[.

V. Équations se ramenant au second degré

1. Équations bicarrées

Équation bicarrée : Équation du type ax⁴ + bx² + c = 0 (a ≠ 0).
Méthode : Poser X = x² → résoudre aX² + bX + c = 0 → pour chaque solution positive X, résoudre x² = X (x = ±√X).

2. Équations et inéquations irrationnelles

Équation √P(x) = Q(x) :
  • √P(x) = Q(x) ⟺ { Q(x) ≥ 0 et P(x) = [Q(x)]² }
Inéquation √P(x) < Q(x) :
  • √P(x) < Q(x) ⟺ { P(x) ≥ 0 ; Q(x) ≥ 0 ; P(x) < [Q(x)]² }
Inéquation √P(x) ≥ Q(x) :
  • √P(x) ≥ Q(x) ⟺ { Q(x) ≥ 0 et P(x) ≥ [Q(x)]² } OU { P(x) ≥ 0 et Q(x) ≤ 0 }

VI. Somme et produit de deux nombres

Propriété : Deux nombres de somme S et de produit P sont les solutions de l'équation x² − Sx + P = 0. Ils existent si et seulement si S² − 4P ≥ 0.
⚠️ Pièges fréquents :
  • Ne pas oublier la condition a ≠ 0 pour parler d'équation du second degré.
  • Dans les inéquations irrationnelles, toujours poser les conditions d'existence AVANT d'élever au carré (sinon solutions parasites).
  • Pour Δ < 0, le polynôme garde un signe constant : celui de a.
  • Penser à exclure les bornes quand l'inégalité est stricte.
