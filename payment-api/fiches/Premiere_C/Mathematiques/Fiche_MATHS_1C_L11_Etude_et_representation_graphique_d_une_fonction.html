Première C Mathématiques Étude et représentation graphique d'une fonction

I. Parité d'une fonction

Ensemble symétrique par rapport à 0 : ∀x ∈ E, −x ∈ E.
Fonction paire : ∀x ∈ Df, −x ∈ Df et f(−x) = f(x) → (OJ) est axe de symétrie de (Cf). Exemples : x², |x|, cos x, constantes.
Fonction impaire : ∀x ∈ Df, −x ∈ Df et f(−x) = −f(x) → O est centre de symétrie de (Cf). Exemples : x, x³, 1/x, sin x.
⚠️ Vérifier d'abord Df : si Df n'est pas symétrique par rapport à 0 (ex. ℝ\{1}), la fonction est ni paire ni impaire — inutile de calculer f(−x).
Intérêt : fonction paire ou impaire → étude limitée à Df ∩ [0 ; +∞[, courbe complétée par symétrie.

II. Éléments de symétrie d'une courbe

1. Axe de symétrie x = a

Critère : la droite x = a est axe de symétrie de (Cf) ⟺ pour tout x de Df :
(2a − x) ∈ Df et f(2a − x) = f(x)
Autre forme : f(a + h) = f(a − h) pour tout h tel que a + h ∈ Df.
Exemple : f(x) = −2(x−3)² + 5 → f(6−x) = f(x) → x = 3 axe de symétrie.

2. Centre de symétrie A(a ; b)

Critère : le point A(a ; b) est centre de symétrie de (Cf) ⟺ pour tout x de Df :
(2a − x) ∈ Df et f(2a − x) + f(x) = 2b
Autre forme : [f(a + h) + f(a − h)]/2 = b.
Exemple : g(x) = (x−2)³ + 3 → g(4−x) + g(x) = 6 = 2×3 → A(2 ; 3) centre de symétrie.
Astuce pratique : pour démontrer que A(a ; b) est centre de symétrie, poser g(x) = f(x + a) − b et montrer que g est impaire (Dg symétrique et g(−x) = −g(x)).

3. Fonction périodique

T-périodique (T > 0) : ∀x ∈ Df : x + T ∈ Df, x − T ∈ Df et f(x + T) = f(x).
Exemples : sin et cos → période 2π ; tan → période π ; x ↦ sin(2x) → période π.
Conséquence : il suffit d'étudier f sur Df ∩ [a ; a + T[ (une période), puis compléter la courbe par les translations de vecteurs kT·OI⃗. Combiné avec la parité : une fonction impaire 2π-périodique s'étudie sur [0 ; π].

III. Asymptote oblique

Définition : la droite y = ax + b (a ≠ 0) est asymptote oblique à (Cf) en +∞ (resp. −∞) lorsque :
limx→+∞ [f(x) − (ax + b)] = 0 (resp. en −∞).
Méthode (fonction rationnelle) : effectuer la division euclidienne pour écrire f(x) = ax + b + r(x) avec limx→±∞ r(x) = 0 → y = ax + b asymptote oblique.
Exemple : f(x) = (2x²+3x−1)/(x−1) = 2x + 5 + 4/(x−1) → y = 2x + 5 asymptote en ±∞.
Position de (Cf) par rapport à l'asymptote : étudier le signe de f(x) − (ax + b) :
  • f(x) − (ax+b) > 0 → (Cf) au-dessus ;
  • f(x) − (ax+b) < 0 → (Cf) en dessous.
Même méthode pour la position par rapport à une tangente : calculer f(x) − yT et étudier son signe.

IV. Plan complet d'étude d'une fonction

Étapes dans l'ordre :
  1. Ensemble de définition Df ;
  2. Parité / périodicité → restreindre le domaine d'étude ;
  3. Limites aux bornes de Df → asymptotes verticales, horizontales, obliques ;
  4. Dérivée f′ → signe → variations → tableau de variation (avec limites et extremums) ;
  5. Éléments de symétrie éventuels (centre, axe) ;
  6. Tangentes remarquables et positions relatives ;
  7. Construction : tracer les asymptotes, les tangentes, placer les extremums, puis la courbe.
⚠️ Pièges fréquents :
  • Un extremum nécessite que f′ s'annule ET change de signe ;
  • Pour une asymptote oblique, la limite de f elle-même est infinie — c'est la limite de f(x) − (ax+b) qui doit être nulle ;
  • Si Df exclut une valeur a, toujours calculer les deux limites latérales en a ;
  • Ne pas oublier dans le tableau de variation les valeurs interdites (double barre) et les limites aux bornes.
