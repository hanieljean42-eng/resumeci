Première C Physique-Chimie Classification quantitative des couples redox

I. La pile électrochimique

Principe : séparer les deux couples redox et faire circuler les électrons par un circuit extérieur → la réaction d'oxydoréduction produit de l'électricité. Une pile transforme l'énergie chimique en énergie électrique.
La pile Daniell : lame de Zn dans une solution de sulfate de zinc + lame de Cu dans une solution de sulfate de cuivre ; pont salin (KCl ou KNO₃) assurant le contact ionique.
  • Pôle − (anode, Zn) : oxydation — Zn → Zn²⁺ + 2e⁻ (la lame s'use) ;
  • Pôle + (cathode, Cu) : réduction — Cu²⁺ + 2e⁻ → Cu (dépôt de cuivre) ;
  • Bilan : Zn + Cu²⁺ → Zn²⁺ + Cu.
Notation conventionnelle : (−) Zn | Zn²⁺ ‖ Cu²⁺ | Cu (+)
Règle des pôles :
  • Pôle négatif = métal le plus réducteur = siège de l'oxydation ;
  • Pôle positif = métal le moins réducteur = siège de la réduction.

II. Potentiel d'oxydoréduction

Électrode standard à hydrogène (ESH) : référence du couple H⁺/H₂, de potentiel E° = 0,00 V (pH = 0, P = 1 atm) ; 2H⁺ + 2e⁻ → H₂.
Potentiel redox d'un couple : f.é.m. de la pile formée par la demi-pile Mⁿ⁺/M associée à l'ESH : EMⁿ⁺/M = VM − VESH.
Potentiel normal E° : mesuré à concentration 1 mol/L et 298 K. Ex. E°(Cu²⁺/Cu) = +0,34 V.
f.é.m. d'une pile :
E = E°(couple du pôle +) − E°(couple du pôle −)
Exemple : pile Fe/Ag → E = 0,80 − (−0,44) = 1,24 V.

III. Classification quantitative

Échelle des potentiels standards :
CoupleZn²⁺/ZnFe²⁺/FePb²⁺/PbH⁺/H₂Cu²⁺/CuAg⁺/Ag
E° (V)−0,77−0,44−0,130,00+0,34+0,80
  • ↑ E° élevé → oxydant fort (pouvoir oxydant croissant vers le haut) ;
  • ↓ E° faible → réducteur fort (pouvoir réducteur croissant vers le bas).
Prévision des réactions : seule réaction spontanée possible = celle de l'oxydant le plus fort avec le réducteur le plus fort (règle de gamma).
Dans une pile : pôle + = couple de plus fort potentiel ; pôle − = couple de plus faible potentiel.

IV. Quelques piles usuelles

  • Pile de Volta (1800) : Zn + 2H₂O → Zn²⁺ + 2HO⁻ + H₂ ;
  • Pile Leclanché (saline) : Zn + 2MnO₂ + 2H⁺ → Zn²⁺ + 2MnO(OH) ;
  • Pile alcaline : électrolyte basique (ex. Duracell) ;
  • Accumulateurs : rechargeables — décharge spontanée en usage, recharge par électrolyse (courant imposé inverse).
Une pile usagée (réactif consommé) ne se recharge pas — seuls les accumulateurs le permettent.
⚠️ Pièges fréquents :
  • Pôle négatif ≠ pôle « − » dans la convention française : c'est l'anode (oxydation) — le métal s'use ;
  • La masse de l'électrode oxydée diminue, celle de l'électrode réduite augmente ;
  • E = E°(+) − E°(−) : toujours positif par construction ;
  • Attention aux coefficients : Ag⁺ + e⁻ → Ag nécessite 2 Ag⁺ face à Zn (2e⁻).
