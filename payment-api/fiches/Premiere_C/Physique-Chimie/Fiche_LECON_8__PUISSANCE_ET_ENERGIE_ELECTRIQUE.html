Première C Physique-Chimie Puissance et énergie électrique

I. Le conducteur ohmique (résistor)

Loi d'Ohm : U = R·I (U en V, R en Ω, I en A).
Conductance : G = 1/R, en siemens (S) → I = G·U.
Bilan énergétique — effet Joule :
Énergie reçue : Ereçue = UAB·I·t = R·I²·t
Puissance reçue : P = U·I = R·I² = U²/R
Toute l'énergie reçue est transformée en chaleur : le résistor est un dipôle purement thermique (puissance Joule PJ).

II. Le générateur (pile)

Loi d'Ohm pour un générateur (E, r) : UPN = E − r·I
UPN : tension aux bornes (V) ; E : f.é.m. (V) ; r : résistance interne (Ω).
Bilan des puissances :
Pfournie = UPN·I = E·I − r·I²
• Pengendrée = E·I — puissance issue des transformations chimiques ;
• Pfournie = U·I — puissance disponible à la sortie ;
• r·I² — puissance dissipée par effet Joule dans la résistance interne.

III. Les récepteurs actifs (électrolyseur, moteur)

Loi d'Ohm pour un récepteur (E′, r′) : U = E′ + r′·I
E′ : force contre-électromotrice (f.c.é.m.) ; r′ : résistance interne.
Caractéristique U = f(I) : droite de pente r′ et d'ordonnée à l'origine E′ (courant nul si U < E′).
Bilan énergétique :
Ereçue = U·I·Δt = E′·I·Δt + r′·I²·Δt = Eutile + Ethermique
• E′·I·Δt : énergie utile (transformée en énergie chimique ou mécanique) ;
• r′·I²·Δt : énergie perdue en chaleur (effet Joule).

IV. Loi de Pouillet

Dans un circuit série comportant générateurs (E) et récepteurs (E′) :
I = (ΣE − ΣE′) / ΣR
obtenue par la loi des mailles : E − E′ = (R + r + r′)·I.

V. Rendement électrique

Rendement η = puissance utile / puissance reçue (toujours < 1) :
  • Générateur : η = Pfournie/Pengendrée = UPN/E = 1 − rI/E ;
  • Récepteur : η = Putile/Preçue = E′/U = E′/(E′ + r′I).
Exemple : récepteur E′ = 6 V, r′ = 2 Ω, I = 0,5 A → η = 6/(6 + 1) ≈ 0,86 = 86%.
⚠️ Pièges fréquents :
  • Ne pas confondre f.é.m. E (générateur) et f.c.é.m. E′ (récepteur) : signes opposés dans les tensions (U = E − rI vs U = E′ + r′I) ;
  • Dans Pouillet : soustraire les E′ des récepteurs, additionner toutes les résistances (internes comprises) ;
  • Un récepteur bloqué (moteur arrêté) se comporte comme une résistance : E′ = 0 → Imax = U/r′ (danger de surintensité) ;
  • Un résistor n'a pas de f.c.é.m. : toute la puissance reçue devient chaleur.
