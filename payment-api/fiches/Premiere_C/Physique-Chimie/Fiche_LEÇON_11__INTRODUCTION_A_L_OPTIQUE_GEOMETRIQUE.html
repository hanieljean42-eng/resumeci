Première C Physique-Chimie Introduction à l'optique géométrique

I. Sources, récepteurs et milieux

Source primaire : produit la lumière qu'elle émet (Soleil, lampe allumée).
Source secondaire : diffuse la lumière reçue d'une source primaire (Lune, miroir, chaise).
Récepteur de lumière : corps sensible à la lumière qui subit une transformation (œil, chlorophylle, photorésistance).
Milieu de propagation : milieu transparent/translucide qui laisse passer la lumière (verre, eau, air, vide) — caractérisé par son indice de réfraction n.

II. Célérité et indice de réfraction

Célérité de la lumière : dans le vide c = 3·10⁸ m·s⁻¹.
Indice de réfraction : n = c/v → v = c/n

Exemple : v dans un verre n = 1,6 → v = 3·10⁸/1,6 ≈ 1,9·10⁸ m/s.

III. Rayons et faisceaux lumineux

Rayon lumineux : dans un milieu homogène, la lumière se propage en ligne droite ; le trajet est représenté par une demi-droite fléchée.
Faisceau lumineux : ensemble de rayons issus d'une même source — parallèles, convergents ou divergents.
Principe du retour inverse : le chemin suivi par la lumière est indépendant du sens de propagation.

IV. Onde lumineuse

Nature : la lumière est une onde (électromagnétique) qui se propage même dans le vide ; fonction sinusoïdale du temps.
  • Période T (s) ; fréquence N = 1/T (hertz, Hz) ;
  • Longueur d'onde λ : distance parcourue pendant une période (m) ; λ = c/N = c·T dans le vide ;
  • Célérité : c = d/Δt.
Lumière monochromatique : une seule couleur → une seule longueur d'onde λ (ex. laser).
Domaine visible : 400 nm (violet) à 750–800 nm (rouge) ; en deçà : UV ; au-delà : IR.
Changement de milieu : la fréquence reste constante, mais λ change : λ′ = λ₀/n.
Exemple : λ₀ = 600 nm dans l'alcool n = 1,36 → λ′ = 441 nm ; N = c/λ₀ = 5·10¹⁴ Hz.

V. Méthode — retard lumière/son

Principe : la lumière arrive quasi instantanément (c = 3·10⁸ m/s) ; le son beaucoup plus lentement (340 m/s).
Retard perçu : Δt = D/c′ − D/c → D = c·c′·Δt/(c − c′)
Exemple : orage à D = 10 km → tonnerre en 29,4 s, éclair en 3,3·10⁻⁵ s.
⚠️ Pièges fréquents :
  • La Lune est une source secondaire (elle réfléchit la lumière du Soleil) ;
  • La lumière blanche est polychromatique (somme de toutes les λ visibles) ;
  • En changeant de milieu : c'est λ qui varie, pas la fréquence N ;
  • n > 1 toujours (v < c dans tout milieu matériel) ;
  • Bien convertir : 1 nm = 10⁻⁹ m.
