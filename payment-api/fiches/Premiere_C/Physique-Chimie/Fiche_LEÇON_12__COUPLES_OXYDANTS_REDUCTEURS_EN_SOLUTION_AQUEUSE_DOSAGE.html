Première C Physique-Chimie Couples redox en solution aqueuse. Dosage

I. Rappels et couples étudiés

Oxydant : espèce qui capte des électrons (réduction).
Réducteur : espèce qui cède des électrons (oxydation).
Un couple Ox/Red est lié par : Ox + ne⁻ ⇌ Red.
Couples classiques à connaître :
Couple Ox/RedDemi-équationE° (V)
MnO₄⁻/Mn²⁺MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O1,52
Cr₂O₇²⁻/Cr³⁺Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O1,33
Fe³⁺/Fe²⁺Fe³⁺ + e⁻ → Fe²⁺0,66
I₂/I⁻I₂ + 2e⁻ → 2I⁻0,54
S₄O₆²⁻/S₂O₃²⁻S₄O₆²⁻ + 2e⁻ → 2S₂O₃²⁻0,08
CH₃COOH/CH₃CH₂OHCH₃COOH + 4H⁺ + 4e⁻ → CH₃CH₂OH + H₂O0,04

II. Équilibrer une équation d'oxydoréduction

Méthode des demi-équations :
  1. Écrire la demi-équation de chaque couple (équilibrer les atomes avec H₂O et H⁺, puis les charges avec e⁻) ;
  2. Multiplier pour avoir le même nombre d'électrons échangés ;
  3. Additionner — les e⁻ s'éliminent.
Exemple (alcootest) : 2 Cr₂O₇²⁻ + 16 H⁺ + 3 CH₃CH₂OH → 4 Cr³⁺ + 11 H₂O + 3 CH₃COOH
(dichromate orange → chrome III vert : changement de couleur révélant l'éthanol).

III. Prévision des réactions (règle de gamma)

Règle : entre deux couples Ox₁/Red₁ (E₁°) et Ox₂/Red₂ (E₂°) :
Si E₁° > E₂° → Ox₁ oxyde Red₂ (l'oxydant du couple de plus fort potentiel réagit avec le réducteur de l'autre).
Réaction considérée totale si E₁° − E₂° ≥ 0,3 V.
Exemple : I₂/I⁻ (0,54 V) > S₄O₆²⁻/S₂O₃²⁻ (0,08 V) → I₂ + 2S₂O₃²⁻ → 2I⁻ + S₄O₆²⁻.

IV. Dosage par oxydoréduction

Doser : déterminer la concentration molaire d'une espèce en solution.
Principe : solution de concentration inconnue dans le bécher (volume connu) ; solution titrante de concentration connue dans la burette ; on verse jusqu'au changement de couleur → équivalence.
Exemple — dosage de Fe²⁺ par MnO₄⁻ :
Équation : 5 Fe²⁺ + MnO₄⁻ + 8H⁺ → 5 Fe³⁺ + Mn²⁺ + 4H₂O
À l'équivalence : teinte violette persistante du permanganate.
Bilan molaire : n(Fe²⁺) = 5·n(MnO₄⁻) → Cr = 5·C₀·V₀eq/Vr.
Dosage en retour (exemple) : Cr₂O₇²⁻ + I⁻ (excès) → I₂ formé, puis I₂ dosé par S₂O₃²⁻ :
• n(I₂) = n(S₂O₃²⁻)/2 ; • n(Cr₂O₇²⁻) = n(I₂)/3 → remonter à la concentration inconnue.
⚠️ Pièges fréquents :
  • L'oxydation de l'éthanol nécessite un milieu acide (acide sulfurique, pas de soude) ;
  • Écrire H⁺ ou H₃O⁺ : si on utilise H₃O⁺, équilibrer avec H₂O en conséquence (H⁺ + H₂O = H₃O⁺) ;
  • À l'équivalence : ce sont les quantités de matière qui sont en rapport stœchiométrique, pas les volumes ;
  • Bien compter le coefficient devant les électrons avant d'additionner les demi-équations.
