Première C Physique-Chimie L'amplificateur opérationnel

I. Description et caractéristiques

L'amplificateur opérationnel (AO) est un circuit intégré linéaire présenté sous forme d'un boîtier à 8 bornes :
• Borne 2 : entrée inverseuse E− ; borne 3 : entrée non inverseuse E+ ;
• Bornes 4 et 7 : alimentations (−Vcc et +Vcc) ; borne 6 : sortie S ;
• Bornes 1 et 5 : réglage d'offset ; borne 8 : non connectée.
Tension différentielle : Ud = V⁺ − V⁻.

II. Les deux régimes de fonctionnement

Régime linéaire : zone centrale où Us = G·Ud ; G = gain différentiel (très grand — infini pour l'AO idéal).
Régime saturé : Us = +Vsat ou −Vsat ; on a toujours |±Vsat| < |±Vcc|.
Propriétés de l'AO idéal en régime linéaire :
  • Résistance d'entrée infinie → i⁺ = i⁻ = 0 ;
  • Ud = 0 → E⁺ et E− au même potentiel ;
  • |Us| < Vsat.
En régime saturé : Ud ≠ 0 et Us = ±Vsat (deux états seulement).

III. Montages en régime linéaire

MontagePrincipeRelation / Gain
SuiveurUe sur E⁺, sortie rebouclée sur E−Us = Ue (adaptateur d'impédance, ex. voltmètre)
Amplificateur inverseurUe via R₁ sur E− ; R₂ contre-réactionUs = −(R₂/R₁)·Ue ; G = R₂/R₁
Amplificateur non inverseurUe sur E⁺ ; R₁ et R₂ en diviseur sur E−Us = (1 + R₂/R₁)·Ue ; G = 1 + R₂/R₁
Sommateur inverseurPlusieurs entrées U₁, U₂ via R₁, R₂Us = −R₃·(U₁/R₁ + U₂/R₂)
Exemples : inverseur avec R₂ = 2R₁ → Us = −2Ue ; non inverseur avec R₂ = 2R₁ → G = 3.

IV. Régime saturé : le comparateur

Montage comparateur : U₁ = tension de référence, U₂ = tension à comparer. Ud = U₂ − U₁ :
• U₂ > U₁ → Ud > 0 → Us = +Vsat ;
• U₂ < U₁ → Ud < 0 → Us = −Vsat.
La sortie compare deux tensions et bascule entre deux états — principe des traitements numériques.
⚠️ Pièges fréquents :
  • Distinguer la réalisation du montage : l'entrée de la source Ue détermine le type (inverseur = entrée sur E− ; non inverseur = entrée sur E⁺) ;
  • Le signe « − » du montage inverseur compte : Us = −(R₂/R₁)Ue ≠ gain positif ;
  • En linéaire : Ud = 0 (E− « masse virtuelle » quand E⁺ est à la masse) ;
  • Us ne peut jamais dépasser ±Vsat, lui-même < ±Vcc ;
  • Pour établir les relations : écrire les lois de mailles + loi des nœuds avec i⁻ = 0 et Ud = 0.
