Première C SVT La gamétogénèse chez les mammifères

I. Les gonades produisent les cellules sexuelles

Preuves expérimentales : castration du rat → stérilité ; ligature des spermiductes → stérilité ; destruction des tubes séminifères → stérilité ; ovariectomie ou ligature des oviductes chez la rate → stérilité.
Conclusion : les testicules (tubes séminifères) produisent les spermatozoïdes ; les ovaires produisent les ovocytes. C'est la fonction exocrine des gonades.

II. La spermatogénèse (4 phases)

  1. Multiplication : les spermatogonies (2n), cellules souches à la périphérie du tube séminifère, se multiplient par mitoses — dès la puberté, en continu ;
  2. Accroissement : légère croissance → spermatocyte I (2n) ;
  3. Maturation : méiose — 1ʳᵉ division réductionnelle : spermatocyte I → 2 spermatocytes II (n) ; 2ᵉ division équationnelle : → 4 spermatides (n) ;
  4. Différenciation (spermiogenèse) : profondes transformations de la spermatide → spermatozoïde.
Bilan : 1 spermatocyte I → 4 spermatozoïdes.

III. L'ovogenèse (3 phases, discontinue)

  1. Multiplication : les ovogonies (2n) se divisent par mitoses — avant la naissance, chez le fœtus ;
  2. Accroissement : forte accumulation de réserves → ovocyte I (2n), entouré de cellules folliculaires = follicule primordial. Après la naissance : long repos ;
  3. Maturation : à la puberté, méiose — 1ʳᵉ division : ovocyte I → ovocyte II (n) + 1ᵉʳ globule polaire ; 2ᵉ division bloquée en métaphase II : ovotide + 2ᵉ globule polaire (ne s'achève qu'à la fécondation).
Bilan : 1 ovocyte I → 1 seule cellule sexuelle (ovocyte II/ovotide) + globules polaires. Pas de différenciation.

IV. La méiose

1ʳᵉ division (réductionnelle) : prophase I (appariement des homologues + crossing-over) → métaphase I → anaphase I (séparation des chromosomes homologues) → télophase I : 2 cellules haploïdes.
2ᵉ division (équationnelle) : prophase II → métaphase II → anaphase II (séparation des chromatides) → télophase II : 4 cellules haploïdes.
Résultat : 1 cellule diploïde → 4 cellules haploïdes différentes entre elles et de la mère.
Biodiversité par deux brassages :
  • Inter-chromosomique : disposition aléatoire des paires de chromosomes en métaphase I ;
  • Intra-chromosomique (crossing-over) : échange de portions entre chromosomes homologues en prophase I.
Méiose atypique (mauvaise séparation) → gamètes anormaux → aberrations chromosomiques (ex. trisomie 21).

V. Comparaison spermatogenèse / ovogenèse

SpermatogenèseOvogenèse
CommunPhases multiplication + accroissement + maturation ; mitoses + méiose
DébutPuberté, continuVie embryonnaire, discontinu (ménopause)
AccroissementMoyenImportant (réserves)
DifférenciationOuiNon
Rendement4 spermatozoïdes1 ovocyte II + globules polaires
⚠️ Pièges fréquents :
  • La 1ʳᵉ division sépare les chromosomes homologues, la 2ᵉ les chromatides — ne pas inverser ;
  • L'ovocyte II est bloqué en métaphase II jusqu'à la fécondation ;
  • Les globules polaires sont de petites cellules non fonctionnelles qui dégénèrent ;
  • Les spermatozoïdes se forment dans les tubes séminifères, pas dans tout le testicule.
