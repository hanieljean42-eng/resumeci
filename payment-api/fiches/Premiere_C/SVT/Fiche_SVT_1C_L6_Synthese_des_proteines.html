Première C SVT La synthèse des protéines

I. Les acteurs de la synthèse protéique

  • ADN : support de l'information génétique ; sert de matrice (un seul brin, le brin codant / transcrit / informatif) ;
  • ARNm (messager) : copie de l'information de l'ADN ; la transporte du noyau vers le cytoplasme. Molécule monocaténaire, sucre = ribose, uracile (U) remplace la thymine ;
  • ARNt (transfert) : transporte les acides aminés ; son anticodon est complémentaire au codon de l'ARNm ;
  • Ribosome : granule cytoplasmique = « atelier » de fabrication ; lit l'ARNm (sites A et P) ;
  • Enzymes + ATP : catalyse et énergie nécessaires aux réactions.

II. Le code génétique

Correspondance entre les triplets de nucléotides de l'ARNm et les 20 acides aminés.
  • Codon : triplet de 3 bases de l'ARNm (U, C, G, A) = la plus petite unité du message génétique ; 64 codons au total ;
  • Codon initiateur : AUG (méthionine) — débute toute synthèse ;
  • Codons stop / non-sens : UAA, UAG, UGA — aucun acide aminé, marquent la fin du message ;
  • Code redondant : plusieurs codons peuvent désigner le même acide aminé (codons synonymes) ;
  • Anticodon : triplet de bases complémentaires au codon, porté par l'ARNt ;
  • Le code génétique est universel.

III. Le mécanisme : transcription puis traduction

1. Transcription — dans le noyau

L'ADN s'ouvre localement ; l'ARN polymérase se déplace le long du brin codant en associant les nucléotides libres par complémentarité (A↔U, T↔A, G↔C, C↔G) → formation de l'ARNm, qui sort du noyau vers le cytoplasme.

2. Traduction — dans le cytoplasme (3 étapes)

  • Initiation : l'ARNt portant la méthionine (anticodon UAC) se place sur le codon initiateur AUG au site P du ribosome ;
  • Élongation : un nouvel ARNt arrive en site A face au codon suivant → liaison peptidique entre les acides aminés ; le 1ᵉʳ ARNt est libéré, le ribosome avance ; ainsi de suite ;
  • Terminaison : le ribosome rencontre un codon stop → dissociation du complexe ARNm–ribosome–ARNt–chaîne polypeptidique ; la méthionine initiale est séparée du reste de la chaîne.
Plusieurs ribosomes lisent simultanément un même ARNm = polysome.

⚠️ Pièges fréquents :
  • L'ARNt transporte l'acide aminé ; c'est le ribosome qui lit l'ARNm (pas l'ARNt) ;
  • Dans l'ARNm, U remplace T : le codon AUG, pas ATG ;
  • Brin codant (transcrit) vs brin non transcrit — ne pas les confondre ;
  • La transcription produit de l'ARN, pas une protéine ;
  • Ordre : transcription (noyau) → puis traduction (cytoplasme) — jamais simultanées.
