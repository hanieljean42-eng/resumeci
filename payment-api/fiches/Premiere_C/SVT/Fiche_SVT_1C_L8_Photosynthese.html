Première C SVT La photosynthèse

I. Les facteurs de la photosynthèse

  • Lumière : l'intensité photosynthétique croît avec l'éclairement jusqu'à un maximum. Plantes sciaphiles (d'ombre, ex. fougère : max ~20 %) vs plantes héliophiles (de lumière, ex. tomate : max ~70 %) ;
  • CO₂ : le dégagement d'O₂ croît entre 0,025 % et 0,4 % puis se sature ; CO₂ de l'air (~0,003 %) = facteur limitant ;
  • Température : nulle à 0 °C (enzymes inhibées), croît jusqu'à ~30 °C, s'annule ~45 °C (enzymes dénaturées).
Point de compensation : éclairement où l'O₂ produit par la photosynthèse = l'O₂ consommé par la respiration (bilan nul). En dessous, l'intensité est « négative » car la respiration domine.

II. Les structures responsables

Expérience de la feuille panachée : après éclairage, décoloration à l'alcool bouillant et test à l'eau iodée → la partie verte se colore en bleu violacé (présence d'amidon) ; la partie non verte ne se colore pas.
→ La photosynthèse a lieu dans les chloroplastes : la chlorophylle des thylakoïdes capte l'énergie lumineuse.
Pigments (séparés par chromatographie) : chlorophylle a et b (verts), xanthophylles (jaunes), carotène (jaune orangé).

III. Le mécanisme : deux phases

1. Phase lumineuse (claire) — dans les thylakoïdes

  1. Photoexcitation : la lumière excite la chlorophylle → chlorophylle oxydée + électrons ; les e⁻ entrent dans la chaîne photosynthétique (chaîne d'oxydoréduction) ;
  2. Photolyse de l'eau : H₂O → 2H⁺ + ½O₂ + 2e⁻ — libération d'O₂ + électrons qui réduisent la chlorophylle ;
  3. Photophosphorylation : ADP + Pi → ATP (énergie chimique) ;
  4. Réduction du transporteur final : T⁺ + 2H⁺ + 2e⁻ → TH₂ (pouvoir réducteur).
Produits : ATP + TH₂ (énergie + réducteur) + O₂ libéré.

2. Phase sombre (assimilation) — dans le stroma : cycle de Calvin

  • Le CO₂ se fixe sur un sucre en C5, le ribulose diphosphate (Rudip), grâce à la carboxylase → sucre C6 instable → hydrolysé en 2 trioses (APG, acide phosphoglycérique, C3) ;
  • Grâce à l'ATP et au TH₂ de la phase lumineuse, les trioses servent à : régénérer le Rudip et fabriquer glucides, lipides, protides ;
  • L'ensemble des réactions = cycle de Calvin ; la phase sombre = phase d'assimilation (ne nécessite pas de lumière mais le CO₂).
6 CO₂ + 6 H₂O —(lumière, chlorophylle)→ C₆H₁₂O₆ + 6 O₂
Importance dans la biosphère :
  • La matière organique produite = nourriture des êtres vivants ;
  • L'O₂ dégagé sert à la respiration ;
  • L'absorption du CO₂ purifie l'air.
⚠️ Pièges fréquents :
  • La phase sombre ne signifie pas « dans l'obscurité permanente » : elle ne nécessite pas de lumière mais dépend des produits (ATP, TH₂) de la phase claire ;
  • L'O₂ dégagé vient de la photolyse de l'eau, pas du CO₂ ;
  • Phase lumineuse → thylakoïdes ; phase sombre → stroma ;
  • En dessous du point de compensation, la plante respire plus qu'elle ne photosynthétise ;
  • L'amidon est mis en évidence par l'eau iodée (bleu violacé), après décoloration à l'alcool bouillant.
