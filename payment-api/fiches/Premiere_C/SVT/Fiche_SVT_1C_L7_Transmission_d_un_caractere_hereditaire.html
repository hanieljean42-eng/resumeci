Première C SVT La transmission d'un caractère héréditaire

I. Vocabulaire essentiel

  • Gène : portion d'ADN du chromosome responsable de l'expression d'un caractère ; son emplacement = locus ;
  • Allèle : l'une des différentes formes d'un gène occupant un locus (ex. ABO : allèles A, B, O) ;
  • Phénotype : forme sous laquelle un caractère s'exprime (noté entre crochets : [gris]) ;
  • Génotype : ensemble des gènes d'un individu ;
  • Homozygote : deux allèles identiques (race pure) ; hétérozygote : deux allèles différents (hybride) ;
  • Dominant : allèle/phénotype qui s'exprime seul en F1 ; récessif : celui qui est masqué ;
  • Test-cross : croisement hybride F1 × parent homozygote récessif — les proportions reflètent les gamètes de l'individu testé ;
  • Monohybridisme : transmission d'un seul caractère gouverné par un couple d'allèles.

II. Cas 1 : dominance complète (pelage de la souris)

Croisements :
  • C1 : grise × blanche (races pures) → F1 homogène, 100 % grises → 1ʳᵉ loi de Mendel = uniformité des hybrides F1. Gris dominant, blanc récessif ;
  • C2 : F1 × F1 → F2 hétérogène : 54 grises / 18 blanches ≈ 3/4 ; 1/4 → gène autosomal avec dominance complète, parents hétérozygotes ;
  • C3 : F1 × blanche (test-cross) → 36 grises / 37 blanches ≈ 1/2 ; 1/2.
Symboles : initiale du récessif → b (blanc), B (gris dominant). Génotypes : blanche = b/b ; grise pure = B/B ; hybride = B/b.

III. Cas 2 : codominance (belle de nuit)

  • C1 : fleurs rouges × fleurs blanches → F1 homogène, toutes roses (phénotype intermédiaire) → codominance : aucun allèle ne domine l'autre ;
  • C2 : roses × roses → 120 rouges / 121 blanches / 242 roses ≈ 1/4 ; 1/2 ; 1/4.
Symboles : majuscules des deux phénotypes : allèle rouge R, blanc B ; génotype des roses = R/B ; phénotype rose = [RB].
Ségrégation en F2Interprétation
3/4 ; 1/4Parents hétérozygotes, dominance complète
1/4 ; 1/2 ; 1/4Parents hétérozygotes, codominance
1/2 ; 1/2Test-cross (F1 × homozygote récessif)
100 % (F1 homogène)Parents homozygotes de races pures
Méthode d'interprétation :
  1. Nommer le caractère et ses phénotypes ;
  2. F1 homogène ? → parents homozygotes + identifier dominant/récessif (ou codominance si intermédiaire) ;
  3. Calculer les proportions F2 → en déduire le type de transmission ;
  4. Choisir les symboles, écrire génotypes et gamètes ;
  5. Vérifier par l'échiquier de croisement (interprétation chromosomique).
⚠️ Pièges fréquents :
  • Le test-cross se fait avec l'homozygote récessif, pas dominant ;
  • F1 uniforme = parents de race pure, pas « toujours hétérogène » ;
  • 75 %/25 % apparaît en F2, pas en F1 ;
  • En codominance : 3 phénotypes possibles, pas 2 — le rose est un nouveau phénotype, pas un mélange dominant ;
  • La transmission d'un caractère est liée aux chromosomes (gènes au locus), transmise par les gamètes à la fécondation.
