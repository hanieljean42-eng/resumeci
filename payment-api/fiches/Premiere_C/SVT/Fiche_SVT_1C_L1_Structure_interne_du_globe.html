Première C SVT La structure interne du globe terrestre

I. Manifestations de l'activité interne

Les séismes (vibrations) et volcans révèlent l'activité interne du globe :
• Éruption volcanique : rejette des produits solides (cendres, bombes), liquides (coulées de lave), gazeux (fumerolles) ;
• Séisme : vibrations nées d'un relâchement brutal des tensions au foyer (hypocentre) ; le point de surface à sa verticale est l'épicentre.
Magnitude : énergie libérée, mesurée sur l'échelle de Richter.

III. Propagation et structure interne

Principe : la vitesse des ondes dépend de la nature du milieu traversé :
  • Vitesse constante → milieu homogène ;
  • Vitesse croissante → milieux de plus en plus denses ;
  • Chute brutale → passage à une couche différente = discontinuité.
Variations de vitesse → structure en couches concentriques :
  • 0 → 70 km : vitesse ↗ rapide = croûte (70 km sous continents, 6–7 km sous océans) ;
  • 70 km — chute : discontinuité de Mohorovicic ;
  • 70 → 2 900 km : manteau — supérieur (70–750 km : lithosphère en haut, asthénosphère visqueuse en bas) + inférieur solide (mésosphère) ;
  • 2 900 km — chute : discontinuité de Gutenberg ; ondes S disparaissent → noyau externe liquide ;
  • 5 100 km : discontinuité de Lehmann ; ondes S réapparaissent → noyau interne (graine) solide.

IV. Récapitulatif

Structure du globe :
  1. Croûte (continentale + océanique) — discontinuité de Moho ;
  2. Manteau (supérieur + inférieur) — discontinuité de Gutenberg à 2 900 km ;
  3. Noyau (externe liquide + interne solide) — discontinuité de Lehmann à 5 100 km.
⚠️ Pièges fréquents :
  • Les ondes S ne traversent pas les liquides → leur disparition à 2 900 km prouve que le noyau externe est liquide ;
  • Magnitude ≠ intensité : la magnitude mesure l'énergie libérée (Richter), l'intensité mesure les dégâts (variable selon le lieu) ;
  • La croûte est beaucoup plus fine sous les océans (6–7 km) que sous les continents (70 km) ;
  • L'asthénosphère (visqueuse) ≠ le noyau externe (liquide).
