I. Notations : intervalles et ensembles de nombres

Les intervalles

Un intervalle est un ensemble de nombres compris entre deux valeurs (ou borné d'un seul côté). Pour a < b :
  • [a ; b] : intervalle fermé — a et b sont inclus ;
  • ]a ; b] ou [a ; b[ : intervalle semi-ouvert ;
  • ]a ; +∞[ , ]-∞ ; b[ : bornés d'un seul côté.
Propriété : si a < b alors a < (a + b)/2 < b — le milieu de deux réels distincts est toujours strictement compris entre eux.

Les ensembles de nombres

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ — entiers naturels ⊂ entiers relatifs ⊂ décimaux ⊂ rationnels ⊂ réels.
Exemples : 2/3 ∉ ℤ (mais ∈ ℚ) ; √2 ∉ ℚ (irrationnel, mais ∈ ℝ).

II. La fonction inverse

La fonction inverse associe à tout réel non nul son inverse : f(x) = 1/x, définie sur ℝ* = ]-∞ ; 0[ ∪ ]0 ; +∞[.
Propriétés : 1/(a × b) = (1/a) × (1/b) ; 1/(a/b) = b/a (a, b ≠ 0).
Exemple de calcul : f(4) + f(1/2) = 1/4 + 2 = 9/4.

III. Calcul de pourcentages

  • x % de a : (x × a)/100 — ex. 15 % de 200 = 30 ;
  • Augmenter de x % : multiplier par (1 + x/100) ;
  • Diminuer de x % : multiplier par (1 − x/100).
Attention : augmenter de 20 % puis diminuer de 20 % ne ramène pas au prix initial : ×1,2 × 0,8 = ×0,96 (baisse de 4 %).

IV. Équations et inéquations

Résoudre f(x) = 0 (ou f(x) < 0, f(x) ≥ 0…) : trouver les valeurs de x du domaine de définition qui vérifient la condition.
  • x² − 4 = 0 ⇔ (x − 2)(x + 2) = 0 ⇔ x ∈ {−2 ; 2} ;
  • 1/x − 1 < 0 : domaine x ≠ 0, puis étude de signe sur ℝ* ;
  • Quotient : P(x)/Q(x) défini seulement si Q(x) ≠ 0.

V. Les polynômes

Polynôme : expression de la forme P(x) = a₀ + a₁x + a₂x² + … + aₙxⁿ (coefficients réels). Le degré est la plus grande puissance de x de coefficient non nul.

Le trinôme du second degré : ax² + bx + c

Discriminant : Δ = b² − 4ac
• Δ > 0 : deux racines x₁ = (−b − √Δ)/(2a) et x₂ = (−b + √Δ)/(2a) ; P(x) = a(x − x₁)(x − x₂)
• Δ = 0 : racine double x₀ = −b/(2a) ; P(x) = a(x − x₀)²
• Δ < 0 : pas de racine réelle — signe constant (celui de a).
Exemple : x² − 5x + 6 → Δ = 25 − 24 = 1 → racines 2 et 3 → x² − 5x + 6 = (x − 2)(x − 3).

VI. Fonctions rationnelles et irrationnelles

  • Fonction rationnelle : f(x) = P(x)/Q(x) avec P, Q polynômes — définie là où Q(x) ≠ 0.
  • Fonction irrationnelle : contient des radicaux (√x) — définie là où la quantité sous la racine est ≥ 0.

VII. La notion de fonction

Une fonction f d'un ensemble A vers un ensemble B est un processus qui associe à chaque élément de A au plus un élément de B, noté f(x).
  • Variable indépendante : x (l'entrée) ; variable dépendante : y = f(x) (le résultat) ;
  • Domaine de définition : ensemble des valeurs de x pour lesquelles f(x) existe ;
  • Image : l'ensemble des valeurs f(x) atteintes ;
  • Graphe G_f : ensemble des points (x ; f(x)).
Domaines types : f(x) = x − 3 → ℝ ; f(x) = √x → [0 ; +∞[ ; f(x) = 1/√(x − 1) → x − 1 > 0 donc ]1 ; +∞[.
Modélisation : une fonction traduit un phénomène réel en langage mathématique. Ex. taxi : prise en charge 1000 F + 450 F/km → A(x) = 1000 + 450x (fonction affine).

VIII. Opérations et fonctions élémentaires

Opérations sur les fonctions

  • Somme/différence : (f + g)(x) = f(x) + g(x) — domaine commun ;
  • Produit : (f × g)(x) = f(x) × g(x) ;
  • Quotient : (f/g)(x) = f(x)/g(x) — seulement là où g(x) ≠ 0 ;
  • Comparer : f ≤ g sur un intervalle signifie f(x) ≤ g(x) pour tout x de cet intervalle (utilisé pour les encadrements).

IX. ⚠️ Pièges d'examen

  • Oublier de préciser le domaine avant de résoudre : 1/√(x − 1) exige x > 1 (strict).
  • Croire que x² = 4 a une seule solution : il y en a deux (±2).
  • Multiplieur de pourcentage : diminuer de x % = ×(1 − x/100), pas ×(x/100).
  • Confondre image et domaine : le domaine = les x possibles ; l'image = les f(x) obtenus.
  • Dire qu'une fonction « passe » par toutes les valeurs : une fonction associe au plus une image à chaque x.
