I. Le problème de programmation linéaire

Forme canonique : max Z = cᵀx sous contraintes Ax ≤ b, x ≥ 0.
Fonction objectif et contraintes linéaires → l'ensemble réalisable est un polyèdre convexe et l'optimum, s'il existe, se trouve à un sommet.
Problème type (suivi dans tout le chapitre) :
max Z = 30A + 50B
s.c. { 2A + 4B ≤ 120 (machine) ; 3A + 2B ≤ 90 (travail) ; A, B ≥ 0 }.

II. Résolution graphique (2 variables)

Les 4 étapes :
1. Tracer les droites limites — pour ax + by ≤ c, tracer ax + by = c avec 2 points : (x=0 → y=c/b) et (y=0 → x=c/a).
2. Choisir le bon demi-plan — pour ≤, garder le côté vers l'origine.
3. Déterminer la zone admissible — intersection de tous les demi-plans + x ≥ 0, y ≥ 0.
4. Faire glisser la droite objectif Z = cte jusqu'au dernier point de contact avec la zone → ce sommet est l'optimum.
Application :
Machine : A + 2B = 60 → (60,0) et (0,30).
Travail : 3A + 2B = 90 → (30,0) et (0,45).
La zone admissible a pour sommets : (0,0), (30,0), (0,30) et l'intersection des deux droites.

III. Méthode des sommets (sans dessin)

Version calculatoire de la méthode graphique :
1. Lister les candidats : x=0 ou y=0 avec chaque contrainte + intersections des contraintes (systèmes 2×2) ;
2. Garder ceux qui respectent toutes les contraintes ;
3. Calculer Z en chaque sommet et comparer.
Application complète :
• S1 = (0,0) → Z = 0
• S2 = (30,0) → Z = 30×30 = 900
• S3 = (0,30) → Z = 50×30 = 1 500
• Intersection : {A + 2B = 60 ; 3A + 2B = 90} → soustraire : 2A = 30 → A = 15, B = 22,5 → Z = 450 + 1 125 = 1 575
⟹ Optimum : A* = 15, B* = 22,5 ; Z* = 1 575.
Vérification : 2(15)+4(22,5) = 120 ✓ ; 3(15)+2(22,5) = 90 ✓ — les 2 contraintes sont saturées.

IV. Le simplexe et Excel Solveur

SimplexeExcel Solveur
NatureMéthode mathématique (algorithme de tableaux successifs)Outil informatique intégré à Excel
RôleComprendre la théorie ; spécifique à la programmation linéaireCalcul automatique ; gère aussi le non-linéaire (GRG), les variables entières
RelationLe Solveur est l'outil pratique ; le simplexe est le moteur mathématique derrière (option « Simplex LP »)
Principe du simplexe : partir d'un sommet réalisable et sauter de sommet en sommet adjacent en améliorant l'objectif jusqu'à ce qu'aucune amélioration ne soit possible → optimum.
Solver en pratique : Fichier → Options → Compléments → cocher « Solver Add-in » → Données → Analyse → Solveur → définir cellule objectif, variables, contraintes → « Simplex LP ».

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Tester les sommets sans vérifier les contraintes — un point peut être une intersection mais hors zone.
  • Prendre le mauvais demi-plan (pour ≤ : vers l'origine).
  • Oublier une intersection de contraintes — elle donne souvent l'optimum.
  • Appliquer la méthode graphique à 3 variables — limitée à 2.
  • Confondre « sommet de la zone » et « point d'intersection » : seuls les sommets réalisables comptent.
