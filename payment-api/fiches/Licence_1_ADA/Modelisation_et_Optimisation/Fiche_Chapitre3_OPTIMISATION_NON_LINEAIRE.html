I. Pourquoi le non linéaire ?

Dans la réalité, les relations ne sont pas proportionnelles : coûts marginaux croissants, utilité concave, rendements décroissants, effets de saturation → modèles non linéaires.
La recherche de l'optimum repose ici sur le calcul différentiel et les conditions marginales — pas sur les sommets.
Problème type : maximiser ou minimiser une fonction f(x) non linéaire (profit quadratique, coût total, fonction de production non proportionnelle).

II. Optimisation d'une fonction d'une variable

Étape 1 — Condition du premier ordre : calculer f′(x) = 0 → points critiques (candidats). La pente est nulle — en économie, c'est l'égalité recette marginale = coût marginal.
Étape 2 — Condition du second ordre : calculer f″(x*) :
• f″(x*) < 0 → maximum ;
• f″(x*) > 0 → minimum ;
• f″(x*) = 0 → impossible à conclure.
Exemple 1 — maximum de profit : P(x) = −2x² + 24x − 40.
P′(x) = −4x + 24 = 0 → x* = 6 ; P″(x) = −4 < 0 → maximum ✓ ; P(6) = 32.
Exemple 2 — minimum de coût : C(x) = x² − 8x + 20.
C′(x) = 2x − 8 = 0 → x* = 4 ; C″(x) = 2 > 0 → minimum ✓ ; C(4) = 16 − 32 + 20 = 4.

III. Optimisation de plusieurs variables

Problème : optimiser f(x₁…xₙ) sans contrainte → résoudre le gradient nul.
∇f = 0 : ∂f/∂x₁ = 0, ∂f/∂x₂ = 0, … — autant d'équations que d'inconnues → point critique.
Étape 2 — la hessienne H = matrice des dérivées secondes partielles. Au point critique :
• H définie négative → maximum ;
• H définie positive → minimum ;
• H indéfinie → point selle.
Avec contrainte d'égalité g(x,y) = c : construire le lagrangien
L = f(x,y) − λ·(g(x,y) − c)
puis annuler les dérivées : ∂L/∂x = 0, ∂L/∂y = 0, ∂L/∂λ = 0.
λ = multiplicateur de Lagrange : valeur marginale du relâchement de la contrainte (prix « ombre » de la ressource).
Exemple : max U(x,y) = 10√(xy) s.c. x + y = 30.
L = 10√(xy) − λ(x+y−30).
∂L/∂x = 5√(y/x) − λ = 0 ; ∂L/∂y = 5√(x/y) − λ = 0 → x = y ; la contrainte donne x* = y* = 15, U* = 150.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Résoudre f′(x)=0 et oublier de vérifier f″ — un point critique n'est pas forcément un maximum.
  • Inverser les signes : f″ < 0 = max, f″ > 0 = min — ne pas confondre.
  • Oublier λ dans le système du lagrangien — il y a n+1 équations.
  • Appliquer le raisonnement « sommet » à un problème non linéaire.
  • Croire que la solution « point critique » respecte automatiquement les contraintes — le lagrangien est là pour ça.
