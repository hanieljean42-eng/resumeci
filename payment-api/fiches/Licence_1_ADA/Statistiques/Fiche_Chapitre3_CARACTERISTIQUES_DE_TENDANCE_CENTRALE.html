I. Généralités

Caractéristiques de tendance centrale : valeurs numériques calculées à partir d'une série qui indiquent la valeur typique ou l'ordre de grandeur de la distribution. Les trois principales : mode, médiane, moyenne.
L'analyse numérique et l'analyse graphique sont complémentaires, pas exclusives.

II. Le mode

Mode (Mo) : la valeur la plus fréquente de la série.
Pour une variable continue : classe modale = classe d'effectif le plus élevé.
Propriétés :
• Le mode peut ne pas exister : [1;7;2;4;5;3] n'a pas de mode ;
• Il peut être multiple : [2;1;2;2;3;1;5;4;4;5;4] a deux modes (2 et 4) ;
• Il n'a de signification véritable que si l'effectif correspondant est nettement le plus élevé.

III. La médiane

Médiane (Me) : valeur qui partage la série ordonnée en deux sous-populations de tailles égales — 50 % des valeurs en dessous, 50 % au-dessus.
Calcul — série brute ordonnée (N observations) :
• N impair : Me = valeur de rang (N+1)/2. Ex. [2;4;4;6;7;8;10;10;12] → Me = 7 ;
• N pair : Me = moyenne des valeurs de rangs N/2 et N/2+1. Ex. [0;1;1;2;2;3;3;3;4;5] → Me = (2+3)/2 = 2,5.
Calcul — données groupées en classes :
1. Classe médiane = celle dont la fréquence cumulée atteint 50 % (la précédente < 50 %) ;
2. Interpolation linéaire dans la classe médiane :
Me = e₁ + [(0,5 − F(e₁)) / (F(e₂) − F(e₁))] × (e₂ − e₁)
e₁,e₂ : bornes de la classe médiane ; F : fréquences cumulées ; variantes avec effectifs cumulés : Me = e₁ + [(N/2 − N(e₁))/N_me] × (e₂−e₁).
3. Ou lecture graphique sur la courbe des fréquences cumulées.
Avantages/inconvénients : calcul facile, bonne idée du centre, insensible aux valeurs extrêmes (atypiques) ; minimise la somme des écarts absolus Σ|xᵢ − Me|. Mais elle ne tient compte que des rangs, pas des valeurs — variables quantitatives seulement.
Généralisation — les quantiles : valeurs partageant la série en sous-populations de tailles égales :
• Quartiles (4 parts, 3 valeurs) : Q1 = 25 % en dessous, Q2 = médiane, Q3 = 75 % en dessous ;
• Déciles (10 parts, 9 valeurs : D1…D9) ; Centiles (100 parts, 99 valeurs : C1…C99).
Même méthode de calcul que la médiane (classe + interpolation).

IV. Les moyennes

Moyenne arithmétique simple : x̄ = (Σ xᵢ) / N
Moyenne arithmétique pondérée : x̄ = (Σ nᵢxᵢ) / (Σ nᵢ) — chaque modalité xᵢ compte avec son effectif nᵢ.
Données groupées : même formule avec xᵢ = centre de classe — la moyenne obtenue diffère légèrement de celle de la série initiale.
Propriétés de la moyenne arithmétique :
• Meilleure caractéristique de position au sens des moindres carrés : Σ(xᵢ − x̄)² est minimal ;
• Σ(xᵢ − x̄) = 0 ;
• Ne concerne que les variables quantitatives ;
• ⚠️ Sensible aux valeurs extrêmes — une valeur aberrante peut la déformer.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier d'ordonner la série avant de chercher la médiane.
  • N pair : prendre la valeur de rang N/2 au lieu de la moyenne des 2 valeurs centrales.
  • Oublier que Q2 = médiane.
  • Utiliser la borne de classe au lieu du centre de classe pour la moyenne groupée.
  • Croire que le mode existe toujours et est unique.
  • Comparer mode/médiane/moyenne sans tenir compte des valeurs extrêmes : la moyenne est sensible, pas la médiane.
