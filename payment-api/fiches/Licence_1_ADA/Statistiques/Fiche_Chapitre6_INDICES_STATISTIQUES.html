📖 Statistiques 🏫 Licence 1 ADA — Semestre 2 Chapitre 6 : Indices statistiques

I. À quoi servent les indices ?

Indice : instrument de mesure des évolutions de grandeurs dans le temps (et l'espace).
• Indices élémentaires : grandeurs simples (un prix, une production) ;
• Indices synthétiques : grandeurs complexes agrégeant plusieurs composantes de natures diverses.
Exemples d'indices : indice des prix à la consommation, indice de production industrielle, indices boursiers, indice de confiance des consommateurs, indice de développement humain (IDH).

II. L'indice élémentaire

Définition : pour une variable X fonction du temps,
I(t/0) = Xt / X₀
• Sans dimension ;
• Exprimé en % : I(t/0)(%) = 100 × (Xt/X₀) ;
• Période 0 = période de référence (dite « base 100 ») ; période t = période courante.
Exemple : le prix du sucre passe de 350 F (2000) à 500 F (2005).
I(2005/2000) = 500/350 = 1,4285 → 142,85 base 100 en 2000 → +42,85 %.
Lecture : l'indice mesure le niveau relatif par rapport à la base — évolution ≠ niveau.

III. Les indices synthétiques : Laspeyres, Paasche, Fischer

Pour une grandeur complexe composée de constituants i (i = 1…n) : chaque indice pondère les indices élémentaires par des coefficients wᵢ (importance/poids du constituant).
IndicePrincipePondération
Laspeyres LMoyenne arithmétique des indices élémentairesPondérée par les coefficients de l'année de base (wᵢ₀)
Paasche PMoyenne harmonique des indices élémentairesPondérée par les coefficients de l'année courante (wᵢₜ)
Fischer FMoyenne géométrique simple des deux autres : F = √(L × P)Combine les deux points de vue
Propriétés :
• Circularité (transitivité) : aucun des trois indices ne la vérifie ;
• Réversibilité : seul l'indice de Fischer est réversible — F(t/0) = 1/F(0/t).

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre indice (rapport Xt/X₀) et taux de variation : indice 142,85 = +42,85 %, pas +142,85 %.
  • Oublier de préciser la base : « I = 142,85 » ne veut rien dire sans « base 100 en 2000 ».
  • Mélanger les pondérations : Laspeyres = poids de l'année de base, Paasche = année courante.
  • Croire que les indices vérifient la circularité — aucun des trois ne la vérifie ; seul Fischer est réversible.
  • Oublier que Fischer = √(L×P) (moyenne géométrique, pas arithmétique).
