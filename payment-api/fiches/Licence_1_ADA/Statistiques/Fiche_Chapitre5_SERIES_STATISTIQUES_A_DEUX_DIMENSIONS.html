📖 Statistiques 🏫 Licence 1 ADA — Semestre 2 Chapitre 5 : Les séries statistiques à deux dimensions

I. Pourquoi deux dimensions ?

Objectif : étudier simultanément deux caractères sur les mêmes individus pour mettre en évidence les relations entre deux séries d'observations — les variables peuvent être qualitatives ou quantitatives.
Données : série de N couples (xᵢ, yᵢ) — ex. sexe × situation matrimoniale, âge × salaire.

II. Le tableau croisé (distribution conjointe)

Structure : les modalités xᵢ de X en lignes croisent les modalités yⱼ de Y en colonnes ; chaque cellule contient Nᵢⱼ = effectif des individus portant à la fois xᵢ et yⱼ.
• Distribution conjointe : les Nᵢⱼ (ou fréquences fᵢⱼ = Nᵢⱼ/N) ;
• Distributions marginales : totaux par ligne Nᵢ· (de X) et par colonne N·ⱼ (de Y) — en « marge » du tableau ;
• Distributions conditionnelles : fréquence de yⱼ sachant xᵢ : fⱼ/ᵢ = Nᵢⱼ/Nᵢ·.

III. L'indépendance de deux variables

X et Y indépendantes ⟺ le résultat de X n'influence en rien celui de Y.
Critère sur le tableau : pour tous i, j — fᵢⱼ = fᵢ· × f·ⱼ (la fréquence conditionnelle égale la marginale).
Fréquences/effectifs théoriques : ce qu'aurait la distribution conjointe si X et Y étaient indépendantes : f*ᵢⱼ = fᵢ·f·ⱼ et N*ᵢⱼ = Nᵢ·N·ⱼ/N.

IV. Mesurer la liaison

1. La covariance

Cov(X,Y) = (1/N) Σ (xᵢ − x̄)(yᵢ − ȳ) = (Σ xᵢyᵢ/N) − x̄·ȳ
• X et Y indépendantes ⟹ Cov = 0 ;
• Cov ≠ 0 ⟹ il existe une dépendance entre X et Y.
⚠️ La réciproque est fausse : Cov = 0 n'implique pas l'indépendance (ex. relation Y = |X| parfaitement dépendante avec Cov = 0) — la covariance ne détecte que les liaisons du type affine y = ax + b ; sa valeur dépend des unités.

2. Le coefficient de corrélation linéaire

r = Cov(X,Y) / [σ(X)·σ(Y)] — nombre compris entre −1 et +1, sans unité :
• r ≈ +1 : relation forte croissante (y = ax+b, a>0) ;
• r ≈ −1 : relation forte décroissante (a<0) ;
• 0 < r < 1 : nuage allongé selon une droite croissante ;
• −1 < r < 0 : nuage allongé selon une droite décroissante ;
• r ≈ 0 : pas de forme allongée (pas de liaison linéaire).

3. La distance du khi-deux

d² = Σᵢ Σⱼ (fᵢⱼ − f*ᵢⱼ)² / f*ᵢⱼ = Σᵢ Σⱼ (Nᵢⱼ − N*ᵢⱼ)² / N*ᵢⱼ
Mesure l'écart entre la distribution observée et la distribution théorique d'indépendance :
• d² = 0 ⟺ indépendance parfaite ;
• d² maximal ⟺ dépendance systématique.
⚠️ Regrouper les modalités dont l'effectif théorique est < 5.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Conclure à l'indépendance parce que Cov = 0 — elle ne détecte que la liaison linéaire.
  • Confondre corrélation (−1 ≤ r ≤ +1) et causalité — une corrélation forte ne prouve pas que X cause Y.
  • Inverser lignes et colonnes dans le tableau croisé.
  • Oublier de regrouper les modalités à effectif théorique < 5 pour le khi-deux.
  • Interpréter r sans regarder le nuage de points — une relation curviligne forte peut donner r faible.
