I. La contrainte de budget

Équation de budget : R = p₁x₁ + p₂x₂ — le consommateur dépense la totalité de son revenu R aux prix p₁ et p₂.
Forme « droite » : x₂ = R/p₂ − (p₁/p₂)·x₁ → pente = −p₁/p₂, ordonnée à l'origine = R/p₂, abscisse à l'origine = R/p₁.
Espace de budget : tous les paniers accessibles (sous la droite) ; sur la droite = dépense totale du revenu.
Statique comparative :
• R augmente (prix constants) → pente inchangée, la droite se déplace parallèlement vers le haut (plus de paniers accessibles) ;
• p₁ diminue (p₂ et R constants) → la droite pivote vers l'extérieur autour de A = (0, R/p₂) ;
• R et les deux prix multipliés par λ → droite inchangée (il n'y a pas d'« illusion monétaire »).

II. Le choix optimal : la condition d'équilibre

L'équilibre du consommateur = le panier qui procure le maximum de satisfaction compatible avec la droite de budget : le point de tangence entre la CI la plus élevée et la droite de budget.
⟹ TMS = Um₁/Um₂ = p₁/p₂ — à l'optimum, le taux marginal de substitution égale le rapport des prix.
Lecture économique : Um₁/p₁ = Um₂/p₂ → la dernière franc dépensé procure la même satisfaction dans chaque bien.
Résolution par le lagrangien (programme marshallien) :
max U(x₁,x₂) sous contrainte R = p₁x₁ + p₂x₂
ℒ = U(x₁,x₂) + λ(R − p₁x₁ − p₂x₂)
CPO : ∂ℒ/∂x₁ = 0 ; ∂ℒ/∂x₂ = 0 ; ∂ℒ/∂λ = 0 → Um₁/p₁ = Um₂/p₂ = λ.
CSO : déterminant du hessien bordé > 0 → maximum.
Les solutions x₁* = x₁(p₁,p₂,R) et x₂* = x₂(p₁,p₂,R) sont les fonctions de demande marshallienne.
Exemple résolu : U(x,y) = x·y ; R = 40, p₁ = 2, p₂ = 3.
Um₁ = y, Um₂ = x → y/x = 2/3 → y = 2x/3.
Budget : 2x + 3(2x/3) = 4x = 40 → x* = 10, y* = 20/3 ≈ 6,67.
Utilité indirecte : U* = 10 × 20/3 = 200/3.

III. Demandes marshallienne et hicksienne — la dualité

Demande marshallienne (ordinaire)Demande hicksienne (compensée)
ProgrammeMaximiser U sous contrainte de budget RMinimiser la dépense pour atteindre un niveau d'utilité Ū fixé
Solutionxᵢ*(p₁, p₂, R) — dépend des prix et du revenuxᵢᶜ(p₁, p₂, Ū) — dépend des prix et de l'utilité visée
PropriétésUnivoque ; homogène de degré 0 en prix et revenu (multiplier tout par λ ne change rien)Homogène de degré 0 en prix
Utilité indirecte : V(p₁,p₂,R) = U(x₁*,x₂*) — l'utilité maximale atteignable. En remplaçant les demandes marshalliennes dans U.
Fonction de dépense : e(p₁,p₂,Ū) = dépense minimale pour atteindre Ū.
Liens de dualité : • demande compensée insérée dans les dépenses → demande marshallienne ;
• Identité de Roy : xᵢ = −(∂V/∂pᵢ)/(∂V/∂R) → retrouver la marshallienne à partir de l'utilité indirecte.
La chaîne de dualité :
Utilité U → max sous budget → demande marshallienne → utilité indirecte V
Utilité Ū → min la dépense → demande hicksienne → fonction de dépense e

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Chercher l'optimum sur n'importe quelle CI : il faut la CI tangente à la droite de budget (TMS = p₁/p₂).
  • Oublier la contrainte dans le calcul : la condition des prix ne suffit pas, il faut aussi R = p₁x₁ + p₂x₂.
  • Confondre rotation (prix change) et translation (revenu change) de la droite de budget.
  • Inverser les programmes : marshallienne = max U ; hicksienne = min dépense.
