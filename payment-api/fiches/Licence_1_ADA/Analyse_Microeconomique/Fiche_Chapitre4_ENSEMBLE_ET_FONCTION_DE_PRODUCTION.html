I. Le producteur : objectifs, décisions, contraintes

Objectifs du producteur rationnel :
• Maximiser le profit = recettes de vente − coûts de production ;
• Minimiser les coûts pour un niveau de production donné.
Décisions : comment produire ? quelle technique ? quelle quantité ?
Position double : la firme est du côté demande sur les marchés des facteurs et du côté offre sur le marché du bien produit.
Contraintes :
• Prix de marché : en concurrence parfaite, tous les prix sont dictés par le marché ;
• Technologiques : la technologie limite les combinaisons de facteurs ; pour un output donné, la firme choisit la combinaison qui minimise le coût.

II. Fonction de production et horizons

Fonction de production : relation liant les quantités d'inputs (facteurs : travail L, capital K) au niveau maximal d'output qu'ils permettent : y = f(K, L).
• Court terme : période où au moins un facteur est fixe (ex. machines, bâtiments → K fixe, L variable) ;
• Long terme : durée suffisante pour que tous les facteurs soient variables.
Isoquante : ensemble des combinaisons efficaces de facteurs produisant le même niveau d'output — l'équivalent producteur de la courbe d'indifférence.
4 propriétés : P1 éloignée = output plus élevé ; P2 ne se croisent jamais ; P3 décroissantes ; P4 convexes.
TMST : quantité de facteur 2 à laquelle renoncer pour une unité de facteur 1 en plus, à output constant — valeur absolue de la pente de l'isoquante : TMST = −dx₂/dx₁ = Pm₁/Pm₂.

III. La production avec un seul facteur variable (court terme)

Cadre : K fixe, seul L varie → y = f(K̄, L). Question type : combien de travailleurs embaucher et quel effet sur la production ?
Les 3 productivités :
• Productivité totale (PT) : l'output total produit ;
• Productivité moyenne (PM) : PM_L = q/L — contribution moyenne par unité de travail ;
• Productivité marginale (Pm) : Pm_L = ∂q/∂L — production supplémentaire du dernier travailleur.
Loi des rendements marginaux décroissants : à partir d'un certain point, l'ajout d'unités supplémentaires d'un facteur variable (les autres étant fixes) produit des accroissements de production de plus en plus faibles.
• Phase 1 : Pm croissante (rendements croissants — spécialisation) ;
• Phase 2 : Pm décroissante mais > 0 (zone économiquement rationnelle) ;
• Phase 3 : Pm < 0 — trop de travailleurs réduisent l'output.
Relation PM ↔ Pm : quand Pm > PM, la PM augmente ; quand Pm < PM, la PM diminue → Pm coupe PM à son maximum.

IV. Les rendements d'échelle (long terme)

Quand TOUS les facteurs varient dans la même proportion λ :
• f(λK, λL) > λf(K,L) → rendements croissants (l'output augmente plus que les inputs) ;
• f(λK, λL) = λf(K,L) → rendements constants (homogène de degré 1) ;
• f(λK, λL) < λf(K,L) → rendements décroissants.
Pour Cobb-Douglas y = KᵅLᵝ : les rendements d'échelle se lisent sur α + β : > 1 croissants ; = 1 constants ; < 1 décroissants.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre rendements marginaux (court terme, 1 seul facteur varie) et rendements d'échelle (long terme, tous varient).
  • Confondre isoquante (même output) et droite d'isocoût (même coût — chap. 5).
  • Dire « Pm décroissante ⟹ production diminue » : faux tant que Pm > 0, l'output augmente.
  • Oublier le « min » des facteurs complémentaires : ajouter du capital sans travail ne produit rien.
