I. La notion de vecteur

Vecteur : objet mathématique caractérisé par trois éléments : une direction, un sens et une norme (sa longueur). On le note u⃗, v⃗… ou simplement x, y en écriture coordonnée : x = (x, y) dans le plan, x = (x, y, z) dans l'espace.
  • En physique : un déplacement, une force (direction + sens + intensité).
  • En économie : un panier de biens — la liste des quantités de différents biens consommés par un agent.
  • En gestion : une liste de données chiffrées (productions, coûts, ventes).
Pourquoi un panier de biens est-il un vecteur ? Un panier de 3 biens (riz, huile, sucre) s'écrit x = (x₁, x₂, x₃) où xi = quantité du bien i. Cette écriture est exactement celle d'un vecteur de ℝ³.

II. Les vecteurs dans ℝⁿ

Vecteur de ℝⁿ : un n-uplet de nombres réels x = (x₁, x₂, …, xn) avec xi ∈ ℝ. ℝⁿ est l'ensemble de tous les vecteurs ayant n composantes réelles.
EnsembleInterprétation
ℝ²Un point ou un déplacement dans le plan
ℝ³Un point ou un vecteur dans l'espace
ℝⁿ (n > 3)Un objet algébrique — en gestion : un ensemble d'informations chiffrées liées à une même activité

III. Opérations sur les vecteurs

Addition : (x₁, …, xn) + (y₁, …, yn) = (x₁ + y₁, …, xn + yn) — on additionne composante par composante (même nombre de composantes obligatoire).
Multiplication par un scalaire : pour λ ∈ ℝ, λ·x = (λx₁, …, λxn) — chaque composante est multipliée par λ.
Vecteur nul : 0⃗ = (0, 0, …, 0). Il représente l'absence totale de quantité ou de variation.
Produit scalaire dans ℝⁿ : x · y = x₁y₁ + x₂y₂ + … + xnyn. Le résultat est un nombre (un scalaire), pas un vecteur. C'est l'outil de base pour calculer des totaux en économie et en gestion.

IV. Application à la gestion

  • q = (q₁, …, qn) : vecteur des quantités produites
  • p = (p₁, …, pn) : vecteur des prix unitaires
  • c = (c₁, …, cn) : vecteur des coûts unitaires
Les 3 formules clés :
Chiffre d'affaires : CA = p · q
Coût total : CT = c · q
Profit : Profit = CA − CT
Exemple résolu : une entreprise fabrique 3 produits A, B, C avec q = (100, 50, 20), p = (10, 20, 50) et c = (6, 12, 30) en milliers de FCFA.
CA = 10×100 + 20×50 + 50×20 = 3 000
CT = 6×100 + 12×50 + 30×20 = 1 800
Profit = 3 000 − 1 800 = 1 200 → profit positif : l'entreprise est rentable.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Additionner deux vecteurs de tailles différentes : impossible — il faut le même nombre de composantes.
  • Croire que le produit scalaire donne un vecteur : il donne un réel (ex. le CA est un montant, pas une liste).
  • Oublier les unités : si p et c sont en milliers de FCFA, CA, CT et Profit le sont aussi.
  • Calculer le profit par CT − CA : c'est CA − CT ; un résultat négatif signifie une perte.
