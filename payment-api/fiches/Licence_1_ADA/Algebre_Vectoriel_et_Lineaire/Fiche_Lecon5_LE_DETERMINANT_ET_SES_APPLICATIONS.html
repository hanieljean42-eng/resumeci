I. Pourquoi le déterminant ? Sens en gestion

Déterminant det(A) : nombre réel associé uniquement aux matrices carrées. Il est nul si et seulement si les lignes (ou colonnes) sont linéairement dépendantes.
Interprétation économique : en regroupant prix et quantités de deux produits dans une matrice, det = 0 → les variables sont proportionnelles : les produits évoluent de la même façon → pas de diversification, risque concentré. det ≠ 0 → variations indépendantes : chaque produit joue un rôle propre → chiffre d'affaires diversifié. Le déterminant est un indicateur synthétique de dépendance économique.

II. Calcul du déterminant

1. Matrice 2×2

Si A = (a b ; c d), alors det(A) = a·d − b·c. On écrit aussi |A|.
Exemple : A = (3 1 ; 2 4) → det(A) = 3×4 − 1×2 = 12 − 2 = 10.

2. Matrice 3×3 : règle de Sarrus

On recopie les deux premières colonnes à droite de la matrice, puis :
det(A) = aei + bfg + cdh − (ceg + afh + bdi)
⚠️ Méthode valable uniquement pour les matrices 3×3.

3. Méthode des cofacteurs (générale, toute taille)

On développe selon une ligne ou une colonne : det(A) = Σ aij·Cij où le cofacteur Cij = (−1)i+j × det(Aij), Aij étant la sous-matrice obtenue en supprimant la ligne i et la colonne j.
Exemple : A = (1 2 3 ; 4 5 6 ; 7 8 10), développement par la ligne 1 :
C₁₁ = +|5 6 ; 8 10| = 50 − 48 = 2 ; C₁₂ = −|4 6 ; 7 10| = −(40 − 42) = 2 ; C₁₃ = +|4 5 ; 7 8| = 32 − 35 = −3
det(A) = 1×2 + 2×2 + 3×(−3) = 2 + 4 − 9 = −3. Toute ligne ou colonne donne le même résultat.

III. À quoi sert le déterminant ?

Le déterminant permet de savoir : si une matrice est inversible (det ≠ 0 ⟺ A inversible) ; si un système linéaire a une solution unique ; gérer les changements de base ; étudier la diagonalisation et les matrices semblables.

1. Inverse d'une matrice carrée

det(A) ≠ 0 ⟺ A inversible, et alors A⁻¹ = (1/det(A)) × com(A)T (transposée de la matrice des cofacteurs, dite adjugée).

2. Matrices semblables et changement de base

Semblables : A et B sont semblables s'il existe P inversible telle que B = P⁻¹·A·P. P = matrice de passage. A et B représentent la même application linéaire dans deux bases différentes — comme décrire la même situation économique en euros ou en dollars.

3. Valeurs propres et vecteurs propres

Valeur propre λ : réel tel qu'il existe un vecteur v ≠ 0 avec Av = λv. λ mesure l'effet d'étirement ou de compression sur v. Le vecteur propre v garde sa direction : il est seulement étiré ou contracté.
En pratique : ① résoudre le polynôme caractéristique det(A − λI) = 0 → les λ ; ② pour chaque λ, résoudre (A − λI)v = 0 → les vecteurs propres.
Exemple complet : A = (2 1 ; 0 3).
① det(A − λI) = (2 − λ)(3 − λ) = 0 → λ₁ = 2, λ₂ = 3.
② λ = 2 : (A − 2I)v = (0 1 ; 0 1)v = 0 → y = 0 → v₁ = (1 ; 0). λ = 3 : (A − 3I)v = (−1 1 ; 0 0)v = 0 → x = y → v₂ = (1 ; 1).
③ v₁ et v₂ sont indépendants → on peut diagonaliser.

4. La diagonalisation (cas particulier de matrices semblables)

On forme P = (v₁, v₂) avec les vecteurs propres en colonnes. Alors B = P⁻¹AP est diagonale : les valeurs propres de A apparaissent sur la diagonale. Ici P = (1 1 ; 0 1) → B = (2 0 ; 0 3).

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Appliquer Sarrus à une matrice 4×4 : réservé au 3×3 — au-delà, cofacteurs obligatoires.
  • Oublier les signes du damier (−1)i+j : les cofacteurs alternent + − + −.
  • Inverser une matrice avec det = 0 : impossible, vérifier det avant toute inversion.
  • Confondre « semblables » et « égales » : B = P⁻¹AP ≠ A en général (même application, autre base).
  • Prendre v = 0 comme vecteur propre : un vecteur propre est forcément non nul.
  • Conclure det < 0 → non inversible : seul det = 0 bloque l'inversion (det négatif = inversible).
