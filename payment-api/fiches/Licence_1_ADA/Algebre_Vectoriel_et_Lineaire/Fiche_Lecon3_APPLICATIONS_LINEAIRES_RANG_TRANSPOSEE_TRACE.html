I. L'application linéaire

Application linéaire : une application f : ℝⁿ → ℝᵐ est linéaire si, pour tous vecteurs u, v de ℝⁿ et tout réel λ : f(u + v) = f(u) + f(v) et f(λu) = λf(u).
  • ℝⁿ (départ) : vecteurs à n composantes = n variables d'entrée (ex. ℝ³ : capital, travail, matière première).
  • ℝᵐ (arrivée) : vecteurs à m composantes = m résultats de sortie (ex. ℝ² : coût, production).
Base canonique de ℝⁿ : ensemble des n vecteurs e₁ = (1;0;…;0), e₂ = (0;1;…;0), …, en = (0;0;…;1). Principe fondamental : une application linéaire est entièrement déterminée par les images f(e₁), f(e₂), …, f(en).

II. Écriture matricielle d'une application linéaire

Construction de la matrice associée A : on place f(e₁) en 1ʳᵉ colonne, f(e₂) en 2ᵉ colonne, …, f(en) en n-ième colonne. La matrice A est de taille m × n : le nombre de lignes = dimension de l'espace d'arrivée ℝᵐ, le nombre de colonnes = dimension de l'espace de départ ℝⁿ. On a alors f(X) = A·X.
Exemple : 3 facteurs de production (entrées ℝ³), 2 types de produits (sorties ℝ²). Si X ∈ ℝ³ et A ∈ M₂,₃, alors AX ∈ ℝ² : chaque ligne de A combine les 3 facteurs pour donner un résultat.

III. Le rang d'une matrice

Rang rg(A) : nombre maximal de lignes (ou de colonnes) linéairement indépendantes — c'est aussi la dimension de l'image de l'application linéaire associée. Toujours rg(A) ≤ min(m, n).
Méthode : une ligne (ou colonne) est dépendante si elle s'écrit comme combinaison linéaire des autres (ex. L₂ = 2L₁). On compte seulement les lignes/colonnes indépendantes. Rang par les lignes = rang par les colonnes.
Exemples :
• A = (1 2 3 ; 0 1 4 ; 2 0 1) : aucune ligne n'est combinaison des autres → rg(A) = 3 (matrice « pleine », aucune information redondante).
• B = (1 2 3 ; 2 4 6 ; 1 0 1) : L₂ = 2×L₁ → L₂ dépendante ; L₁ et L₃ indépendantes → rg(B) = 2.

IV. La transposée

Transposée AT : obtenue en échangeant les lignes et les colonnes de A. Si A est m × n, alors AT est n × m.
Propriétés : (AT)T = A ; (A + B)T = AT + BT ; (λA)T = λAT ; (AB)T = BTAT (ordre inversé !) ; rg(A) = rg(AT).

V. La trace

Trace tr(A) : somme des éléments de la diagonale principale : tr(A) = a₁₁ + a₂₂ + … + ann. ⚠️ Définie uniquement pour les matrices carrées.
Propriétés : tr(A + B) = tr(A) + tr(B) ; tr(λA) = λ·tr(A) ; tr(AT) = tr(A) ; tr(AB) = tr(BA) (quand les produits existent).
Exemple : M = (2 10 −1 ; 3 4 5 ; 0 1 2) → tr(M) = 2 + 4 + 2 = 8 (on ne prend que la diagonale).

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Mettre les f(ei) en lignes : c'est en colonnes.
  • Inverser m et n : les lignes = espace d'arrivée ℝᵐ, les colonnes = départ ℝⁿ.
  • Compter toutes les lignes pour le rang : il faut éliminer les lignes dépendantes (proportionnelles, combinaisons).
  • Écrire (AB)T = ATBT : c'est BTAT.
  • Calculer la trace d'une matrice non carrée : impossible.
  • Croire que rg(A) peut dépasser min(m, n) : jamais.
