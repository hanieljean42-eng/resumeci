I. Définition et types de matrices

Matrice : tableau rectangulaire de nombres disposés en lignes et colonnes. Une matrice de m lignes et n colonnes est de dimension m × n. On la note par une majuscule (A, B, C…) et ses coefficients par aij : i = ligne, j = colonne.
Type de matriceCaractéristique
LigneUne seule ligne, n colonnes : M = (1, 2, 3)
Colonnen lignes, une seule colonne (comme un vecteur vertical)
CarréeAutant de lignes que de colonnes → ordre n
Identité InDiagonale de 1, zéros ailleurs — élément neutre du produit
DiagonaleZéros partout sauf sur la diagonale principale
NulleNe contient que des 0

II. Addition et multiplication par un scalaire

Addition : possible uniquement entre matrices de même dimension. On additionne coefficient par coefficient : (A + B)ij = aij + bij.
Exemple : A = (1 2 ; 3 4), B = (5 6 ; 7 8) → A + B = (6 8 ; 10 12)
Multiplication par un scalaire λ : on multiplie chaque coefficient par λ : (λA)ij = λ·aij. Exemple : 2·(1 2 ; 3 4) = (2 4 ; 6 8).

III. Produit de deux matrices

Condition de compatibilité : le produit AB existe si et seulement si le nombre de colonnes de A = nombre de lignes de B. Si A est m × n et B est n × p, alors AB est m × p.
Principe fondamental — ligne × colonne : chaque coefficient (AB)ij s'obtient en multipliant la ligne i de A par la colonne j de B : (AB)ij = ai1b1j + ai2b2j + … + ainbnj. Ce n'est pas un produit coefficient par coefficient !
Exemple complet : A = (1 2 ; 3 4), B = (5 6 ; 7 8)
(1,1) : 1×5 + 2×7 = 19  |  (1,2) : 1×6 + 2×8 = 22
(2,1) : 3×5 + 4×7 = 43  |  (2,2) : 3×6 + 4×8 = 50
→ AB = (19 22 ; 43 50). Attention : AB ≠ BA en général.

IV. Produit d'une matrice par un vecteur colonne

Si A est m × n et X un vecteur colonne de n composantes, alors AX est un vecteur colonne de m composantes. Chaque composante = une ligne de A × le vecteur X. On note f(X) = AX : c'est une application linéaire de ℝⁿ vers ℝᵐ.
  • Sens économique : la matrice est le modèle, le vecteur est la décision, le produit est la conséquence.
  • Application gestion : matrice des coûts unitaires (lignes = ressources, colonnes = produits) × vecteur des quantités produites = vecteur des coûts totaux par ressource.
Exemple : A = (2 3 ; 1 4) avec X = (50 ; 30) → AX = (2×50 + 3×30 ; 1×50 + 4×30) = (190 ; 170) : 190 de coût en travail, 170 de coût en capital.

V. Puissance d'une matrice

An (réservé aux matrices carrées) : A¹ = A ; A² = A×A ; An = A × … × A (n fois). On multiplie la matrice par elle-même.
  • Cas particuliers : In = I ; si D est diagonale, Dn = diagonale des λin (on élève juste les coefficients diagonaux à la puissance n).
  • Propriétés : Am·An = Am+n ; (An)p = Anp. Mais (AB)n ≠ AnBn en général (car AB ≠ BA).

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Additionner des matrices de dimensions différentes : impossible.
  • Faire le produit coefficient par coefficient : c'est ligne × colonne.
  • Oublier de vérifier la compatibilité : si A est 2×3 et B est 2×3, AB n'existe pas.
  • Écrire AB = BA : le produit matriciel n'est pas commutatif.
  • Calculer A² pour une matrice non carrée : la puissance exige une matrice carrée.
  • Appliquer (AB)n = AnBn : faux en général.
