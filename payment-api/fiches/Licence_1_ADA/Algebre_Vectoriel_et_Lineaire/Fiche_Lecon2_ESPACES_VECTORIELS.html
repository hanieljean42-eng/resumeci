I. L'ensemble ℝⁿ et ses opérations

ℝⁿ : pour n entier naturel non nul, ℝⁿ est l'ensemble des n-uplets (x₁, x₂, …, xn) de nombres réels. ℝ² = couples (x ; y), ℝ³ = triplets (x ; y ; z), ℝ⁴ = quadruplets (x₁ ; x₂ ; x₃ ; x₄).
Égalité dans ℝⁿ : (x₁, …, xn) = (y₁, …, yn) si et seulement si x₁ = y₁, x₂ = y₂, …, xn = yn. Deux n-uplets sont égaux quand toutes leurs composantes sont égales.
Addition dans ℝⁿ : (x₁, …, xn) + (y₁, …, yn) = (x₁ + y₁, …, xn + yn). Multiplication par un réel λ : λ(x₁, …, xn) = (λx₁, …, λxn).
Exemple gestion : une entreprise produit 3 matériels. Production mensuelle = triplet (x₁ ; x₂ ; x₃). Deux mois consécutifs : (x₁ ; x₂ ; x₃) + (y₁ ; y₂ ; y₃) = production globale. Même production deux mois de suite : 2(x₁ ; x₂ ; x₃) = (2x₁ ; 2x₂ ; 2x₃).
Ex. : (3 ; 2 ; −1) + (−5 ; 4 ; 2) = (−2 ; 6 ; 1).
ℝⁿ est un espace vectoriel : muni de l'addition et de la multiplication par un réel, ℝⁿ possède les mêmes propriétés que l'ensemble des vecteurs du plan (élément neutre, opposé, distributivité). On appelle vecteur tout élément de ℝⁿ : U⃗ = (x₁, x₂, …, xn) et O⃗ = (0, 0, …, 0).
Dans ℝ³Dans le plan
(x₁, x₂, x₃) + (0, 0, 0) = (x₁, x₂, x₃)u⃗ + 0⃗ = u⃗
(x₁, x₂, x₃) + (−x₁, −x₂, −x₃) = (0, 0, 0)u⃗ + (−u⃗) = 0⃗
2(x₁, x₂, x₃) + 3(x₁, x₂, x₃) = 5(x₁, x₂, x₃)2u⃗ + 3u⃗ = 5u⃗
Vecteur ou matrice ? Un vecteur est une liste ordonnée de nombres (tableau 1D) ; une matrice est un tableau 2D de nombres. Un vecteur est une matrice particulière : une seule ligne ou une seule colonne. Ex. : u⃗ = (a ; b) peut s'écrire en ligne ou en colonne.

II. Combinaison linéaire

Combinaison linéaire : soient u⃗₁, u⃗₂, …, u⃗p des vecteurs de ℝⁿ. Tout vecteur de la forme λ₁u⃗₁ + λ₂u⃗₂ + … + λpu⃗p, où λ₁, λ₂, …, λp sont des réels, est une combinaison linéaire de ces vecteurs. Les λi sont les coefficients de la combinaison.
Exemple : u⃗ = (−2 ; 0 ; 1) et v⃗ = (2 ; 4 ; −3) dans ℝ³.
3u⃗ = (−6 ; 0 ; 3) et 2v⃗ = (4 ; 8 ; −6)
3u⃗ + 2v⃗ = (−2 ; 8 ; −3) → combinaison linéaire de u⃗ et v⃗ de coefficients 3 et 2.

III. Système générateur et système libre

Système générateur : un système de vecteurs est générateur si tout vecteur de l'espace peut s'écrire comme combinaison linéaire de ces vecteurs.
Exemple : (1 ; 1) et (−1 ; 1) sont-ils générateurs de ℝ² ? Pour tout (x ; y) ∈ ℝ², on cherche α et β tels que (x ; y) = α(1 ; 1) + β(−1 ; 1).
Système : x = α − β et y = α + β → α = (x + y)/2 et β = (y − x)/2.
La solution existe toujours → le système {(1 ; 1), (−1 ; 1)} est générateur de ℝ².
Système libre : un système de vecteurs est libre si la seule combinaison linéaire égale au vecteur nul est celle dont tous les coefficients sont nuls :
λ₁u⃗₁ + λ₂u⃗₂ + … + λnu⃗n = 0⃗ ⟺ λ₁ = λ₂ = … = λn = 0.
Sinon, le système est lié (vecteurs linéairement dépendants).
Exemple de système lié : d₁ = (2 ; 4 ; 6) et d₂ = (1 ; 2 ; 3). On a d₁ = 2·d₂, c.-à-d. d₁ − 2d₂ = 0⃗ : combinaison nulle à coefficients non nuls → système lié (vecteurs colinéaires). En économie : deux variables proportionnelles n'apportent qu'une seule information réelle.

IV. Base, dimension et base canonique

Base : on appelle base d'un espace vectoriel tout système de vecteurs à la fois libre et générateur. Exemple : {(1 ; 1), (−1 ; 1)} est une base de ℝ².
Dimension : la dimension d'un espace vectoriel est le nombre de vecteurs de l'une quelconque de ses bases. ℝⁿ est de dimension n.
Théorème de la dimension : tout système libre de n vecteurs dans un espace de dimension n est une base de cet espace.
Corollaire : tout système générateur de n vecteurs dans un espace de dimension n est une base de cet espace.
→ En dimension n, il suffit de vérifier une seule des deux propriétés (libre ou générateur) pour conclure à une base.
Base canonique de ℝⁿ : l'ensemble Bc = {e₁ ; e₂ ; … ; en} où le vecteur ei a toutes ses composantes nulles sauf la i-ème, égale à 1 :
e₁ = (1 ; 0 ; … ; 0), e₂ = (0 ; 1 ; 0 ; … ; 0), …, en = (0 ; 0 ; … ; 1).
⚠️ Attention : {(1 ; 1), (−1 ; 1)} est une base de ℝ² mais pas la base canonique. La base canonique de ℝ² est {(1 ; 0), (0 ; 1)}.

V. Applications linéaires et endomorphismes

Application linéaire : une application f de ℝᵖ dans ℝⁿ est linéaire si et seulement si :
• ∀ u⃗, v⃗ ∈ ℝᵖ : f(u⃗ + v⃗) = f(u⃗) + f(v⃗) (additivité)
• ∀ u⃗ ∈ ℝᵖ, ∀ λ ∈ ℝ : f(λu⃗) = λ·f(u⃗) (homogénéité)
Propriété caractéristique (test unique) : f est linéaire ssi pour tous réels λ et β :
f(λu⃗ + βv⃗) = λ·f(u⃗) + β·f(v⃗)
Exemple en gestion : f(vA, vB) = (0,5vA + 0,2vB ; 0,3vA + 0,7vB) calcule les quantités à commander pour réapprovisionner le stock selon les ventes prévues de deux produits A et B.
• Additivité : f((vA, vB) + (wA, wB)) = f(vA, vB) + f(wA, wB) ✓
• Homogénéité : f(αvA, αvB) = α·f(vA, vB) ✓
→ f est linéaire. Remarque : la demande d'un produit influence partiellement le stock de l'autre ; les coefficients traduisent la politique de gestion des stocks.
Endomorphisme : une application f : E → E est un endomorphisme de E si f est linéaire et si l'espace de départ et l'espace d'arrivée sont le même. Exemple : f(x, y) = (2x, y) est un endomorphisme de ℝ² (linéaire, et départ = arrivée = ℝ²).

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Croire que 3 vecteurs forment toujours une base de ℝ³ : (1 ; 0 ; 2), (0 ; 1 ; 1), (1 ; 1 ; 3) ne sont pas une base car (1 ; 1 ; 3) = (1 ; 0 ; 2) + (0 ; 1 ; 1) → système lié.
  • Confondre « libre » et « générateur » : libre = aucune combinaison nulle à coefficients non nuls ; générateur = tout vecteur de l'espace est atteignable. Une base exige les deux (ou une seule si on sait déjà qu'on est en dimension n).
  • Oublier qu'une application linéaire envoie toujours 0⃗ sur 0⃗ : si f(0⃗) ≠ 0⃗, f n'est pas linéaire.
  • Confondre base et base canonique : seule la base {(1 ; 0 ; … ; 0), …, (0 ; … ; 0 ; 1)} est canonique.
  • Déclarer endomorphisme une application linéaire entre deux espaces différents : un endomorphisme impose même espace au départ et à l'arrivée.
