I. Notion de variable aléatoire

Variable aléatoire (v.a.) : fonction X : Ω → ℝ qui associe une valeur numérique à chaque résultat ω d'une expérience aléatoire : ω ↦ X(ω). Elle fait le lien entre l'espace échantillonnal et les nombres réels.
Discrète : quand X(Ω) (ensemble des valeurs possibles) est fini ou dénombrable.
Notations des événements :
• {X = a} = {ω ∈ Ω / X(ω) = a}
• {X ≤ a} = {ω ∈ Ω / X(ω) ≤ a} ; {X ≥ a} idem
• {a ≤ X ≤ b} = {ω ∈ Ω / a ≤ X(ω) ≤ b}
Exemples :
1. Dé à 6 faces, événement « obtenir 6 » : Ω = {1,…,6}, X(ω) = 1 si ω = 6, sinon 0 → X(Ω) = {0, 1}.
2. 3 lancers de pièce, X = nombre de PILE : plusieurs ω donnent la même valeur (PPF, PFP, FPP → X = 2) → X(Ω) = {0, 1, 2, 3}.
Propriété : si X et Y sont des v.a. discrètes, λ ∈ ℝ et f une application, alors X + Y, λX, X·Y et f(X) sont aussi des v.a. discrètes.

II. Loi de probabilité et fonction de répartition

Loi de probabilité de X : liste de toutes les valeurs différentes xᵢ de X(Ω) avec les probabilités associées P(X = xᵢ) = pᵢ.
Condition obligatoire : Σ pᵢ = 1 (somme de toutes les probabilités).
Exemples :
• Dé, événement « 6 » : P(X=0) = 5/6, P(X=1) = 1/6.
• 3 lancers (X = nb de PILE) : P(X=0) = 1/8, P(X=1) = 3/8, P(X=2) = 3/8, P(X=3) = 1/8 → total = 1 ✓
Fonction de répartition : F : ℝ → [0,1] définie par F(t) = P(X ≤ t) — on cumule les probabilités jusqu'à t (d'où « fonction cumulative »).
• F est croissante, en escalier pour une v.a. discrète.
• P(a < X ≤ b) = F(b) − F(a) ; on peut retrouver la loi de X à partir de F.

III. Espérance, variance, écart-type

Espérance (moyenne théorique) : E[X] = Σ xᵢ × P(X = xᵢ)
Joue le même rôle que la moyenne en statistique descriptive : la valeur « espérée ».
Variance (dispersion) : Var[X] = E[X²] − (E[X])² où E[X²] = Σ xᵢ² × pᵢ
Écart-type : σ(X) = √Var[X]
Exemple résolu — 3 lancers (X = nb de PILE) :
E[X] = 0×⅛ + 1×⅜ + 2×⅜ + 3×⅛ = 3/2
E[X²] = 0×⅛ + 1×⅜ + 4×⅜ + 9×⅛ = 3 → Var[X] = 3 − (3/2)² = 3/4 ; σ = √3/2 ≈ 0,87
Variable centrée-réduite : Y = (X − E[X]) / σ(X).
Propriété : E[Y] = 0 et σ(Y) = 1 — permet de comparer des variables sur une même échelle.

IV. Couple de variables aléatoires discrètes

Loi jointe de (X,Y) : ensemble des P(X = xᵢ, Y = yⱼ).
Lois marginales : P(X = xᵢ) = Σⱼ P(X = xᵢ, Y = yⱼ) (somme en ligne) ; P(Y = yⱼ) = Σᵢ P(X = xᵢ, Y = yⱼ) (somme en colonne).
⚠️ La loi jointe donne les marginales, mais la réciproque est FAUSSE.
Exemple résolu : une poche contient 1 pièce de 5 F, 2 pièces de 10 F et 1 pièce de 25 F ; on tire 2 pièces successivement. X = valeur de la 1ʳᵉ pièce, Y = somme des deux.
X(Ω) = {5, 10, 25} ; Y(Ω) = {15, 20, 30, 35}. On construit le tableau à double entrée (lignes = X, colonnes = Y) : les totaux de lignes/colonnes donnent les lois marginales.
Fonction de répartition du couple : F(s, t) = P(X ≤ s, Y ≤ t) → les répartitions marginales s'en déduisent.
Loi conditionnelle de X sachant Y = yⱼ : P(X = xᵢ | Y = yⱼ) = P(X = xᵢ, Y = yⱼ) / P(Y = yⱼ).
Indépendance stochastique : X et Y indépendantes ⟺ P(X = xᵢ, Y = yⱼ) = P(X = xᵢ) × P(Y = yⱼ) pour tout couple (i, j).
Covariance : Cov(X,Y) = E[XY] − E[X]·E[Y] où E[XY] = Σᵢ Σⱼ xᵢyⱼ P(X=xᵢ, Y=yⱼ).
Coefficient de corrélation : ρ(X,Y) = Cov(X,Y) / [σ(X)·σ(Y)] ∈ [−1, 1].
Var(X + Y) = Var[X] + Var[Y] + 2·Cov(X,Y)
Si X et Y indépendantes : E[XY] = E[X]·E[Y], Cov = 0, Var(X+Y) = Var(X) + Var(Y). (Indépendance ⟹ Cov = 0, réciproque fausse !)

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier de vérifier Σ pᵢ = 1 — une « loi » dont la somme ≠ 1 est fausse.
  • Confondre E[X²] et (E[X])² — la variance c'est la différence des deux.
  • Croire que les lois marginales suffisent à reconstruire la loi jointe.
  • Conclure à l'indépendance parce que Cov = 0 (réciproque fausse).
  • Oublier le terme 2·Cov(X,Y) dans Var(X + Y) quand les variables sont dépendantes.
