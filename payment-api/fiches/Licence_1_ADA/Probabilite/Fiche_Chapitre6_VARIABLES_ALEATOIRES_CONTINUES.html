I. Du discret au continu : ce qui change

Variable aléatoire continue : v.a. qui peut prendre toutes les valeurs d'un intervalle (borné ou non) — en général, toute variable issue d'une mesure (temps, taille, prix, durée de vie).
Conséquence fondamentale : P(X = x) = 0 pour toute valeur exacte x — l'infini des valeurs possibles rend chaque cas isolé de probabilité nulle. On ne peut plus définir la loi par une liste de pᵢ : on passe par la densité et les intégrales.
Fonction de répartition : F(t) = P(X ≤ t), comme dans le cas discret — mais ici F est continue et croissante (pas en escalier), de ℝ vers [0, 1].
P(a ≤ X ≤ b) = F(b) − F(a) — et comme P(X=a) = 0, les inégalités strictes ou larges donnent le même résultat.

II. La densité de probabilité

Densité de probabilité f : fonction définie sur ℝ qui remplace la « liste des pᵢ ». Pour être une densité sur un intervalle I :
1. f est continue sur I (par morceaux) ;
2. f est positive : f(x) ≥ 0 ;
3. L'intégrale totale vaut 1 : ∫ f(x)dx = 1 (aire sous la courbe = 1).
Les deux formules à connaître :
• P(a ≤ X ≤ b) = ∫ab f(x)dx — une probabilité = une aire sous la densité.
• F(t) = ∫−∞t f(x)dx et réciproquement F′(x) = f(x) : la densité est la dérivée de la répartition.
Espérance et variance (versions continues) :
E[X] = ∫ x·f(x)dx ; E[X²] = ∫ x²·f(x)dx ; Var[X] = E[X²] − (E[X])² ; σ = √Var.
Même logique que le discret : la somme Σ devient une intégrale ∫.

III. Les lois continues usuelles

1. Loi uniforme U([a ; b]) : toutes les valeurs de [a, b] équiprobables — la densité est constante :
f(x) = 1/(b − a) si x ∈ [a, b], et 0 sinon.
On note X ~ U([a ; b]). Typique d'un temps d'attente aléatoire dans une fenêtre donnée.
Propriétés de l'uniforme : densité = rectangle de hauteur 1/(b−a).
E[X] = (a + b)/2 (le milieu) ; Var[X] = (b − a)²/12.
P(c ≤ X ≤ d) = (d − c)/(b − a) pour [c,d] ⊆ [a,b] — simple rapport de longueurs.
2. Loi exponentielle ℰ(λ) : variable positive modélisant une durée de vie / temps d'attente sans mémoire.
Densité : f(x) = λ·e^(−λx) pour x ≥ 0 (0 sinon), λ > 0. On note X ~ ℰ(λ).
E[X] = 1/λ ; Var[X] = 1/λ².
Propriété « sans mémoire » : P(X > s + t | X > s) = P(X > t) — le fait d'avoir déjà attendu ne change pas la probabilité d'attendre encore. C'est l'analogue continu de la loi géométrique.
Applications : durée de vie d'un composant, temps entre deux pannes, temps d'attente à un guichet (lié au processus de Poisson : si les arrivées suivent 𝒫(λ), l'intervalle entre deux arrivées ~ ℰ(λ)).
3. Loi normale (Laplace-Gauss) N(m, σ) : la loi la plus célèbre — courbe en cloche, symétrique autour de la moyenne m.
Densité : f(x) = (1/σ√(2π)) × e^(−(x−m)²/(2σ²))
m = moyenne (E[X] = m) ; σ = écart-type (Var[X] = σ²). On note X ~ N(m, σ²).
Centrage et réduction — la clé de tous les calculs :
Si X ~ N(m, σ²), alors Z = (X − m)/σ ~ N(0, 1) (loi normale centrée réduite, notée Φ).
On lit P(Z ≤ z) dans la table de la loi normale, puis on revient à X.
Repères : environ 68 % des valeurs dans [m−σ ; m+σ], 95 % dans [m−2σ ; m+2σ], 99,7 % dans [m−3σ ; m+3σ].

⚠️ Pièges classiques :
  • Écrire « P(X = 5) » pour une variable continue — la réponse est toujours 0 ; on calcule des P(a ≤ X ≤ b).
  • Oublier de vérifier ∫f = 1 quand on construit une densité (constante de normalisation).
  • Confondre densité f(x) (peut dépasser 1 !) et probabilité (toujours ≤ 1).
  • Loi uniforme : calculer des probabilités par intégrale alors qu'un rapport de longueurs suffit.
  • Loi normale : lire directement X dans la table au lieu de centrer-réduire d'abord (Z = (X−m)/σ).
