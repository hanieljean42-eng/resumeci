I. Notion d'ensemble et cardinal

Ensemble : collection d'objets appelés éléments — ordonnés ou non, en nombre fini (dénombrable) ou infini. Désigné par une lettre majuscule.
Cardinal : nombre d'éléments d'un ensemble fini E, noté Card(E) ou |E|. Ex. E = {1,2,3,4,5,6} (lancé de dé) → Card(E) = 6.
Dénombrer = compter le nombre d'éléments — indispensable pour calculer des probabilités (dénombrer l'univers des possibles).
Inclusion : A ⊆ B si tout élément de A est élément de B : A ⊆ B ⟺ [∀x, x ∈ A ⟹ x ∈ B]. On dit aussi que A est un sous-ensemble de B.
Égalité : A = B ⟺ (A ⊆ B et B ⊆ A).
Ensemble des parties P(E) : ensemble dont les éléments sont tous les sous-ensembles de E (y compris ∅ et E lui-même).
Si Card(E) = n alors Card(P(E)) = 2ⁿ.
Ex. E = {x, y, z} → P(E) = {∅, {x}, {y}, {z}, {x,y}, {x,z}, {y,z}, {x,y,z}} → 2³ = 8 parties.
Application gestion : avec une équipe de 3 spécialistes, le nombre d'équipes possibles (y compris l'équipe vide) = 8.

II. Les opérations sur les ensembles

OpérationNotationDéfinition
IntersectionA ∩ BÉléments appartenant à A ET à B (ce qu'ils ont en commun).
RéunionA ∪ BÉléments appartenant à A, à B ou aux deux (« ou » non exclusif).
Ensembles disjointsA ∩ B = ∅Aucun élément en commun.
DifférenceA \ BÉléments dans A mais pas dans B.
Différence symétriqueA Δ BÉléments dans A ou dans B mais pas dans A ∩ B : A Δ B = (A\B) ∪ (B\A) = (A∪B)\(A∩B).
ComplémentaireĀ (ou U\A)Éléments de l'univers U qui ne sont pas dans A.
Exemples : A = {a,b}, B = {b,1,2} → A ∪ B = {a,b,1,2}, A ∩ B = {b}.
A = {a,b,c,d,e,f}, B = {e,f,g,h} → A\B = {a,b,c,d} ; A Δ B = {a,b,c,d,g,h}.
U = {1,…,10}, A = {2,4,6,8,10} → Ā = {1,3,5,7,9}.
Lois de Morgan : le complément « distribue » en inversant l'opération :
(A ∪ B)̄ = Ā ∩ B̄ (ni dans A, ni dans B)
(A ∩ B)̄ = Ā ∪ B̄ (en dehors de l'intersection)

III. Propriétés de ∩ et ∪

  • A ∩ A = A ; A ∩ E = A ; A ∩ ∅ = ∅
  • A ∪ A = A ; A ∪ E = E ; A ∪ ∅ = A
  • A ∩ B ⊆ A ⊆ A ∪ B
  • Distributivité : A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) ; A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
  • A ⊆ B ⟹ (A ∩ C ⊆ B ∩ C) et (A ∪ C ⊆ B ∪ C)

IV. Les ensembles finis : les deux principes de dénombrement

Principe additif : si E₁, E₂, …, Ep sont deux à deux disjoints :
Card(E₁ ∪ E₂ ∪ … ∪ Ep) = Card(E₁) + Card(E₂) + … + Card(Ep)
Ex. E réparti en 3 classes disjointes : A (4 él.), B (3 él.), C (5 él.) → Card(E) = 4 + 3 + 5 = 12.
⚠️ Si les ensembles ne sont PAS disjoints : formule d'inclusion-exclusion :
Card(A ∪ B) = Card(A) + Card(B) − Card(A ∩ B)
Exemple résolu : dans une classe, 16 élèves pratiquent le latin, 14 le théâtre, 5 les deux, 8 aucune option.
Card(L ∪ T) = 16 + 14 − 5 = 25 ; total classe = 25 + 8 = 33 élèves.
Principe multiplicatif (produit cartésien) :
A × B = {couples (a,b) / a ∈ A et b ∈ B}
Card(E₁ × E₂ × … × Ep) = Card(E₁) × Card(E₂) × … × Card(Ep)

Exemple restaurant : 3 entrées, 4 plats, 2 desserts → menus (entrée, plat, dessert) = 3 × 4 × 2 = 24. Si le dessert est imposé (tarte) → 3 × 4 × 1 = 12.
Exemple : 3 femmes × 3 robes × 3 renards = 27 triplets possibles.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Appliquer le principe additif à des ensembles non disjoints → soustraire l'intersection !
  • Confondre ∈ (élément) et ⊆ (sous-ensemble) : A ⊆ E ⟺ A ∈ P(E).
  • Oublier ∅ dans P(E) : un ensemble de n éléments a 2ⁿ parties.
  • Lire « ou » comme exclusif : en mathématiques, A ∪ B inclut les éléments communs.
  • Inverser les lois de Morgan : le complément de ∪ = ∩ des compléments (et inversement).
