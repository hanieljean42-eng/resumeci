I. L'épreuve de Bernoulli et la loi de Bernoulli

Épreuve de Bernoulli : phénomène aléatoire à 2 issues seulement : succès (S) de probabilité p, échec (E) de probabilité q = 1 − p. On pose Ω = {S, E} et X(S) = 1, X(E) = 0 → X(Ω) = {0, 1}.
Loi de Bernoulli B(p) : P(X=1) = p ; P(X=0) = 1 − p.
E[X] = p ; Var[X] = p(1 − p).
Exemples :
• Boîte de 80 stylos (35 bleus, 20 rouges, 25 verts), événement « stylo rouge » : X ~ B(20/80) = B(1/4).
• 10 chaînes de fabrication, une défaillante testée au hasard : X ~ B(1/10).
• Dé équilibré, événement « obtenir 2 » : X ~ B(1/6).

II. La loi binomiale B(n, p)

X = nombre de succès après n répétitions indépendantes d'une même épreuve de Bernoulli (≡ n tirages AVEC remise).
X(Ω) = {0, 1, …, n} ; P(X = k) = C(n,k) × pᵏ × (1−p)ⁿ⁻ᵏ. On note X ~ B(n, p).
Propriétés : E[X] = np ; Var[X] = np(1−p).
Si X₁ ~ B(n₁,p) et X₂ ~ B(n₂,p) indépendantes → X₁ + X₂ ~ B(n₁+n₂, p).
Cas particulier : B(p) = B(1, p).
Exemples :
• 12 tirages avec remise dans la boîte de stylos, « nombre de rouges » : X ~ B(12, 1/4) → E[X] = 3.
• 10 lancers de dé, probabilité d'obtenir 4 fois le chiffre 5 : P(X=4) = C(10,4) × (1/6)⁴ × (5/6)⁶.

III. La loi hypergéométrique H(N, n, p)

Tirage SANS remise : population de N individus dont K possèdent le caractère étudié (p = K/N) ; on prélève un échantillon de n individus.
X = nombre de fois que le caractère apparaît : P(X = k) = C(K,k) × C(N−K, n−k) / C(N, n).
Propriétés : E[X] = np (comme la binomiale !) ; Var[X] = np(1−p) × (N−n)/(N−1).
Binomiale = tirage AVEC remise (indépendant) ; Hypergéométrique = SANS remise (dépendant).
Approximation : si N → ∞ (grande population), H(N,n,p) ≈ B(n,p) — sans remise ≈ avec remise.
Exemples :
• 15 employés dont 6 de niveau master ; on en choisit 5 pour un contrôle : X ~ H(15, 5, 6/15) → E[X] = 5 × 6/15 = 2.
• Examen de 20 sujets, le candidat en a révisé 12 et en tire 2 : P(X ≥ 1) = 1 − P(X=0) = 1 − C(8,2)/C(20,2).

IV. Loi géométrique et loi de Pascal

Loi géométrique G(p) : X = nombre de répétitions pour obtenir le 1ᵉʳ succès.
X(Ω) = ℕ* ; P(X = k) = p × (1−p)ᵏ⁻¹.
E[X] = 1/p ; Var[X] = (1−p)/p².
Exemple : machine avec probabilité de panne 0,01 à chaque utilisation ; X = nombre d'utilisations avant la 1ʳᵉ panne : X ~ G(0,01) → P(X=k) = 0,01 × 0,99ᵏ⁻¹ ; E[X] = 1/0,01 = 100 utilisations.
Loi de Pascal Pasc(n, p) : X = nombre de répétitions pour obtenir les n premiers succès (généralisation de la géométrique : n = 1).
X(Ω) = {n, n+1, n+2, …} ; P(X = k) = C(k−1, n−1) × pⁿ × (1−p)ᵏ⁻ⁿ.
E[X] = n/p ; Var[X] = n(1−p)/p².
Exemple : même machine, X = nombre d'utilisations pour 10 pannes : X ~ Pasc(10 ; 0,01) → E[X] = 10/0,01 = 1 000.

V. La loi de Poisson 𝒫(λ)

Processus de Poisson : événements indépendants, se produisant un à la fois, à rythme constant sur une période fixe.
Loi des événements rares : X(Ω) = ℕ ; P(X = k) = e⁻λ × λᵏ / k! avec λ > 0. On note X ~ 𝒫(λ).
E[X] = λ et Var[X] = λ (le paramètre = moyenne ET variance).
Approximation binomiale → Poisson : si n → ∞, p → 0 avec np → λ, alors B(n,p) ≈ 𝒫(λ).
Concrètement : événement rare (p faible) répété un grand nombre de fois (n grand) → Poisson avec λ = np.
Si le rythme est λ par unité de temps : P(k événements en temps t) = e^(−λt) × (λt)ᵏ / k!.
Exemple résolu : atterrissages dans un petit aéroport ~ 𝒫(2) par semaine (moyenne 2). Probabilité de 6 atterrissages en 1 mois ?
1 mois = 4 semaines → λt = 2 × 4 = 8 → P(X = 6) = e⁻⁸ × 8⁶ / 6! ≈ 0,122.

⚠️ Pièges classiques :
  • Confondre binomiale et hypergéométrique : la question « avec ou sans remise ? » décide de tout.
  • Oublier le coefficient C(n,k) dans P(X=k) de la binomiale.
  • Loi géométrique : le dernier essai est le succès → exposant (k−1) sur l'échec.
  • Poisson : adapter λ à la période demandée (λ par semaine ≠ λ par mois).
  • Croire que « rare » = « impossible » : Poisson donne P(X=k) > 0 pour tout k.
