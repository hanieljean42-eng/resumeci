📐 Mathématiques🏫 Terminale CLeçon 10 – Fonction exponentielle et fonction puissance

I. Fonction exponentielle

La fonction exponentielle exp, notée eˣ, est définie sur ℝ et vérifie :

  • exp(0) = 1 ;
  • (exp x)′ = exp x ;
  • exp est strictement croissante sur ℝ.
  • eˣ > 0 pour tout x ;
  • eˣ eʸ = eˣ⁺ʸ ;
  • e⁻ˣ = 1/eˣ.

II. Fonctions puissance x ↦ xᵃ

Pour un réel a, on définit des fonctions puissance du type :

f(x) = xᵃ

  • Pour a entier naturel n, f(x) = xⁿ définie sur ℝ.
  • Pour a = 1/n (n entier ≥ 2), f(x) = x¹/ⁿ définie sur [0; +∞[.
  • Pour d’autres réels a, les définitions passent par exp et ln (pas tous les détails ici).

III. Dérivées usuelles

  • (eˣ)′ = eˣ.
  • Pour n ≥ 1 entier, (xⁿ)′ = n xⁿ⁻¹.
  • Pour a réel, sous conditions de définition :

(xᵃ)′ = a xᵃ⁻¹

IV. Comparaisons de croissance

  • Pour x → +∞, eˣ domine toute puissance xᵃ (croît plus vite).
  • Pour x → −∞, eˣ tend plus vite vers 0 que 1/xᵃ.

V. À retenir

  • La fonction exponentielle est un modèle de croissance continue.
  • Les fonctions puissance généralisent les fonctions de type xⁿ et sont essentielles en analyse.
  • Les dérivées de eˣ et xᵃ sont des outils de base pour les études de fonctions et les intégrales.
