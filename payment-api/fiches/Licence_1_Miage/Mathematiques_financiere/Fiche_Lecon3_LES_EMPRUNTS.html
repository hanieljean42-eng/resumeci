I. L'emprunt indivis et le tableau d'amortissement

Emprunt indivis : emprunt ordinaire entre un seul prêteur et un emprunteur (indivisible). Remboursé généralement par annuités de fin de période. Chaque annuité comprend : ① un amortissement (remboursement d'une partie du capital) + ② un intérêt calculé sur le capital restant dû.
Tableau d'amortissement type :
Période | Capital restant dû Cₚ₋₁ | Intérêt Iₚ = Cₚ₋₁·i | Amortissement mₚ | Annuité aₚ = Iₚ + mₚ
Propriétés : Σmₚ = C₀ (les amortissements remboursent toute la dette) ; Cₙ₋₁ = mₙ (dernier restant dû = dernier amortissement) ; aₚ₊₁ = aₚ + mₚ₊₁ − mₚ(1+i) (relation entre annuités successives).

II. Les trois modes de remboursement

ModePrincipeCaractéristiques
In fineCapital remboursé en une fois à la fin ; chaque année ne paie que l'intérêt I = C₀·ia₁…aₙ₋₁ = I ; aₙ = I + C₀. Le capital restant dû reste C₀ jusqu'à la fin
Annuités constantesa₁ = a₂ = … = a constante ; les amortissements croissentmₚ₊₁ = mₚ(1+i) : les amortissements forment une progression géométrique de raison (1+i) ; a = m₁(1+i)ⁿ = mₙ(1+i) ; a = C₀·i / [1 − (1+i)⁻ⁿ]
Amortissements constantsm = C₀/n constant ; les annuités décroissentIₚ = (C₀ − (p−1)m)·i ; annuités en progression arithmétique de raison −m·i (elles décroissent car le restant dû diminue)
Dette remboursée après p annuités : Rₚ = m₁ + m₂ + … + mₚ. En annuités constantes : Rₚ = m₁×[(1+i)ᵖ − 1]/i = C₀×[(1+i)ᵖ − 1]/[(1+i)ⁿ − 1]. Dette non amortie = C₀ − Rₚ.

III. L'emprunt obligataire

Emprunt obligataire : quand le montant est trop élevé, l'emprunteur s'adresse à plusieurs prêteurs (obligataires/souscripteurs). L'emprunt est divisé en parts égales négociables : les obligations.
L'obligation donne droit à un intérêt annuel (coupon) et au remboursement du titre à l'échéance.
Relation de base : C₀ = N × VN (capital = nombre d'obligations × valeur nominale).
Éléments : valeur nominale VN (base du coupon), prix d'émission (peut différer du nominal), prix de remboursement (prime de remboursement si > nominal), taux nominal → coupon = VN × i.
Les principes mathématiques sont identiques à l'emprunt indivis — seul change le nombre de prêteurs.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Annuité = amortissement + intérêt : l'intérêt se calcule toujours sur le capital restant dû en début de période, pas sur C₀ (sauf in fine).
  • Annuités constantes → amortissements en progression géométrique (1+i) ; amortissements constants → annuités en progression arithmétique (−m·i). Ne pas inverser !
  • In fine : l'intérêt annuel est constant (= C₀·i) car le capital n'est jamais amorti avant la fin.
  • Retrouver a depuis le tableau : a = mₙ(1+i) (dernière ligne) ou a = C₀·i/[1−(1+i)⁻ⁿ].
  • Obligation : le coupon se calcule sur la valeur nominale VN, pas sur le prix d'émission ni le prix de remboursement.
