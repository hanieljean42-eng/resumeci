I. Les trois catégories de structures

StructurePrincipe
LinéaireLes actions s'exécutent les unes après les autres, en séquence
Alternative (conditionnelle)Selon une condition, le programme exécute des opérations différentes
Itérative (répétitive)Sous contrôle d'une condition, une séquence est exécutée répétitivement

II. Structure linéaire

Les actions successives sont mentionnées les unes après les autres. Ex. : saisir a, saisir b, p ← a * b, afficher p.

III. Structures alternatives

1. Si … Alors … FinSi

Si x > 0 Alors
  r ← racine(x) ; afficher(r)
FinSi

La condition testée détermine si l'action est exécutée.

2. Si … Alors … Sinon … FinSi

Si x < 0 Alors afficher('x est négatif')
Sinon r ← racine(x) ; afficher(r)
FinSi

La condition choisit entre deux groupes d'actions. On peut enchaîner avec SinonSi (ex. : négatif / nul / positif).

3. Choix multiple — Suivant … Faire … FinSuivant

Suivant c Faire
  'A'..'Z' : afficher('Lettre majuscule')
  'a'..'z' : afficher('Lettre minuscule')
  '0'..'9' : afficher('Chiffre')
  Sinon : afficher('Ni lettre ni chiffre')
FinSuivant
  • Une donnée est comparée successivement à des valeurs constantes ou plages de valeurs.
  • La partie Sinon est facultative ; plusieurs valeurs peuvent être regroupées si les actions sont identiques.

IV. Structures itératives

1. Répéter … Jusqu'à …

⚠️ Point clé : la condition est testée après les actions → les actions sont exécutées au moins une fois.
Répéter
  saisir a ; saisir b ; p ← a*b ; afficher p ; saisir réponse c
Jusqu'à c = 'N'

2. Tant Que … Faire … FinFaire

La condition est testée avant les actions → les actions peuvent ne jamais s'exécuter si la condition est fausse d'emblée.
Tant Que Non(ToucheAppuyée) Faire
  afficher('Attente')
FinFaire

3. Pour indice De … À … Faire … FinPour

  • Exécute les actions un nombre déterminé de fois : l'indice parcourt les valeurs de Val1 à Val2 (bornes incluses).
  • Un pas d'incrémentation différent est possible (+2, −1…).
  • Équivalent à un TantQue : i ← 1 ; TantQue i ≤ 80 Faire afficher('*') ; i ← i+1 FinFaire.
Pour i de 1 à 80 Faire
  afficher('*')
FinFaire

V. Techniques d'exercices à maîtriser

  • Signe d'un produit sans le calculer : Si (m>0 ET n>0) OU (m<0 ET n<0) → positif.
  • Loi de Morgan : Non(A OU B) = Non A ET Non B — ex. l'inverse de Tutu > Toto+4 OU Tata = "OK" est Tutu ≤ Toto+4 ET Tata ≠ "OK".
  • Gestion du temps : incrémenter les minutes, remettre à 0 et reporter quand on atteint 60 (minutes→heures), 24 (heures→0).
  • Tarifs par tranches : cumuler tranche par tranche (10×0,10 + 20×0,09 + (n−30)×0,08).
  • Conditions multiples : tester de la borne la plus grande vers la plus petite (ou l'inverse) avec SinonSi ; variables booléennes intermédiaires pour simplifier.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre Répéter…Jusqu'à (au moins 1 exécution, test après) et TantQue (0 exécution possible, test avant).
  • Oublier que les bornes du Pour sont incluses.
  • Mal inverser une condition composée : Non(A OU B) ≠ Non A OU Non B — c'est ET.
  • Mettre un SinonSi après un Sinon final.
💡 Réflexe : demande-toi d'abord si le test doit précéder ou suivre l'action — cela choisit entre TantQue et Répéter.
