II. Les fichiers

Fichier : ensemble de données servant soit à la lecture (rentrer des informations dans un programme), soit à l'écriture (sauvegarder des résultats).

Deux notions caractérisent un fichier :

  • Mode d'organisation : comment les données sont organisées (séquentiel, indexé…) ;
  • Mode d'accès : comment on accède aux données (séquentiel, direct…).
Toute manipulation d'un fichier = 3 phases : OUVRIR → Traitement (LIRE / ECRIRE / AJOUT) → FERMER.

1. Les fichiers texte

  • Organisation séquentielle : informations disposées les unes à la suite des autres, repérées par un pointeur ; l'accès ne peut être que séquentiel.
  • Trois opérations :
    • Lecture (Lire) : à l'ouverture le pointeur pointe la 1re information ; chaque Lire déplace le pointeur sur la suivante. Pour relire en amont → fermer, rouvrir, relire jusqu'à l'information voulue.
    • Écriture (Ecrire) : un fichier non vide ouvert en écriture perd tout son contenu — le pointeur se place au début.
    • Ajout (Ajout) : ajoute des données à la fin sans détruire l'existant — le pointeur se place sur la marque de fin de fichier.
  • EOF(Nomfichier) : fonction qui rend Vrai quand la fin du fichier est atteinte.

Pour i ← 1 à 100 Faire Lire(Fich1, Tab[i]) FinPour — lit 100 données dans un tableau
Ecrire(Fich1, "Le salaire annuel est de : ", Sal_Annuel) — écrit à la position du pointeur

⚠️ Attention : un fichier séquentiel ne peut être ouvert qu'en lecture OU en écriture — la première opération (Lire, Ecrire ou Ajout) détermine le mode d'accessibilité.

III. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Ouvrir un fichier non vide en écriture pour ajouter des données → tout est effacé ; il fallait Ajout.
  • Croire qu'on peut revenir en arrière dans un fichier texte sans le fermer/rouvrir.
  • Confondre enregistrement (champs de types différents) et tableau (éléments de même type).
  • Oublier la phase OUVRIR/FERMER autour du traitement.
💡 Réflexe : fichier texte = ruban séquentiel à pointeur : Lecture (avance), Ecrire (efface tout), Ajout (fin). Fin détectée par EOF.
