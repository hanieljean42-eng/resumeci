📖 Algorithme de base 🏫 Licence 1 MIAGE — Semestre 1 Leçon 3 : Les tableaux

I. Définition

Tableau : regroupement de variables de même type identifié par un nom. Chaque variable du tableau (appelée élément) est repérée par un numéro : l'indice. Un élément est donc caractérisé par nom du tableau + indice.
  • Par opposition : une variable qui n'est pas un tableau est une variable scalaire.
  • Structure statique : après déclaration, le tableau ne peut plus être redimensionné pendant l'exécution.
  • Convention possible : première case numérotée 1 (ou 0 selon les conventions) ; le numéro de la dernière case doit être supérieur à celui de la première.

II. Déclaration et accès

Syntaxes équivalentes :
numérique : T[4] — tableau T de 4 cases numériques
Tableau Notes[9] : Numérique
v : TABLEAU[ENTIER][1,30] — cases numérotées de 1 à 30
v : TABLEAU[1..30] d'ENTIER (style Pascal)
  • L'accès se fait par T[i] : l'élément d'indice i du tableau T.
  • Un tableau de 10 éléments a des indices de 1 à 10 (ou 0 à 9 selon la convention).

III. Traitements classiques (boucle Pour)

Initialiser à zéro :
Pour i ← 0 à 6 Faire Truc[i] ← 0 FinPour

Saisie utilisateur :
Pour i ← 0 à 8 Faire Ecrire "Entrez la note n°", i+1 ; Lire Notes[i] FinPour

Moyenne :
s ← 0 ; Pour i ← 0 à 8 Faire s ← s + Notes[i] FinPour ; Ecrire s/9

Exemples typiques produits par les exercices :

  • Nb[i] ← i*i → tableau des carrés : 0, 1, 4, 9, 16, 25.
  • N[k] ← N[k-1] + 2 avec N[0]=1 → suite arithmétique : 1, 3, 5, 7, 9, 11, 13.
  • Suite[i] ← Suite[i-1] + Suite[i-2] avec 1, 1 au départ → Fibonacci : 1, 1, 2, 3, 5, 8, 13, 21.

IV. Tableaux multidimensionnels

Tableau à N dimensions : structure contenant des éléments de même type où chaque élément est repéré par N indices.
Matrice 3 lignes × 5 colonnes :
m : TABLEAU[ENTIER][1,3][1,5] ou m : MATRICE[ENTIER][1,3][1,5]
Accès : m[i,j] = élément de la ligne i, colonne j.
Autre ex. : Note[1..30, 1..8] : Réel
  • Une matrice = tableau de tableaux : TABLEAU[1,3][1,5] = 3 tableaux de 5 composantes.
  • On peut déclarer un tableau de matrices, une matrice de matrices…

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Déclarer un tableau sans préciser le type et le nombre de cases — les deux sont obligatoires.
  • Confondre l'indice de départ (0 ou 1 selon la convention) — vérifier la déclaration avant de dérouler une boucle.
  • Essayer de redimensionner un tableau en cours d'exécution : structure statique, interdit.
  • Mélanger les types : un tableau ne contient que des données homogènes.
  • Erreur de borne : dans Pour i ← 0 à 5, i prend 6 valeurs (0 incluse).
💡 Réflexe : pour lire un algorithme à tableau, déroule les 2-3 premières itérations à la main — la loi de remplissage apparaît immédiatement (carrés, Fibonacci, suite arithmétique…).
