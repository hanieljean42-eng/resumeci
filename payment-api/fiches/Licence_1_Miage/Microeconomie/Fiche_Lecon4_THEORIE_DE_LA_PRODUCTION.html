I. Concepts de base

Fonction de production : relation entre les quantités de facteurs employées et le volume de production obtenu : q = f(x, y). Supposée continue, dérivable, obéissant au principe de non-gaspillage. Facteurs : travail (L, coût w), capital (K, coût r) ; technologie = ensemble des connaissances industrielles et agricoles. Facteur fixe : quantité indépendante du volume produit (terre, équipements) ; facteur variable : modifiable à volonté (travail, matières premières).
HorizonFonctionCaractéristique
Court termeQ = F(K̄, L)La capacité installée (K) est une donnée ; seuls les facteurs variables font varier la production
Long termeQ = F(K, L)Délai suffisamment long pour que tous les facteurs soient variables

La firme poursuit un objectif unique — maximiser le profit — par deux voies équivalentes : maximiser l'output sous contrainte de coût (programme primal) ou minimiser le coût sous contrainte d'output (programme dual).

II. Court terme : PT, PM et Pm

GrandeurDéfinitionFormule
Produit total (PT)Quantité produite avec K fixePT = F(K̄, L)
Produit moyen (PM)PT par unité de facteur variablePML = PT/L
Produit marginal (Pm)Variation de PT d'une unité supplémentaire de LPmL = ∂PT/∂L
Trois phases de la courbe PT :
① Jusqu'au point d'inflexion A : PT convexe, croît plus que proportionnellement → Pm maximum en A′.
② De A à B : PT concave, croît moins que proportionnellement → Pm décroissante ; PM maximale en B′, où PmL = PML (le marginal coupe le moyen en son maximum).
③ De B à C : saturation, Pm s'annule en C′ → loi des productivités marginales décroissantes (loi des rendements factoriels décroissants).

III. Long terme : isoquantes et TMST

Isoquante (isoproduit) : lieu géométrique des combinaisons (K, L) procurant le même niveau de production — équivalent, pour la firme, de la courbe d'indifférence. Cas atypiques : facteurs parfaitement substituables (isoquantes droites) ou complémentaires/fixes (en L).
TMSTK/L : quantité de K que l'on peut abandonner par unité de L ajoutée, à production constante : TMSTK/L = −dK/dL = PmL/PmK (par la différentielle totale : PmKdK + PmLdL = 0). Isocline : lieu des points où le TMST est constant ; les isoclines limites (TMSTK/L = 0 c.-à-d. PmL = 0, et TMSTL/K = 0 c.-à-d. PmK = 0) délimitent la zone de production efficiente.

IV. Les décisions de l'entreprise

Droite d'isocoût : lieu des combinaisons de facteurs (x₁, x₂) accessibles pour un coût total donné : C₀ = r₁x₁ + r₂x₂ (+ b pour les facteurs fixes). Pente = −r₁/r₂.
Primal : max f(x₁, x₂) s.c. C₀ = r₁x₁ + r₂x₂ → L = f + λ[C₀ − r₁x₁ − r₂x₂] → f′x₁/f′x₂ = r₁/r₂ (TMST = rapport des prix des facteurs) → hessien bordé > 0.
Dual : min r₁x₁ + r₂x₂ + b s.c. f(x₁, x₂) = q̄ → même condition f′x₁/f′x₂ = r₁/r₂ → fonctions de demande conditionnelle de facteurs → hessien bordé < 0.
  • Multiplicateurs : dans la max : Pmx₁/r₁ = Pmx₂/r₂ — la productivité marginale du dernier franc dépensé est égale pour tous les facteurs ; dans la min : le multiplicateur μ = coût marginal (coût d'une unité additionnelle produite).

V. Les rendements d'échelle

Indiquent dans quelle proportion varie l'output quand tous les inputs varient dans la même proportion t : F(tK, tL) = tαF(K, L). α > 1 → croissants ; α = 1 → constants ; α < 1 → décroissants.
Ex. : F(K, L) = K1/2L2/3 → F(tK, tL) = t7/6F(K, L) : fonction homogène de degré 7/6 > 1 → rendements croissants : doubler les facteurs multiplie la production par plus de 2.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre productivités marginales décroissantes (court terme, un seul facteur varie) et rendements d'échelle (long terme, tous les facteurs varient).
  • Pm ≠ PM : la Pm coupe la PM en son maximum — c'est la relation clé du graphique.
  • À l'optimum : c'est le TMST qui égale r/w (prix relatifs des facteurs), pas les prix des biens comme pour le consommateur.
  • Pour une Cobb-Douglas AKαLβ, le degré d'homogénéité = α + β.
