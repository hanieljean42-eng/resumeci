📖 Microéconomie 🏫 Licence 1 MIAGE — Semestre 1 Leçon 5 : La théorie des coûts et l'offre de la firme

I. Les coûts de courte période

CoûtDéfinitionFormule
Coût fixe (CF)Charges indépendantes du niveau de production (loyers, impôt foncier) — aucun contrôle à CTconstante
Coût variable (CV)Dépenses en facteurs variables (matières, main-d'œuvre, intérêts CT) — modifiables à volontéCV(q)
Coût total (CT)Somme des deuxCT = CF + CV
Coût fixe moyenCFM = CF/q
Coût variable moyenCVM = CV/q
Coût moyen totalCM = CT/q = CFM + CVM
Coût marginal (Cm)Accroissement du coût total dû à une unité supplémentaire produiteCm = dCT/dq = dCV/dq (dCF/dq = 0)
Relation clé : le Cm coupe la courbe de CM en son minimum (comme Pm coupait PM en son maximum).

II. La condition d'équilibre du producteur (court terme)

La firme maximise le profit Π(q) = RT(q) − CT(q) = p·q − CT(q).
CIO : dΠ/dq = p − Cm(q) = 0 ⇒ p = Cm(q) (le prix égale le coût marginal).
CIIO : d²Π/dq² < 0 ⇔ dCm/dq > 0 ⇒ le Cm doit être croissant.

III. Seuil de rentabilité, seuil de fermeture et fonction d'offre

Situation du prix pConséquence
p = pe (min CM)Seuil de rentabilité E : la recette couvre exactement CV + CF — profit nul
p > peLa firme produit plus que qe et dégage un profit
pa < p < pePertes : les recettes couvrent le CV mais pas tout le CF — on produit quand même (mieux que fermer)
p = pa (min CVM)Seuil de fermeture A : la recette rembourse juste le coût variable total
p < paOffre nulle : la firme ferme
Fonction d'offre : la branche croissante du coût marginal au-dessus du seuil de fermeture (au-dessus du min CVM) : p = Cm(q) ⇒ q = f(p) pour p ≥ pa, et 0 sinon.
Exemple corrigé : CT(q) = q³ + q + 16.
CF = 16 ; CV = q³ + q ; CVM = q² + 1 ; CM = q² + 1 + 16/q ; Cm = 3q² + 1.
Seuil de fermeture (min CVM, q > 0) ou min CM de l'offre : CM′(q) = 2q − 16/q² = 0 → q³ = 8 → q = 2 → CM(2) = 13 = pmin.
Offre : p = 3q² + 1 → q = √((p−1)/3) si p ≥ 13, et 0 si p < 13.

IV. La décision de production à long terme

À long terme, la firme produit au point où recette marginale = coût marginal de long terme (Rm = CmL), puis vérifie sa rentabilité :
• p > CML → profits, elle reste dans la branche ;
• p = CML → point d'équilibre d'exploitation (point mort) : RT = CT, ni profit ni perte ;
• p < CML → pertes → elle doit envisager de cesser son activité.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Seuil de rentabilité = min du coût moyen (couvre CV+CF) ; seuil de fermeture = min du CVM (couvre juste le variable). Ne pas les confondre.
  • L'offre n'existe que sur la partie croissante de Cm au-dessus de pa — pas en dessous.
  • Entre pa et pe, produire malgré les pertes est rationnel : cela couvre le CV et une partie du CF.
  • Cm = dCT/dq = dCV/dq car dCF/dq = 0 — ne pas dériver le coût fixe.
