📖 Microéconomie 🏫 Licence 1 MIAGE — Semestre 1 Leçon 2 : Contrainte budgétaire et équilibre du consommateur

I. La droite de budget

Contrainte budgétaire : la dépense totale ne doit pas dépasser le revenu : R = X·Px + Y·Py (le consommateur dépense tout son revenu). La droite de budget représente tous les paniers coûtant exactement R. Extrémités : tout en Y → (0, R/Py) ; tout en X → (R/Px, 0). Pente = −Px/Py (prix relatif).
  • Variation du revenu (prix constants) : déplacement parallèle — hausse → vers la droite ; baisse → vers la gauche.
  • Variation d'un prix : pivotement de la droite autour de l'intersection de l'autre axe (seule l'intersection du bien concerné change).
  • Si les deux prix varient dans la même proportion (rapport inchangé) : la pente ne change pas → déplacement parallèle.

II. L'équilibre du consommateur

Programme : max U(x, y) sous contrainte R = XPx + YPy. Le panier optimal doit : (1) se situer sur la droite de budget et (2) être la combinaison préférée → point de tangence entre droite de budget et courbe d'indifférence la plus élevée possible.
Condition d'équilibre : TMS = Px/Py, c.-à-d. Umx/Umy = Px/Py — le taux d'échange subjectif égale le taux d'échange objectif (marché).

III. Les méthodes de résolution

1. Méthode de substitution

De la contrainte : Y = R/Py − (Px/Py)X. On injecte dans U(x, y) → fonction d'une seule variable à maximiser : U′(X) = 0 (condition nécessaire) et U″(X) < 0 pour un maximum (> 0 pour un minimum).

2. Méthode graphique

Avec U = XY = k (constante) : Y = k/X — famille d'hyperboles ; l'équilibre est la tangence avec la droite de budget.

3. Multiplicateur de Lagrange (programme primal / marshallien)

L(x, y, λ) = U(x, y) + λ[R − XPx − YPy]
CIO : L′x = 0 → Umx = λPx (1) ; L′y = 0 → Umy = λPy (2) ; L′λ = 0 → R = XPx + YPy (3).
(1)/(2) : Umx/Umy = Px/Py → combinée à (3) → fonctions de demande marshallienne X*(Px, Py, R) et Y*(Px, Py, R).
CIIO : déterminant hessien bordé > 0 pour un maximum.
λ = utilité marginale d'un franc supplémentaire dépensé ; de façon générale le multiplicateur mesure l'effet d'une variation de la contrainte sur la solution optimale.
Propriétés des demandes marshalliennes : (1) univoques en prix et revenu (convexité des préférences → maximum unique) ; (2) homogènes de degré 0 : X(kPx, kPy, kR) = X(Px, Py, R) — si tous les prix et le revenu varient dans la même proportion, la demande est inchangée.
Exemple corrigé : U = XY, R = 40, Px = 2, Py = 3 → condition : Y = XPx/Py → X* = R/2Px = 10 ; Y* = R/2Py ≈ 6,67 ; hessien bordé = 12 > 0 ; U* ≈ 66,7.

4. Programme dual : demandes compensées (hicksiennes)

Objectif dual : minimiser la dépense XPx + YPy sous contrainte d'utilité fixée U(x, y) = Ū. L(x, y, μ) = XPx + YPy + μ[Ū − U(x, y)] → CIO : Px = μ·U′x, Py = μ·U′y, U = Ū → même condition Umx/Umy = Px/Py → fonctions de demande compensée Xc(Px, Py, Ū) et Yc(Px, Py, Ū). CIIO : hessien bordé < 0 pour un minimum.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Écrire TMS = Py/Px : c'est Px/Py (le prix du bien en abscisse au numérateur).
  • Confondre les programmes : primal = max U sous contrainte de revenu (demandes marshalliennes, paramètre R) ; dual = min dépense sous contrainte d'utilité (demandes hicksiennes, paramètre Ū).
  • Hessien bordé : > 0 pour un maximum, < 0 pour un minimum — l'inverse des conventions habituelles.
  • Oublier que les prix doubles ET le revenu doublé laissent la demande inchangée (homogénéité de degré 0).
