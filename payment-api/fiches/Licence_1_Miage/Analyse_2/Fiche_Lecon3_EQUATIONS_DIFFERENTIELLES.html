I. Équations linéaires du 1ᵉʳ ordre

Équation homogène : y′(x) = a(x)y(x), a continue sur I. Solution générale : y(x) = CeA(x) où A est une primitive de a.
Problème de Cauchy : y′ = a(x)y avec y(x₀) = y₀ admet l'unique solution y(x) = y₀·e∫x₀x a(t)dt. Conséquence : une solution nulle en un point est identiquement nulle.
Ex. : y′ + ky = 0 (coefficients constants) → y(x) = Ce−kx.

Équation avec second membre : y′ = a(x)y + b(x)

Structure : y = yh + yp — solution générale de l'homogène + une solution particulière. Méthode en 2 phases : (1) résoudre l'homogène, (2) chercher yp.
Second membre (a constant)Forme de yp
Polynôme P de degré nPolynôme de degré n (n+1 si a = 0), coefficients par identification
βeαx, α ≠ ayp = βeαx/(α − a)
βeαx, α = ayp = βx·eαx
α cos(ωx) + β sin(ωx)A cos(ωx) + B sin(ωx), A et B par identification
Autre formeVariation de la constante
Variation de la constante : poser yp(x) = φ(x)eA(x) ; en reportant, φ′(x)eA(x) = b(x), donc φ = primitive de b(x)e−A(x). Solution générale : y = [C + φ(x)]eA(x).

II. Équations linéaires du 2nd ordre à coefficients constants

Forme : ay″ + by′ + cy = f(x) (a,b,c ∈ ℝ). Solution générale : y = yh + yp.
Équation caractéristique : ar² + br + c = 0 associée à l'homogène ay″ + by′ + cy = 0.
Racines de ar² + br + c = 0Solution générale yh
Deux racines réelles distinctes r₁, r₂y = αer₁x + βer₂x
Racine double ry = (α + βx)erx
Racines complexes conjuguéesy = [α cos(ωx) + β sin(ωx)]e−(b/2a)x
Solutions indépendantes : φ et ψ sont indépendantes si le wronskien W(x) = φψ′ − φ′ψ ≠ 0.

Solutions particulières (2nd ordre)

  • P polynôme de degré n : yp polynôme de degré n si c ≠ 0 ; n+1 si c = 0 et b ≠ 0 ; n+2 si b = c = 0.
  • A cos(βx) + B sin(βx) : yp = C cos + D sin ; si cos(βx) est solution de l'homogène → yp = x[C cos + D sin].
  • φ(x)eαx : poser yp = u(x)eαx pour éliminer l'exponentielle.

III. Équations non linéaires

Variables séparables

Forme : a(y(x))·y′(x) = b(x) — y d'un côté, x de l'autre. En intégrant : A(y(x)) = B(x) + C (A, B primitives de a, b) ; si A est bijective : y(x) = A⁻¹[B(x) + C].
Ex. : x³y′ + y³ = 0 → y′/y³... conduit à y(x) = ±√(x²/(Cx² − 1)).

Équation de Bernoulli

Forme : y′ = a(x)yα + b(x)y (α ≠ 0,1). y = 0 est solution évidente. Pour les autres : poser z = y1−α → on obtient une équation linéaire en z.

Équation de Riccati

Forme : y′ = a(x)y² + b(x)y + c(x). Résoluble si l'on connaît une solution particulière φ : poser y = u + φ → équation de Bernoulli en u (α = 2), puis z = 1/u → linéaire.
Ex. : y′ + y/x − y² = −1/x² ; φ = 1/x est particulière → u = y − 1/x → z = 1/u → y = 1/x − 2x/(x² + C).

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier yh : la solution générale = homogène + particulière, toujours.
  • Racine double de l'équation caractéristique : c'est (α + βx)erx, pas une seule exponentielle.
  • Second membre eαx avec α = a : la forme Aeαx échoue → βx·eαx.
  • Bernoulli : ne pas oublier la solution triviale y = 0.
  • Variables séparables : la solution peut rester implicite A(y) = B(x) + C — expliciter seulement si A est inversible.
