I. Primitives : définitions

Primitive : F est une primitive de f sur l'intervalle I si F est dérivable sur I et F′(x) = f(x) pour tout x ∈ I.
Propriétés clés :
  • Si F est une primitive de f, alors toutes les primitives sont G(x) = F(x) + C (C réel) — deux primitives ne diffèrent que d'une constante.
  • Unicité : x ↦ F(x) − F(a) est l'unique primitive de f qui s'annule en a.
  • Théorème fondamental : si f est continue sur I, la fonction x ↦ ∫ax f(t)dt est l'unique primitive de f qui s'annule en a.
Calcul intégral : pour f continue et F primitive de f : ∫ab f(t)dt = [F(t)]ab = F(b) − F(a). Ex. : ∫0π/2 cos x dx = [sin x] = 1.
Notations : ∫ab f(t)dt = intégrale définie = un nombre réel (t est une variable muette). ∫ f(x)dx = intégrale indéfinie = une primitive quelconque = une fonction.

III. Méthodes de calcul

Intégration par parties (IPP)

∫ab u(t)v′(t)dt = [u(t)v(t)]ab − ∫ab u′(t)v(t)dt
Usage type : ∫ x ln x dx, ∫ x²ex dx (on dérive le polynôme ou le ln).

Changement de variable — règles de Bioche

Pour f(x) rationnelle en cos x et sin x :
  • f(x)dx invariant par x → −x : poser u = cos x
  • invariant par x → π−x : poser u = sin x
  • invariant par x → π+x : poser u = tan x
  • deux invariances ⟹ la 3ᵉ aussi : poser u = cos 2x
  • Cas général : u = tan(x/2) ; alors cos x = (1−u²)/(1+u²), sin x = 2u/(1+u²), dx = 2du/(1+u²).

IV. Calcul d'aires

  • f ≥ 0 sur [a;b] : A = ∫ab f(t)dt u.a
  • f ≤ 0 : A = −∫ab f(t)dt u.a
  • Signe non constant : A = ∫ab |f(t)|dt u.a
  • Entre deux courbes (f ≤ g) : A = ∫ab [g(x) − f(x)]dx u.a
Unité d'aire : 1 u.a = ‖i‖ × ‖j‖ cm². Ex. : ‖i‖ = 2 cm, ‖j‖ = 3 cm → 1 u.a = 6 cm².

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier la constante +C dans une primitive (et la déterminer par la condition initiale).
  • ∫1/x dx = ln||x||, pas ln x — penser à la valeur absolue.
  • Confondre intégrale définie (nombre) et indéfinie (fonction).
  • IPP : vérifier que la nouvelle intégrale est plus simple — sinon inverser u et v′.
  • Aire ≠ intégrale : une aire est toujours positive → intégrer |f| ou découper.
