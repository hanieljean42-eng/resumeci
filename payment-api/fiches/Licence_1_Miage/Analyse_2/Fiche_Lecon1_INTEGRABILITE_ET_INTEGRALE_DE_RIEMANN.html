📖 Analyse 2 🏫 Licence 1 MIAGE — Semestre 2 Leçon 1 : Intégrabilité et intégrale de Riemann

I. Objectif et démarche

Intégrale définie : pour une fonction réelle f définie sur un intervalle I et deux points a, b de I, le symbole ∫ab f(x)dx représente l'aire de l'ensemble Ea,b(f) = {(x,y) ∈ ℝ², a ≤ x ≤ b, 0 ≤ y ≤ f(x)} — les aires sous l'axe des x étant comptées négativement.
Démarche en 3 étapes : découper l'intervalle [a;b] → encadrer f par des fonctions constantes (f doit être bornée) → additionner les aires.
Conditions fondamentales :
  • f constante = k : ∫ab f = k(b − a)
  • m ≤ f ≤ M ⟹ m(b−a) ≤ ∫ab f ≤ M(b−a)
  • ∫ab f = ∫ac f + ∫cb f pour c ∈ ]a;b[

II. Subdivisions et sommes de Darboux

Subdivision de [a;b] : sous-ensemble fini σ = {x₀ = a < x₁ < … < xn = b}. Le pas de σ est h = max |xi − xi+1|.
Sommes de Darboux : pour f bornée, mi = inf f et Mi = sup f sur [xi−1;xi] :
  • Somme inférieure : s(f,σ) = Σ mi(xi − xi−1)
  • Somme supérieure : S(f,σ) = Σ Mi(xi − xi−1)
Pour toute subdivision : s(σ) ≤ ∫ab f ≤ S(σ). Si f est constante = k : s = S = k(b−a).

III. Intégrabilité au sens de Riemann

f est Riemann-intégrable sur [a;b] si s(f) = S(f) : la borne sup des sommes inférieures égale la borne inf des sommes supérieures ; cette valeur commune est ∫ab f.
Critère (CNS) : f est Riemann-intégrable ⟺ pour tout ε > 0, il existe une subdivision σ telle que S(f,σ) − s(f,σ) < ε.
Subdivision régulière d'ordre n : σn = {xi = a + i(b−a)/n} — tous les intervalles ont la même longueur h = (b−a)/n. Alors S(σn) − s(σn) = (b−a)/n × Σ(Mi − mi) : le problème devient un problème de limite de suite.
Théorèmes d'intégrabilité :
  • f monotone sur [a;b] ⟹ f intégrable.
  • f continue sur [a;b] ⟹ f intégrable.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier que f doit être bornée sur [a;b] pour parler d'intégrabilité de Riemann.
  • Inverser les sommes de Darboux : s (inférieure) ≤ ∫ ≤ S (supérieure).
  • Dire qu'une fonction discontinue n'est jamais intégrable : les fonctions monotones le sont.
  • Oublier le signe : les aires sous l'axe des x comptent négativement.
  • Schwarz : c'est la racine du produit des intégrales des carrés, pas le produit des intégrales.
