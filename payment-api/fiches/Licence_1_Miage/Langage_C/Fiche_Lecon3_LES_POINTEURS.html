I. L'opérateur adresse & et la notion de Lvalue

Opérateur adresse & : retourne l'adresse mémoire d'une variable. Ex. printf("%p", &i) affiche l'adresse de i en hexadécimal (format %p).
Lvalue (left value) : tout objet pouvant figurer à gauche d'une affectation. Une Lvalue est caractérisée par : son adresse (où l'objet est stocké) et sa valeur (ce qui est stocké à cette adresse).
int i, j; i = 3; j = i; → i et j ont des adresses différentes (ex. 4831836000 et 4831836004) mais la même valeur (3). L'affectation n'opère que sur les valeurs. Un int occupe 4 octets → sa valeur est stockée sur 4 adresses d'octets consécutives.
⚠️ Point clé : une adresse est un entier quel que soit le type de l'objet (16, 32 ou 64 bits selon l'architecture). &i n'est pas une Lvalue mais une constante — on ne peut pas lui affecter de valeur. Pour manipuler des adresses : les pointeurs.

II. Définition et déclaration des pointeurs

Pointeur : objet (Lvalue) dont la valeur est l'adresse d'un autre objet. On dit que le pointeur « pointe sur » cette adresse. Déclaration : type *nom-du-pointeur; où type est le type de l'objet pointé.
char *pc; pointeur sur char · int *pi; pointeur sur int · float *pr; pointeur sur float.
Exemple complet : int i = 3; int *p; p = &i; → p contient l'adresse de i (ex. 4831836000).
Pourquoi typer le pointeur ? Bien que la valeur d'un pointeur soit toujours un entier, son type dépend de l'objet pointé : pour un char*, la valeur = adresse de l'octet de l'objet ; pour un int*, la valeur = adresse du premier des 4 octets. Cette distinction est indispensable à l'interprétation de la valeur.

L'opérateur d'indirection *

Indirection * : accède directement à la valeur de l'objet pointé. Si p pointe vers i, alors *p désigne la valeur de i — c'est une Lvalue : *p = 34; modifie i.
Double sens de * : à la déclaration (int *p) il annonce un pointeur ; à l'utilisation (*p) il donne le contenu de l'adresse. printf("%c", *pc) affiche le contenu de la case mémoire, printf("%p", pc) affiche l'adresse elle-même.

III. Pointeurs et tableau / allocation dynamique

  • Déclarer un tableau int tableau[10] définit automatiquement un pointeur (l'adresse du premier élément).
  • ⚠️ La déclaration d'un tableau réserve la mémoire ; celle d'un pointeur seul non → utiliser malloc : tableau = (int*)malloc(sizeof(int)*10);
  • Équivalences : *tableau ≡ tableau[0] ; *(tableau+i) ≡ tableau[i] ; tableau ≡ &tableau[0] ; tableau+i ≡ &tableau[i].

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Confondre p (l'adresse) et *p (le contenu de l'adresse).
  • Utiliser un pointeur non initialisé : *p = 34; sans p = &i; ni malloc → comportement indéfini.
  • Penser que &i est une Lvalue : c'est une constante, non affectable.
  • Oublier que le type du pointeur sert à interpréter l'adresse (1 octet pour char, 4 pour int).
  • Format d'affichage d'une adresse : %p dans printf, pas %s.
