I. Les fonctions

Fonction : les programmes C s'écrivent comme une collection de fonctions. Les paramètres sont passés entre parenthèses, le code entre accolades. Une fonction retourne au plus une valeur, via return.
type nom(paramètre type1 nom1, …) { corps; return expression; }
Ex. : int abs(int i) { if (i < 0) return -i; else return i; }
  • Le type des paramètres est re-déclaré à chaque fois (même s'il est identique) : int f(int i, int j).
  • Le type de retour indique quel objet sera calculé par return.
  • main() : point d'entrée du programme ; return 0 signale au système une fin sans erreur.
Passage par valeur : en C les arguments sont transmis par valeur — la fonction travaille sur des copies ; les variables d'origine ne sont pas modifiées. Pour modifier une variable de l'appelant, il faut passer son adresse (pointeur).
Portée : une fonction est reconnue uniquement dans le fichier où elle est définie. Si la fonction appelante se trouve ailleurs, le fichier appelant doit inclure le prototypage de la fonction (déclaration de son type et de ses arguments — fichier .h).

Les pointeurs comme arguments

Exemple swap :
void swap(int *px, int *py) { int tmp = *px; *px = *py; *py = tmp; }
Appel : swap(&a, &b) — les variables originales sont échangées car la fonction reçoit leurs adresses.

II. typedef et les structures

typedef : permet de nommer un nouveau type à partir d'un type existant. typedef int entier; → entier utilisable à la place de int.
Structure (struct) : ensemble de champs de types différents regroupés sous un même nom. struct article { int numero; char nom[20]; float prix; }; → accès aux champs par . : a.prix = 12.5; ; via pointeur : p->prix.

III. Les fichiers

Fichier : structure de données externe permettant la persistance des données. Un fichier est manipulé via un pointeur FILE * (stdio.h).
FonctionRôle
fopen("nom", "mode")Ouverture : "r" lecture, "w" écriture, "a" ajout ; retourne NULL en cas d'échec
fclose(f)Fermeture du fichier (obligatoire)
fgetc / fputcLecture/écriture d'un caractère
fgets / fputsLecture/écriture d'une chaîne
fscanf / fprintfLecture/écriture formatée
fread / fwriteLecture/écriture binaire de blocs
feof(f)Test de fin de fichier
Exemple : FILE *f = fopen("donnees.txt","w"); if (f == NULL) exit(1); fprintf(f, "%d", x); fclose(f);

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Croire qu'une fonction modifie ses arguments : passage par valeur → passer des pointeurs pour modifier.
  • Oublier le prototype quand l'appelant est dans un autre fichier.
  • Confondre champ.valeur (variable struct) et pointeur->champ (pointeur sur struct).
  • Oublier fclose après fopen, ou ne pas tester NULL au retour de fopen.
  • Mélanger les modes : "r" échoue si le fichier n'existe pas ; "w" écrase le contenu existant ; "a" ajoute en fin.
