I. Les opérateurs

Incrémentation et affectation composée

Postfixe : X = N++ → X reçoit la valeur avant incrémentation (N=5 → X=5, N=6). Préfixe : X = ++N → X reçoit la valeur après (X=6, N=6).
  • Affectation composée : += -= *= /= %= &= ^= |= <<= >>= — a += b ≡ a = a + b ; dans x(op)=y, x n'est évalué qu'une fois.
  • Relationnels (== != < <= > >=) : renvoient un int — 0 = faux, 1 = vrai.
  • Logiques (&& || !) : toute valeur ≠ 0 est vraie. ⚠️ Évaluation paresseuse : && n'évalue l'opérande droit que si le gauche est vrai ; || seulement si le gauche est faux (ex. (i<max) && (f(14)==1) : f n'est appelée que si i<max).
  • Bit à bit (& | ^ ~ << >>) : n'opèrent que sur des entiers — p = n << 3 décale de 3 bits à gauche.
  • Divers : & adresse d'une variable ; sizeof(type) nombre d'octets (sizeof(char) = 1) ; cast (int)r conversion de type.

II. Les structures alternatives

if / else

if (expression) { bloc1 } else { bloc2 } — le else est optionnel ; les {} inutiles pour une seule instruction. Écritures contractées admises : if ((reponse = getchar()) == 'o').
  • Tests : == égalité, != différence, && ET, || OU, ! NON.

switch

switch (variable int ou char) { case v1: …; break; case v2: …; break; default: …; } — choix multiples, équivalent à une cascade de if/else ; default optionnel et sans break.
⚠️ Piège : sans break, l'exécution continue dans le case suivant. Le switch ne fonctionne que sur entiers et caractères — jamais sur des flottants ni des chaînes. Idéal pour les « menus ».

III. Les structures itératives

BoucleSyntaxeParticularité
whilewhile (expression) { … }Test d'abord : le bloc peut ne jamais s'exécuter. while(expression); seul = « attendre tant que l'expression est vraie »
forfor (init ; condition ; modification) { … }Les 3 parties peuvent porter sur des variables différentes ; une partie peut être omise mais pas les « ; ». for(;;) = boucle infinie
do…whiledo { … } while (expression);Test après : le bloc s'exécute au moins une fois
Tests en C : une expression nulle (0) est fausse, non nulle vraie. if (delta) ≡ if (delta != 0) ; if (!delta) ≡ if (delta == 0).

InstructionEffet

return [expr]Sort d'une fonction, renvoie éventuellement une valeur

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • N++ vs ++N : postfixe = valeur avant, préfixe = valeur après incrémentation.
  • Oublier le break dans un switch → exécution en cascade.
  • while teste avant (0 exécution possible), do…while teste après (≥ 1 exécution).
  • Utiliser == au lieu de = : if (a = b) est une affectation (presque toujours vraie), pas un test.
  • break ne sort que de la boucle la plus interne, pas de toutes les boucles imbriquées.
