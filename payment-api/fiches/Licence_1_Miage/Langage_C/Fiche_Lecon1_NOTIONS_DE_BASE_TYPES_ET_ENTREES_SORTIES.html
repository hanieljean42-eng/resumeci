I. Présentation du langage C

Langage C : langage évolué et structuré, proche du langage machine, destiné notamment aux applications de contrôle de processus (entrées/sorties, temps réel). Ses compilateurs ont les taux d'expansion les plus faibles des langages évolués.
  • Peu d'instructions propres : le langage fait appel à des bibliothèques (stdio.h entrées/sorties, fonctions mathématiques…).
  • C est un langage compilé ; un programme C est en principe compris par un compilateur C++.
  • ⚠️ Le C distingue majuscules et minuscules ; les mots réservés s'écrivent en minuscules.

La compilation en 4 phases

PhaseRôleFichier produit
1. PréprocesseurTransformations textuelles : remplacements, inclusions (#include), compilation conditionnelle.i
2. CompilationTraduction en assembleur (mnémoniques du microprocesseur).s
3. AssemblageCode assembleur → fichier binaire (instructions processeur)fichier objet .o (.a pour les librairies)
4. Édition de liensLiaison des fichiers objets entre eux et avec les librairiesexécutable (a.out par défaut)
Prototype : les fichiers d'en-tête (.h : conio.h, stdio.h…) contiennent les prototypes des fonctions (nom, paramètres, valeur retournée). Grâce aux #include, le compilateur vérifie la syntaxe des appels.

II. Les types de variables

Les entiers

TypeDescriptionTaille
intEntier standard signé4 octets (−2³¹ ≤ n ≤ 2³¹−1)
unsigned intEntier positif4 octets (0 ≤ n ≤ 2³²)
shortEntier court signé2 octets
charCaractère signé1 octet
À retenir : en C, char est un cas particulier d'entier — un caractère est un entier de 8 bits (code ASCII : 'b' = 98). On peut donc faire des calculs sur les caractères (ex. d = c + 'a' - 'A' transforme une majuscule en minuscule). Nombres : décimal tel quel, 0x pour l'hexadécimal.

Les réels et les constantes caractères

  • Un réel = signe + mantisse + exposant ; float (4 octets) et double (8 octets, double précision).
  • Constantes caractères : '\n' interligne (LF), '\t' tabulation, '\\' backslash, '\'' cote, '\"' guillemets.
  • Initialisation possible à la déclaration : int i = 50;

III. Les entrées/sorties

Fonctions de sortie

  • printf("format", exp1, exp2, …) : affichage formaté (%d entier, %c caractère, %s chaîne, %f flottant, %x hexadécimal, %o octal, %p adresse). Paramètres de format : %10d (champ de 10, cadré droite), %-10d (cadré gauche), %.2f (2 décimales), %30.4s (30 car. réservés, 4 imprimés). Sans précision, un flottant affiche 6 décimales.
  • putchar(c) : affiche un caractère ; puts("texte") : affiche un texte + retour à la ligne. Plus rapides que printf (non formatées).

Fonctions d'entrée

  • getch() (conio.h) : saisie d'un caractère sans écho écran, arrêt dès la frappe.
  • scanf("chaîne de contrôle", &var, …) (stdio.h) : saisie formatée avec écho, arrêt sur RETURN. ⚠️ le nom de la variable est précédé de & (adresse) ; la chaîne de contrôle ne contient pas de \n ; les éléments saisis après un espace/tabulation sont ignorés.
Exemple : scanf("%c%d%lf", &un_caractere, &un_entier, &un_double); — à chaque % correspond une variable, séparée par des virgules et précédée de &.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier le & dans scanf — c'est l'adresse de la variable.
  • Mettre un \n dans la chaîne de contrôle de scanf — interdit.
  • Confondre printf (formatée) et puts (texte + retour ligne automatique, plus rapide).
  • Oublier que char est un entier : on peut l'afficher en %d (code ASCII) ou %c (caractère).
  • Les 4 phases de compilation : préprocesseur → compilation → assemblage → édition de liens (≠ exécution).
