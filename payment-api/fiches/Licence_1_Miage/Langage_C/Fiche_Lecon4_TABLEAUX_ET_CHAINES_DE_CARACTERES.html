I. Les tableaux de nombres

Tableau : équivalent des matrices en mathématiques — ensemble d'éléments de même type, caractérisé par sa taille et ses éléments. Déclaration : type nom[dim]; → le compilateur réserve dim places en mémoire.
int compteur[10]; → 10 entiers (40 octets en C standard) · float nombre[20]; → 80 octets. int t[4][5]; → tableau 2 dimensions.
⚠️ Règles : dim est nécessairement une valeur numérique (jamais une variable). Les indices commencent à 0 : indice maximum = dim-1. Les éléments se repèrent par nom[indice] (lecture printf("%d", t[i]), saisie scanf("%f", &t[i])). Dimensionner « au plus juste » : les tableaux consomment beaucoup de mémoire.

Initialisation et tableaux multidimensionnels

Initialisation à la déclaration : int liste[10] = {1,2,4,8,…}; · float nombre[4] = {2.67,5.98,-8,0.09}; · int x[2][3] = {{1,5,7},{8,4,3}}; (2 lignes × 3 colonnes).
  • À plusieurs dimensions, on ajoute des indices : nom[i][j], indices max dim1-1 et dim2-1.
  • En mémoire, les éléments sont contigus (rangés ligne par ligne).

Tableaux et pointeurs

Lien fondamental : déclarer un tableau définit un pointeur sur le premier élément. tableau[i] ≡ *(tableau+i) et &tableau[i] ≡ tableau+i. Un tableau à plusieurs dimensions est un pointeur de pointeur : t[i] ≡ &t[i][0]. Déclarer un tableau alloue la mémoire ; déclarer un pointeur seul non → malloc.

II. Les chaînes de caractères

Chaîne de caractères : tableau de char. Déclaration : char nom[dim]; ou char *nom; nom = (char*)malloc(dim);
⚠️ Caractère nul : le compilateur ajoute toujours le caractère '\0' (NUL) à la fin de la chaîne → il réserve dim-1 places utiles. Une chaîne de char[10] contient au plus 9 caractères.
  • Affichage : printf("%s", chaine) avec le format %s.
  • Saisie : scanf("%s", chaine) — ⚠️ pas de & : le nom du tableau est déjà une adresse.
  • Manipulation analogue aux tableaux à une dimension : chaine[i] ≡ *(chaine+i).

III. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Indices de 0 à dim-1 : t[10] sur un tableau déclaré t[10] = débordement.
  • Déclarer un tableau avec une variable pour dim → interdit (valeur numérique obligatoire).
  • Oublier le '\0' final : une chaîne de N caractères utiles exige char[N+1].
  • Écrire &chaine dans scanf("%s", …) : le nom du tableau est déjà l'adresse.
  • Confondre déclaration de tableau (mémoire réservée) et de pointeur (rien de réservé → malloc).
