I. Séquences : listes et tuples

Séquence : conteneur ordonné d'éléments indexés par des entiers (position). 3 types prédéfinis : chaînes, listes, tuples.
Liste : collection ordonnée et modifiable d'éléments éventuellement hétérogènes — ['trèfle', 14, 'coeur'] (crochets).
Tuple : collection ordonnée et non modifiable — ('a', 2, [1,3]) (parenthèses) ; parcours plus rapide ; utile pour les constantes.
Initialisations : [] liste vide · [0.0]*3 répétition → [0.0, 0.0, 0.0] · list(range(2,9,2)) → [2,4,6,8] · test x in liste.
Méthodes de liste : append(x) ajoute en fin · extend(l) concatène · insert(i,x) · remove(x) supprime la 1ʳᵉ occurrence · pop() retire et retourne le dernier · index(x) position · count(x) · sort() · reverse().
Tranches en affectation : mots[1:3] = ['salade'] remplace · mots[2:4] = [] efface · mots[2:2] = ['miel'] insère.
Imbrication : list3 = [list1, list2] — listes de listes ; parcours par boucles for imbriquées.

II. Références et copies

L'affectation b = a crée une référence, pas une copie : si l'objet est modifiable, toute modification via b est visible via a (b.append(4) modifie aussi a !).
Pour modifier séparément : c = a[:] (tranche complète = copie simple), copy.copy(a) (copie de surface), copy.deepcopy(a) (copie profonde/récursive des éléments et sous-objets).

III. Dictionnaires et ensembles

dict (tableau associatif) : collection de couples clé : valeur, accès très rapide par la clé (unique). Itérable mais non ordonné ; clé = tout type hachable (pas de liste ni de dict !) ; valeur = tout type.
Créations : {} ou dict() vide · {"nom":3, "taille":176} · {x: x**2 for x in (2,4,6)} (compréhension) · dict(nom=3) · dict([("nom",3)]).
Opérations : d['clé'] lecture/écriture · del d['clé'] · 'k' in d teste la présence d'une clé · len(d) = nombre de couples · parcours : for k,v in d.items():.
set : collection non ordonnée d'éléments uniques hachables — l'ensemble mathématique. set modifiable, frozenset non modifiable. Opérations : X - Y différence, X | Y union, X & Y intersection, x in X.

IV. Les fichiers textuels

La RAM est volatile → pour conserver les données on utilise des fichiers sur mémoire permanente. Modes d'ouverture : "r" lecture (défaut), "w" écriture (écrase), "a" ajout ; texte par défaut, "b" pour binaire ; paramètre encoding='utf8' recommandé.
Écriture séquentielle : f.write(s), f.writelines(l). Lecture : f.read() tout → chaîne · f.read(n) n octets · f.readline() ligne suivante · f.readlines() tout → liste de chaînes · itération directe for ligne in f:.
Fermeture : f.close() obligatoire (contenu garanti) — ou bloc with open(...) as f: (fermeture automatique).

V. Itérer et afficher

Techniques classiques : for k,v in d.items(): clés+valeurs · for i,v in enumerate(liste): indice+élément · for q,a in zip(seq1,seq2): parcours apparié · reversed(seq) inversée · sorted(set(liste)) triée sans doublons (originale inchangée).
format() : "{} {}".format(a,b) · positions "{1} {0}" · nommés "{c}".format(c=x) · indices "{0[3]}" · attributs "{0.real}" · numériques "{:.2f}" "{:d}" "{:x}" "{:.4e}" "{:.2%}" "{:+d}" "{:,}".

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • b = a sur une liste = référence partagée, pas copie → utiliser a[:] ou copy.
  • sort(), reverse(), append() modifient en place et retournent None ; sorted(), reversed() retournent un nouvel objet.
  • Clés de dict : hachables uniquement (str, int, tuple) — jamais de liste.
  • remove(x) supprime la valeur ; pop() l'élément en fin ; del l[i] l'élément d'indice i.
  • Ensemble set : pas d'ordre, pas de doublons — set([1,1,2]) = {1,2}.
  • "w" écrase le fichier existant ; toujours fermer (ou with).
