I. Instructions composées et indentation

Un script Python = suite d'instructions exécutées en séquence de haut en bas. Cette séquence est modifiée par des instructions composées qui choisissent ou répètent des portions de code.
Structure : une ligne d'en-tête terminée par deux-points « : » + un bloc indenté. Python utilise l'indentation significative : toutes les instructions au même niveau d'indentation appartiennent au même bloc. Les instructions composées peuvent s'imbriquer.
Une ligne logique peut se poursuivre sur plusieurs lignes physiques avec \ ou un caractère ouvrant [({ non fermé. Plusieurs instructions sur une ligne : séparées par ; (déconseillé).

II. Choisir : if – elif – else

if condition:
    instructions
elif autre_condition:
    instructions
else:
    instructions

• elif et else sont optionnels ; elif répétable
• Tester directement le booléen : if estPair: (mieux que if estPair == True:)
• Opérateur ternaire (syntaxe compacte, c'est une expression qui produit une valeur) :
plus_petit = x if x < y else y

III. Répéter : les boucles

Conteneur : type de données stockant un ensemble d'autres données. Itérable : conteneur que l'on peut parcourir élément par élément (chaîne, liste, range…). range(6) → 0,1,2,3,4,5.
BoucleUsageExemple
whileRépète tant qu'une expression booléenne est vraie — nombre d'itérations inconnu (saisie filtrée)while not(1 <= n <= 10): n = int(input(…))
forParcourt un itérable élément par élémentfor lettre in "ciao": · for x in [2,'a',3.14]: · for i in range(1,11):
Ruptures de séquence :
• break : sort immédiatement de la boucle en cours
• continue : passe immédiatement à l'itération suivante (retour à l'en-tête)
• else après while/for : clause exécutée uniquement si la boucle se termine normalement (sans break) — ex. détecter « valeur non trouvée » dans une recherche.

IV. Le traitement des erreurs : les exceptions

Exception : mécanisme séparant le code normal du code de traitement d'erreur → applications plus robustes. Deux phases : la levée d'exception (détection de l'erreur, création d'un objet exception) puis son traitement par le gestionnaire ad hoc.
try:
    … # séquence normale
except ZeroDivisionError:
    … # traitement de cette exception
except TypeError as e:
    …
else:
    … # exécuté en l'absence d'erreur
finally:
    … # toujours exécuté
Exceptions standard : ZeroDivisionError, IndexError, KeyError, AttributeError, IOError, ImportError, NameError, SyntaxError, TypeError, ValueError — toutes héritent de Exception.
raise : lève volontairement une exception — raise ValueError("msg") ; raise seul dans un except propage l'exception courante.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • L'indentation définit le bloc : un mélange tabulations/espaces ou un retrait oublié change le sens du programme.
  • range(a, b) : a inclus, b exclu ; range(n) → 0 à n−1.
  • break sort de la boucle la plus proche seulement ; continue ne sort pas, il saute.
  • Le else d'une boucle s'exécute sans break — pas « sinon » au sens if.
  • Dans except, toujours préciser le type d'exception ; finally s'exécute même si erreur ou return.
  • Tester if n % 2: = « si n impair » (0 = False) ; penser aux comparaisons en chaîne : 1 <= n <= 10.
