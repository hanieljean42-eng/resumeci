I. Programmation événementielle et tkinter

En programmation graphique, on remplace le déroulement séquentiel par une boucle d'événements : le programme attend et traite les interactions utilisateur (clics, saisies, redimensionnements).
tkinter : bibliothèque graphique issue de Tcl/Tk, installée de base dans toutes les distributions Python (alternatives : GTK+, wxPython, Qt). Extensions : Tix (~40 widgets), Ttk (thèmes/styles).
Démarche minimale :
import tkinter
widget = tkinter.Label(None, text='Bonjour monde graphique !') # création
widget.pack() # positionnement
widget.mainloop() # lancement de la boucle d'événements

3 gestionnaires de positionnement : packer (place selon l'espace requis — .pack()) · gridder (cellules d'un tableau — .grid()) · placer (position absolue, peu fréquent — .place()).
Callbacks : fonctions « rappelées » par la bibliothèque quand un événement survient — on les associe aux widgets (ex. command=maFonction).
Méthodologie : séparer l'interface graphique (classe parente) des callbacks (classe enfant) — cas de polymorphisme par dérivation. Conception papier d'abord : zones d'affichage, de liste, de boutons → des Frame empilées dans un Tk.

III. Techniques avancées

Introspection : obtenir des informations sur les objets manipulés — help(obj) (aide interactive), type(obj) (le type), dir(obj) (attributs et méthodes), id(obj) (adresse mémoire unique), locals()/globals() (dictionnaires des noms). Module sys : sys.executable, sys.platform, sys.version, sys.argv, sys.path. Interpréteur enrichi : IPython.
Gestionnaire de contexte (with) : garantit les opérations avant/après un bloc — ex. fermeture automatique de fichier :
with open(filename) as fh: remplace try: fh = open(...) … finally: fh.close().
Dictionnaire de fonctions : implémenter un menu sans cascades de if : dico = {"chat": gererChat, "chien": gererChien} puis dico[bete]() appelle la bonne fonction.
Fonctions récursives : s'appellent elles-mêmes — adaptées aux structures arborescentes (ex. parcours de répertoires : listdir, isdir, join) — toujours prévoir une condition terminale.
Compréhensions : notation compacte et performante, proche des maths ({x² | x ∈ [2,11[}) :
• Liste simple : [x**2 for x in range(2,11)] → [4, 9, 16, …, 100]
• Avec filtre : [x+1 for x in seq if x > 23]
• Combinaison : [x+y for x in s1 for y in s2]
• Dictionnaire : {x: x**2 for x in (2,4,6)} · Ensemble : {x % 3 for x in seq}
Équivaut à une boucle for + append(), en plus lisible et plus rapide.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier mainloop() → la fenêtre s'affiche puis le programme se termine immédiatement (ou rien ne répond).
  • Un GUI ≠ script séquentiel : le code après mainloop() ne s'exécute qu'à la fermeture.
  • Récursivité sans condition terminale → récursion infinie (RecursionError).
  • dir(obj) liste aussi les méthodes spéciales __x__ ; id() donne l'adresse, pas la valeur.
  • Compréhension ≠ boucle : elle construit un nouveau conteneur, elle ne modifie pas l'existant.
  • with open(...) : le fichier est fermé même si une exception survient dans le bloc.
