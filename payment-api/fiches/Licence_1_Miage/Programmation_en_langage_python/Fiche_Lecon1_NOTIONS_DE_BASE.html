II. Identificateurs et mots réservés

Identificateur : suite non vide de caractères = lettre Unicode ou _ (caractère de début) + lettres, chiffres, _ (continuation). Sensible à la casse ; interdit d'employer un mot réservé.
Style de nommage (PEP 8) : UPPER_CASE constantes · TitleCase classes · camelCase fonctions/méthodes · lower_case autres. Éviter les lettres seules l, O, I.
Mots réservés Python 3 : and, as, assert, break, class, continue, def, del, elif, else, except, False, finally, for, from, global, if, import, in, is, lambda, None, nonlocal, not, or, pass, raise, return, True, try, while, with, yield.
Expression : portion de code que l'interpréteur peut évaluer pour obtenir une valeur (littéraux + identificateurs + opérateurs).

IV. Variables, références et affectation

Variable : identificateur associé à une valeur — en Python c'est une référence d'objet (l'identificateur « pointe » vers la donnée en mémoire). Quand une donnée n'est plus référencée, le ramasse-miettes (garbage collector) la supprime.
Affectation = : le membre de droite est évalué d'abord, puis affecté au membre de gauche → a = a + 1 (incrémentation) est valide. Dire « a reçoit 2 », pas « a égal 2 ».
Affecter ≠ comparer : = a un effet (modifie l'état) mais pas de valeur ; == a une valeur (bool) mais pas d'effet. s = (c = True) and True → SyntaxError !
Variantes : v += 2 (augmentée) · c = d = 8 (droite à gauche) · e, f = 2.7, 5.1 (parallèle/tuple) · x, y = f() (retour multiple).

V. Les chaînes de caractères (str)

str : séquence de caractères Unicode non modifiable (toute transformation crée une nouvelle chaîne). 3 syntaxes : "…" ou '…' · r"…" (brute : \n non interprété) · """…""" (multi-lignes).
Opérations : len(s) longueur · s1 + s2 concaténation · s * 3 répétition.
Méthodes de test : isupper() islower() istitle() isalnum() isalpha() isdigit() isspace() startswith() endswith() → bool.
Méthodes de transformation : lower() upper() capitalize() swapcase() center() ljust() rjust() zfill() strip() find() (−1 si absent) index() (erreur si absent) replace() split() join().
Indexation : s[0] 1ᵉʳ caractère, s[-1] dernier. Tranches : s[1:4] (caractères 1 à 3), s[:3], s[3:], s[-2:] — la borne droite est exclue.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • 20 / 3 → 6.666… (flottant !) ; 20 // 3 → 6. La division / donne TOUJOURS un float.
  • = ≠ == : affecter n'est pas comparer.
  • Les indices commencent à 0 ; s[-1] = dernier caractère ; tranche [début:fin] : fin exclue.
  • str non modifiable : s.upper() ne change pas s, il retourne une nouvelle chaîne → écrire s = s.upper().
  • input() saisit une chaîne → convertir : n = int(input(…)).
  • Un int Python n'a pas de taille maximale (contrairement à C/Java).
