📖 Statistiques descriptives 🏫 Licence 1 MIAGE — Semestre 2 Leçon 4 : Statistique descriptive bivariée — relation entre 2 variables

I. Distributions marginales et conditionnelles

Série double {(X(1),Y(1)),…,(X(N),Y(N))} sur p modalités de X et q de Y.
Effectif joint nᵢⱼ : nb d'individus ayant xᵢ et yⱼ ; fréquence jointe fᵢⱼ = nᵢⱼ/N.
Marginales : nᵢ· = Σⱼ nᵢⱼ (total de la ligne i) · n·ⱼ = Σᵢ nᵢⱼ (total de la colonne j) · fᵢ· = nᵢ·/N. On a Σᵢⱼ nᵢⱼ = N, Σᵢⱼ fᵢⱼ = 1.
Tableau de contingence : nᵢⱼ à l'intersection ligne i / colonne j ; derniere ligne/colonne = totaux marginaux. Se lit comme une matrice : 1ᵉʳ indice = ligne.
Distribution conditionnelle : extraire une colonne (ou ligne) = étudier un critère quand l'autre est fixé : X|Y=yⱼ.
Fréquences conditionnelles : fᵢ|Y=yⱼ = nᵢⱼ/n·ⱼ · fⱼ|X=xᵢ = nᵢⱼ/nᵢ·.
Profils : tableau des profils-colonne = distributions X|Y ; profils-ligne = distributions Y|X.
Lien jointe/conditionnelle : fᵢⱼ = fᵢ|Y=yⱼ × f·ⱼ = fⱼ|X=xᵢ × fᵢ·.

II. Indépendance

X et Y indépendantes ⇔ ∀(i,j) : fᵢⱼ = fᵢ· × f·ⱼ ⇔ nᵢⱼ = (nᵢ· n·ⱼ)/N ⇔ les distributions conditionnelles = les marginales (fᵢ|Y=yⱼ = fᵢ·).
Chi-carré observé : χ² = N Σᵢⱼ (fᵢⱼ − fᵢ·f·ⱼ)² / (fᵢ·f·ⱼ). χ² ≥ 0 ; χ² = 0 ⇔ indépendance. ⚠️ χ² croît avec N → on renormalise :
V de Cramer : V = √[χ² / (N min(p−1, q−1))] — 0 ≤ V ≤ 1 ; V = 0 ⇔ indépendance ; proche de 1 → forte dépendance. Mesure l'écart à l'indépendance indépendamment de la taille de la population.

III. Nuage de points et résumés numériques

Nuage de points N(P) : représentation des N couples dans ℝ² · Barycentre G = (x̄, ȳ).
Covariance : Cov(X,Y) = moyenne des produits des écarts = (1/N) Σ (X(u)−x̄)(Y(u)−ȳ) = Σᵢⱼ fᵢⱼ(xᵢ−x̄)(yⱼ−ȳ)
Formule développée : Cov(X,Y) = moyenne de XY − x̄·ȳ
Symétrique : Cov(X,Y) = Cov(Y,X) · unité = produit des unités · Cov(X,X) = Var(X).
Cov > 0 : varient dans le même sens · < 0 : sens contraires · Indépendance ⇒ Cov = 0 mais pas la réciproque !
Coefficient de corrélation : r(X,Y) = Cov(X,Y) / (σ_X σ_Y) · −1 ≤ r ≤ 1.
|r| = 1 ⇔ relation affine exacte Y = aX + b (r = 1 → a > 0, r = −1 → a < 0).
|r| ≥ 0,9 → liaison affine importante · r ≈ 0 → pas de liaison affine (≠ aucune liaison !).

IV. Ajustement affine (régression linéaire)

Principe : trouver la droite y = âx + b̂ qui approche au mieux le nuage.
Méthode des moindres carrés : minimiser l'erreur Δ = Y − (aX + b) :
â = Cov(X,Y)/Var(X) = r(X,Y)·σ_Y/σ_X · b̂ = ȳ − â·x̄
✅ La droite de régression passe par le barycentre G.
Méthode de Mayer (plus simple) : classer la série par x croissant, la couper en 2 sous-séries, calculer leurs points moyens G₁(x̄₁,ȳ₁) et G₂(x̄₂,ȳ₂), tracer (G₁G₂) : a = (ȳ₁−ȳ₂)/(x̄₁−x̄₂).
Liaison indirectement affine Y = a·f(X) + b → poser Z = f(X), régresser (Z, Y) : régression après changement de variable.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Indépendance ⇒ Cov(X,Y) = 0, mais Cov = 0 n'implique PAS l'indépendance (liaison non affine possible).
  • r proche de 0 → pas de liaison affine, pas « aucune relation ».
  • Fréquence conditionnelle fᵢ|Y=yⱼ = nᵢⱼ/n·ⱼ (diviser par le total de la colonne, pas par N).
  • χ² = 0 ⇔ indépendance exacte ; utiliser V de Cramer pour comparer car χ² dépend de N.
  • La droite de régression de Y en X ≠ droite de X en Y ; la droite passe toujours par G = (x̄, ȳ).
