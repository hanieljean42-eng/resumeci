📖 Statistiques descriptives 🏫 Licence 1 MIAGE — Semestre 2 Leçon 1 : Les données statistiques

I. Vocabulaire de base

La statistique (méthode scientifique) : observer et étudier une ou plusieurs particularités communes dans un groupe de personnes ou de choses. ≠ « une statistique » = un nombre calculé sur une population.
Population : ensemble des éléments étudiés ayant des propriétés communes. Individu : un élément de la population. Taille : nombre d'individus (N). Échantillon : la partie étudiée de la population.
Collecte : l'obtention de l'échantillon est une étape délicate — hypothèse sous-jacente : individus choisis « au hasard ». Dans ce cours, sauf mention contraire, l'étude porte sur la population complète.

II. Les variables (caractères)

Variable / caractère : propriété commune aux individus que l'on souhaite étudier.
TypeDéfinitionSous-types et exemples
QualitativeValeurs = catégories (modalités), non mesurables par un nombreNominale : pas de hiérarchie (sexe, couleur des yeux, constructeur préféré) · Ordinale : modalités ordonnées naturellement (mention au BAC, fréquence : jamais/rarement/souvent)
QuantitativeValeurs = quantités mesurables données par des nombresDiscrète : ensemble fini/dénombrable (nombre d'enfants, pointure, étoiles d'un avis) · Continue : toutes les valeurs d'un intervalle réel (taille, poids, température)
Nuances : un code numérique n'est pas forcément une quantité (code postal, sexe 1/2 → qualitatif). L'âge peut être discret ou continu selon la précision ; une « tranche d'âge » est qualitative ordinale.

III. La série statistique

Série statistique : ensemble des données de la/des variables. Simple (univariée) : un seul critère (longueur des pétales) ; double (bivariée) : deux critères (longueur + largeur) ; multiple : davantage.
Notations : taille N · population P = {1,…,N} · individu u ∈ P · variables X, Y · donnée X(u) · série brute simple {X(1),…,X(N)} · série brute double {(X(1),Y(1)),…,(X(N),Y(N))}.
Exemples : 11 utilisateurs → constructeur préféré (qualitative nominale, X(P)={P,R,C,N,T}) · avis 0-5 étoiles (qualitative ordinale) · températures de villes (quantitative continue).

IV. Deux directions en statistique

Statistique descriptiveStatistique inférentielle
ButDécrire : résumer et représenter les données disponiblesInférer : tirer des conclusions sur une population infinie à partir de données partielles
DonnéesInformation complèteRéalisations de variables aléatoires (loi de probabilité)
QuestionsReprésentations graphiques, paramètres de position/dispersion/relation, régression linéaireEstimation, intervalles de confiance, tests d'hypothèse, modélisation
Ce cours = statistique descriptive uniquement. L'inférentielle nécessite la théorie des probabilités.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Qualitative nominale vs ordinale : la clé = existence d'un ordre naturel entre les modalités.
  • Un nombre peut être qualitatif (code postal, numéro de joueur) — c'est l'usage qui décide, pas la forme.
  • Quantitative discrète vs continue : discrète = valeurs isolées ; continue = tout un intervalle.
  • Échantillon ≠ population : l'échantillon n'est que la partie étudiée.
  • « La statistique » (méthode) ≠ « une statistique » (nombre calculé).
