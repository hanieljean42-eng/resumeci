I. Groupement des données

Face à un grand nombre d'individus, on regroupe la série brute {X(1),…,X(N)} :
• Qualitative / discrète : identifier les modalités/valeurs prises : X(P) = {m₁,…,m_p} ou {x₁,…,x_p}
• Continue : construire des classes [a₀,a₁[,…,[a_{p−1},a_p] formant une partition — si possible à amplitude égale, au nombre de 5 à 20 (idéal 6-12), borne inférieure incluse, supérieure exclue (sauf la dernière).
⚠️ Le regroupement en classes fait perdre l'information sur la répartition interne. p ≤ N.

II. Effectifs, fréquences et cumuls

Effectif (fréquence absolue) nᵢ : nombre d'individus dont la variable vaut mᵢ/xᵢ/appartient à la classe i.
Fréquence (relative) fᵢ : fᵢ = nᵢ / N — proportion de la modalité.
Propriétés : Σnᵢ = N · Σfᵢ = 1 · 0 ≤ fᵢ ≤ 1.
Cumuls (variables ordonnées uniquement — exclut la nominale !) :
• Effectif cumulé croissant νᵢ = n₁+…+nᵢ · décroissant ν̃ᵢ = nᵢ+…+n_p
• Fréquence cumulée croissante φᵢ = f₁+…+fᵢ (φ_p = 1) · décroissante φ̃ᵢ = fᵢ+…+f_p
Lecture : φᵢ = proportion d'individus dont la valeur ≤ xᵢ ; φ̃ᵢ = proportion ≥ xᵢ.
Ex. (ordinateurs) : N=3774 étudiants, X = nombre d'ordinateurs : φ(2) = 0,6388 → 63,9 % des étudiants ont ≤ 2 ordinateurs.
Variable continue — amplitude et densité : amplitude de la classe : lᵢ = aᵢ − aᵢ₋₁ ; densité de proportion : dᵢ = fᵢ / lᵢ — compare les effectifs en tenant compte de la largeur des classes. Inutile si toutes les classes ont la même amplitude.

Fonction de répartition empirique F_X : ℝ → [0,1] ; F_X(x) = proportion d'individus dont la valeur est ≤ x. Croissante, en escalier pour une variable discrète, par morceaux pour une continue. Elle sert à lire médiane et quantiles (leçon suivante).

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Fréquences cumulées sans objet sur une variable nominale (pas d'ordre).
  • Histogramme : hauteur = densité, pas l'effectif, si les amplitudes diffèrent — l'aire compte.
  • Classes : borne inférieure incluse, supérieure exclue → x ∈ [a_{i−1}, a_i[.
  • Σfᵢ doit faire exactement 1 — vérifier les arrondis.
  • Diagramme en bâtons ≠ histogramme : bâtons = discrète (séparés), histogramme = continue (barres jointives).
