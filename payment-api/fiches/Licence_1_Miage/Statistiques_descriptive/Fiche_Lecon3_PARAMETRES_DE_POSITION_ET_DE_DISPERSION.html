📖 Statistiques descriptives 🏫 Licence 1 MIAGE — Semestre 2 Leçon 3 : Paramètres de position et de dispersion (statistique univariée)

I. Paramètres de position

Mode : la modalité/valeur la plus fréquente (effectif maximal). Pour une variable continue : classe modale = classe de densité maximale. Il peut y avoir plusieurs modes.
Moyenne arithmétique x̄ :
• Données brutes : x̄ = (1/N) Σ X(u)
• Regroupées (discrète) : x̄ = Σ fᵢ xᵢ · (qualitative : impossible)
• Continue : approximation par les centres de classes cᵢ : x̄ ≈ Σ fᵢ cᵢ
Propriété (changement affine) : si Y = aX + b alors ȳ = a x̄ + b.
Médiane m : valeur qui partage la série en deux moitiés d'effectif égal (50 % ≤ m, 50 % ≥ m).
• Discrète, N impair : valeur centrale X((N+1)/2) ; N pair : convention du cours = X(N/2)
• Continue : plus petite solution de F_X(x) = 1/2 (fonction de répartition) — on localise la classe médiane (où φᵢ atteint 0,5) puis on interpole linéairement.
Quantile d'ordre r (Q_r) : généralisation : Q_r partage la série avec proportion r en dessous. Discrète : première valeur où φᵢ ≥ r · Continue : plus petite solution de F_X(x) = r.
Cas particuliers : m = Q_{1/2} = 2ᵉ quartile = 50ᵉ centile · quartiles Q₁ (= Q_{1/4}) et Q₃ (= Q_{3/4}) · déciles (r = n/10) · centiles (r = n/100).
Médiane vs moyenne : la médiane est robuste — une donnée erronée ou extrême ne la change quasiment pas, alors qu'elle peut fortement déplacer la moyenne. ⚠️ moyenne et médiane coïncident rarement.

II. Paramètres de dispersion

Étendue δe : δe = X(N) − X(1) = max − min. Simple mais peu informative (ignore la répartition interne, sensible aux extrêmes).
Distance inter-quartile : IQR = Q₃ − Q₁ — largeur de la bande contenant les 50 % centraux de la population. Plus précise que l'étendue, robuste.
Diagramme en boîte (boxplot) : rectangle de bornes Q₁ et Q₃, coupé à la médiane, prolongé par des « moustaches ».
Variance :
• Discrète : Var(X) = Σ fᵢ (xᵢ − x̄)² ; données brutes : (1/N) Σ (X(u) − x̄)² ; continue : centres de classes.
• Formule de König-Huygens (calcul rapide) : Var(X) = moyenne des carrés − carré de la moyenne = Σ fᵢ xᵢ² − x̄²
• Unité = le carré de l'unité de X.
Écart-type σ_X = √Var(X) — même unité que X ; mesure la dispersion moyenne autour de x̄.
Théorème : Var(X) = 0 ⇔ X constante.
Propriétés : Var(aX + b) = a² Var(X) ; σ_{aX+b} = |a| σ_X.
Variable centrée réduite : Y = (X − x̄)/σ_X → ȳ = 0, σ_Y = 1 — permet de comparer des séries d'unités différentes.
Moments : moment d'ordre k = moyenne des x^k ; moment centré μ_k = Σfᵢ(xᵢ−x̄)^k.
Forme : coefficient d'asymétrie (Fisher) γ₁ = μ₃/σ³ : γ₁ > 0 → étalée à droite, < 0 → à gauche ; kurtosis γ₂ = μ₄/σ⁴ − 3 : > 0 leptokurtique (pointue), < 0 platykurtique (aplatie).

III. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Médiane ≠ moyenne : deux concepts différents qui coïncident rarement.
  • Médiane continue : d'abord repérer la classe où φᵢ dépasse 0,5, puis interpoler — ne pas prendre le centre de classe directement.
  • Variance : utiliser König-Huygens (moyenne des carrés − carré de la moyenne) pour calculer plus vite ; Var ≥ 0 toujours.
  • Médiane/quantiles : se baser sur les fréquences cumulées croissantes, pas les effectifs bruts.
  • Unités : variance = unité², écart-type = unité.
