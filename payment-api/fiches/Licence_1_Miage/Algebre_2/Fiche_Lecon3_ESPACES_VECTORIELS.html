I. Espace vectoriel et combinaisons linéaires

Groupe commutatif (G,+) : loi interne, associative, élément neutre, symétrique pour tout élément, + commutative. Espace vectoriel réel (E,+,×) : (E,+) groupe commutatif + loi externe λ·x vérifiant : (λ+μ)x = λx+μx ; λ(x+y) = λx+λy ; (λμ)x = λ(μx) ; 1·x = x. Éléments de E = vecteurs, éléments de ℝ = scalaires.
  • Exemples fondamentaux : ℝⁿ (n-uplets), ℝ[X] (polynômes), ℂ vu comme ℝ-e.v., A(D,ℝ) (fonctions ; D = ℕ → suites).
  • Combinaison linéaire : v est CL de (v₁,…,vn) si v = λ₁v₁ + … + λnvn (répétitions et coefficients nuls admis).

II. Sous-espaces vectoriels (s.e.v.)

F ⊆ E est un s.e.v. ssi : ① 0E ∈ F ; ② stable par addition : u,v ∈ F ⇒ u+v ∈ F ; ③ stable par multiplication externe : λu ∈ F. Ex. : {(x,y) ∈ ℝ² / 2x−3y = 0} est un s.e.v. ; {3x−5y = 2} n'en est pas un (0 n'y appartient pas).
  • Intersection de s.e.v. = s.e.v. ; réunion : non (sauf si F₁ ⊂ F₂ ou l'inverse).
  • Vect{v₁,…,vn} = <v₁,…,vn> : s.e.v. engendré = ensemble des CL des vi. Si v ∈ <v₁,…,vn> alors ajouter v ne change rien : <v₁,…,vn,v> = <v₁,…,vn>.
  • Somme F₁+F₂ = {v₁+v₂} (s.e.v.) ; supplémentaires : E = F₁ ⊕ F₂ ⇔ E = F₁+F₂ et F₁∩F₂ = {0} ⇔ tout v ∈ E s'écrit de façon unique v = v₁+v₂. Ex. : fonctions paires ⊕ impaires.

III. Familles libres, liées, génératrices

FamilleDéfinition
Liée∃ λ₁…λn non tous nuls : Σλivi = 0 → un vecteur est CL des autres
LibreΣλivi = 0 ⇒ tous les λi = 0 (indépendants)
GénératriceE = <v₁,…,vn> : tout vecteur de E est CL des vi
BaseLibre + génératrice → décomposition unique u = Σλiei (coordonnées)
Propriétés : famille contenant 0E → liée ; sous-famille d'une libre → libre ; sur-famille d'une génératrice → génératrice ; sur-famille d'une liée → liée. Bases canoniques : ℝⁿ : ei = (0,…,1,…,0) ; ℝn[X] : {1,X,…,Xⁿ} ; ℂ : {1, i}.

IV. Dimension

E de dimension finie s'il admet une famille génératrice finie. Toutes les bases ont le même cardinal : dim E = nombre de vecteurs d'une base. dim ℝⁿ = n ; dim ℝn[X] = n+1 ; dimℝ ℂ = 2 ; ℝ[X] : dimension infinie.
Soit (v₁,…,vk) dans E, dim E = nConclusion
Librek ≤ n
Génératricek ≥ n
Libre et k = n⇔ c'est une base
Génératrice et k = n⇔ c'est une base
k > n⇒ famille liée
Théorèmes clés : toute famille libre se complète en base ; toute famille génératrice contient une base. Sous-espace : dim F ≤ dim E et dim F = dim E ⇔ F = E. Grassmann : dim(F₁+F₂) = dim F₁ + dim F₂ − dim(F₁∩F₂). Somme directe : dim(F₁⊕F₂) = dim F₁ + dim F₂.
Rang d'un système de vecteurs : rg(v₁,…,vn) = dim <v₁,…,vn>. Déterminant d'un système de n vecteurs dans une base (dim n) : déterminant de la matrice des coordonnées en colonnes → (u₁,…,un) base ⇔ det ≠ 0.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • S.e.v. : toujours vérifier 0E ∈ F d'abord — un s.e.v. ne contient jamais que des « solutions » non nulles (ex. xy > 0, x ≠ 1 : éliminés d'office).
  • n vecteurs dans un e.v. de dimension n ne forment pas forcément une base : il faut libre ou génératrice (pas les deux à vérifier si k = n).
  • Réunion ≠ s.e.v. ; intersection = s.e.v.
  • Somme directe exige F₁∩F₂ = {0} — sinon la décomposition n'est pas unique.
  • dim ℝn[X] = n+1 (les degrés 0 à n), pas n.
