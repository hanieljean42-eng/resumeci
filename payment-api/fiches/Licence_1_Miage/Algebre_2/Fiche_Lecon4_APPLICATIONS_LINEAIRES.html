📖 Algèbre 2 (Algèbre linéaire) 🏫 Licence 1 MIAGE — Semestre 2 Leçon 4 : Applications linéaires

I. Définitions

Application linéaire f : E → F : ① f(u+v) = f(u)+f(v) ; ② f(λu) = λf(u). Équivalent : f(u + λv) = f(u) + λf(v). Conséquences : f(0E) = 0F, f(−u) = −f(u). Ex. : f(x,y,z) = (2x−3y, x−z) ; g(P) = P′ (dérivation).
  • Vocabulaire : L(E,F) = e.v. des applications linéaires ; E = F → endomorphisme (End(E)) ; bijective → isomorphisme ; endomorphisme bijectif → automorphisme (GL(E) ou Aut(E)).
  • Composée, somme, produit par un scalaire, bijection réciproque d'applications linéaires → encore linéaires.

II. Noyau et image

Noyau : ker(f) = {u ∈ E / f(u) = 0F} — s.e.v. de E ; c'est résoudre f(v) = 0. Image : Im(f) = {v ∈ F / ∃u ∈ E, v = f(u)} — s.e.v. de F.
Critères de bijectivité : ① f surjective ⇔ Im(f) = F ; ② f injective ⇔ ker(f) = {0E} — pour tester l'injectivité, il suffit que le seul antécédent de 0 soit 0.

III. Théorème du rang

Rang de f : rg(f) = dim Im(f).
Théorème du rang : E de dimension finie ⇒ dim E = dim ker(f) + dim Im(f), c.-à-d. dim E = dim ker(f) + rg(f).
  • f est entièrement déterminée par les images des vecteurs d'une base : f(x) = Σxkf(ek).
  • Im(f) = <f(e₁),…,f(en)> (engendrée par les images des vecteurs de base).
  • dim E = dim F finie : f injective ⇔ f surjective ⇔ f bijective — vérifier un seul critère suffit.

IV. Matrice d'une application linéaire

MB,B′(f) : dim E = m, dim F = n → matrice de type (n, m) dont la j-ième colonne = coordonnées de f(ej) dans la base B′. Relation : Y = A·X (coordonnées de f(x) = A × coordonnées de x).
Ex. : f : ℝ³ → ℝ⁴, f(x,y,z) = (x+y, x−2z, y+5z, z+3x).
f(e₁) = (1,1,0,3) ; f(e₂) = (1,0,1,0) ; f(e₃) = (0,−2,5,1) → ces 3 vecteurs en colonnes donnent MB,B′(f) (4×3).
Calculs matriciels ↔ applications : M(f+g) = A+B ; M(λf) = λA ; MB,B″(g∘f) = MB′,B″(g) × MB,B′(f) (produit des matrices, ordre respecté). f bijectif ⇔ sa matrice A inversible (dim E = dim F).

V. Changement de base

Matrice de passage P de B vers B′ : j-ième colonne = coordonnées du j-ième vecteur de la nouvelle base B′ exprimé dans l'ancienne B. P est toujours inversible ; la matrice de passage de B′ vers B = P⁻¹.
Changement de base : A′ = P⁻¹AP où P = matrice de passage de B vers B′. Matrices A et A′ représentant le même endomorphisme dans deux bases → semblables.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Poser les f(ej) en lignes : les coordonnées se rangent en colonnes.
  • Croire ker(f) = {0} suffit pour conclure « bijective » quand dim E ≠ dim F : non, elle garantit seulement l'injectivité.
  • M(g∘f) = produit dans le bon ordre : Mat(g) × Mat(f), pas l'inverse.
  • Matrice de passage de B vers B′ : colonnes = vecteurs de B′ écrits dans B (sens contre-intuitif).
  • Théorème du rang : c'est dim E (l'espace de départ) qui se décompose, pas dim F.
