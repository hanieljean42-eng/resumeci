I. Définitions

Matrice : tableau rectangulaire à n lignes et m colonnes d'éléments de K (K = ℝ ou ℂ) : A = (aij) où i = indice de ligne, j = indice de colonne. Notation : Mn,m(K) ; si n = m on écrit Mn(K) (matrice carrée d'ordre n ; les aii forment la diagonale principale).
Transposée ᵗA : matrice de type (m, n) de terme a′ij = aji (on échange lignes et colonnes). ᵗ(ᵗA) = A.
Type de matrice carréeCondition
Triangulaire supérieureaij = 0 si i > j (zéros sous la diagonale)
Triangulaire inférieureaij = 0 si i < j
Diagonaleaij = 0 si i ≠ j (triangulaire sup. et inf.)
Identité InDiagonale de 1, zéros ailleurs
Symétriqueaij = aji pour tout i, j (A = ᵗA)

Trace : Tr(A) = Σaii (somme des éléments diagonaux).

II. Opérations

  • Somme (même type) : (A+B)ij = aij + bij.
  • Produit externe : (λA)ij = λaij.
  • Produit A×B (A de type n×p, B de type p×m → résultat n×m) : cij = Σk=1..p aikbkj — le nombre de colonnes de A = nombre de lignes de B.
Propriétés : commutative pour + ; associative pour + et × ; distributivité ; In élément neutre (A·In = In·A = A) ; binôme de Newton seulement si A·B = B·A. Transposée : ᵗ(A+B) = ᵗA + ᵗB ; ᵗ(A·B) = ᵗB·ᵗA (ordre inversé !).
⚠️ Deux règles fausses en général : ① A·B = 0 n'implique pas A = 0 ou B = 0 (contre-ex. : matrices nilpotentes non nulles). ② A·B ≠ B·A en général : le produit n'est pas commutatif.

III. Matrices inversibles

Inversible : A carrée est inversible s'il existe A′ telle que A·A′ = A′·A = In ; A′ = A⁻¹. Propriétés : (A·B)⁻¹ = B⁻¹·A⁻¹ (ordre inversé) ; (Ak)⁻¹ = (A⁻¹)k.

IV. Opérations élémentaires et rang

3 opérations élémentaires sur lignes (id. colonnes avec C) : ① Li ← Li + λLj ; ② Li ← λLi (λ ≠ 0) ; ③ Li ↔ Lj. Elles sont réversibles et conservent le rang. Effectuées sur les lignes, elles reviennent à multiplier à gauche par des matrices élémentaires : B = Ps…P₁A.
Matrice échelonnée : (i) 1ᵉʳ élément non nul de chaque ligne = 1 (1 directeur) ; (ii) lignes nulles en bas ; (iii) le 1 directeur d'une ligne est à droite de celui de la précédente. Échelonnée réduite si de plus (iv) toute colonne à 1 directeur n'a que des zéros ailleurs. Rang = nombre de 1 directeurs = nombre de lignes non nulles.
Algorithme de Gauss (calcul du rang) : placer un pivot non nul en (1,1) → annuler le reste de la colonne par Li ← Li − (ai1/α)L₁ → réitérer sur la sous-matrice A′ : rg(A) = 1 + rg(A′). On obtient une forme échelonnée avec r pivots ≠ 0 → rg(A) = r. Même procédé sur (A|In) pour calculer A⁻¹ (Gauss-Jordan) : si on réduit A à In, le bloc droit donne A⁻¹.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Multiplier terme à terme : le produit matriciel est ligne × colonne, pas coefficient par coefficient.
  • Utiliser le binôme de Newton sans vérifier AB = BA.
  • Écrire (A·B)⁻¹ = A⁻¹B⁻¹ : c'est B⁻¹A⁻¹.
  • Oublier λ ≠ 0 dans l'opération Li ← λLi : diviser une ligne par 0 est interdit.
  • Confondre « échelonnée » et « échelonnée réduite » (la réduite exige des zéros au-dessus des 1 directeurs).
