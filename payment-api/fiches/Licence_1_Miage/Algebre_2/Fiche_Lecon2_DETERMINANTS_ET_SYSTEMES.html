I. Le déterminant

Définition : pour A = (aij) carrée d'ordre n : det A = Σσ∈Sₙ (−1)I(σ) a1σ(1)…anσ(n), somme sur le groupe symétrique Sₙ (I(σ) = nombre d'inversions). Noté aussi |A|.
  • n = 2 : det A = a11a22 − a12a21.
  • n = 3 (Sarrus) : a11a22a33 + a12a23a31 + a13a21a32 − a13a22a31 − a11a23a32 − a12a21a33.
Cofacteur : cij = (−1)i+j|Aij| où Aij = A privée de la ligne i et de la colonne j. Comatrice com(A) = matrice des cofacteurs.
Développement suivant la ligne i : det A = Σj (−1)i+jaij|Aij| — idem suivant une colonne. Astuce : développer selon la ligne/colonne avec le plus de zéros. Triangulaire : det A = a11…ann (produit des diagonaux).

II. Propriétés essentielles

PropriétéÉnoncé
InversibilitéA inversible ⇔ det A ≠ 0
Produitdet(AB) = det A · det B ; det(λA) = λⁿ det A (n = ordre !)
Transposée / inversedet(ᵗA) = det A ; det(A⁻¹) = 1/det A
Cramer (comatrice)A·ᵗcom(A) = ᵗcom(A)·A = (det A)In → A⁻¹ = (1/det A)·ᵗcom(A)
Effet des opérations sur le déterminant : ① deux lignes identiques ou une ligne nulle → det = 0 ; ② échanger deux lignes → det × (−1) ; ③ une ligne combinaison linéaire des autres → det = 0 ; ④ Li ← Li + λLj → det inchangé ; ⑤ multiplier une ligne par λ → det × λ. (Idem pour les colonnes.) But : créer des zéros puis développer — c'est la méthode du pivot.
Rang : rg(A) = ordre maximal d'une matrice carrée extraite de déterminant non nul. rg(A) = rg(ᵗA) ≤ min(n, p).

III. Systèmes linéaires

Système de n équations à p inconnues : forme matricielle AX = B (A = matrice du système, B = second membre). Homogène si B = 0 (toujours compatible : solution nulle). Compatible = au moins une solution. Interprétation vectorielle : ΣxjCj = B — compatible ⇔ B ∈ Vect(C₁,…,Cp).
Système de Cramer : A carrée inversible (det A ≠ 0) → solution unique : X = A⁻¹B, et formules de Cramer : xj = Δj/det A où Δj = déterminant de A avec la j-ième colonne remplacée par B.
Ex. : det A = −8 ≠ 0 → x₁ = Δ₁/(−8) = 2 ; x₂ = −3/4 ; x₃ = 3/4.

IV. Pivot de Gauss — cas général

On échelonne la matrice complétée (A|B) :
① rg(A|B) > rg(A) → aucune solution (système incompatible) ;
② rg(A|B) = rg(A) = p → solution unique (par remontée) ;
③ rg(A|B) = rg(A) < p → infinité de solutions : r = rg(A) inconnues principales exprimées avec p − r paramètres.
  • Solutions d'un système homogène : sous-espace vectoriel de Kp de dimension p − rg(A).

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • det(λA) = λ·det A : FAUX — c'est λndet A.
  • A⁻¹ = ᵗcom(A)/det A — ne pas oublier la transposée de la comatrice.
  • Échanger deux lignes change le signe du déterminant ; ajouter un multiple d'une ligne ne change rien.
  • Dans Cramer, Δj remplace la colonne j (pas la ligne) par B.
  • « rg(A|B) > rg(A) » signifie une équation impossible type 0 = b → pas de solution.
