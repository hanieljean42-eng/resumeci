I. Généralités sur les fonctions

Fonction f : A → B : correspondance associant à chaque élément de A au plus un élément de B. A = ensemble de départ, B = d'arrivée, f(x) = image, x = antécédent de y. Ensemble de définition D_f : éléments de A ayant une image. Image d'une partie : f(A) = {f(x) ; x ∈ A} ; image réciproque : f⁻¹(B) = {x ∈ D_f ; f(x) ∈ B} (ne suppose pas f bijective !).
  • Pour trouver D_f : dénominateur ≠ 0 ; radicande ≥ 0 ; ln du strictement positif.
  • Restriction/prolongement : f = g|_I si I ⊂ J et f(x) = g(x) sur I.
  • Paire : D_f centré (symétrique/0) et f(−x) = f(x) → courbe symétrique /axe des ordonnées. Impaire : f(−x) = −f(x) → symétrie /origine. Périodique : ∃T > 0 : f(x+T) = f(x).
  • Monotonie : croissante : x ≤ y ⇒ f(x) ≤ f(y). Règle des signes pour g∘f : ↗∘↗=↗, ↗∘↘=↘, ↘∘↗=↘, ↘∘↘=↗.
  • f strictement monotone sur I ⇒ bijection de I sur f(I), et f⁻¹ strictement monotone de même sens. Graphes symétriques par rapport à y = x.
  • Bornée ⇔ majorée en valeur absolue : ∃α : |f(x)| ≤ α. Combinaisons linéaires et produits de fonctions bornées sont bornés.
Fonction k-lipschitzienne : ∃k ≥ 0 : ∀x, y ∈ I, |f(x) − f(y)| ≤ k|x − y| — l'ensemble des pentes des cordes est borné. Ex. : |x| est 1-lipschitzienne sur R ; 1/x est 1-lipschitzienne sur [1, +∞[ mais pas sur ]0, +∞[.

II. Limites de fonctions

Limite finie l en a ∈ R : ∀ε > 0, ∃δ > 0 : ∀x ∈ I, |x − a| ≤ δ ⇒ |f(x) − l| ≤ ε. En +∞ : ∀ε > 0, ∃M : x ≥ M ⇒ |f(x) − l| ≤ ε. Limite +∞ en a : ∀B, ∃δ > 0 : |x − a| ≤ δ ⇒ f(x) ≥ B.
  • Unicité de la limite ; limite finie en a ⇒ f localement bornée au voisinage de a.
  • Majoration : |f(x) − l| ≤ θ(x) avec θ → 0 ⇒ f(x) → l.
  • Opérations : lim(f+g) = l₁+l₂ ; lim fg = l₁l₂ ; lim |f| = |l| ; lim 1/f = 1/l si l ≠ 0 — sauf formes indéterminées (∞−∞, 0×∞, 0/0, ∞/∞).
  • Limites à gauche/à droite : f admet une limite en a ⇔ limite gauche l₁ = limite droite l₂.
  • Passage à la limite : f(x) ≥ k au voisinage de a et f → l ⇒ l ≥ k (élargit les inégalités strictes).
  • Composition : f(x) → b quand x → a et g(y) → l quand y → b ⇒ (g∘f)(x) → l.
  • Limite séquentielle : uₙ → a et f(x) → l en a ⇒ f(uₙ) → l. Pour prouver l'absence de limite : deux suites uₙ, vₙ → a avec f(uₙ) → l₁ ≠ f(vₙ) → l₂. Ex. : sin(1/x) n'a pas de limite en 0.

III. Comparaison des fonctions

  • f = O(g) : f = B·g avec B bornée ⇔ f/g bornée ; f = o(g) : f = ε·g avec ε → 0 ⇔ f/g → 0 ; f ∼ g : f − g = o(g) ⇔ f/g → 1.
  • Croissances comparées : en +∞ : (ln x)ᵞ = o(xᵅ) et xᵅ = o(e^{βx}). « Exponentielle l'emporte sur puissance, puissance sur logarithme. »
  • Équivalents en 0 : ln(1+x) ∼ x ; eˣ−1 ∼ x ; sin x ∼ x ; tan x ∼ x ; arcsin x ∼ x ; arctan x ∼ x ; cos x − 1 ∼ −x²/2 ; (1+x)ᵅ−1 ∼ αx.
  • Mêmes règles que pour les suites : produits/quotients/puissances OK ; jamais de somme ni de composition (log/exp d'équivalents interdits). f ∼ 0 ⇒ f nulle au voisinage (souvent une erreur).

IV. Continuité

f continue en x₀ : x₀ ∈ D_f et lim_{x→x₀} f(x) = f(x₀). Continuité à droite/à gauche : limite à droite/gauche égale à f(x₀). Continue sur un intervalle D : continue en tout point de D.
  • Prolongement par continuité : si f admet une limite finie l en x₀ ∉ D_f, on pose g(x₀) = l. Ex. : sin(x)/x prolongée par 1 en 0 ; (x−9)/(√(x−5)−2) = √(x−5)+2 prolongée par 4 en 9. Attention : si limites gauche ≠ droite → pas prolongeable.
  • Caractérisation séquentielle : f continue en a ⇔ pour toute suite xₙ → a, f(xₙ) → f(a).
Théorème des valeurs intermédiaires (TVI) : f continue sur I : pour tout m entre f(a) et f(b), l'équation f(x) = m a au moins une solution entre a et b. Si f est en plus strictement monotone → solution unique. Corollaire : f continue sur [a;b] strictement monotone avec f(a)×f(b) < 0 ⇒ f(x) = 0 a une unique solution dans ]a;b[.
  • f continue strictement monotone sur I ⇒ bijection de I sur f(I), f⁻¹ continue strictement monotone de même sens.
  • Continuité uniforme : ∀ε > 0, ∃δ > 0 (indépendant de x) : |x − y| < δ ⇒ |f(x) − f(y)| < ε. Ex. : √x est uniformément continue sur R₊.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • f⁻¹(B) (image réciproque) ≠ fonction réciproque : elle existe pour toute fonction.
  • Prouver la continuité en x₀ exige la limite égale à f(x₀), pas seulement l'existence.
  • Pas de prolongement possible si les limites à gauche et à droite diffèrent.
  • Le TVI donne l'existence ; l'unicité exige la stricte monotonie — penser à la dérivée pour la prouver.
  • « Sommer des équivalents » ou « composer des équivalents » = faute grave.
