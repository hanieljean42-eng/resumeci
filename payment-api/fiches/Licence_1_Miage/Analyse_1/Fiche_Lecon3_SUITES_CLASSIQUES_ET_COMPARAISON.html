I. Suites arithmétiques

Définition : ∃a ∈ R (la raison) : ∀n, uₙ₊₁ = a + uₙ. Forme explicite : uₙ = uₚ + (n − p)r.
  • r < 0 : strictement décroissante, diverge vers −∞ ; r = 0 : constante ; r > 0 : strictement croissante, diverge vers +∞.
  • Somme de termes consécutifs : uₚ + uₚ₊₁ + … + uₙ = (n − p + 1)·(uₚ + uₙ)/2 = (nb de termes) × (premier + dernier)/2.

II. Suites géométriques

Définition : ∃q ∈ R : ∀n, uₙ₊₁ = q·uₙ. Forme explicite : uₙ = uₚ·qⁿ⁻ᵖ.
  • |q| < 1 ⇒ converge vers 0 ; |q| ≥ 1 et q ≠ 1 ⇒ diverge ; q = 1 ⇒ constante.
  • Somme : uₚ + … + uₙ = uₚ·(qⁿ⁻ᵖ⁺¹ − 1)/(q − 1), pour q ≠ 1.

III. Suites arithmético-géométriques

Définition : uₙ₊₁ = q·uₙ + r (q, r réels). Cas particuliers : r = 0 → géométrique ; q = 1 → arithmétique.
Méthode : trouver le point fixe α vérifiant α = qα + r (soit α = r/(1−q) si q ≠ 1). Poser vₙ = uₙ − α : alors vₙ₊₁ = q·vₙ (géométrique) donc vₙ = qⁿv₀, d'où uₙ = α + (u₀ − α)qⁿ. Ex. : uₙ₊₁ = 3uₙ + 1, u₀ = 1 → α = −1/2, uₙ = (3/2)·3ⁿ − 1/2.

IV. Suites récurrentes linéaires d'ordre 2

uₙ₊₂ = b·uₙ₊₁ + c·uₙ (avec u₀, u₁ donnés). On résout l'équation caractéristique r² − br − c = 0 :
Solutions de l'équation caractéristiqueTerme général
2 racines réelles r₁ ≠ r₂uₙ = λ₁r₁ⁿ + λ₂r₂ⁿ
1 racine double r₀ ≠ 0uₙ = λ₁r₀ⁿ + λ₂·n·r₀ⁿ
2 racines complexes ρe^{iθ}, ρe^{-iθ}uₙ = ρⁿ(λ₁cos(nθ) + λ₂sin(nθ))

λ₁, λ₂ déterminés par u₀ et u₁. Ex. : uₙ₊₂ = uₙ₊₁ − ¼uₙ, u₀=1, u₁=9 → r = 1/2 double → uₙ = (17n + 1)(1/2)ⁿ.

V. Suites de Cauchy et suites complexes

Suite de Cauchy : ∀ε > 0, ∃N : ∀n ≥ p ≥ N, |uₙ − uₚ| ≤ ε. Théorème : une suite réelle converge ⇔ elle est de Cauchy. Exemple de non-Cauchy : uₙ = Σ1/k (harmonique) car |u₂ₙ − uₙ| ≥ 1/2.
Suite complexe (zₙ) : converge vers a ∈ C ⇔ |zₙ − a| → 0 ⇔ Re(zₙ) → Re(a) ET Im(zₙ) → Im(a). Perte : pas de relation d'ordre → ni limite monotone, ni gendarmes, ni inégalités pour les suites complexes. Suite géométrique kⁿ : converge vers 0 ⇔ |k| < 1 ; série géométrique Σkⁱ → 1/(1−k) si |k| < 1.

VI. Relations de comparaison : O, o, ∼

RelationDéfinitionCaractérisation (vₙ ≠ 0)
uₙ = O(vₙ) (dominée)uₙ = Bₙvₙ avec (Bₙ) bornée(uₙ/vₙ) bornée
uₙ = o(vₙ) (négligeable)uₙ = εₙvₙ avec εₙ → 0uₙ/vₙ → 0
uₙ ∼ vₙ (équivalentes)uₙ − vₙ = o(vₙ)uₙ/vₙ → 1
  • uₙ = o(1) ⇔ uₙ → 0. Les relations O, o, ∼ sont transitives ; ∼ est une relation d'équivalence (réflexive, symétrique, transitive).
  • Équivalents et limites : uₙ ∼ vₙ et vₙ → l ⇒ uₙ → l ; uₙ → l ≠ 0 ⇒ uₙ ∼ l. Un équivalent donne le signe à partir d'un rang.
  • Opérations permises : produits, quotients, puissances (uₙ ∼ aₙ et vₙ ∼ bₙ ⇒ uₙvₙ ∼ aₙbₙ ; uₙᵅ ∼ aₙᵅ si positifs).
Comparaison des suites de référence (a > 1, α, β > 0) : (ln n)ᵝ = o(nᵅ) ; nᵅ = o(aⁿ) ; aⁿ = o(n!) ; n! = o(nⁿ). « Log ≺ puissance ≺ exponentielle ≺ factorielle ≺ nⁿ. »
Équivalents usuels quand uₙ → 0 : sin uₙ ∼ uₙ ; tan uₙ ∼ uₙ ; ln(1+uₙ) ∼ uₙ ; e^{uₙ} − 1 ∼ uₙ ; 1 − cos uₙ ∼ uₙ²/2 ; sinh uₙ ∼ uₙ ; (1+uₙ)ᵅ − 1 ∼ αuₙ.
Comparaison logarithmique : si uₙ > 0 et uₙ₊₁/uₙ → l : l < 1 ⇒ uₙ → 0 ; l > 1 ⇒ uₙ → +∞.

VII. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Jamais de somme d'équivalents : n+1 ∼ n et −n ∼ −n+2, mais 1 ≁ 2 !
  • Jamais de composition d'équivalents : 2ⁿ+n ∼ 2ⁿ mais e^(2ⁿ⁺ⁿ) ≁ e^(2ⁿ). Interdit de passer au ln ou à l'exponentielle.
  • uₙ ∼ 0 signifie que uₙ est nulle à partir d'un rang — en général une erreur d'écriture.
  • Somme géométrique : (qⁿ⁺¹ − 1)/(q − 1) n'existe que pour q ≠ 1.
  • Récurrente ordre 2 : n'oublier le facteur n devant r₀ⁿ quand la racine est double.
