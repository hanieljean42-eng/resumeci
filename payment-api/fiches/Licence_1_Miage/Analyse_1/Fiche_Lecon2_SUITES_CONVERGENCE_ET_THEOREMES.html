📖 Analyse 1 🏫 Licence 1 MIAGE — Semestre 1 Leçon 2 : Suites de nombres réels — convergence et théorèmes

I. Définitions de base

Suite réelle : application u : I ⊂ N → R, notée (uₙ). Trois façons de la définir : explicite (uₙ = f(n), ex. uₙ = 5n + 2ⁿ), récurrente (uₙ₊₁ = φ(uₙ) + terme(s) initial(aux)), implicite (uₙ unique solution d'une équation).
  • Croissante (à partir de nₚ) : uₙ ≤ uₙ₊₁ ; décroissante : uₙ ≥ uₙ₊₁ ; monotone : l'une ou l'autre ; stricte : inégalité stricte.
  • Bornée : majorée et minorée. Opérations : somme, produit, multiplication par un scalaire, terme à terme.

II. Convergence et divergence

Convergence vers l : ∀ε > 0, ∃N ∈ N, ∀n ≥ N : |uₙ − l| ≤ ε. Sinon la suite diverge. Divergence vers +∞ : ∀A > 0, ∃N : ∀n ≥ N, uₙ ≥ A (1ʳᵉ espèce ; sinon 2ᵉ espèce).
Plan de preuve ε-N : (1) Soit ε > 0 ; (2) trouver N tel que |uₙ − l| ≤ ε (résolution d'inéquation) ; (3) poser N = E(...) + 1 ; (4) vérifier pour n ≥ N ; (5) conclure. Ex. : lim 1/n = 0 avec N = E(1/ε) + 1 ; lim (2n+1)/(n+2) = 2 avec |... − 2| = 3/(n+2) ≤ ε ⇔ n ≥ 3/ε − 2.
RésultatÉnoncé
UnicitéLa limite, si elle existe, est unique
Convergente ⇒ bornéeRéciproque fausse : (−1)ⁿ bornée mais divergente
Opérationslim(uₙ+vₙ) = l₁+l₂ ; lim uₙvₙ = l₁l₂ ; lim |uₙ| = |l₁| ; lim 1/uₙ = 1/l₁ si l₁ ≠ 0
Passage à la limiteuₙ ≤ k (à partir d'un rang) ⇒ l ≤ k ; uₙ ≤ vₙ ⇒ l ≤ l′. Les inégalités strictes deviennent larges
Théorème des gendarmes : si vₙ ≤ uₙ ≤ wₙ (à partir d'un rang) et vₙ, wₙ → même limite l, alors uₙ → l. Ex. : (−1)ⁿ/n → 0 car −1/n ≤ (−1)ⁿ/n ≤ 1/n.
Méthode de majoration : si |uₙ − l| ≤ αₙ avec αₙ → 0, alors uₙ → l. Idem pour +∞ : si vₙ ≤ uₙ et vₙ → +∞ alors uₙ → +∞.

III. Suites extraites et valeurs d'adhérence

Suite extraite (sous-suite) : vₙ = uφ(n) où φ : N → N strictement croissante (ex. u₂ₙ, u₂ₙ₊₁). Lemme : φ(n) ≥ n.
  • Toute sous-suite d'une suite convergente converge vers la même limite.
  • Critère de divergence : deux sous-suites convergent vers l₁ ≠ l₂ ⇒ (uₙ) diverge. Ex. : (−1)ⁿ : u₂ₙ → 1, u₂ₙ₊₁ → −1.
  • Critère de convergence : si u₂ₙ → l et u₂ₙ₊₁ → l alors uₙ → l.
  • Valeur d'adhérence : limite d'une sous-suite convergente. Une suite convergente n'a qu'une seule valeur d'adhérence : sa limite.
Bolzano-Weierstrass : de toute suite réelle bornée on peut extraire une sous-suite convergente.

IV. Suites monotones et adjacentes

Théorème de la limite monotone : une suite croissante soit est majorée (alors elle converge vers l = sup{uₙ}) soit diverge vers +∞. Une suite décroissante minorée converge vers l = inf{uₙ}. « Toute suite croissante majorée converge. »
  • Si (uₙ) croissante converge vers l : ∀n, uₙ ≤ l (décroissante : l ≤ uₙ).
  • Suite récurrente uₙ₊₁ = f(uₙ) : si f continue et uₙ → l, alors l est solution de f(x) = x (point fixe).
Suites adjacentes : (uₙ) croissante, (vₙ) décroissante et lim(uₙ − vₙ) = 0. Théorème : deux suites adjacentes convergent vers la même limite l avec uₙ ≤ l ≤ vₙ.
Approximation décimale : aₙ = E(10ⁿx)/10ⁿ et bₙ = (E(10ⁿx)+1)/10ⁿ sont adjacentes, bₙ − aₙ = 10⁻ⁿ, de limite commune x (aₙ = valeur approchée par défaut, bₙ par excès).
Théorème des segments emboîtés : segments Iₙ = [aₙ, bₙ] avec Iₙ₊₁ ⊂ Iₙ et (bₙ − aₙ) → 0 ⇒ ∩Iₙ = {l} (un unique réel).

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • « Bornée ⇒ convergente » est FAUX (contre-ex. (−1)ⁿ). C'est « convergente ⇒ bornée ».
  • Le passage à la limite élargit les inégalités : uₙ < 1 ∀n ne donne que l ≤ 1 (ex. uₙ = 1 − 1/n → 1).
  • Pour la récurrence uₙ₊₁ = f(uₙ), ne pas oublier de montrer d'abord la convergence (monotonie + bornitude) AVANT de résoudre f(x) = x.
  • Adjacentes : il faut les 3 conditions (croissance, décroissance, différence → 0).
