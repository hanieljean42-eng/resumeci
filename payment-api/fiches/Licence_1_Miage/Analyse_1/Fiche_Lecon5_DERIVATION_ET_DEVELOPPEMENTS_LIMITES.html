I. Dérivabilité

Dérivée en x₀ : f′(x₀) = lim_{x→x₀} (f(x) − f(x₀))/(x − x₀) = lim_{h→0} (f(x₀+h) − f(x₀))/h, lorsque la limite existe. Dérivées à gauche/à droite : f dérivable en x₀ ⇔ dérivée gauche = dérivée droite. Interprétation : pente de la tangente : y − f(x₀) = f′(x₀)(x − x₀). Si le taux → ±∞ : tangente verticale (pas dérivable).
  • Dérivée d'ordre n : f⁽ⁿ⁾ = (f⁽ⁿ⁻¹⁾)′. Classe Cⁿ : f⁽ⁿ⁾ existe et est continue. C∞ : indéfiniment dérivable.
  • Dérivable ⇒ continue, mais la réciproque est fausse : |x| est continue mais non dérivable en 0 (dérivée gauche −1 ≠ droite +1).
Opérations : (f+g)′ = f′+g′ ; (fg)′ = f′g + fg′ ; (f/g)′ = (f′g − fg′)/g² ; (g∘f)′(x₀) = g′(f(x₀))·f′(x₀). Fonction réciproque : si f continue strictement monotone, dérivable en x₀ avec f′(x₀) ≠ 0 : (f⁻¹)′(f(x₀)) = 1/f′(x₀). Leibniz : (fg)⁽ⁿ⁾ = Σₖ₌₀ⁿ (n,k)·f⁽ᵏ⁾g⁽ⁿ⁻ᵏ⁾.

II. Variations, extremums, grands théorèmes

  • Monotonie : f′ ≥ 0 ⇔ croissante ; f′ > 0 ⇒ strictement croissante ; f′ = 0 ⇔ constante (sur un intervalle). f′ peut s'annuler en des points isolés sans perdre la stricte monotonie.
  • Extremum local : condition nécessaire : f dérivable en x₀ et extremum en x₀ ⇒ f′(x₀) = 0. Condition suffisante : f′(x₀) = 0 et f″(x₀) ≠ 0 ⇒ extremum (max si f″ < 0, min si f″ > 0). Si f″ = 0, regarder les dérivées suivantes.
Théorème de Rolle : f continue sur [a,b], dérivable sur ]a,b[, f(a) = f(b) ⇒ ∃c ∈ ]a,b[ : f′(c) = 0. Égalité des accroissements finis : ∃c : f(b) − f(a) = (b−a)f′(c). Inégalité : si m ≤ f′ ≤ M alors m(b−a) ≤ f(b)−f(a) ≤ M(b−a) ; en particulier |f′| ≤ M ⇒ |f(b)−f(a)| ≤ M(b−a).
Règle de l'Hospital : pour les FI 0/0 ou ∞/∞, si f′/g′ a une limite l en α alors lim f/g = lim f′/g′ = l. Ex. : lim(x→1) (x−1)/(x²+x−2) = 1/3 ; lim(x→0) sin x/x = 1 ; lim(x→+∞) x²e⁻ˣ = 0 (par applications successives).

III. Fonctions convexes et fonctions usuelles

  • Convexe : f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y) — graphe sous ses cordes. f concave ⇔ −f convexe. f dérivable convexe ⇔ f′ croissante ⇔ f″ ≥ 0 ; graphe au-dessus de ses tangentes. Ex. : exp convexe, ln concave.
  • Puissances : xᵃ = exp(a ln x) sur R₊* ; (xᵃ)′ = axᵃ⁻¹ ; croissante si a > 0 ; convexe si a > 1 ou a < 0.
  • Circulaires réciproques : arcsin : [−1,1] → [−π/2, π/2], (arcsin)′ = 1/√(1−x²) ; arccos : [−1,1] → [0,π], (arccos)′ = −1/√(1−x²) ; arctan : R → ]−π/2, π/2[, (arctan)′ = 1/(1+x²), et arctan x + arctan(1/x) = (π/2)·signe(x).
  • Hyperboliques : sinh x = (eˣ−e⁻ˣ)/2, cosh x = (eˣ+e⁻ˣ)/2 ; sinh′ = cosh, cosh′ = sinh ; cosh²−sinh² = 1 ; tanh′ = 1 − tanh². Réciproques : argsh′ = 1/√(1+x²), argch′ = 1/√(x²−1), argth′ = 1/(1−x²) ; expressions log : argsh x = ln(x+√(1+x²)), argth x = ½ln((1+x)/(1−x)).

IV. Formules de Taylor

Soit f de classe C^{n+1} sur I, x₀ ∈ I : f(x) = f(x₀) + (x−x₀)f′(x₀) + (x−x₀)²/2!·f″(x₀) + … + (x−x₀)ⁿ/n!·f⁽ⁿ⁾(x₀) + reste.
— Taylor-Young : reste = (x−x₀)ⁿε(x) avec ε(x) → 0 (locale, base des DL).
— Taylor-Lagrange : reste = f⁽ⁿ⁺¹⁾(c)/(n+1)!·(x−a)ⁿ⁺¹ pour un c entre a et x (borne globale).
— Taylor-Mac Laurin : x₀ = 0, reste avec θx, θ ∈ ]0,1[.

V. Développements limités (DL)

DL d'ordre n en x₀ : f(x) = F(x) + (x−x₀)ⁿh(x) avec h → 0, où F(x) = Σaₖ(x−x₀)ᵏ est la partie régulière et (x−x₀)ⁿh(x) = o((x−x₀)ⁿ) le reste. Le DL est unique ; se ramener à 0 par h = x − a (en ±∞ : u = 1/x). f continue en 0 avec DL d'ordre 1 ⇒ dérivable en 0. f paire ⇒ coefficients impairs nuls ; f impaire ⇒ pairs nuls.
DL usuels en 0 :
eˣ = 1 + x + x²/2! + … + xⁿ/n! + o(xⁿ)
sin x = x − x³/3! + x⁵/5! + … + (−1)ⁿx²ⁿ⁺¹/(2n+1)! + o(x²ⁿ⁺²)
cos x = 1 − x²/2! + x⁴/4! + … + (−1)ⁿx²ⁿ/(2n)! + o(x²ⁿ⁺¹)
ln(1+x) = x − x²/2 + x³/3 − … + (−1)ⁿ⁺¹xⁿ/n + o(xⁿ)
arctan x = x − x³/3 + x⁵/5 − … + (−1)ⁿx²ⁿ⁺¹/(2n+1) + o(x²ⁿ⁺²)
(1+x)ᵅ = 1 + αx + α(α−1)x²/2! + … + o(xⁿ)
1/(1+x) = 1 − x + x² − … + (−1)ⁿxⁿ + o(xⁿ) ; 1/(1−x) = 1 + x + x² + … + xⁿ + o(xⁿ) ; √(1+x) = 1 + x/2 − x²/8 + x³/16 + o(x³)
  • Opérations : combinaison linéaire (λF + μG), produit (tronquer au degré n), composée, quotient (se ramener à un produit par 1/(1−u)), dérivation et primitivation terme à terme.
  • Usages : recherche d'équivalents, calcul de limites, étude de dérivabilité, branches infinies, position par rapport à la tangente.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • f′(x₀) = 0 n'est que nécessaire pour un extremum : vérifier le signe de f″ (f″(0) = 0 ne permet pas de conclure).
  • Dérivable ⇒ continue, mais pas l'inverse (|x| en 0).
  • Hospital exige une FI 0/0 ou ∞/∞ — réduire d'abord les autres formes (∞−∞, 0×∞).
  • Dans un produit de DL, tronquer les termes de degré > n — ne pas garder x⁵ dans un DL d'ordre 4.
  • DL en a ≠ 0 : faire h = x − a avant d'appliquer les DL usuels.
