I. Le corps des nombres réels

R est un ensemble muni de deux opérations (+, ×) prolongeant celles de N, Z et Q, et d'une relation d'ordre totale. Propriétés essentielles : addition et multiplication associatives et commutatives ; 0 et 1 éléments neutres ; tout réel a un opposé (−a) ; tout réel non nul a un inverse (a⁻¹) ; distributivité de × sur + ; a×b = 0 ⇒ a = 0 ou b = 0.
Relation d'ordre ≤ : totale (∀x, y : x ≤ y ou y ≤ x), compatible avec l'addition (x ≤ y ⇒ x + z ≤ y + z) et avec la multiplication par un positif (a ≤ b et 0 ≤ c ⇒ ac ≤ bc). On définit ≥, <, > à partir de ≤.

II. Intervalles de R

Intervalle : partie I ⊂ R telle que ∀x, y ∈ I, ∀z ∈ R : x ≤ z ≤ y ⇒ z ∈ I (« tout ce qui est entre deux points de I est dans I »).

Notations : ⊂ pour les parties (I ⊂ R), ∈ pour les éléments (a ∈ I). Singleton {a} = [a; a] (fermé) ; ∅ = ]a; a[ (ouvert). R et ∅ sont à la fois ouverts et fermés. Le segment [a; b] = {x = (1−t)a + bt ; t ∈ [0;1]}.

III. Voisinages

Voisinage de a ∈ R : V ⊂ R tel qu'il existe ε > 0 avec [a − ε; a + ε] ⊂ V (ou ]a − ε; a + ε[⊂ V). « Ce qu'il y a autour de a, tout près de a ».
Voisinage de +∞ (resp. −∞) : V contient un intervalle [A; +∞[ (resp. ]−∞; A]).

IV. Majorants, minorants, bornes supérieure et inférieure

Soit A ⊂ R et a ∈ R : a est un majorant de A si ∀x ∈ A, x ≤ a ; un minorant si ∀x ∈ A, x ≥ a. A majoré/minoré = admet un majorant/minorant ; borné = majoré et minoré. Un majorant n'est pas unique.
Borne supérieure sup E : le plus petit des majorants : (1) M majore E et (2) tout majorant M′ vérifie M ≤ M′. Borne inférieure inf E : le plus grand des minorants.
Caractérisation : M = sup(E) ⇔ M majore E et ∀ε > 0, ∃x ∈ E : x ∈ ]M − ε; M]. De même m = inf(E) ⇔ m minore E et ∀ε > 0, ∃x ∈ E : x ∈ [m; m + ε[.
Axiome de la borne supérieure : toute partie non vide et majorée de R possède une borne supérieure. Attention : X = {x ∈ Q ; x² ≤ 2} n'a PAS de borne sup dans Q, mais √2 dans R.
Maximum/Minimum : a = max(A) si a ∈ A et a majore A (unique s'il existe). Si sup(E) ∈ E alors c'est le maximum : sup E = max E.
Propriété d'Archimède : ∀x > 0, ∀y ∈ R, ∃n ∈ N : y ≤ nx. Droite réelle achevée R̄ = R ∪ {−∞; +∞} : toute partie de R̄ possède une borne sup et une borne inf (convention : sup X = +∞ si X non majorée).

V. Valeur absolue, partie entière, densité

Valeur absolue : |a| = a si a > 0, −a si a < 0, 0 sinon. Interprétation : |x| = distance de x à 0 ; |x − y| = distance entre x et y.
  • |x| = max{x, −x} ; |x| ≥ 0 ; |x| = 0 ⇔ x = 0 ; |xy| = |x||y| ; √x² = |x| ; |−x| = |x|.
  • Inégalités triangulaires : |x + y| ≤ |x| + |y| et ||x| − |y|| ≤ |x + y|.
  • |x − y| ≤ r ⇔ y − r ≤ x ≤ y + r (r > 0).
  • max{x, y} = ½(x + y + |x − y|) ; min{x, y} = ½(x + y − |x − y|).
Partie entière E(x) : le plus grand entier ≤ x. Encadrement clé : E(x) ≤ x < E(x) + 1 et x − 1 < E(x) ≤ x. Ex. : E(π) = 3 mais E(−π) = −4.
Densité : A est dense dans R si ∀x ∈ R, ∀ε > 0, ∃a ∈ A : |x − a| ≤ ε (on peut approcher tout réel d'aussi près qu'on veut). Q est dense dans R et R∖Q (irrationnels) est dense dans R.

VI. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • E(−π) = −4, pas −3 : la partie entière va vers −∞.
  • sup E peut ne pas appartenir à E : sup ]0;1[ = 1 ∉ ]0;1[ (pas de maximum).
  • √x² = |x|, pas x : (−3)² = 9 → √9 = 3 = |−3|.
  • Majorant ≠ borne supérieure : 2 et 3 majorent [0;1], mais sup = 1.
  • Ne pas confondre ⊂ (parties) et ∈ (éléments).
