I. Les sélecteurs simples

SélecteurSyntaxeCible
Balise (élément)p {…}Tous les éléments de ce type (<p>, <h2>…)
Classe.maClasse {…}Tout élément portant class="maClasse" — réutilisable sur des balises différentes, plusieurs classes par élément
Classe restreinteh3.renforce {…}Uniquement les <h3> portant cette classe
Identifiant#resume {…}L'élément portant id="resume" — unique dans le document (sinon → classe)
Universel* {…}Tous les éléments de la page
Groupementh1, h2, .titre {…}Une même règle appliquée à plusieurs sélecteurs

II. L'arbre DOM et les sélecteurs combinés

La page forme un arbre DOM (Document Object Model) : nœud racine, nœuds, feuilles. Relations : enfant (x enfant de y = contenu direct), descendant (enfant, ou enfant d'un enfant…), 1ᵉʳ frère suivant (adjacent), frère suivant (même parent, placé après).
CombinateurSyntaxeSélectionne sélecteur2 quand…
Espace (descendant)nav a {…}Il descend (à n'importe quel niveau) de sélecteur1 → ex. les liens situés dans un <nav>
> (enfant)div > p {…}Son parent direct est sélecteur1
+ (adjacent)h2 + p {…}Il est le 1ᵉʳ frère directement précédé de sélecteur1
~ (frères)h2 ~ p {…}Un frère précédent est sélecteur1 (pas forcément immédiat)
Intérêt : cibler par la position dans l'arborescence sans ajouter de classes partout — plus léger et moins source d'erreurs. Combinaisons chaînées possibles : s1 s2 … sn.

III. Pseudo-classes, pseudo-éléments et attributs

Pseudo-classes (sélecteur:pseudoClasse) : sélectionnent selon l'état de l'élément.
• D'ancres : :link (non visité), :visited (visité)
• Dynamiques : :hover (survol), :active (clic enfoncé), :focus (focus clavier/champ)
• Structurelles : :first-child, :last-child, :nth-child(n), :lang(fr)
Ordre obligatoire pour les liens : :link → :visited → :hover → :focus → :active
Pseudo-éléments (sélecteur::pseudoElt) : stylent une partie de l'élément ou un contenu généré, absent du code source : ::first-line, ::first-letter, ::before, ::after (avec content), ::selection.
Sélecteurs d'attribut : p[class] (attribut présent) · p[class="x"] (valeur exacte) · p[class~="x"] (x parmi une liste séparée par des espaces) · a[href^="https"] (commence par) · a[href$=".pdf"] (finit par) · a[href*="mozilla"] (contient) → ex. styliser les liens selon leur destination.

IV. Propagation et cascade

Héritage : certaines propriétés (color, font…) se propagent d'un élément à ses descendants — mais pas toutes (ex. border ne se propage pas). La valeur inherit force la reprise de la valeur du parent.
Règles de la cascade (résolution des conflits, propriété par propriété) :
① À sélecteur et propriété identiques → la dernière règle écrase les précédentes
② À spécificité égale → la dernière déclarée gagne
③ Sinon → le sélecteur le plus spécifique l'emporte
Calcul de spécificité (x1 x2 x3 x4) : x1 = 1 si style en ligne ou !important ; x2 = nb d'#id ; x3 = nb de classes/attributs/pseudo-classes ; x4 = nb de balises. On compare de gauche à droite.
Ordre : !important / inline > #id (≈100) > .classe (≈10) > balise (≈1). Ex. : .alerte.title (20) > h1.title (11) > .title (10) > h1 (1). ⚠️ !important supplante tout — à éviter.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • div > p (parent direct) ≠ div p (descendant à tout niveau) — confusion fatale.
  • + = frère immédiatement après ; ~ = tous les frères suivants.
  • Pseudo-classe = 1 deux-points (:hover) ; pseudo-élément = 2 deux-points (::before).
  • Ordre des pseudo-classes de liens : LoVe HA (:link :visited :hover :active) — sinon :hover peut être écrasé.
  • Un id doit être unique : besoin de styler plusieurs éléments → classe.
  • border, margin, padding ne s'héritent pas ; color et font-family oui.
