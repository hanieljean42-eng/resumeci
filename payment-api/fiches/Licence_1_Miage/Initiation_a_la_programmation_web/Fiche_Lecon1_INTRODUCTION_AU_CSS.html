I. Qu'est-ce que le CSS ?

CSS (Cascading Style Sheets) : langage de feuilles de style servant à présenter les informations d'une page web : couleurs, tailles, bordures, positions des éléments HTML. Ce n'est pas un langage de programmation (comme HTML) ; il peut être étendu par des préprocesseurs (Sass, Less : variables, imbrication).
Un site web = 3 couches :
• Contenu structuré → HTML5 (paragraphes, tableaux, sections, articles)
• Présentation → CSS (design + layout : comment afficher et positionner les éléments)
• Comportement → JavaScript (interactions)
Principe fondateur : séparer le contenu de la présentation — un même document HTML peut être affiché avec des feuilles de style totalement différentes.
Repères historiques : HTML 1.0 (1989) → CSS1 : 1ʳᵉ recommandation W3C (1996) → CSS2/CSS2.1 (1998-2002) → HTML5 + CSS3 (2012 : animations, effets textuels, transformations 2D/3D). Plus de 500 propriétés recensées — le cours vise les principes essentiels, pas l'exhaustivité.

II. Les 3 façons d'intégrer du CSS

MéthodeSyntaxeAvantages / limites
1. InlineAttribut style dans la balise : <p style="color:red">⚠️ Mélange structure et présentation, ne s'applique qu'à une balise → à éviter
2. InterneBalise <style> dans le <head> du documentStyles regroupés en un seul endroit ; mais utilisables uniquement dans ce document
3. Externe ✅Fichier .css lié par <link rel="stylesheet" href="./css/styles.css"> dans le <head>Vraie séparation contenu/présentation ; styles partageables entre plusieurs pages ; plusieurs feuilles combinables
Attributs de <link> : rel="stylesheet" (relation), href (chemin — toujours relatif pour les ressources du site, ne commence jamais par « / » : ./css/styles.css), type="text/css" (souvent implicite), media (screen, print, all…), integrity/crossorigin (ressources externes : vérification SRI + CORS).
@import : alternative dans le CSS (@import url(autre.css) screen;) mais chargement plus lent → préférer <link>.

III. Syntaxe d'une règle CSS

Structure générale :
sélecteur { propriété : valeur ; propriété : valeur ; }

• sélecteur : désigne les éléments HTML concernés par la règle
• propriété : indique au navigateur quoi modifier (color, font-size…)
• valeur : indique comment modifier (red, 14px…)
• : sépare propriété et valeur ; ; termine chaque déclaration ; { } encadrent le bloc de déclarations.
Ex. : h1 { background-color: yellow ; color: navy ; }
Bonnes pratiques : commentaires = /* texte ignoré par le navigateur */ ; nommer les classes selon la sémantique et non la présentation (.alerte, .resume plutôt que .rougeSurJaune) ; fixer margin/padding dans le CSS pour un rendu indépendant du navigateur ; un élément peut porter plusieurs classes (class="alerte surligne").
Unités de mesure : px (pixel), pt (point, 1/72"), em (hauteur de la police courante), ex (hauteur du « x »), % , cm, mm, in. Règles : unité collée au chiffre (12px), séparateur décimal = le point (0.5em, pas de virgule !). Valeurs relatives (em, %) calculées par rapport à l'élément parent.

IV. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • CSS ≠ langage de programmation : c'est un langage de description de présentation.
  • La méthode recommandée = feuille externe via <link>; le style inline est à proscrire.
  • Chemin relatif : ./css/styles.css — ne commence jamais par « / ».
  • Oublier le ; entre deux déclarations → la règle entière peut être ignorée.
  • HTML fait le contenu, CSS la présentation, JS le comportement — ne pas inverser les rôles.
