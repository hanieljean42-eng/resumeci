I. Le modèle de boîte (box model)

Chaque élément HTML est une boîte rectangulaire composée de 4 couches, de l'intérieur vers l'extérieur :
contenu (texte, image — dimensionné par width/height) → marge interne / padding (entre contenu et bordure) → bordure (le cadre) → marge externe / margin (entre le cadre et les boîtes voisines).
Propriétés associées :
• Dimensions du contenu : width, height
• Arrière-plan : background-color, background-image
• Padding : padding, padding-top/right/bottom/left
• Bordure : border-style (obligatoire pour voir une bordure !), border-width, border-color
• Margin : margin, margin-top/right/bottom/left
Valeurs par défaut : 0 pour les éléments en ligne et <div> ; margin/padding des éléments bloc dépendent du navigateur → les fixer en CSS pour un rendu homogène.
Écriture raccourcie (1 à 4 valeurs) :
margin: 10px; → les 4 côtés · margin: 10px 20px; → haut/bas puis gauche/droite · margin: 10px 20px 30px; → haut, gauche/droite, bas · margin: t r b l; → haut, droite, bas, gauche (sens horaire). Même logique pour padding et border-style.

III. Bordures et arrière-plans

Bordures : 3 propriétés complémentaires — border-style (solid, dashed, dotted, double, none…), border-width (px ou thin/medium/thick), border-color. Individualisation par côté : border-top-style, border-left-width… Raccourci : border: 2px solid navy;
Arrière-plans : background-color (couleur) ; background-image: url(images/logo.png) (chemin relatif — répétée en damier par défaut) ; background-repeat (repeat, repeat-x, repeat-y, no-repeat) ; background-position (left/right/top/bottom ou %) ; background-attachment: fixed (fige l'image au scroll).

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • padding ≠ margin : padding = à l'intérieur (entre contenu et bordure), margin = à l'extérieur (entre les boîtes).
  • Sans border-style, border-width et border-color ne font rien apparaître.
  • #F00 = #FF0000 : l'abrégé hexa duplique chaque chiffre.
  • display:none retire l'élément du flux (pas de place réservée) ; float le sort du flux en gardant le texte autour.
  • font-family : les polices à espaces entre guillemets ('times new roman'), liste ordonnée de la préférée à la générique.
  • Décimales avec un point (0.5em), unité collée au chiffre.
