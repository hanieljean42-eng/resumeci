I. Cardinal d'un ensemble fini

Ensemble fini : bijection avec {1,…,n} → Card(E) = n. Dénombrable : bijection avec ℕ (ex. ℤ, ℚ) ; sinon infini non dénombrable (ℝ).
Formules : Card(Ā) = Card(E) − Card(A) ; Card(A∪B) = Card(A) + Card(B) − Card(A∩B) ; A∩B = ∅ → somme directe ; Card(A×B) = Card(A)×Card(B).

Ex. : 5 chemins Abidjan→Agboville puis 3 Agboville→Akoupé → 5×3 = 15 ; mais Abidjan→Agboville ou Adzopé → 5+3 = 8.

Question clé pour choisir la formule : l'ordre compte-t-il ? la répétition est-elle permise ?

Propriétés des coefficients binomiaux : C⁰n = Cnn = 1 ; Cpn = Cn−pn ; Pascal : Cpn = Cp−1n−1 + Cpn−1 ; binôme : (a+b)ⁿ = Σ Cpnapbn−p ; Σp Cpn = 2ⁿ (nombre de parties d'un ensemble).
Traductions à retenir : Apn = injections {1,…,p} → ensemble à n = tirages sans remise ordonnés ; np = toutes les applications = tirages avec remise ; Cpn = parties à p éléments = tirages sans remise non ordonnés.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Arrangement vs combinaison : demandez-vous si « ABC » et « BAC » comptent pour 1 ou 2. Comité/tirage non ordonné → C ; podium/code → A.
  • n!/(n−p)! s'arrête à n−p+1, pas à 1 — compter les p facteurs.
  • Objets indiscernables sans vide : Cr−1n−1 ; sans contrainte : Cr−1n+r−1. Ne pas les inverser.
  • Penser « ET » → multiplier ; « OU » exclusifs → additionner. Les cas qui se recoupent → inclusion-exclusion.
  • Permutations avec répétitions : diviser par les factorielles des répétitions (ex. mot « ANANAS » : 6!/(3!·2!·1!)).
