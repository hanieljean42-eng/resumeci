I. Vecteurs aléatoires : loi conjointe

Vecteur aléatoire X = (X₁,…,Xn) : application (Ω,F) → (ℝⁿ, 𝔹ℝⁿ) dont chaque composante Xi est une v.a.r. Loi conjointe : PX(B) = P(X ∈ B). Fonction de répartition : FX(x₁,…,xn) = P(X₁ ≤ x₁,…,Xn ≤ xn).
  • Discret : loi = masses pX(x₁,…,xn) = P(X₁ = x₁,…,Xn = xn).
  • Absolument continu : densité fX ≥ 0 avec ∫ℝⁿf = 1 et FX(x) = ∫−∞x₁…∫−∞xₙfXdt₁…dtn ; fX = ∂ⁿF/∂x₁…∂xn aux points de continuité.
Lois marginales : lois des composantes Xi. Discret : pXᵢ(xi) = Σ sur les autres coordonnées de pX. Continu : fXᵢ(xi) = ∫ fX d(toutes les autres variables) ; ou FXᵢ(xi) = limxⱼ→+∞FX(x).
⚠️ La conjointe détermine les marginales, mais pas l'inverse (sauf indépendance).

II. Espérance, covariance, indépendance

E(X) = (E(X₁),…,E(Xn))ᵗ. Covariance : Cov(Xi,Xj) = E(XiXj) − E(Xi)E(Xj). Matrice de covariance ΣX = matrice des Cov(Xi,Xj) — symétrique, semi-définie positive ; diagonale = variances.
Propriétés : Y = AX + B ⇒ E(Y) = A·E(X) + B et ΣY = AΣXAᵗ ; V(X+Y) = V(X) + V(Y) + 2Cov(X,Y).
Indépendance des composantes ⇔ loi conjointe = produit des marginales ⇔ FX = ΠFXᵢ ⇔ fX = ΠfXᵢ ⇔ φX(a) = ΠφXᵢ(ai). Alors : E(ΠXi) = ΠE(Xi) et ΣX diagonale.
Stabilité par somme : Poisson P(λi) → P(Σλi) ; γ(ai,ρ) → γ(Σai,ρ) ; N(mi,σ²i) → N(Σmi, Σσ²i).
Conditionnement : densité conditionnelle fY|Z=z(y) = f(Y,Z)(y,z)/fZ(z). Espérance conditionnelle E(Y|Z) = φ(Z) ; théorème clé : E(Y) = E(E(Y|Z)) (espérance totale) et Var(Y) = E(Var(Y|Z)) + Var(E(Y|Z)).

III. Vecteurs gaussiens

Vecteur gaussien X ~ N(m,Σ) : toute combinaison linéaire aᵗX est une v.a. normale. Chaque Xi ~ N(mi, σii). Si Σ régulière : fX(x) = [(2π)n/2√det Σ]⁻¹ · e−½(x−m)ᵗΣ⁻¹(x−m).
Propriétés fondamentales :
• Σ diagonale ⇔ composantes indépendantes (pour un vecteur gaussien, non-corrélation ⇒ indépendance !)
• φX(a) = eiaᵗm − ½aᵗΣa
• Lois dérivées : ΣX²i (Xi ~ N(0,1) indép.) ~ χ²(n) ; N(0,1)/√(χ²(n)/n) ~ Student T(n) ; (χ²(n₁)/n₁)/(χ²(n₂)/n₂) ~ Fisher F(n₁,n₂).

IV. Convergences et théorèmes limites

ConvergenceDéfinitionNotation
En loiFn(x) → F(x) en tout point de continuité de F (⇔ φXₙ(t) → φX(t) ⇔ E(h(Xn)) → E(h(X)) pour h bornée continue par morceaux)Xn L→ X
En probabilité∀ε > 0, P(|Xn−X| > ε) → 0Xn P→ X
Presque sûreP({ω : Xn(ω) → X(ω)}) = 1Xn p.s.→ X
Hiérarchie : p.s. ⇒ en probabilité ⇒ en loi. Réciproques fausses en général, sauf : convergence en loi vers une constante a ⇒ convergence en probabilité vers a.
Loi faible des grands nombres : v.a. de moyenne m, Cov(Xi,Xj) = δijσ² ⇒ X̄n P→ m.
Loi forte des grands nombres : v.a. indépendantes de même loi, E(Xi) = m ⇒ X̄n p.s.→ m — « la moyenne empirique converge vers l'espérance ».
Théorème central limite (TCL) : v.a. i.i.d., E(Xi) = m, Var = σ² ⇒ √n(X̄n − m)/σ L→ N(0,1) — la somme/moyenne de beaucoup de v.a. indépendantes ≈ gaussienne.
Méthode delta : √n(Xn−m) L→ N(0,σ²) et g dérivable ⇒ √n(g(Xn)−g(m)) L→ N(0,[g′(m)]²σ²). Version vectorielle du TCL idem avec Σ.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Les marginales ne suffisent pas à retrouver la conjointe : il faut l'indépendance (fX = produit des marginales).
  • Cov(X,Y) = 0 n'implique pas l'indépendance en général — sauf pour les vecteurs gaussiens.
  • Domaine d'intégration : pour une densité sur {0 < x₃ < x₂ < x₁}, dessiner/ordonner les bornes avant d'intégrer.
  • TCL : c'est √n(X̄−m)/σ qui tend vers N(0,1), pas X̄n lui-même (qui tend vers m par la LGN).
  • V(X+Y) = V(X)+V(Y) exige l'indépendance ; sinon +2Cov(X,Y).
