I. Expérience aléatoire et événements

Expérience aléatoire : résultat non prévisible, reproductible dans les mêmes conditions avec des issues variables. Univers Ω : ensemble de tous les résultats (éventualités ω). Événement : partie de Ω ; élémentaire = singleton.
  • Impossible = ∅ ; certain = Ω ; contraire Ā (= ∁AΩ) : A ∪ Ā = Ω, A ∩ Ā = ∅.
  • A∩B : « A et B » ; A∪B : « A ou B » ; incompatibles : A∩B = ∅.
  • A\B = A∩B̄ ; différence symétrique AΔB = (A∪B)\(A∩B) ; A implique B ⇔ A ⊂ B.
Tribu F : famille de parties de Ω avec : Ω ∈ F ; stable par complémentaire ; stable par réunion dénombrable. Ex. : {∅,Ω} (grossière), 𝒫(Ω) (triviale), σ(A) = {∅, A, Ā, Ω}. Le couple (Ω,F) = espace probabilisable. Tribu borélienne 𝔹ℝ : engendrée par les intervalles. Système complet : famille d'événements deux à deux incompatibles dont la réunion = Ω (partition d'événements).

II. Axiomes de la probabilité

Probabilité P : application F → [0,1] avec : ① P(Ω) = 1 ; ② σ-additivité : pour une suite d'événements deux à deux incompatibles, P(⋃Ai) = ΣP(Ai). Le triplet (Ω, F, P) = espace probabilisé. Interprétation fréquentiste : fn(A) = nA/n → P(A) quand n → ∞.
Propriétés : P(∅) = 0 ; P(Ā) = 1 − P(A) ; P(A\B) = P(A) − P(A∩B) ; A⊂B ⇒ P(A) ≤ P(B) ; P(A∪B) = P(A)+P(B)−P(A∩B) ; formule de Poincaré (généralisation à n événements, signes alternés) ; continuité croissante et décroissante.
Événement négligeable : P(A) = 0 ; presque sûr (p.s.) : P = 1 — attention, p.s. ≠ certain et négligeable ≠ impossible !
Équiprobabilité (Ω fini) : si les éventualités ont même chance : P(A) = Card(A)/Card(Ω) = « cas favorables / cas possibles ». Sur un Ω dénombrable : il suffit que les pi = P({ωi}) vérifient pi ≥ 0 et Σpi = 1.

III. Probabilités conditionnelles

Pour P(B) > 0 : P(A|B) = P(A∩B)/P(B) — probabilité de A quand on sait B réalisé. P(·|B) est elle-même une probabilité.
① Probabilités composées : P(A₁∩…∩An) = P(A₁)·P(A₂|A₁)·P(A₃|A₁∩A₂)···P(An|A₁∩…∩An−1) — tirages sans remise.
② Probabilités totales : (Ai) système complet ⇒ P(B) = ΣP(Ai)·P(B|Ai).
③ Bayes (probabilité des causes) : P(Ai₀|B) = P(Ai₀)·P(B|Ai₀) / ΣiP(Ai)P(B|Ai) — on « remonte » de l'effet vers la cause.

IV. Indépendance

A et B indépendants ⇔ P(A∩B) = P(A)·P(B) ⇔ P(A|B) = P(A) : la réalisation de l'un n'influence pas l'autre. A,B indép. ⇔ Ā,B ⇔ Ā,B̄. L'événement certain et l'impossible sont indépendants de tout événement.
Indépendance mutuelle de n événements : toutes les sous-familles vérifient P(∩Aij) = ΠP(Aij) — pour 3 événements : les 3 produits par paires ET P(A∩B∩C) = P(A)P(B)P(C). 2ⁿ−n−1 conditions.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Incompatible ≠ indépendant : deux événements incompatibles non triviaux sont dépendants (si A arrive, B devient impossible → P(B|A) = 0 ≠ P(B)).
  • P(A|B) n'est pas P(B|A) — la confusion cause↔effet est la faute n°1 dans Bayes.
  • P(A∪B) = P(A)+P(B) n'est valable que si A∩B = ∅ ; sinon retrancher P(A∩B).
  • « A ou B » en probabilité = ou inclusif ; l'événement « l'un seulement des deux » = AΔB.
  • Indépendance deux à deux n'implique pas l'indépendance mutuelle.
