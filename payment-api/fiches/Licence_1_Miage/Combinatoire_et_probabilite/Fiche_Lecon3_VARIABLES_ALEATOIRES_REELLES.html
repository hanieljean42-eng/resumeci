I. Définition et types

Variable aléatoire réelle (v.a.r) X : application Ω → ℝ qui associe à chaque issue ω un nombre réel X(ω). Support X(Ω) = SX = ensemble des valeurs possibles.
• Discrète (v.a.r.d) : support fini ou dénombrable (ex. nombre de piles sur 3 lancers : {0,1,2,3}).
• Continue (v.a.r.c) : support = intervalle (ex. abscisse d'un point tiré dans un triangle : ]0,1[).
Définition mesurable : ∀B ∈ 𝔹ℝ, X⁻¹(B) ∈ F ; en pratique il suffit que {X ≤ x} ∈ F ∀x.
Loi de X : PX(B) = P(X ∈ B) = P(X⁻¹(B)). Comme l'application PX est difficile à expliciter, on la caractérise par des fonctions.

II. Les trois fonctions qui caractérisent une loi

FonctionDéfinitionPropriétés clés
Fonction de répartition FXFX(x) = P(X ≤ x)0 ≤ F ≤ 1 ; F(−∞) = 0, F(+∞) = 1 ; croissante (au sens large) ; continue à droite ; en escalier si X discrète, continue si X continue
Fonction de masse pX (cas discret)pX(x) = P(X = x) — = le « saut » de F en xpX ≥ 0, Σx∈SpX(x) = 1 ; nulle hors du support ; pour une v.a.c : P(X=x) = 0 ∀x
Fonction de densité fX (cas continu)P(X∈B) = ∫B fX(t)dt ; P(a≤X≤b) = ∫ab ff ≥ 0 ; continue par morceaux ; ∫ℝf = 1 ; F′X = fX aux points de continuité
Lecture de F : P(a < X ≤ b) = F(b) − F(a) ; pour les autres combinaisons de bornes, ajuster avec les limites à gauche de F.
V.a.r.d : F en escalier avec sauts aux points xi ; on retrouve la loi : P(X = xi) = F(xi) − F(xi−1).
V.a.r.c absolument continue : F(x) = ∫−∞xf(t)dt ; P(a < X ≤ b) = F(b) − F(a) quelles que soient les inégalités strictes/larges (P(X=a)=0).

III. V.a. discrètes : loi et fonction d'une v.a.

Déterminer la loi de X discrète : ① trouver le support {xi} ; ② calculer chaque pi = P(X = xi) ; ③ vérifier Σpi = 1. Présentation en tableau pour un support fini. Les {X = xi} forment un système complet.
Loi de Y = φ(X) : support SY = φ(SX) et pY(y) = Σ{x : φ(x)=y} pX(x) — on additionne les probabilités des antécédents. Cas continu : φ strictement monotone dérivable → fY(y) = fX(φ⁻¹(y))·|(φ⁻¹)′(y)| ; sinon passer par FY(y) = P(φ(X) ≤ y).

IV. Moments : espérance et variance

Espérance E(X) = moyenne pondérée : discret → E(X) = Σx x·P(X=x) ; continue → E(X) = ∫ x·f(x)dx (si convergence).
Théorème du transfert : E(g(X)) = Σg(x)p(x) ou ∫g(x)f(x)dx — permet de calculer E(g(X)) sans trouver la loi de g(X) et caractérise même la loi.
Propriétés : E(aX+b) = aE(X)+b (linéarité) ; X ≤ Y ⇒ E(X) ≤ E(Y) ; X,Y indépendantes ⇒ E(XY) = E(X)E(Y).
Variance : V(X) = E[(X−E(X))²] = E(X²)−[E(X)]² ≥ 0 ; V(aX+b) = a²V(X) ; X,Y indépendantes ⇒ V(X+Y) = V(X)+V(Y).
Écart-type σX = √V(X) ; moment d'ordre k : mk = E(Xᵏ) ; centré : μk = E[(X−E(X))ᵏ].
Inégalités (à citer aux partiels) : Markov (X ≥ 0) : P(X ≥ α) ≤ E(X)/α ; Bienaymé-Tchebychev : P(|X−E(X)| ≥ α) ≤ V(X)/α².
Fonctions auxiliaires : caractéristique φX(t) = E(eitX) (caractérise la loi ; moments par dérivation en 0) ; génératrice GX(s) = E(sX) pour X à valeurs dans ℕ (E(X) = G′X(1⁻)).

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Vérifier Σpi = 1 ou ∫f = 1 avant tout calcul — c'est souvent l'objet de la question 1 (trouver k ou p).
  • Pour une v.a. continue, P(X = a) = 0 : inégalités strictes ou larges indifférentes ; ce n'est pas vrai pour une discrète.
  • V(X) = E(X²) − E(X)² : ne pas oublier le carré sur E(X) ; V(X) ≠ E(X²) en général.
  • F est continue à droite, pas nécessairement continue : les sauts = masses de probabilité.
  • Pour E(g(X)), inutile de trouver la loi de g(X) : appliquer le théorème du transfert.
