III. La loi normale centrée réduite — méthode de la table

Standardisation : si X ~ N(m,σ²) alors T = (X−m)/σ ~ N(0,1).
On utilise la fonction de répartition Π(t) = P(T ≤ t) (table fournie aux examens) :
• Π(−∞) = 0, Π(+∞) = 1, Π(0) = 0,5 ; Π(−t) = 1 − Π(t)
• P(a ≤ X ≤ b) = Π((b−m)/σ) − Π((a−m)/σ)
• P(|T| ≤ t) = 2Π(t) − 1 ; P(|T| ≥ t) = 2(1 − Π(t))
Intégrales gaussiennes à retenir : ∫ℝe−αx²dx = √(π/α) ; ∫ℝe−αx²+βxdx = eβ²/4α√(π/α).

IV. Comment choisir la loi ?

2 issues, 1 essai → Bernoulli · n essais indépendants, on compte les succès → Binomiale · tirages SANS remise → Hypergéométrique · attente du 1er succès → Géométrique · attente du r-ième → BN · événements rares / flux par unité de temps → Poisson · équiprobabilité → Uniforme · durée de vie, sans mémoire → Exponentielle · somme d'exponentielles → Gamma · bruit, erreurs, moyennes → Normale.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Avec remise → Binomiale ; sans remise → Hypergéométrique. C'est LE piège n°1 : relire l'énoncé.
  • Géométrique : P(X=k) = p(1−p)k−1, exposant k−1 (k−1 échecs puis 1 succès), pas k.
  • Ne pas oublier Ckn dans la binomiale : pk(1−p)n−k seul = proba d'UNE séquence précise.
  • Poisson : E = V = λ — si l'énoncé donne « en moyenne 3 clients/heure », λ = 3.
  • Loi exponentielle : « sans mémoire » ⇒ P(X > t+s | X > t) = P(X > s) — ne pas recalculer F.
  • Normale : toujours centrer-réduire avant d'utiliser la table ; Π(−t) = 1 − Π(t).
