📖 Gestion financière (Finance d'entreprise) 🏫 Licence 1 MIAGE — Semestre 2 Leçon 3 : Décision d'investissement — VAN, DRCI, TRI, IP

I. Types d'investissement et étapes de la décision

CritèreTypes
Selon l'objetRemplacement (équipement usé) · Expansion (↑ capacité) · Productivité (↓ coûts) · Stratégique (défensif/offensif)
Selon la natureCommercial (positionnement du produit) · Financier (acquisition de titres)
Les 4 étapes : 1. Conception (réflexion, créativité) → 2. Présélection (étude commerciale, technique, personnel, financement) → 3. Sélection et financement (choix + montage financier) → 4. Réalisation, suivi et contrôle.
Paramètres : I = dépense d'investissement · CF = cash-flows prévisionnels · i = taux d'actualisation · n = durée de vie · VR = valeur résiduelle.

II. Les 4 critères de choix

1. VAN — Valeur Actuelle Nette

VAN = Σ CF × (1+i)−n − I
Règle : VAN > 0 → projet rentable, accepter ; VAN < 0 → rejeter. Entre deux projets : choisir la VAN la plus élevée.

2. DRCI — Délai de Récupération du Capital Investi

Date à laquelle le cumul des CF actualisés = I. Méthode : calculer les CF actualisés → cumuler année par année → repérer entre quelles années le cumul dépasse I → interpoler pour trouver mois et jours.
Interpolation : Reste = I − cumul(année k) ; x mois = (12 × Reste) / CF actualisé(année k+1) ; la fraction de mois × 30 = jours.

3. TRI — Taux de Rentabilité Interne

Taux i pour lequel VAN = 0, c.-à-d. Σ CF×(1+TRI)−n = I. Se résout par interpolation ou calculatrice financière.

4. IP — Indice de Profitabilité

IP = Σ CF actualisés / I — IP > 1 → projet rentable.

IV. Comparaison de deux projets

Règles de choix : VAN la plus élevée · DRCI le plus court · IP le plus élevé. Ex. cours : Projet A (VAN 4,07M, DRCI 3 ans 3 jours, IP 1,20) bat Projet B (VAN 3,66M, DRCI 3 ans 5 mois, IP 1,15) sur les 3 critères.

V. ⚠️ Pièges d'examen

⚠️ Pièges classiques :
  • Oublier de soustraire I dans la VAN : VAN = Σ CF actualisés − I.
  • Utiliser les CF bruts pour le DRCI : il faut les CF actualisés (même (1+i)−n).
  • Confondre TRI et taux d'actualisation : le TRI est le taux qui annule la VAN.
  • IP : seuil = 1, pas 0 (IP = 1 + VAN/I).
  • Interpolation DRCI : diviser par le CF actualisé de l'année suivante, pas le cumul.
