🧪 Physique-ChimieLeçon 7 : Les mélanges

I. Mélanges homogènes

Un mélange homogène est un mélange dans lequel on ne distingue plus les constituants à l'œil nu.
ExempleRésultat
Sel + eauLe sel se dissout (soluble) → solution
Alcool + eauLiquides miscibles → mélange homogène
Vocabulaire :
  • Soluté : substance qui se dissout
  • Solvant : liquide dans lequel se dissout la substance
  • Solution : mélange homogène liquide
  • Solution saturée : mélange où le soluté n'est pas totalement dissous

II. Mélanges hétérogènes

Un mélange hétérogène est un mélange dans lequel on distingue les constituants à l'œil nu.
ExempleRésultat
Sable + eauLe sable est insoluble → particules en suspension puis dépôt
Huile + eauLiquides non miscibles (immiscibles) → 2 couches visibles

III. Techniques de séparation

TechniquePrincipeMélange traité
DécantationLaisser reposer pour séparer par gravitéSable+eau, Huile+eau
FiltrationPassage à travers un filtre (papier filtre)Sable+eau (après décantation)
ÉvaporationChauffer pour éliminer le solvantSel+eau (solution)
DistillationChauffer puis condenser la vapeurAlcool+eau
Hétérogène → Décantation / Filtration | Homogène → Évaporation / Distillation
