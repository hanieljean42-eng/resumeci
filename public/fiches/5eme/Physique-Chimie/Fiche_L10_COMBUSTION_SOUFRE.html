I. Combustion du soufre

La combustion du soufre dans le dioxygène est une réaction chimique qui produit du dioxyde de soufre (SO₂).
  • Dans l'air : flamme bleue
  • Dans le dioxygène : flamme bleue plus vive + fumée blanche
Test d'identification : Le dioxyde de soufre décolore la solution de permanganate de potassium.
Équation-bilan : S + O₂ → SO₂

Remarque : Le SO₂ est un gaz incolore, à odeur suffocante, toxique et soluble dans l'eau.
