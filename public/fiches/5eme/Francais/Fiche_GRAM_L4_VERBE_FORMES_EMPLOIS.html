I. La tournure pronominale

Les verbes pronominaux se conjuguent avec un pronom réfléchi (me, te, se, nous, vous, se) qui désigne la même personne que le sujet.
TypeDéfinitionExemple
Essentiellement pronominalN'existe qu'à la forme pronominales'évanouir, s'emparer, s'écrier
Sens réfléchiLe sujet fait l'action sur lui-mêmeJe me baigne
Sens réciproqueAction exercée l'un sur l'autreLes fiancés s'embrassent
Sens passifLe sujet subit l'actionLes fleurs se vendent cher

II. Morphologie des verbes irréguliers (1er et 3e groupe)

Morphologie du verbe = les différentes formes qu'il prend selon le temps, le mode, la personne et le nombre.

Le radical (base)

Partie qui ne change presque jamais. Les verbes irréguliers ont des bases qui varient :
  • 1er groupe : jeter → je jette / je jetais ; acheter → j'achète / j'achetais
  • 3e groupe : aller → je vais / j'irai / j'allais

Les marques temporelles (terminaisons)

La terminaison (ou désinence) donne des informations sur :
  • La personne
  • Le mode
  • Le temps
  • Le groupe

III. Structure du verbe

VERBE = Radical (base) + Terminaison (marque temporelle)
Ex : Nous étudi-ons → radical « étudi » + terminaison « ons » (1re pers. pluriel, présent)
