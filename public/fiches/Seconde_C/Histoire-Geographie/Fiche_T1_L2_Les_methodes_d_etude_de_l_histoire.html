📝 FICHE DE RÉSUMÉ

📖 Histoire-Géographie🏫 Seconde CT1 L2 – Les méthodes d’étude de l’histoire
Objectif de la leçon : identifier les différentes sources de l’histoire et comprendre la démarche scientifique utilisée par l’historien pour reconstituer le passé.

I. Les sources de l’histoire

Source historique : tout document, témoignage ou vestige qui permet de connaître un fait ou un événement du passé.

1. Les sources écrites

  • Textes manuscrits ou imprimés : correspondances, journaux, lois, traités, mémoires, autobiographies, ouvrages scientifiques, livres saints…
  • Provenant surtout des sociétés ayant développé très tôt l’écriture (Égypte ancienne, Europe, Chine…).
  • Avantages : souvent précises, datées, conservées dans des archives ou des bibliothèques.
  • Limites : documents parfois partiels, orientés, difficiles d’accès ou détruits.

2. Les sources orales (tradition orale)

  • Témoignages transmis de génération en génération : contes, épopées, récits des griots, légendes, chants, proverbes…
  • Très importantes pour les sociétés où l’écriture s’est peu développée ou est arrivée tardivement (cas de nombreuses sociétés africaines).
  • Avantages : conservent la mémoire des peuples, de leurs croyances, de leurs institutions.
  • Limites : risque de déformation, d’oubli ou d’exagération ; datation difficile.

3. Les sources archéologiques (ou muettes)

  • Vestiges matériels du passé : ossements, poteries, monnaies, outils, armes, monuments, tombes, sarcophages, gravures rupestres…
  • Très utilisées pour l’étude de la préhistoire.
  • Avantages : témoignages concrets de l’existence humaine.
  • Limites : fouilles coûteuses, problèmes de conservation et de datation.

4. Les sources audiovisuelles et numériques

  • Films documentaires, reportages, interviews, photographies, enregistrements sonores…
  • Médias et technologies : radio, télévision, cinéma, internet, ordinateurs, clés USB, téléphones portables.
  • Avantages : accès rapide à l’information, possibilité de revoir les évènements.
  • Limites : risque de manipulation, de montage, de fausses informations (fake news).
À retenir : aucune source ne doit être négligée. L’historien croise plusieurs types de sources pour approcher la vérité historique.

II. La démarche de l’historien

L’historien suit une démarche scientifique en plusieurs étapes pour reconstituer le passé.

1. Choix du thème

  • Le sujet d’étude doit être clair, précis et digne d’intérêt.
  • Exemples : « l’apport des sources orales dans l’histoire africaine », « la colonisation de la Côte d’Ivoire ».

2. Collecte des données

  • Rassembler un maximum de documents et d’informations sur le sujet : sources écrites, orales, archéologiques, audiovisuelles, numériques…
  • Ne négliger aucun type de source.

3. Traitement critique des documents

L’historien soumet les documents à une double critique :

  • Critique externe :
    • Vérifier l’origine du document (auteur, date, lieu, nature du document).
    • Examiner les conditions de production (contexte historique, but de l’auteur).
    • Éviter les anachronismes (erreurs de date) et les faux documents.
  • Critique interne :
    • Étudier le contenu du document.
    • Comparer les informations avec d’autres sources.
    • Apprécier la sincérité de l’auteur et la fiabilité des informations.
But de la critique historique : vérifier l’authenticité des documents et la vérité des faits qu’ils rapportent.

4. Interprétation des informations

  • Donner un sens aux faits observés.
  • Expliquer les causes, les conséquences et le contexte des événements.
  • Comparer les points de vue pour mieux comprendre les enjeux.

5. Synthèse historique

  • Classer les informations dans l’ordre chronologique (dates) et logique (enchaînement des faits).
  • Rédiger un récit ou une étude qui présente les faits et leur signification.
  • Cette synthèse devient à son tour une source pour d’autres recherches.

III. Exercices et entraînements typiques

1. Reconnaître les types de sources

Exemples de documents à classer :

  • Récit de griot → source orale.
  • Monnaie antique → source archéologique.
  • Mémoire d’un dirigeant politique → source écrite.
  • Documentaire télévisé → source audiovisuelle.

2. Vrai / Faux sur les sources

  • « Les sources sont des outils indispensables à l’étude de l’histoire. » → Vrai.
  • « Les faits rapportés par les sources écrites sont toujours vrais. » → Faux.
  • « Les sources orales ne sont pas utiles pour étudier l’histoire de l’Europe. » → Faux.
  • « Toutes les sources doivent être soumises à la critique historique. » → Vrai.
À retenir pour le contrôle :
  • L’histoire est une science qui repose sur des sources variées et une démarche rigoureuse.
  • Les quatre grands types de sources : écrites, orales, archéologiques, audiovisuelles/numériques.
  • Les étapes de la démarche de l’historien : thème → collecte → critique → interprétation → synthèse.
