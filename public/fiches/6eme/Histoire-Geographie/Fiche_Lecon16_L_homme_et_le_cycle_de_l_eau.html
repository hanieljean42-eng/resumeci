📚 Histoire-Géographie🏫 6èmeLeçon 16 – L’homme et le cycle de l’eau
Objectifs de la leçon :
  • Connaître les états et les formes de l’eau.
  • Comprendre le cycle de l’eau.
  • Identifier les utilités de l’eau et les problèmes liés à son usage.

I. États et formes de l’eau

1. États de l’eau

  • Solide : glaciers, banquises, icebergs (≈ 2 % des eaux terrestres).
  • Liquide : océans, mers, fleuves, rivières, lacs, nappes souterraines (≈ 98 %).
  • Gazeux : vapeur d’eau dans l’atmosphère (très faible quantité).

2. Types d’eau

  • Eaux continentales :
    • eaux courantes (fleuves, rivières…) ;
    • eaux stagnantes (lacs, marais…) ;
    • eaux d’infiltration (puits, forages).
  • Eaux océaniques ou marines :
    • océans (Atlantique, Pacifique, Indien) ;
    • mers (Méditerranée, Rouge…).

II. Le cycle de l’eau

Le cycle de l’eau est le circuit permanent que suit l’eau entre la Terre et l’atmosphère.

  • l’eau des océans, mers, lacs, sols s’évapore sous l’effet de la chaleur ;
  • la vapeur d’eau monte dans l’atmosphère, se refroidit et se condense en nuages ;
  • les nuages donnent des précipitations (pluie, grêle, neige) ;
  • une partie de l’eau ruisselle en surface, une autre s’infiltre dans le sol ;
  • les eaux rejoignent les cours d’eau, les nappes souterraines, les mers et océans… et le cycle recommence.
Cycle de l’eau : évaporation → condensation → précipitations → ruissellement / infiltration → retour aux océans.

III. Utilités et problèmes liés à l’eau

1. Utilités de l’eau

  • production d’électricité (barrages hydroélectriques) ;
  • irrigation des champs ;
  • pêche ;
  • usage domestique : boisson, cuisine, lessive, toilette ;
  • industrie (fabrication de nombreux produits).

2. Problèmes

  • rareté et cherté de l’eau potable dans certaines régions ;
  • pollution des eaux par les déchets industriels, les produits toxiques (pêche avec produits chimiques…) ;
  • gaspillage de l’eau ;
  • risque de pénurie si rien n’est fait.

3. Actions de préservation

  • utiliser l’eau de façon rationnelle (éviter le gaspillage) ;
  • protéger les cours d’eau de la pollution ;
  • traiter les eaux usées avant rejet ;
  • faciliter l’accès à l’eau potable pour toutes les populations ;
  • sanctionner les pollueurs et sensibiliser les populations.
À retenir : l’eau est une ressource vitale mais menacée ; chacun doit contribuer à la préserver.

IV. Synthèse pour le contrôle

  • L’eau existe à l’état solide, liquide et gazeux.
  • Le cycle de l’eau renouvelle l’eau disponible sur Terre.
  • L’eau est indispensable à la vie, mais son mauvais usage peut entraîner des pénuries et des pollutions.
