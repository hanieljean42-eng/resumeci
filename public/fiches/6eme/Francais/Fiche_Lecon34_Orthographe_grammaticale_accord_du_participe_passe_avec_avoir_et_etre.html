📚 Français🏫 6èmeLeçon 34 – Orthographe grammaticale : accord du participe passé avec avoir et être
Objectifs de la leçon :
  • Rappeler la formation du participe passé.
  • Savoir l’accorder avec l’auxiliaire être.
  • Appliquer la règle d’accord avec l’auxiliaire avoir.

I. Avec l’auxiliaire être

Le participe passé employé avec être s’accorde toujours en genre et en nombre avec le sujet.

Exemples :

  • Il est parti.
  • Ils sont partis.
  • Elle est tombée.
  • Elles sont arrivées.

II. Avec l’auxiliaire avoir

Le participe passé employé avec avoir :

  • ne s’accorde jamais avec le sujet ;
  • peut s’accorder avec le complément d’objet direct (COD) si celui‑ci est placé avant le verbe.

1. COD après le verbe → pas d’accord

Exemple :

  • Les élèves ont lavé les mangues.
    COD les mangues après le verbe → lavé reste invariable.

2. COD avant le verbe → accord

Exemples :

  • Cette leçon, les élèves l’ont bien comprise.
    COD = cette leçon (féminin singulier) → comprise.
  • La chaussure que j’ai ramassée est à toi.
Avec être → accord avec le sujet.
Avec avoir → accord avec le COD placé avant (s’il existe), sinon invariable.
À retenir : pour savoir si le participe passé s’accorde, il faut d’abord chercher s’il y a un COD et voir s’il est avant ou après le verbe.

III. Synthèse pour le contrôle

  • Participe passé + être : accord systématique avec le sujet.
  • Participe passé + avoir : accord uniquement avec le COD placé avant ; pas d’accord sinon.
  • Bien appliquer ces règles est essentiel pour réussir les dictées et rédactions.
