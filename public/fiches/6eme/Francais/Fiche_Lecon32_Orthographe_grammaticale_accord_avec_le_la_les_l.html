📚 Français🏫 6èmeLeçon 32 – Orthographe grammaticale : accord avec le, la, les, l'
Objectifs de la leçon :
  • Identifier le, la, les, l’ comme pronoms COD.
  • Savoir quand on accorde ou non le participe passé avec eux.

I. Le, la, les, l’ pronoms COD

Devant un verbe, le, la, les, l’ peuvent être des pronoms personnels compléments d’objet direct (COD) du verbe.

Exemple : Ces bicyclettes, on les conduit facilement.

II. Cas de non‑accord

Lorsque le verbe est conjugué à un temps simple, il s’accorde avec le sujet et non avec les pronoms :

  • Ces bicyclettes, on les conduit facilement.

Ici, conduit ne s’accorde pas avec les, mais avec le sujet on.

III. Cas d’accord (participe passé avec avoir)

Avec l’auxiliaire avoir, le participe passé :

  • ne s’accorde jamais avec le sujet ;
  • mais il s’accorde avec le COD placé avant le verbe.

Exemple :

  • Cette leçon, les élèves l’ont bien comprise.
    Ici, l’ remplace cette leçon (COD féminin singulier) placé avant → comprise.
Participe passé avec AVOIR :
→ accord avec le COD placé avant (le, la, les, l’…),
→ pas d’accord si le COD est après le verbe.
À retenir : repère d’abord le COD et vois s’il est placé avant ou après le verbe.

IV. Synthèse pour le contrôle

  • Le, la, les, l’ peuvent être des pronoms COD du verbe.
  • Avec un temps simple, le verbe s’accorde avec le sujet (pas avec le pronom COD).
  • Avec un participe passé + avoir, on accorde avec le COD quand il est placé avant (le, la, les, l’).
