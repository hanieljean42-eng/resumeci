📝 FICHE DE RÉSUMÉ

📚 Français🏫 6èmeLeçon 2 – La description d’un objet familier
Objectifs de la leçon :
  • Savoir ce qu’est une description d’objet.
  • Identifier les outils de langue nécessaires pour décrire un objet familier.
  • Organiser un texte descriptif (introduction, développement, conclusion).

I. Définition

Décrire un objet, c’est faire une présentation détaillée de cet objet :

  • sa forme,
  • sa couleur,
  • son aspect,
  • la matière dont il est fait,
  • ses éléments particuliers (dessins, poches, accessoires…).
La description d’un objet familier doit permettre au lecteur de bien l’imaginer.

II. Outils de langue pour décrire un objet

1. Outils grammaticaux

  • Temps verbaux :
    • présent et imparfait de l’indicatif pour décrire (ex. « Le sac est en cuir », « Il avait des poches »).
  • Adjectifs de couleur :
    • ex. « rose », « vert foncé », « bleu clair »…
  • Adjectifs qualificatifs et expansions du GN :
    • adjectifs qualificatifs : « beau sac », « chaise confortable » ;
    • compléments du nom : « sac en cuir », « chaise de plage » ;
    • propositions relatives : « un sac qui attire les regards ».
  • Types et formes de phrases :
    • phrases déclaratives : « Le sac est en cuir. »
    • phrases exclamatives : « Quel beau sac ! »
    • formes affirmative, négative, emphatique pour insister ou nuancer.
  • Mots de liaison :
    • pour ordonner les idées : « d’abord », « ensuite », « enfin », « de plus », « par ailleurs »…

2. Lexique

  • Lexique lié au thème : mots spécifiques à l’objet (sac, fermeture éclair, bretelles, poches, etc.).
  • Vocabulaire évaluatif :
    • Mélioratif (appréciatif) pour une description positive : « joli », « agréable », « confortable », « éclatant »…
    • Dépréciatif (négatif) pour une description critique : « laid », « sale », « usé », « abîmé »…
  • Éventuellement des figures de style (comparaisons, métaphores) pour rendre la description plus vivante.
Astuce : plus le vocabulaire est précis, plus la description est réussie.

III. Structure d’un texte descriptif d’objet

1. Introduction

On présente l’objet de façon générale :

  • nature de l’objet (sac, chaise, montre…),
  • à qui il appartient (au guide, à mon père…),
  • dans quel contexte on l’a vu (excursion, maison, magasin…).

2. Développement

On décrit les caractéristiques de l’objet en suivant un ordre logique, par exemple :

  • De l’extérieur vers l’intérieur ;
  • ou de l’allure générale aux détails.

Exemples d’éléments à décrire :

  • matière : cuir, bois, plastique…
  • couleur(s) : rose, multicolore, etc.
  • éléments visibles : dessins, poches, cordes, ornements…
  • intérieur : nombre de poches, profondeur, capacité de rangement…

3. Conclusion

On exprime son avis ou ses sentiments sur l’objet :

  • « J’aime ce sac car il est très pratique. »
  • « C’est la chaise la plus confortable que je connaisse. »
Plan type :
Introduction → Présentation générale de l’objet
Développement → Description détaillée
Conclusion → Impression personnelle

IV. Synthèse pour le contrôle

  • Décrire un objet, c’est en faire une présentation détaillée (forme, couleur, matière, aspect…).
  • On utilise des temps de description (présent, imparfait), des adjectifs, des expansions du nom et un lexique précis.
  • Le texte descriptif est organisé en introduction, développement (caractéristiques) et conclusion (impression).
À retenir : une bonne description permet au lecteur d’imaginer clairement l’objet comme s’il le voyait.
