📝 FICHE DE RÉSUMÉ

📚 Français🏫 6èmeLeçon 3 – La description d’un lieu non animé
Objectifs de la leçon :
  • Savoir ce qu’est une description de lieu.
  • Identifier les outils de langue spécifiques pour décrire un lieu.
  • Organiser un texte descriptif de lieu (introduction, développement, conclusion).

I. Définition

Décrire un lieu, c’est présenter de façon détaillée un endroit ou un espace :

  • son emplacement (où il se trouve) ;
  • ses composantes (bâtiments, objets, végétation…) ;
  • son aspect général et l’impression qu’il produit.
Une bonne description permet de situer le lieu et de le visualiser mentalement.

II. Outils de langue pour décrire un lieu

1. Outils grammaticaux

  • Temps verbaux : présent et imparfait de l’indicatif.
  • Adjectifs :
    • adjectifs de couleur,
    • adjectifs qualificatifs (grand, petit, animé, calme, propre, sale…).
  • Adjectifs numéraux cardinaux : pour indiquer les quantités (deux salles, trois bâtiments…).
  • Types et formes de phrases : déclaratives, exclamatives ; formes affirmative, négative, emphatique.
  • Adverbes de lieu : ici, là‑bas, derrière, près de, à côté de…
  • Indicateurs spatiaux : à gauche, à droite, plus loin, au centre, à l’entrée…
  • Degrés de comparaison de l’adjectif : plus… que, moins… que, aussi… que.

2. Lexique

  • Lexique lié au thème : vocabulaire des bâtiments, rues, boutiques, éléments de paysage…
  • Lexique des sentiments : pour exprimer admiration, plaisir, rejet…
  • Vocabulaire évaluatif :
    • appréciatif : agréable, magnifique, accueillant, propre…
    • dépréciatif : bruyant, sale, étroit, dangereux…
  • Figures de style pour rendre la description plus vivante.
Astuce : utiliser des repères spatiaux clairs pour que le lecteur puisse « se promener » dans le lieu décrit.

III. Structure d’un texte descriptif de lieu

1. Introduction

On présente le lieu de façon générale :

  • type de lieu : site touristique, école, marché, boulangerie…
  • emplacement général : à l’entrée de la ville, au centre‑ville, dans le quartier, etc.
  • ex. « À l’entrée de la ville de Grand‑Bassam se situe un site touristique : le village artisanal. »

2. Développement

On décrit progressivement :

  • Disposition générale :
    • le lieu s’étend de part et d’autre d’une route, autour d’une place, etc.
  • Éléments visibles :
    • types de bâtiments (maisons en dur, en terre, couvertes de paille…),
    • fonctions (ateliers, boutiques, logements…),
    • objets présents (objets d’art, meubles, instruments de musique…).
  • Ambiance :
    • fleurs, décorations, propreté, bruit, foule, couleurs.
  • Organisation logique :
    • par exemple du portail vers l’intérieur, de la rue principale vers les allées, etc.

3. Conclusion

On donne son opinion sur le lieu :

  • « Ce marché est un lieu très bien entretenu et agréable à visiter. »
  • « C’est la plus belle boulangerie du quartier. »
Plan type :
Introduction → Présentation et localisation du lieu
Développement → Description détaillée (bâtiments, objets, ambiance)
Conclusion → Impression personnelle

IV. Synthèse pour le contrôle

  • Décrire un lieu, c’est présenter ses caractéristiques (emplacement, éléments, ambiance) avec précision.
  • On utilise des adverbes de lieu, des indicateurs spatiaux, des adjectifs et un vocabulaire précis.
  • Le texte descriptif de lieu est structuré en introduction, développement et conclusion.
À retenir : pour aider un lecteur à retrouver un lieu (ex. une boulangerie), la description doit donner des repères clairs et une image fidèle de l’endroit.
