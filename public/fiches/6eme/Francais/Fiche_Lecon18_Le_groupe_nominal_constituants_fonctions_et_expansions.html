📚 Français🏫 6èmeLeçon 18 – Le groupe nominal : constituants, fonctions et expansions
Objectifs de la leçon :
  • Définir le groupe nominal (GN).
  • Identifier ses constituants (déterminant, nom, expansions).
  • Connaître ses fonctions dans la phrase.

I. Définition et constituants du groupe nominal

Le groupe nominal est un ensemble de mots organisé autour d’un nom‑noyau.

Exemple : La légende baoulé.

1. Constituants obligatoires

  • Déterminant (article, adjectif démonstratif ou possessif…) ;
  • Nom noyau.

Exemple : Mon ami → GN = déterminant + nom.

Le GN peut aussi être réduit à :

  • un nom propre : Mariam joue à la balle.
  • un pronom : Elle joue à la balle.

2. Constituants facultatifs : les expansions du nom

Les expansions du nom apportent des précisions sur le nom noyau :

  • Adjectif qualificatif :
    • épithète : Ce tissu déchiré ne peut servir.
    • apposé : Déchiré, ce tissu ne peut servir.
  • Complément du nom (groupe prépositionnel) :
    • La maison de repos, une maison en bois, un jouet pour enfant.
  • Proposition subordonnée relative :
    • Ce tissu qui est déchiré ne peut servir.
    • C’est une grande ville où foisonnent les rythmes musicaux.
GN = Déterminant + Nom (+ éventuelles expansions : adjectif, complément du nom, relative).

II. Fonctions du groupe nominal dans la phrase

Le GN peut avoir plusieurs fonctions :

  • Sujet du verbe :
    • Les élèves de 6ᵉ ont effectué une sortie d’étude.
  • Complément d’objet du verbe :
    • COD : Les habitants ont levé une cotisation.
    • COI : Narcisse a donné un morceau de pain à son ami.
  • Complément circonstanciel (lieu, temps, manière, but, cause, conséquence…) :
    • Narcisse a donné un morceau de son pain à son ami pendant la récréation.
  • Complément du nom :
    • Les habitants de la cour sont solidaires.
  • Apposition :
    • Sa Sainteté, le Pape François, était en visite.
À retenir : repérer les GN dans une phrase permet de comprendre qui fait l’action, sur quoi porte l’action et les précisions données sur les noms.

III. Synthèse pour le contrôle

  • Le GN est centré sur un nom noyau et comporte un déterminant, parfois des expansions.
  • Les expansions du nom peuvent être : adjectif, complément du nom, proposition relative.
  • Le GN peut être sujet, COD, COI, complément du nom, complément circonstanciel ou apposition.
