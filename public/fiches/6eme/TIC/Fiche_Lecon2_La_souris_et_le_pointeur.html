📚 TIC🏫 6èmeLeçon 2 – La souris et le pointeur
Objectifs de la leçon :
  • Définir la souris comme périphérique d’entrée.
  • Identifier les principales formes du pointeur.
  • Connaître les différents types de clics.

I. La souris

  • La souris est un périphérique de pointage (périphérique d’entrée).
  • Elle permet de :
    • déplacer un pointeur sur l’écran ;
    • sélectionner, déplacer, manipuler des objets (icônes, textes…) ;
    • lancer des commandes (ouvrir un fichier, un menu…).

II. Le pointeur

Le pointeur est la représentation visuelle de la souris à l’écran (le plus souvent, une flèche blanche).

Différentes formes du pointeur informent sur ce qui se passe :

  • flèche classique : état normal ;
  • sablier / cercle : système en cours de chargement ;
  • barre verticale (curseur texte) : zone où l’on peut saisir ou modifier du texte ;
  • main : lien cliquable (surtout sur Internet) ;
  • double flèche (verticale / horizontale / diagonale) : redimensionnement d’une fenêtre ou d’un objet ;
  • flèches croisées : déplacement d’un objet.
Observer la forme du pointeur aide à comprendre quelle action est possible (saisir, cliquer, redimensionner…).

III. Les types de clics

  • Clic gauche :
    • appuyer une fois sur le bouton gauche ;
    • sert à sélectionner, activer un lien, placer le curseur texte…
  • Double‑clic gauche :
    • deux clics rapides sur le bouton gauche ;
    • sert à ouvrir un fichier, un dossier ou un programme.
  • Clic droit :
    • appuyer une fois sur le bouton droit ;
    • affiche un menu contextuel (options supplémentaires).
  • Clic central / molette (si présente) :
    • fait défiler le contenu d’une page (rouler la molette) ;
    • peut activer des fonctions spéciales selon les logiciels.
À retenir : savoir utiliser correctement la souris (clic gauche, clic droit, double‑clic, molette) est indispensable pour manipuler un ordinateur.

IV. Synthèse pour le contrôle

  • La souris est un périphérique d’entrée utilisé pour pointer et cliquer.
  • Le pointeur change de forme pour indiquer l’action possible.
  • Les principaux clics sont : clic gauche, double‑clic, clic droit et molette de défilement.
