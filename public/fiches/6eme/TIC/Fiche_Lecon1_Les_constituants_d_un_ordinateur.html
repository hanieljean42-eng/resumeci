📝 FICHE DE RÉSUMÉ

📚 TIC🏫 6èmeLeçon 1 – Les constituants d’un ordinateur
Objectifs de la leçon :
  • Définir information, ordinateur et informatique.
  • Distinguer matériel (hardware) et logiciel (software).
  • Identifier les principaux éléments matériels de l’ordinateur.

I. Définitions et généralités

  • Information / donnée : ensemble de renseignements qui ont un sens pour l’esprit humain.
  • Ordinateur : système informatique qui traite automatiquement de grandes quantités d’informations.
  • Informatique : science du traitement automatique de l’information.

Exemples d’ordinateurs : ordinateur de bureau (desktop), ordinateur portable (laptop).

II. Parties matérielle et logicielle

  • Partie matérielle (hardware) : tous les éléments physiques de l’ordinateur (boîtier, écran, clavier, souris…).
  • Partie logicielle (software) : programmes permettant de traiter l’information (système d’exploitation, logiciels…).
Un ordinateur = matériel + logiciels.

III. Principaux constituants matériels

1. Unité centrale

  • boîtier qui contient les composants électroniques principaux (processeur, mémoire, disque dur…) ;
  • assure le traitement des données ;
  • les périphériques (écran, clavier, souris…) y sont connectés.

2. Périphériques d’entrée

  • Clavier : saisie de textes, chiffres, commandes.
  • Souris : déplacement d’un pointeur, sélection, clic, glisser‑déposer.
  • Scanner, microphone, webcam…

3. Périphériques de sortie

  • Écran : affichage des informations.
  • Imprimante : impression sur papier.
  • Haut‑parleurs, casque, vidéoprojecteur…

4. Périphériques de stockage

  • Disque dur interne ;
  • clé USB ;
  • CD/DVD…

IV. Quelques ports de connexion (rappel)

  • Ports USB : branchement universel (souris, clavier, clé USB, imprimante…).
  • Ports audio : microphone, écouteurs / haut‑parleurs.
  • Ports vidéo : VGA (bleu), DVI (blanc) pour relier l’écran.
  • Port réseau (LAN) : connexion à un réseau local ou à Internet.
À retenir : l’unité centrale est le « cœur » de l’ordinateur ; tous les périphériques servent à entrer, sortir ou stocker des informations.

V. Synthèse pour le contrôle

  • Un ordinateur est un système qui traite automatiquement l’information.
  • Il comprend une partie matérielle (hardware) et une partie logicielle (software).
  • Les périphériques se classent en entrée, sortie et stockage.
