🌱 SVT🏫 6èmeLeçon 3 : La reproduction chez les mammifères

I. Caractères sexuels externes

Caractères sexuels externes : Organes visibles permettant de distinguer le mâle de la femelle.
MâleFemelle
Organes externesPénis, boursesVulve, mamelles

II. Caractères sexuels internes

Caractères sexuels internes : Organes situés à l'intérieur du corps, visibles après dissection.
MâleFemelle
Gonades (glandes sexuelles)2 testicules2 ovaires
Conduits génitaux2 spermiductes2 oviductes
Autres organesProstate, 2 vésicules séminalesUtérus, vagin
Cellules reproductrices :
  • Spermatozoïdes : produits par les testicules (cellule mâle, avec flagelle)
  • Ovules : produits par les ovaires (cellule femelle, plus grosse)

III. La fécondation

Fécondation : Fusion du noyau du spermatozoïde avec le noyau de l'ovule, donnant une cellule-œuf.
Étapes de la fécondation :
  1. Accouplement : le mâle dépose les spermatozoïdes dans le vagin
  2. Émission des spermatozoïdes qui se déplacent grâce à leur flagelle
  3. Rapprochement : les spermatozoïdes entourent l'ovule dans l'oviducte
  4. Pénétration d'un seul spermatozoïde dans l'ovule
  5. Fusion des noyaux → cellule-œuf
La fécondation a lieu dans l'appareil reproducteur femelle → fécondation INTERNE.

IV. Développement de l'œuf

Étapes du développement :
  1. Cellule-œuf : résultat de la fécondation
  2. Divisions successives : 2 cellules → 4 cellules → …
  3. Embryon : se fixe dans la paroi de l'utérus
  4. Fœtus : l'embryon se transforme, les organes se forment
  5. Mise bas : naissance d'un individu semblable aux parents
Le développement se fait entièrement dans l'utérus → développement INTERNE.
Les mammifères sont des VIVIPARES.

V. Résumé chronologique

Ordre complet :
Accouplement → Fécondation → Cellule-œuf → Divisions → Embryon → Fœtus → Mise bas → Nouveau-né
