I. Discours Rapporté

Discours rapporté : Manières de rapporter les paroles de quelqu'un dans un texte. Les trois formes sont le discours direct (citation), le discours indirect (subordonnées) et le discours indirect libre (mélange).
Discours direct :
  • Citation : Citation exacte des paroles
  • Guillemets : Utilisation de guillemets
  • Deux-points : Deux-points avant la citation
  • Verbe : Verbe introducteur (dire, déclarer...)
  • Authenticité : Conserve l'authenticité des paroles
Discours indirect :
  • Subordonnées : Utilisation de subordonnées
  • Que : Utilisation de "que"
  • Changements : Changements de temps et de pronoms
  • Intégration : Intégration dans le récit
  • Distanciation : Distanciation par rapport aux paroles
Discours indirect libre :
  • Mélange : Mélange de discours direct et indirect
  • Guillemets : Absence de guillemets
  • Verbe : Absence de verbe introducteur
  • Imbrication : Imbrication dans le récit
  • Expressivité : Forte expressivité

II. Changements de Temps

Changements de temps : Modifications des temps verbaux lors du passage du discours direct au discours indirect. Les changements principaux sont : passé simple → imparfait, présent → imparfait, futur → conditionnel.
Passé simple → imparfait :
  • Changement : Le passé simple devient imparfait
  • Exemple : "Il dit : 'Il alla'" → "Il dit qu'il allait"
  • Concordance : Respect de la concordance des temps
  • Passé : Action située dans le passé
  • Simultanéité : Simultanéité avec le verbe principal
Présent → imparfait :
  • Changement : Le présent devient imparfait
  • Exemple : "Il dit : 'Je vais'" → "Il dit qu'il allait"
  • Simultanéité : Simultanéité avec le verbe principal
  • Passé : Action située dans le passé
  • Concordance : Respect de la concordance des temps
Futur → conditionnel :
  • Changement : Le futur devient conditionnel
  • Exemple : "Il dit : 'J'irai'" → "Il dit qu'il irait"
  • Futur dans le passé : Futur vu du passé
  • Hypothèse : Valeur d'hypothèse
  • Concordance : Respect de la concordance des temps

III. Valeurs Expressives

Valeurs expressives des temps : Utilisation des temps verbaux pour créer des effets particuliers : suspense, urgence, émotion, distance.
Suspense :
  • Futur : Utilisation du futur pour créer le suspense
  • Conditionnel : Utilisation du conditionnel
  • Anticipation : Anticipation de l'action
  • Attente : Crée l'attente
  • Tension : Crée la tension
Urgence :
  • Présent : Utilisation du présent de narration
  • Passé simple : Actions rapides
  • Rythme : Rythme rapide
  • Immédiateté : Effet d'immédiateté
  • Énergie : Crée de l'énergie
Émotion :
  • Présent : Actualisation de l'émotion
  • Imparfait : Description émotionnelle
  • Subjonctif : Expression du sentiment
  • Intensité : Intensité émotionnelle
  • Empathie : Crée l'empathie
Distance :
  • Passé simple : Distance narrative
  • Imparfait : Distance descriptive
  • Passé composé : Distance plus proche
  • Objectivité : Crée l'objectivité
  • Neutralité : Crée la neutralité

IV. Analyse

Analyse des temps : Méthode pour analyser les temps verbaux dans un texte. Il faut repérer les temps, comprendre leurs valeurs et interpréter les choix de l'auteur.
Repérer les temps :
  • Identification : Identifier les temps utilisés
  • Fréquence : Noter la fréquence des temps
  • Alternance : Repérer l'alternance des temps
  • Progression : Observer la progression
  • Regroupement : Regrouper par catégories
Comprendre leurs valeurs :
  • Valeur : Déterminer la valeur de chaque temps
  • Contexte : Analyser le contexte
  • Fonction : Déterminer la fonction
  • Effet : Analyser l'effet produit
  • Justification : Justifier l'interprétation
Interpréter les choix de l'auteur :
  • Intention : Comprendre l'intention de l'auteur
  • Stratégie : Analyser la stratégie narrative
  • Style : Analyser le style
  • Expressivité : Analyser l'expressivité
  • Cohérence : Vérifier la cohérence

V. Conclusion

Les valeurs des temps verbaux et le discours rapporté sont essentiels pour comprendre un texte. Le discours rapporté comprend le discours direct (citation), le discours indirect (subordonnées) et le discours indirect libre (mélange). Les changements de temps lors du passage du discours direct au discours indirect sont : passé simple → imparfait, présent → imparfait, futur → conditionnel. Les valeurs expressives des temps permettent de créer des effets : suspense, urgence, émotion, distance. L'analyse des temps consiste à repérer les temps, comprendre leurs valeurs et interpréter les choix de l'auteur. La maîtrise des temps verbaux et du discours rapporté est essentielle pour analyser et écrire des textes.
