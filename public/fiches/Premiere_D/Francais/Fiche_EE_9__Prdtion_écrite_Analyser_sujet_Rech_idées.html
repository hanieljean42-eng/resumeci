I. Analyse du Sujet

Analyse du sujet : Première étape de la production écrite qui consiste à comprendre la consigne, repérer les mots-clés et identifier le type de production attendue.
Compréhension de la consigne :
  • Lecture attentive : Lire plusieurs fois la consigne
  • Type de production : Identifier le type (article, lettre, discours...)
  • Destinataire : Identifier à qui s'adresse la production
  • Objectif : Comprendre l'objectif de la production
  • Contraintes : Repérer les contraintes (longueur, format...)
Repérage des mots-clés :
  • Identification : Repérer les termes essentiels
  • Soulignement : Souligner les mots importants
  • Compréhension : Comprendre le sens de chaque terme
  • Relations : Identifier les relations entre les termes
  • Polysémie : Repérer les sens multiples
Identification du type de production :
  • Article de presse : Informatif, argumentatif
  • Lettre : Formelle ou informelle
  • Discours : Persuasif, délibératif
  • Essai : Réflexif, argumentatif
  • Récit : Narratif, descriptif

II. Recherche d'Idées

Recherche d'idées : Deuxième étape de la production écrite qui consiste à mobiliser ses connaissances, faire des associations et chercher des exemples pertinents.
Mobilisation des connaissances :
  • Œuvres étudiées : Mobiliser les œuvres du programme
  • Connaissances culturelles : Utiliser sa culture générale
  • Documents étudiés : Se souvenir des documents travaillés
  • Thèmes abordés : Se rappeler des thèmes vus en classe
  • Arguments : Mobiliser des arguments connus
Associations d'idées :
  • Brainstorming : Noter toutes les idées sans filtrer
  • Carte mentale : Organiser les idées visuellement
  • Associations libres : Laisser les idées s'associer
  • Analogies : Chercher des analogies
  • Questions : Se poser des questions sur le sujet
Recherche d'exemples pertinents :
  • Exemples littéraires : Œuvres, auteurs, personnages
  • Exemples personnels : Expériences personnelles (si pertinent)
  • Exemples historiques : Faits historiques
  • Exemples d'actualité : Faits d'actualité
  • Citations : Citations pertinentes

III. Sélection

Sélection des idées : Troisième étape de la production écrite qui consiste à choisir les idées les plus adaptées au sujet, éliminer les hors-sujet et organiser logiquement.
Choix des idées les plus adaptées :
  • Pertinence : Choisir les idées en lien avec le sujet
  • Originalité : Privilégier les idées originales
  • Force : Sélectionner les arguments les plus solides
  • Clarté : Choisir les idées claires
  • Variété : Assurer la variété des arguments
Élimination des hors-sujet :
  • Vérification : Vérifier que chaque idée est pertinente
  • Fidélité : Rester fidèle à la consigne
  • Limite : Respecter les limites du sujet
  • Épuration : Éliminer les idées inutiles
  • Centrage : Centrer sur l'essentiel
Organisation logique :
  • Ordre : Choisir un ordre logique (du plus simple au plus complexe)
  • Progression : Assurer une progression des idées
  • Transitions : Prévoir les transitions entre les idées
  • Hiérarchie : Établir une hiérarchie entre les idées
  • Cohérence : Assurer la cohérence de l'ensemble

IV. Préparation

Préparation : Quatrième étape de la production écrite qui consiste à élaborer un plan rapide, noter les exemples clés et préparer le vocabulaire essentiel.
Élaboration d'un plan rapide :
  • Introduction : Accroche, présentation, problématique
  • Développement : 2 ou 3 parties avec arguments
  • Conclusion : Synthèse, réponse, ouverture
  • Équilibre : Équilibrer les parties
  • Progression : Assurer la progression
Notation des exemples clés :
  • Exemples littéraires : Noter les œuvres et auteurs
  • Citations : Noter les citations exactes
  • Références : Noter les références précises
  • Contexte : Noter le contexte des exemples
  • Lien : Noter le lien avec l'argument
Préparation du vocabulaire essentiel :
  • Vocabulaire littéraire : Préparer les termes littéraires
  • Vocabulaire thématique : Préparer les termes du thème
  • Connecteurs : Préparer les connecteurs logiques
  • Expressions : Préparer des expressions variées
  • Formulations : Préparer des formulations précises

V. Conclusion

L'analyse du sujet et la recherche d'idées sont des étapes essentielles de la production écrite. L'analyse du sujet consiste à comprendre la consigne, repérer les mots-clés et identifier le type de production attendue. La recherche d'idées mobilise les connaissances, fait des associations et cherche des exemples pertinents. La sélection choisit les idées les plus adaptées au sujet, élimine les hors-sujet et organise logiquement. La préparation élabore un plan rapide, note les exemples clés et prépare le vocabulaire essentiel. La maîtrise de cette méthode est indispensable pour réussir la production écrite.
