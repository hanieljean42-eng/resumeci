I. Connecteurs Logiques

Connecteurs logiques : Mots ou expressions qui relient les propositions entre elles et indiquent le type de relation logique. Les principaux connecteurs sont : addition (et, de plus), opposition (mais, cependant), cause (car, parce que), conséquence (donc, par conséquent).
Addition :
  • Et : Connecteur d'addition simple
  • De plus : Ajoute une information
  • En outre : Ajoute un argument
  • Aussi : Ajoute également
  • Par ailleurs : Ajoute un autre point
Opposition :
  • Mais : Connecteur d'opposition simple
  • Cependant : Marque l'opposition
  • Pourtant : Marque le contraste
  • Néanmoins : Marque l'opposition atténuée
  • Toutefois : Marque l'opposition
Cause :
  • Car : Introduit la cause
  • Parce que : Explique la raison
  • Puisque : Donne la cause
  • Étant donné que : Explique la cause
  • En effet : Justifie l'affirmation
Conséquence :
  • Donc : Introduit la conséquence
  • Par conséquent : Marque la conséquence
  • Ainsi : En déduit la conséquence
  • Alors : Marque le résultat
  • C'est pourquoi : Explique la conséquence

II. Types d'Arguments

Types d'arguments : Différentes formes d'arguments utilisés pour convaincre : d'autorité, d'exemple, par analogie, ad hominem, de fait, de valeur.
Argument d'autorité :
  • Définition : S'appuie sur une autorité reconnue
  • Expert : Citation d'un expert
  • Célèbre : Citation d'une personne célèbre
  • Texte : Référence à un texte sacré
  • Force : Force de l'autorité citée
Argument d'exemple :
  • Définition : Utilise un exemple concret
  • Cas : Prend un cas particulier
  • Illustration : Illustre l'affirmation
  • Preuve : Sert de preuve
  • Concret : Rend l'argument concret
Argument par analogie :
  • Définition : Compare deux situations similaires
  • Comparaison : Établit une comparaison
  • Transfert : Transfère une propriété
  • Probable : Conclusion probable
  • Persuasif : Argument persuasif
Argument ad hominem :
  • Définition : Attaque la personne plutôt que l'argument
  • Critique : Critique l'adversaire
  • Personnalité : Attaque la personnalité
  • Faible : Argument considéré comme faible
  • Déloyal : Peut être considéré comme déloyal
Argument de fait et de valeur :
  • De fait : Se fonde sur des faits réels
  • Preuve : Utilise des preuves factuelles
  • De valeur : Se fonde sur des valeurs morales
  • Principe : S'appuie sur des principes
  • Éthique : Fait appel à l'éthique

III. Figures de Style Argumentatives

Figures de style argumentatives : Figures de rhétorique utilisées pour renforcer l'argumentation : ironie, hyperbole, antithèse, question rhétorique, accumulation.
Ironie :
  • Définition : Dire le contraire de ce que l'on pense
  • Critique : Critique indirecte
  • Moquerie : Moquerie des défauts
  • Humour : Utilisation de l'humour
  • Effet : Effet de dérision
Hyperbole :
  • Définition : Exagération délibérée
  • Amplification : Amplifie le propos
  • Impact : Augmente l'impact
  • Expressivité : Renforce l'expressivité
  • Effet : Effet de frappe
Antithèse :
  • Définition : Opposition de deux idées contraires
  • Contraste : Crée un contraste
  • Équilibre : Crée un équilibre
  • Clarté : Clarifie le propos
  • Force : Renforce l'argument
Question rhétorique :
  • Définition : Question qui n'attend pas de réponse
  • Effet : Fait réfléchir le lecteur
  • Insistance : Insiste sur un point
  • Engagement : Engage le lecteur
  • Persuasion : Outil de persuasion
Accumulation :
  • Définition : Énumération d'éléments
  • Abondance : Montre l'abondance
  • Intensité : Augmente l'intensité
  • Preuve : Apporte de nombreuses preuves
  • Effet : Effet de profusion

IV. Organisation

Organisation de l'argumentation : Structures d'organisation des arguments dans un texte : thèse-antithèse-synthèse, problème-solution, cause-conséquence.
Thèse-antithèse-synthèse :
  • Thèse : Présentation de la thèse
  • Antithèse : Présentation de l'opposition
  • Synthèse : Résolution du conflit
  • Dialectique : Structure dialectique
  • Équilibre : Recherche d'équilibre
Problème-solution :
  • Problème : Présentation du problème
  • Analyse : Analyse du problème
  • Solution : Proposition de solution
  • Argumentation : Argumentation de la solution
  • Efficacité : Structure efficace
Cause-conséquence :
  • Cause : Présentation de la cause
  • Explication : Explication du phénomène
  • Conséquence : Présentation des conséquences
  • Chaîne : Chaîne de causalité
  • Logique : Structure logique

V. Conclusion

Les outils de l'argumentation sont essentiels pour convaincre et persuader. Les connecteurs logiques relient les propositions et indiquent les relations : addition, opposition, cause, conséquence. Les types d'arguments sont d'autorité, d'exemple, par analogie, ad hominem, de fait, de valeur. Les figures de style argumentatives renforcent l'argumentation : ironie, hyperbole, antithèse, question rhétorique, accumulation. L'organisation de l'argumentation suit des structures comme thèse-antithèse-synthèse, problème-solution, cause-conséquence. La maîtrise des outils de l'argumentation est essentielle pour analyser et écrire des textes argumentatifs.
