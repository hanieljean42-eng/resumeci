Première D Français Valeurs temps 1

I. Temps du Passé

Temps du passé : Temps verbaux qui situent l'action dans le passé. Les principaux temps du passé sont le passé simple (action achevée), l'imparfait (description, habitude) et le plus-que-parfait (antériorité).
Passé simple :
  • Action achevée : Action achevée dans le passé
  • Succèsif : Actions successives
  • Brutal : Action soudaine
  • Premier plan : Action au premier plan
  • Littéraire : Utilisé à l'écrit
Imparfait :
  • Description : Description d'un cadre
  • Habitude : Habitude dans le passé
  • Durée : Action en cours de déroulement
  • Second plan : Action au second plan
  • Simultanéité : Simultanéité avec une autre action
Plus-que-parfait :
  • Antériorité : Action antérieure à une autre action passée
  • Accompli : Action accomplie
  • Arrière-plan : Action à l'arrière-plan
  • Cause : Peut exprimer la cause
  • Explication : Peut expliquer une situation

II. Temps du Présent

Temps du présent : Temps verbal qui situe l'action dans le présent. Les principales valeurs du présent sont le présent de narration (actualisation), le présent de vérité générale et le présent d'habitude.
Présent de narration :
  • Actualisation : Actualise le passé
  • Vivacité : Donne de la vivacité au récit
  • Immédiateté : Crée un effet d'immédiateté
  • Récit : Utilisé dans le récit
  • Remplacement : Remplace le passé simple
Présent de vérité générale :
  • Vérité : Exprime une vérité générale
  • Intemporel : Valable pour tous les temps
  • Scientifique : Utilisé dans les textes scientifiques
  • Maxime : Utilisé dans les maximes
  • Définition : Utilisé dans les définitions
Présent d'habitude :
  • Habitude : Exprime une habitude
  • Répétition : Action répétée
  • Régularité : Action régulière
  • Valeur : Valeur de présent itératif
  • Description : Description d'un mode de vie

III. Temps du Futur

Temps du futur : Temps verbaux qui situent l'action dans le futur. Les principaux temps du futur sont le futur simple (action à venir) et le futur antérieur (antériorité future).
Futur simple :
  • Action à venir : Action qui se produira
  • Prédiction : Prédiction d'un événement
  • Projection : Projection dans l'avenir
  • Promesse : Peut exprimer une promesse
  • Menace : Peut exprimer une menace
Futur antérieur :
  • Antériorité future : Action antérieure à une action future
  • Accompli : Action accomplie dans le futur
  • Condition : Souvent utilisé dans une condition
  • Certitude : Exprime la certitude
  • Conclusion : Peut conclure un raisonnement
Valeurs particulières :
  • Futur proche : Exprime un futur proche
  • Futur historique : Futur dans un récit au passé
  • Probabilité : Exprime la probabilité
  • Conseil : Peut donner un conseil
  • Ordre : Peut donner un ordre

IV. Valeurs Modales

Valeurs modales : Modes verbaux qui expriment l'attitude du locuteur. Les principaux modes modaux sont le conditionnel (hypothèse), le subjonctif (doute, volonté) et l'impératif (ordre).
Conditionnel :
  • Hypothèse : Exprime une hypothèse
  • Condition : Exprime une condition
  • Futur dans le passé : Futur vu du passé
  • Politesse : Peut exprimer la politesse
  • Incertain : Exprime l'incertitude
Subjonctif :
  • Doute : Exprime le doute
  • Volonté : Exprime la volonté
  • Sentiment : Exprime le sentiment
  • Nécessité : Exprime la nécessité
  • Ordre : Peut exprimer un ordre
Impératif :
  • Ordre : Exprime un ordre
  • Conseil : Exprime un conseil
  • Commande : Exprime une commande
  • Invitation : Peut inviter
  • Interdiction : Peut exprimer une interdiction

V. Conclusion

Les valeurs des temps verbaux sont essentielles pour comprendre le sens d'un texte. Les temps du passé situent l'action dans le passé : le passé simple pour une action achevée, l'imparfait pour la description ou l'habitude, le plus-que-parfait pour l'antériorité. Les temps du présent situent l'action dans le présent : le présent de narration actualise le passé, le présent de vérité générale exprime une vérité intemporelle, le présent d'habitude exprime une habitude. Les temps du futur situent l'action dans l'avenir : le futur simple pour une action à venir, le futur antérieur pour l'antériorité future. Les valeurs modales expriment l'attitude du locuteur : le conditionnel pour l'hypothèse, le subjonctif pour le doute ou la volonté, l'impératif pour l'ordre. La maîtrise des valeurs des temps est essentielle pour analyser et écrire des textes.
