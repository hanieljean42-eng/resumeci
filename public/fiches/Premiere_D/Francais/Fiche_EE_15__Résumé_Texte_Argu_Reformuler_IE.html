I. Identification des Idées Essentielles

Identification des idées essentielles : Première étape de la reformulation qui consiste à repérer la thèse principale, les arguments clés et les exemples significatifs du texte argumentatif.
Repérage de la thèse principale :
  • Définition : Position défendue par l'auteur
  • Localisation : Généralement dans l'introduction ou la conclusion
  • Formulation : Formuler clairement la thèse
  • Nuance : Repérer les nuances de la thèse
  • Centralité : La thèse est centrale dans le texte
Repérage des arguments clés :
  • Identification : Repérer les arguments principaux
  • Hiérarchie : Distinguer arguments principaux et secondaires
  • Liens : Repérer les liens entre les arguments
  • Force : Évaluer la force des arguments
  • Originalité : Repérer les arguments originaux
Repérage des exemples significatifs :
  • Pertinence : Choisir les exemples les plus pertinents
  • Force : Choisir les exemples les plus forts
  • Variété : Varier les types d'exemples
  • Représentativité : Choisir des exemples représentatifs
  • Nombre : Limiter le nombre d'exemples

II. Reformulation

Reformulation : Expression des idées essentielles dans ses propres mots. Il faut éviter les citations littérales, conserver le sens et montrer la compréhension.
Expression dans ses propres mots :
  • Reformulation : Reformuler avec ses propres mots
  • Compréhension : Montrer la compréhension du texte
  • Originalité : Être original dans la formulation
  • Clarté : Rendre les idées claires
  • Simplicité : Simplifier les formulations complexes
Évitement des citations littérales :
  • Paraphrase : Paraphraser plutôt que citer
  • Synthèse : Synthétiser les idées
  • Reformulation : Reformuler les citations
  • Exception : Citer uniquement si nécessaire
  • Guillemets : Utiliser les guillemets si citation
Conservation du sens :
  • Fidélité : Rester fidèle au sens du texte
  • Précision : Être précis dans la reformulation
  • Nuance : Conserver les nuances
  • Contre-sens : Éviter le contre-sens
  • Vérification : Vérifier la fidélité au sens

III. Synthèse

Synthèse : Condensation de l'information. Il faut condenser l'information, éliminer les répétitions et regrouper les idées similaires.
Condensation de l'information :
  • Concision : Condenser l'information
  • Essentiel : Garder l'essentiel
  • Élimination : Éliminer les détails inutiles
  • Synthèse : Synthétiser les idées
  • Densité : Augmenter la densité d'information
Élimination des répétitions :
  • Repérage : Repérer les répétitions
  • Fusion : Fusionner les idées répétées
  • Simplification : Simplifier les formulations
  • Épuration : Épurer le texte
  • Varier : Varier le vocabulaire
Regroupement des idées similaires :
  • Classification : Classer les idées par thème
  • Regroupement : Regrouper les idées similaires
  • Synthèse : Synthétiser les idées regroupées
  • Hiérarchie : Établir une hiérarchie
  • Organisation : Organiser logiquement

IV. Vérification

Vérification : Dernière étape qui consiste à s'assurer que le résumé est fidèle au texte, qu'il est complet et qu'il respecte la consigne de longueur.
Fidélité au texte :
  • Sens : Vérifier que le sens est fidèle
  • Thèse : Vérifier que la thèse est fidèle
  • Arguments : Vérifier que les arguments sont fidèles
  • Nuance : Vérifier que les nuances sont respectées
  • Contre-sens : Vérifier l'absence de contre-sens
Complétude :
  • Thèse : Vérifier que la thèse est présente
  • Arguments : Vérifier que les arguments principaux sont présents
  • Exemples : Vérifier que les exemples significatifs sont présents
  • Progression : Vérifier que la progression est respectée
  • Cohérence : Vérifier la cohérence globale
Respect de la consigne de longueur :
  • Consigne : Respecter la consigne de longueur
  • Équilibre : Équilibrer les parties
  • Concision : Être concis
  • Synthèse : Synthétiser si nécessaire
  • Adaptation : Adapter au nombre de mots imposé

V. Conclusion

La reformulation des idées essentielles est une étape clé du résumé de texte argumentatif. L'identification des idées essentielles consiste à repérer la thèse principale, les arguments clés et les exemples significatifs. La reformulation exprime les idées dans ses propres mots, évite les citations littérales et conserve le sens. La synthèse condense l'information, élimine les répétitions et regroupe les idées similaires. La vérification s'assure que le résumé est fidèle au texte, complet et respecte la consigne de longueur. La maîtrise de ces éléments est essentielle pour réussir le résumé de texte argumentatif.
