I. Analyse du Composé d'Information

Composé d'information (CI) : Document qui combine plusieurs types de supports (texte, image, graphique, tableau, schéma) pour transmettre une information sur un même thème. L'analyse du CI consiste à identifier chaque composant et à comprendre leurs relations.
Identification des composants :
  • Texte : Article, extrait littéraire, document explicatif
  • Image : Photographie, illustration, affiche, publicité
  • Graphique : Courbe, histogramme, diagramme circulaire
  • Tableau : Données chiffrées, comparaison, statistiques
  • Schéma : Schéma explicatif, organigramme, carte
Compréhension des relations :
  • Complémentarité : Chaque composant apporte une information différente
  • Redondance : Certains éléments répètent l'information
  • Hiérarchie : Certains composants sont plus importants que d'autres
  • Progression : L'information se construit progressivement
  • Thématique : Tous les composants traitent du même thème
Méthode d'analyse :
  • 1. Identifier la nature de chaque composant
  • 2. Extraire l'information principale de chaque support
  • 3. Repérer les liens entre les composants
  • 4. Identifier le thème commun
  • 5. Dégager l'intention du document

II. Construction de l'Information

Construction de l'information : Processus d'extraction et de sélection des informations pertinentes dans chaque composant du CI pour construire une compréhension globale du document.
Extraction des informations :
  • Texte : Repérer les idées principales, les arguments, les exemples
  • Image : Décrire ce qui est représenté, analyser la composition
  • Graphique : Lire les données, identifier les tendances
  • Tableau : Comparer les données, repérer les écarts
  • Schéma : Comprendre le fonctionnement, les étapes
Établissement des liens logiques :
  • Comparaison : Mettre en relation des informations similaires
  • Opposition : Repérer les contradictions ou différences
  • Causalité : Identifier les causes et les conséquences
  • Illustration : Un composant illustre un autre
  • Approfondissement : Un composant complète l'autre
Conseils pour la construction :
  • Ne pas se perdre dans les détails
  • Sélectionner les informations essentielles
  • Reformuler les informations avec ses propres mots
  • Veiller à la cohérence entre les informations
  • Conserver l'ordre logique du document

III. Organisation du CI

Organisation du CI : Structuration de l'information extraite du composé d'information de manière cohérente et hiérarchisée pour faciliter la compréhension et la rédaction.
Structuration de l'information :
  • Introduction : Présentation du thème et des composants
  • Développement : Organisation thématique ou progressive
  • Conclusion : Synthèse de l'information globale
  • Transitions : Liens entre les différentes parties
  • Hiérarchisation : Distinction entre idées principales et secondaires
Types d'organisation :
  • Organisation thématique : Regroupement par thèmes
  • Organisation progressive : Du général au particulier
  • Organisation comparative : Comparaison des composants
  • Organisation chronologique : Suivre l'ordre du document
  • Organisation problématique : Autour d'une question centrale
Hiérarchisation des idées :
  • Identifier l'idée principale de chaque composant
  • Distinguer les informations essentielles des détails
  • Classer les idées par ordre d'importance
  • Regrouper les idées similaires
  • Éliminer les redondances inutiles

IV. Synthèse

Synthèse : Intégration de toutes les informations extraites du CI dans un texte cohérent, fluide et clair qui rend compte de l'ensemble du document.
Intégration des informations :
  • Unité : Le texte doit former un tout cohérent
  • Fluidité : Utiliser des connecteurs logiques
  • Clarté : Formulations simples et précises
  • Complétude : Ne rien oublier d'essentiel
  • Neutralité : Restituer fidèlement l'information
Rédaction de la synthèse :
  • Commencer par une présentation du document
  • Intégrer progressivement les informations de chaque composant
  • Utiliser des connecteurs (d'abord, ensuite, en outre, enfin)
  • Citer les composants si nécessaire (selon le texte, comme le montre le graphique)
  • Conclure par une synthèse globale
Exemples de connecteurs :
  • Addition : et, de plus, également, par ailleurs
  • Comparaison : comme, de même que, similairement
  • Opposition : mais, cependant, en revanche, alors que
  • Causalité : car, parce que, donc, par conséquent
  • Illustration : ainsi, par exemple, comme le montre

V. Conclusion

L'analyse et l'organisation d'un composé d'information (CI) nécessitent une méthode rigoureuse. L'analyse consiste à identifier les différents composants (texte, image, graphique, tableau, schéma) et à comprendre leurs relations. La construction de l'information consiste à extraire les informations essentielles de chaque composant et à établir des liens logiques entre elles. L'organisation du CI demande de structurer l'information de manière cohérente et hiérarchisée. La synthèse intègre toutes les informations dans un texte fluide et clair. La maîtrise de cette méthode est essentielle pour réussir l'épreuve de synthèse de documents.
