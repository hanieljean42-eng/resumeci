Première D Mathématiques La Trigonométrie

I. Fonctions Trigonométriques

  • sin : R → [-1;1]
  • cos : R → [-1;1]
  • tan : R \ {π/2 + kπ} → R

II. Périodicité

sin et cos sont 2π-périodiques. tan est π-périodique.

III. Dérivées

  • (sin x)' = cos x
  • (cos x)' = -sin x
  • (tan x)' = 1/cos² x

IV. Équations

sin x = sin a ⇔ x = a + 2kπ ou x = π - a + 2kπ

V. Inéquations

Utiliser le cercle trigonométrique pour résoudre.
