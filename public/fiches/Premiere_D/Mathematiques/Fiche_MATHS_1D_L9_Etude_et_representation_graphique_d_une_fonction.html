Première D Mathématiques Les Polynômes du Second Degré

I. Forme Canonique

P(x) = a(x - α)² + β avec α = -b/2a et β = P(α)

II. Discriminant

Δ = b² - 4ac

III. Racines

  • Δ > 0 : 2 racines x₁ = (-b - √Δ)/2a et x₂ = (-b + √Δ)/2a
  • Δ = 0 : 1 racine double x₀ = -b/2a
  • Δ < 0 : Pas de racine réelle

IV. Signe

Si a > 0 : P(x) ≥ 0 à l'extérieur des racines. Si a < 0 : P(x) ≤ 0 à l'extérieur des racines.

V. Factorisation

P(x) = a(x - x₁)(x - x₂) si Δ > 0
