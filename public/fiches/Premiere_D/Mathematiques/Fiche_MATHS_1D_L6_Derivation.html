Première D Mathématiques La Dérivée

I. Nombre Dérivé

f'(a) = lim(h→0) [f(a+h) - f(a)]/h

II. Dérivées Usuelles

  • (xⁿ)' = nxⁿ⁻¹
  • (√x)' = 1/(2√x)
  • (1/x)' = -1/x²
  • (eˣ)' = eˣ
  • (ln x)' = 1/x

III. Opérations

(u+v)' = u'+v', (uv)' = u'v+uv', (u/v)' = (u'v-uv')/v²

IV. Lien avec Variations

f' > 0 ⇒ f croissante. f' < 0 ⇒ f décroissante.

V. Tangente

y = f'(a)(x-a) + f(a)
