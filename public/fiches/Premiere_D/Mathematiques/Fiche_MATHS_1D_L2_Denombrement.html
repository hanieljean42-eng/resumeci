Première D Mathématiques Le Dénombrement

I. Factorielle

n! = n × (n-1) × ... × 1
0! = 1

II. Arrangements

Aₙᵖ = n!/(n-p)! : Nombre de façons de choisir p éléments parmi n avec ordre.

III. Permutations

Pₙ = n! : Nombre de façons d'ordonner n éléments.

IV. Combinaisons

Cₙᵖ = n!/[p!(n-p)!] : Nombre de façons de choisir p éléments parmi n sans ordre.

V. Triangle de Pascal

Cₙ₊₁ᵖ = Cₙᵖ + Cₙᵖ⁻¹
