Première D Mathématiques Les Suites Numériques

I. Suite Arithmétique

uₙ₊₁ = uₙ + r
uₙ = u₀ + nr, Sₙ = (n+1)(u₀+uₙ)/2

II. Suite Géométrique

uₙ₊₁ = uₙ × q
uₙ = u₀ × qⁿ, Sₙ = u₀(1-qⁿ⁺¹)/(1-q) si q ≠ 1

III. Sens de Variation

  • Croissante : uₙ₊₁ ≥ uₙ
  • Décroissante : uₙ₊₁ ≤ uₙ

IV. Limite

Si |q| < 1, lim(n→+∞) qⁿ = 0

V. Suite définie par récurrence

uₙ₊₁ = f(uₙ) avec f donnée.
