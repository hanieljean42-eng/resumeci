Première D Physique-Chimie L'Électrolyse

I. Définition

Électrolyse : Transformation chimique forcée par un courant électrique. C'est l'inverse du fonctionnement d'une pile.
Principe :
  • Un générateur impose le sens du courant
  • Les réactions aux électrodes sont forcées
  • Énergie électrique → Énergie chimique

II. Montage d'Électrolyse

Constitution :
  • Anode : Électrode reliée au pôle + (oxydation)
  • Cathode : Électrode reliée au pôle - (réduction)
  • Électrolyte : Solution conductrice
  • Générateur : Source de courant continu

III. Réactions aux Électrodes

Anode : Siège d'une oxydation (perte d'électrons).
Cathode : Siège d'une réduction (gain d'électrons).
Exemple : électrolyse de l'eau :
  • Anode : 2H2O → O2 + 4H+ + 4e-
  • Cathode : 2H2O + 2e- → H2 + 2OH-

IV. Quantité d'Électricité

Loi de Faraday :
Q = I × t
Q : quantité d'électricité (C)
I : intensité (A)
t : temps (s)
Relation avec les moles d'électrons :
n(e-) = Q / F
F : constante de Faraday = 96500 C/mol

V. Applications

  • Électrozingage : Dépôt de zinc sur le fer
  • Électrolyse de l'eau : Production de H2 et O2
  • Raffinage des métaux : Purification du cuivre
  • Anodisation : Protection de l'aluminium
  • Galvanoplastie : Reproduction d'objets
