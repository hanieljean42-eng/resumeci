Première D Physique-Chimie L'Énergie et la Puissance

I. Formes d'Énergie

  • Énergie mécanique : Cinétique + potentielle
  • Énergie thermique : Chaleur
  • Énergie chimique : Liaisons chimiques
  • Énergie électrique : Charges électriques
  • Énergie nucléaire : Noyau atomique
  • Énergie rayonnante : Lumière, ondes

II. Conversion d'Énergie

Principe de conservation : L'énergie totale d'un système isolé est constante.
Rendement : η = Eutile / Efournie = Putile / Pfournie

III. Puissance

Puissance : Taux de transfert d'énergie.
Formules :
P = W / t
P = E / t
P = U × I (électrique)
P = F × v (mécanique)
Unité : Watt (W)

IV. Chaînes Énergétiques

Diagramme : Source → Convertisseur → Utilisateur
Exemple : Centrale thermique : Chimique → Thermique → Mécanique → Électrique
