📐 Mathématiques🏫 Terminale CLeçon 12 – Suites numériques

I. Définition

Une suite numérique (un) est une fonction définie sur ℕ (ou une partie de ℕ) à valeurs réelles. On note un la valeur de la suite au rang n.

1. Modes de définition

  • Par terme général : un = f(n).
  • Par récurrence : u0 (ou u1) donné, et une relation un+1 = g(un).

II. Suites arithmétiques

(un) est une suite arithmétique de raison r si :

un+1 = un + r

On montre que :

un = u0 + n r (ou un = up + (n − p) r)

III. Suites géométriques

(vn) est une suite géométrique de raison q si :

vn+1 = q vn

On montre que :

vn = v0 qⁿ (ou vn = vp qⁿ⁻ᵖ)

IV. Monotonie

Une suite (un) est :

  • croissante si ∀n, un+1 ≥ un ;
  • décroissante si ∀n, un+1 ≤ un ;
  • monotone si elle est croissante ou décroissante.

Pour étudier le sens de variation, on regarde le signe de un+1 − un ou on utilise les propriétés spécifiques des suites arithmétiques/géométriques.

V. Convergence (idées)

Une suite (un) converge vers ℓ si les termes un se rapprochent indéfiniment de ℓ quand n → +∞. On écrit lim un = ℓ.

  • Une suite croissante majorée converge.
  • Une suite décroissante minorée converge.
  • Si |q| < 1, une suite géométrique vn = v0 qⁿ converge vers 0.

VI. À retenir

  • Reconnaître le type d’une suite (arithmétique, géométrique, autre) est essentiel.
  • Les formules de un pour les suites arithmétiques et géométriques sont à maîtriser.
  • La monotonicité et les bornes permettent de conclure sur la convergence d’une suite.
