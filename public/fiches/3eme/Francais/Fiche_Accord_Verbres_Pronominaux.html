I. Verbes pronominaux

Se conjuguent avec un pronom réfléchi : se laver, se lever, se souvenir...

II. Règle générale

Aux temps composés, ils se conjuguent avec l'auxiliaire être.
Ex : Elle s'est levée tôt.

III. Accord du participe passé

CasRègleExemple
Le pronom est CODAccord avec le sujetElle s'est lavée. (elle = COD)
Le pronom est COIPas d'accordElle s'est lavé les mains. (COD = « mains », après le verbe)

IV. Méthode

  1. Remplacer « se » par un autre pronom (me, te, nous, vous).
  2. Chercher le COD : qui ? quoi ?
  3. Si le COD est avant le verbe → accord.
    Si le COD est après ou s'il n'y a pas de COD → pas d'accord.
