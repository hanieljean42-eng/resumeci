I. Le schéma de la communication

Tout acte de communication comporte :
  • Émetteur : celui qui parle / écrit
  • Récepteur : celui qui écoute / lit
  • Message : ce qui est dit / écrit
  • Code : langue utilisée (français, signes, symboles...)
  • Canal : moyen (voix, téléphone, lettre, internet...)
  • Contexte : situation (lieu, moment, relation entre émetteur et récepteur)

III. Fonctions du langage

  • Informer : transmettre une information (fonction référentielle)
  • Exprimer un sentiment (fonction expressive)
  • Agir sur l'autre (ordre, conseil) (fonction conative)
  • Maintenir le contact (fonction phatique)
  • Parler du langage lui-même (fonction métalinguistique)

IV. Obstacles à la communication

  • Langue mal maîtrisée
  • Bruitage (bruit, mauvaise connexion...)
  • Préjugés, incompréhensions
  • Message mal formulé (trop long, confus)

V. Améliorer sa communication

  • Adapter le langue au destinataire
  • Être clair et précis
  • Vérifier que le message est bien compris
  • Respecter son interlocuteur
