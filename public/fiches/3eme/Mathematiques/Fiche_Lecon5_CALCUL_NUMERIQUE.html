II. Encadrements

Encadrer x : trouver a et b tels que a ≤ x ≤ b.

Opérations sur les encadrements

Si a ≤ x ≤ b et c ≤ y ≤ d :
  • Somme : a + c ≤ x + y ≤ b + d
  • Différence : a − d ≤ x − y ≤ b − c
  • Produit (nombres positifs) : a×c ≤ x×y ≤ b×d

III. Comparaison de nombres réels

Pour comparer a et b : calculer a − b
Si a − b > 0 → a > b | Si a − b < 0 → a < b | Si a − b = 0 → a = b
