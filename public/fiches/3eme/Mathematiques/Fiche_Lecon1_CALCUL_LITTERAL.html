I. Quotients

Égalité de quotients : a/b = c/d ⟺ a×d = b×c (b ≠ 0, d ≠ 0)

II. Puissances à exposant entier relatif

a−n = 1/an (a ≠ 0)
Propriétés :
  • an × bn = (a×b)n
  • an × am = an+m
  • (am)n = am×n
  • am / an = am−n

III. Développement et factorisation

Développement

  • k(a + b) = ka + kb
  • k(a − b) = ka − kb
  • (a + b)(c + d) = ac + ad + bc + bd

Identités remarquables

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²

Factorisation

Factoriser = écrire une expression sous forme de produit.
  • Chercher un facteur commun : ka + kb = k(a + b)
  • Reconnaître une identité remarquable
