📝 FICHE DE RÉSUMÉ

📚 Français🎓 Terminale DRésumé texte argumentatif – Questions
Objectifs :
  • Comprendre un texte argumentatif pour mieux répondre aux questions.
  • Identifier la thèse, les arguments et les procédés.

I. Lire le texte de façon active

  • Repérer la thèse défendue par l’auteur.
  • Identifier les arguments principaux et leurs exemples.

II. Analyser les questions

  • Questions sur le sens global : thème, thèse, point de vue de l’auteur.
  • Questions sur les procédés : figures de style, registres, connecteurs logiques…
Conseils :
  • Répondre de façon structurée : reprendre les mots de la question, citer brièvement le texte, expliquer.
  • Éviter les réponses trop générales non appuyées sur le texte.
