II. Vecteur-Position

Le vecteur-position OM donne la position du point M dans le repère à chaque instant t.
OM = x·⃗i + y·⃗j + z·⃗k  (3D)
OM = x·⃗i + y·⃗j  (plan)
OM = x·⃗i  (droite)

III. Vecteur-Vitesse

Le vecteur-vitesse instantanée est la dérivée du vecteur-position par rapport au temps.
⃗v = dOM/dt = ẋ·⃗i + ẏ·⃗j + ż·⃗k
v = √(ẋ² + ẏ² + ż²)   [en m·s⁻¹]

Dans la base de Frenet

⃗v = v·⃗τ   avec v = ds/dt = ṡ

⃗τ : vecteur unitaire tangent à la trajectoire ; ⃗n : vecteur normal orienté vers la concavité.

IV. Vecteur-Accélération

⃗a = d⃗v/dt = ẍ·⃗i + ÿ·⃗j + z̈·⃗k
a = √(ẍ² + ÿ² + z̈²)   [en m·s⁻²]

Dans la base de Frenet

⃗a = aτ·⃗τ + aₙ·⃗n
ComposanteExpressionRôle
aτ (tangentielle)aτ = dv/dt = s̈Modifie la valeur de v
aₙ (normale)aₙ = v²/ρModifie la direction de ⃗v

ρ = rayon de courbure (ρ = R si trajectoire circulaire).

Mouvement accéléré : ⃗a·⃗v > 0 (aₓ·vₓ > 0)
Mouvement retardé : ⃗a·⃗v < 0 (aₓ·vₓ < 0)

V. Mouvements Particuliers

1. Mouvement Rectiligne Uniforme (MRU)

Trajectoire rectiligne + vitesse constante + accélération nulle.
a = 0
v = v₀ = constante
x = v₀·t + x₀

2. Mouvement Rectiligne Uniformément Varié (MRUV)

Trajectoire rectiligne + accélération constante (≠ 0).
a = constante
v = a·t + v₀
x = ½·a·t² + v₀·t + x₀
Relation sans le temps : v² − v₀² = 2·a·(x − x₀)

3. Mouvement Circulaire Uniforme (MCU)

Trajectoire circulaire + valeur de la vitesse constante.
v = R·ω  (vitesse linéaire)
θ = ω·t + θ₀  (abscisse angulaire)
s = R·θ = v·t + s₀  (abscisse curviligne)
aτ = 0  (pas d'accélération tangentielle)
aₙ = v²/R = R·ω²  (accélération centripète)
