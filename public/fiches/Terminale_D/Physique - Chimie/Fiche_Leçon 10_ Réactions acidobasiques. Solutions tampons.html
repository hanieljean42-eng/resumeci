I. Réaction Acide Fort + Base Forte

1. Caractéristiques

  • Réaction totale
  • Réaction exothermique
H₃O⁺ + OH⁻ → 2 H₂O

2. Courbe de dosage pH = f(Vb)

  • Avant l'équivalence : pH augmente lentement (excès d'acide)
  • À l'équivalence : saut de pH brutal
  • Après l'équivalence : pH augmente peu (excès de base)

3. Point d'équivalence E

L'équivalence acido-basique est l'état du mélange où les réactifs sont dans les proportions stœchiométriques.
Relation d'équivalence : Ca·Va = Cb·VbE
À l'équivalence (acide fort + base forte) :
• pHE = 7 (solution neutre)
• [H₃O⁺] = [OH⁻] = 10⁻⁷ mol/L
• Détermination graphique : méthode des tangentes parallèles

II. Réaction Acide Faible + Base Forte

1. Caractéristiques

  • Réaction totale et exothermique
CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O

Forme générale : AH + OH⁻ → A⁻ + H₂O

2. Courbe de dosage

4 parties : montée rapide → zone quasi-linéaire (avec point F) → saut de pH (point E) → asymptote.

3. Point d'équivalence E

Ca·Va = Cb·VbE
À l'équivalence (acide faible + base forte) :
• pHE > 7 (solution basique)
• Espèce majoritaire : la base conjuguée A⁻ (ici CH₃COO⁻)

4. Point de demi-équivalence F

VbF = VbE / 2   et   pHF = pKa
Au point F : [A] = [B] → pH = pKa du couple. Ce point permet de lire graphiquement le pKa.

III. Réaction Acide Fort + Base Faible

B + H₃O⁺ → BH⁺ + H₂O

Exemple : NH₃ + H₃O⁺ → NH₄⁺ + H₂O

À l'équivalence (acide fort + base faible) :
• pHE < 7 (solution acide)
• Espèce majoritaire : l'acide conjugué BH⁺ (ici NH₄⁺)

IV. Solutions Tampons

1. Définition

Une solution tampon est un mélange équimolaire d'un acide faible et de sa base conjuguée. C'est la solution obtenue au point de demi-équivalence d'un dosage.

2. Propriétés

Le pH d'une solution tampon varie peu :
  • Lors d'une dilution modérée
  • Lors de l'ajout modéré d'un acide
  • Lors de l'ajout modéré d'une base
pH ≈ pKa du couple

3. Trois méthodes de préparation

MéthodeCondition
Acide faible + base forten(OH⁻) = n(A) / 2 → demi-équivalence
Base faible + acide fortn(H₃O⁺) = n(B) / 2 → demi-équivalence
Mélange équimolairen(A) = n(B) soit CaVa = CbVb

4. Applications

  • Chimie : étalonnage des pH-mètres, contrôle du pH en oxydoréduction
  • Biologie : réactions enzymatiques, régulation du pH sanguin
