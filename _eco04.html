📖 Économie politique 🏫 Licence 1 Droit — Semestre 2 Leçon 4 : Le libéralisme économique — physiocrates, classiques anglais, classiques français, néoclassiques
Le libéralisme repose sur deux principes fondateurs : le respect de l'ordre naturel (l'État n'intervient pas) et l'harmonie des intérêts individuels — chacun, en maximisant son utilité, œuvre sans le vouloir pour l'intérêt général (utilitarisme).

I. L'école physiocrate (XVIIIᵉ s., France)

  • Courant bref, autour de François Quesnay (1694-1774) ; sympathisants : Turgot, Catherine II, Stanislas II ;
  • Vraie richesse = agricole, non monétaire (contre les mercantilistes) : seule l'agriculture dégage un produit net ; la manufacture est « stérile » (elle transforme sans créer) mais utile (elle fournit les avances) ; la richesse devient matérielle — agrarianisme (Gonnard) ;
  • Tableau économique (1758) : 1ʳᵉ comptabilité nationale — circulation des flux entre 3 classes : agriculteurs (classe productive), propriétaires fonciers, classe urbaine (« stérile ») ;
  • 3 avancées : premiers libéraux (ordre naturel, propriété privée) ; enrichissement matériel ; premier circuit économique ; libre-échange contre le protectionnisme de Colbert (interdiction des exportations de blé → ils veulent au contraire le haut prix du blé).

II. Les classiques britanniques (1776-1848)

  • Adam Smith (1723-1790), fondateur du libéralisme moderne : richesse = produit consommable ; division du travail (manufacture d'épingles) ; « main invisible » — l'intérêt personnel sert l'intérêt général ; avantages absolus → libre-échange et spécialisation ; État minimal = 3 fonctions régaliennes (armée, justice/police, travaux non rentables pour le privé) ;
  • Malthus (1766-1834), Essai sur le principe de population (1798) : population en progression géométrique vs subsistances en progression arithmétique → obstacles naturels (famines, guerres) ou artificiels (mariage tardif, chasteté ; refus de la contraception) ; hostile aux poor laws — père du darwinisme social ; 1ᵉʳ à voir l'importance de la demande (annonce Keynes) ;
  • Ricardo (1772-1823), Principes (1817) : valeur-travail (travail direct + indirect) ; 3 revenus : salaire de subsistance (loi d'airain), profit, rente foncière (écart de fertilité des terres) ; rendements décroissants → baisse du profit → état stationnaire, sauf importation de blé (abolir les Corn Laws — fait en 1846) ; avantages comparatifs : chaque pays se spécialise là où il est le plus avantagé ou le moins désavantagé (vin/tissu, Portugal/Grande-Bretagne) ;
  • Bentham (1748-1832) : utilitarisme — « le plus grand bonheur du plus grand nombre » ; rejette droit naturel et contrat social ; l'État justifié par l'utilité ; influence sur le Code civil et l'analyse économique du droit ;
  • J.S. Mill (1806-1873) : dernier classique — laisser-faire + réformisme social (instruction publique, émancipation des femmes) ; théorie quantitative de la monnaie (MV=PT, reprise par Fisher) ; affine les avantages comparatifs (demande réciproque).

III. Les classiques français

  • Jean-Baptiste Say (1767-1832) : richesse = tout ce qui répond à un besoin (utilité) ; les services sont productifs ; loi des débouchés : la production ouvre ses propres débouchés — la monnaie est neutre, pas de crise générale de surproduction (vivement critiquée par Keynes) ;
  • Frédéric Bastiat (1801-1850) : libéral radical — l'État doit se cantonner à la paix intérieure/extérieure et abandonner tout le reste à l'activité privée (« l'ordre et la liberté sont à ce prix »).

IV. Les néoclassiques et le marginalisme

  • Nés au dernier tiers du XIXᵉ s. — fondateurs : Walras (Français, école de Lausanne), Jevons (Anglais), Menger (école de Vienne : Böhm-Bawerk, Mises, Hayek) ;
  • Walras : mathématisation (influence de Cournot) ; interdépendance de tous les marchés → équilibre général ;
  • Jevons : utilité marginale = valeur accordée à la dernière unité consommée ; loi de l'utilité marginale décroissante ;
  • Menger : théorie subjective de la valeur — hiérarchie des besoins ; la dernière unité mesure la valeur de l'ensemble (verres d'eau) ;
  • Marginalisme : raisonner sur les quantités additionnelles (à la marge), non globales ; l'utilité marginale décroît, et à zéro le désir est maximisé ;
  • Les néoclassiques fondent la microéconomie ; équilibre possible sous concurrence pure et parfaite ; vision contestée par Keynes.

V. ⚠️ Pièges d'examen & méthode

⚠️ Erreurs fréquentes :
  • Confondre avantages absolus (Smith) et comparatifs (Ricardo — même le pays le moins compétitif gagne à l'échange) ;
  • Attribuer la main invisible aux physiocrates : c'est Smith ; eux ont le Tableau économique et le produit net ;
  • Dire que la loi de Say permet les crises générales : au contraire, elle les exclut (monnaie neutre) — critique centrale de Keynes.
💡 Axe de synthèse : physiocrates (ordre naturel) → classiques (main invisible, valeur-travail) → néoclassiques (valeur subjective, équilibre) : le fil conducteur est la foi dans le marché autorégulé.
