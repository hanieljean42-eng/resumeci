💻 Technologie (TICE)Leçon 5 : L'insertion d'images dans un texte

I. Pourquoi insérer des images ?

Pour rendre le message d'un texte plus expressif, on peut y insérer des objets graphiques : cliparts, photos, formes géométriques, zones de texte, etc.

II. Insérer une image

Procédure :
  1. Placer le curseur à l'endroit souhaité
  2. Menu Insertion → Image
  3. Choisir l'image depuis l'ordinateur ou Internet
  4. Valider

III. Insérer une forme

  • Menu Insertion → Formes
  • Choisir la forme souhaitée (rectangle, cercle, flèche…)
  • Dessiner la forme dans le document

IV. Insérer une zone de texte

  • Menu Insertion → Zone de texte
  • Dessiner le cadre dans le document
  • Saisir le texte à l'intérieur

V. Habillage du texte

OptionEffet
Aligné sur le texteL'image suit le texte comme un caractère
CarréLe texte entoure l'image en forme carrée
RapprochéLe texte épouse les contours de l'image
Derrière le texteL'image est en arrière-plan
Devant le texteL'image est en premier plan
Les images, formes et zones de texte enrichissent un document et améliorent la communication visuelle.
