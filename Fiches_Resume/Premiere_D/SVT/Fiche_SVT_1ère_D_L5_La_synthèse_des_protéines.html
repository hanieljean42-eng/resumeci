Première D SVT L5 La synthèse des protéines

I. Le Code Génétique

Code génétique : Système qui permet de traduire la séquence de nucléotides de l'ADN en séquence d'acides aminés des protéines. Il est universel (le même pour tous les êtres vivants).
Caractéristiques du code génétique :
  • Dégénéré : Plusieurs codons peuvent coder pour le même acide aminé
  • Non chevauchant : Chaque nucléotide appartient à un seul codon
  • Universel : Le même code est utilisé par tous les organismes
Le codon :
  • Unité du code génétique composée de 3 nucléotides
  • Il code pour un acide aminé spécifique
  • Il existe 64 codons possibles (4³ = 64)
  • 3 codons sont des codons STOP (terminent la traduction)
  • 1 codon est le codon START (initie la traduction)

II. La Transcription

Transcription : Synthèse d'un ARN messager (ARNm) à partir d'un brin d'ADN matrice. Cette étape se déroule dans le noyau de la cellule.
Mécanisme de la transcription :
  1. L'ARN polymérase se fixe sur l'ADN au niveau du promoteur
  2. L'enzyme ouvre la double hélice d'ADN
  3. L'ARN polymérase synthétise l'ARNm en complémentarité avec le brin d'ADN
  4. L'ARNm est libéré et quitte le noyau vers le cytoplasme
Règles de complémentarité :
  • ADN → ARN : A → U, T → A, G → C, C → G
  • Exemple : ADN (ATGC) → ARN (UACG)

III. La Traduction

Traduction : Synthèse d'une protéine sur les ribosomes à partir de l'information contenue dans l'ARNm. Cette étape se déroule dans le cytoplasme.
Acteurs de la traduction :
  • ARNm : Porte le message génétique (séquence de codons)
  • Ribosomes : Machines de synthèse des protéines
  • ARNt (ARN de transfert) : Transportent les acides aminés et les positionnent sur le ribosome
  • Acides aminés : Les briques élémentaires des protéines
Étapes de la traduction :
  1. Initiation : Le ribosome se fixe sur l'ARNm au niveau du codon START
  2. Elongation : Les ARNt apportent les acides aminés correspondants aux codons. Le ribosome les lie ensemble pour former la chaîne polypeptidique.
  3. Terminaison : La traduction s'arrête lorsqu'un codon STOP est atteint. La protéine est libérée.

IV. Structure des Protéines

Protéine : Macromolécule formée par l'enchaînement d'acides aminés reliés par des liaisons peptidiques.
Les 4 niveaux de structure :
  1. Structure primaire : Séquence linéaire d'acides aminés
  2. Structure secondaire : Enroulement local (hélice alpha, feuillet bêta)
  3. Structure tertiaire : Repliement tridimensionnel de la protéine
  4. Structure quaternaire : Association de plusieurs chaînes polypeptidiques

V. Rôle des Protéines

Fonctions des protéines dans l'organisme :
  • Structure : Kératine (cheveux, ongles), collagène (peau, os)
  • Enzymatique : Catalysent les réactions biochimiques
  • Hormonale : Insuline, hormone de croissance
  • Transport : Hémoglobine (transporte l'oxygène), albumine
  • Défense immunitaire : Anticorps
  • Mouvement : Actine, myosine (contraction musculaire)
  • Stockage : Caséine (lait), ferritine (fer)

VI. Conclusion

La synthèse des protéines est un processus fondamental qui permet à la cellule de produire les protéines nécessaires à son fonctionnement à partir de l'information génétique contenue dans l'ADN. Ce processus comprend deux étapes principales : la transcription (synthèse de l'ARNm dans le noyau) et la traduction (synthèse de la protéine dans le cytoplasme). Les protéines jouent des rôles essentiels dans l'organisme : structure, enzymes, hormones, transport, défense immunitaire et mouvement.
