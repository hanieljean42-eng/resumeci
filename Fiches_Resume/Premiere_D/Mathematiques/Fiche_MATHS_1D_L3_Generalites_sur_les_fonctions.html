Première D Mathématiques Les Fonctions

I. Définition

Fonction : Relation qui à chaque x associe une unique image f(x).

II. Ensemble de Définition

Ensemble des x pour lesquels f(x) existe.

III. Variations

  • Croissante : x₁ < x₂ ⇒ f(x₁) ≤ f(x₂)
  • Décroissante : x₁ < x₂ ⇒ f(x₁) ≥ f(x₂)

IV. Extremums

  • Maximum : Plus grande valeur de f
  • Minimum : Plus petite valeur de f

V. Parité

  • Paire : f(-x) = f(x)
  • Impaire : f(-x) = -f(x)
