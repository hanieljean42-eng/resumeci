I. Types d'Argumentation

Types d'argumentation : Différentes formes d'argumentation selon la manière dont la thèse est présentée : directe (thèse explicite), indirecte (fiction, apologue), délibérative, démonstrative.
Argumentation directe :
  • Définition : La thèse est explicite et clairement énoncée
  • Structure : Thèse, arguments, exemples
  • Types : Essai, article de presse, discours
  • Avantage : Clarté et précision
  • Utilisation : Pour convaincre directement
Argumentation indirecte :
  • Définition : La thèse est implicite, véhiculée par une fiction
  • Structure : Récit, personnages, situation
  • Types : Apologue, fable, conte philosophique, roman à thèse
  • Avantage : Persuasion par l'émotion et l'identification
  • Utilisation : Pour persuader indirectement
Argumentation délibérative :
  • Définition : Débat sur une question d'actualité ou de société
  • Objectif : Convaincre ou persuader
  • Types : Éditorial, tribune, débat
  • Caractéristiques : Présentation de plusieurs points de vue
  • Utilisation : Pour traiter un sujet controversé
Argumentation démonstrative :
  • Définition : Démonstration logique d'une thèse
  • Objectif : Prouver par la raison
  • Types : Texte scientifique, philosophique
  • Caractéristiques : Rigueur logique, raisonnement
  • Utilisation : Pour établir une vérité

II. Indices d'Argumentation

Indices d'argumentation : Éléments du texte qui signalent la présence d'une argumentation : connecteurs logiques, marques d'opinion, exemples, chiffres, citations, structure du texte.
Connecteurs logiques :
  • D'addition : Et, de plus, en outre, par ailleurs
  • D'opposition : Mais, cependant, pourtant, en revanche
  • De causalité : Car, parce que, donc, par conséquent
  • De conclusion : En conclusion, enfin, ainsi
  • Fonction : Marquent les liens entre les arguments
Marques d'opinion :
  • Verbes d'opinion : Je pense, je crois, je considère
  • Adverbes d'opinion : Sans doute, certainement, probablement
  • Termes appréciatifs : Bien, mal, heureusement, malheureusement
  • Modalisation : Indices de la subjectivité de l'auteur
  • Fonction : Marquent la prise de position
Exemples, chiffres, citations :
  • Exemples : Illustrations concrètes des arguments
  • Chiffres : Statistiques, données chiffrées
  • Citations : Citations d'autorités
  • Témoignages : Témoignages de personnes
  • Fonction : Soutiennent et illustrent les arguments
Structure du texte :
  • Introduction : Présentation de la thèse
  • Développement : Arguments et exemples
  • Conclusion : Synthèse et ouverture
  • Paragraphes : Organisation en paragraphes argumentatifs
  • Fonction : Structure typique de l'argumentation

III. Situation d'Énonciation

Situation d'énonciation : Contexte dans lequel le texte est produit. Il faut identifier l'auteur, le destinataire, le contexte et le but de l'argumentation.
Identification de l'auteur :
  • Identité : Nom de l'auteur
  • Statut : Statut de l'auteur (expert, journaliste, écrivain...)
  • Position : Position de l'auteur sur le sujet
  • Engagement : Degré d'engagement de l'auteur
  • Crédibilité : Crédibilité de l'auteur
Identification du destinataire :
  • Type : Destinataire individuel ou collectif
  • Statut : Statut du destinataire
  • Relation : Relation entre l'auteur et le destinataire
  • Adaptation : Adaptation au destinataire
  • Influence : Influence sur le ton et le style
Identification du contexte :
  • Contexte historique : Époque et contexte historique
  • Contexte culturel : Contexte culturel et social
  • Contexte médiatique : Type de publication
  • Contexte idéologique : Courant de pensée
  • Influence : Influence sur le contenu
Identification du but de l'argumentation :
  • Convaincre : Persuader par la raison
  • Persuader : Persuader par l'émotion
  • Informer : Donner des informations
  • Délibérer : Débattre d'une question
  • Agir : Inciter à l'action

IV. Stratégies Argumentatives

Stratégies argumentatives : Choix faits par l'auteur pour argumenter efficacement : choix des exemples, ton adopté, registre de langue, organisation des arguments.
Choix des exemples :
  • Pertinence : Exemples pertinents par rapport à la thèse
  • Variété : Variété des types d'exemples
  • Originalité : Originalité des exemples
  • Force : Force persuasive des exemples
  • Placement : Placement stratégique des exemples
Ton adopté :
  • Ton sérieux : Ton sérieux et formel
  • Ton ironique : Ton ironique ou satirique
  • Ton passionné : Ton passionné ou engagé
  • Ton didactique : Ton pédagogique
  • Adaptation : Adaptation au but et au destinataire
Registre de langue :
  • Registre courant : Langage standard
  • Registre soutenu : Langage formel et littéraire
  • Registre familier : Langage familier (rare en argumentation)
  • Vocabulaire : Choix du vocabulaire
  • Syntaxe : Complexité de la syntaxe
Organisation des arguments :
  • Ordre : Ordre des arguments (du plus faible au plus fort)
  • Progression : Progression logique
  • Équilibre : Équilibre entre les arguments
  • Transitions : Transitions fluides
  • Structure : Structure globale du texte

V. Conclusion

L'identification de la situation d'argumentation est essentielle pour comprendre un texte argumentatif. Les types d'argumentation sont l'argumentation directe (thèse explicite), indirecte (fiction, apologue), délibérative et démonstrative. Les indices d'argumentation sont les connecteurs logiques, les marques d'opinion, les exemples, les chiffres, les citations et la structure du texte. La situation d'énonciation identifie l'auteur, le destinataire, le contexte et le but de l'argumentation. Les stratégies argumentatives sont le choix des exemples, le ton adopté, le registre de langue et l'organisation des arguments. La maîtrise de ces éléments est essentielle pour analyser un texte argumentatif.
