I. Compréhension du Texte

Compréhension du texte : Première étape de l'épreuve de questions sur un texte argumenté qui consiste à lire attentivement le texte, repérer la thèse, identifier les arguments et comprendre le vocabulaire.
Lecture attentive :
  • Double lecture : Lire le texte au moins deux fois
  • Repérage : Repérer les passages importants
  • Soulignement : Souligner les idées clés
  • Annotation : Annoter le texte si autorisé
  • Compréhension globale : Comprendre le sens global du texte
Repérage de la thèse :
  • Définition : Position défendue par l'auteur
  • Localisation : Généralement dans l'introduction ou la conclusion
  • Formulation : Formuler clairement la thèse
  • Nuance : Repérer les nuances de la thèse
  • Évolution : Repérer l'évolution de la thèse
Identification des arguments :
  • Repérage : Repérer les arguments principaux
  • Hiérarchie : Établir une hiérarchie entre les arguments
  • Liens : Repérer les liens entre les arguments
  • Exemples : Repérer les exemples illustratifs
  • Connecteurs : Repérer les connecteurs logiques
Compréhension du vocabulaire :
  • Mots inconnus : Chercher le sens des mots inconnus
  • Contexte : Déduire le sens d'après le contexte
  • Termes clés : Comprendre les termes clés du texte
  • Connotations : Repérer les connotations
  • Champs lexicaux : Repérer les champs lexicaux

II. Analyse des Questions

Analyse des questions : Deuxième étape qui consiste à comprendre ce qui est demandé, repérer les mots-clés et identifier le type de réponse attendue.
Compréhension de ce qui est demandé :
  • Lecture attentive : Lire attentivement chaque question
  • Compréhension : Comprendre la demande
  • Precision : Être précis dans la compréhension
  • Interprétation : Éviter les interprétations erronées
  • Vérification : Vérifier la compréhension
Repérage des mots-clés :
  • Identification : Repérer les mots-clés de la question
  • Soulignement : Souligner les termes importants
  • Compréhension : Comprendre le sens des mots-clés
  • Lien : Lier les mots-clés au texte
  • Guidance : Utiliser les mots-clés comme guide
Identification du type de réponse attendue :
  • Question de compréhension : Réponse dans le texte
  • Question d'analyse : Analyse d'un passage
  • Question de réflexion : Réflexion personnelle
  • Question de comparaison : Comparaison d'éléments
  • Question d'explication : Explication d'un terme ou d'une idée

III. Réponses

Réponses : Troisième étape qui consiste à répondre précisément à chaque question, s'appuyer sur le texte, citer si nécessaire et reformuler.
Réponse précise à chaque question :
  • Pertinence : Répondre précisément à la question
  • Complétude : Répondre à tous les aspects de la question
  • Clarté : Être clair dans la réponse
  • Précision : Être précis
  • Concision : Aller à l'essentiel
S'appuyer sur le texte :
  • Fidélité : Rester fidèle au texte
  • Preuves : S'appuyer sur des preuves textuelles
  • Références : Référencer précisément le texte
  • Citation : Citer si nécessaire
  • Contre-sens : Éviter le contre-sens
Citation si nécessaire :
  • Pertinence : Citer uniquement si pertinent
  • Exactitude : Citer exactement
  • Guillemets : Mettre entre guillemets
  • Référence : Indiquer la référence (ligne, paragraphe)
  • Intégration : Intégrer naturellement la citation
Reformulation :
  • Reformulation : Reformuler avec ses propres mots
  • Compréhension : Montrer la compréhension
  • Paraphrase : Paraphraser le texte
  • Synthèse : Synthétiser les informations
  • Clarté : Rendre la réponse claire

IV. Présentation

Présentation des réponses : Quatrième étape qui consiste à numéroter les réponses, utiliser un vocabulaire précis et respecter la consigne de longueur.
Numérotation des réponses :
  • Ordre : Respecter l'ordre des questions
  • Numérotation : Numéroter chaque réponse
  • Séparation : Séparer clairement les réponses
  • Aération : Aérer la présentation
  • Lisibilité : Assurer la lisibilité
Utilisation d'un vocabulaire précis :
  • Vocabulaire : Utiliser un vocabulaire précis
  • Terminologie : Utiliser la terminologie appropriée
  • Variété : Varier le vocabulaire
  • Exactitude : Être exact dans les termes
  • Adaptation : Adapter le vocabulaire au type de question
Respect de la consigne de longueur :
  • Consigne : Respecter la consigne de longueur
  • Équilibre : Équilibrer les réponses
  • Concision : Être concis
  • Synthèse : Synthétiser si nécessaire
  • Respect : Respecter les limites

V. Conclusion

La réponse aux questions sur un texte argumenté demande rigueur et méthode. La compréhension du texte consiste à lire attentivement, repérer la thèse, identifier les arguments et comprendre le vocabulaire. L'analyse des questions consiste à comprendre ce qui est demandé, repérer les mots-clés et identifier le type de réponse attendue. Les réponses doivent être précises, s'appuyer sur le texte, citer si nécessaire et reformuler. La présentation doit numéroter les réponses, utiliser un vocabulaire précis et respecter la consigne de longueur. La maîtrise de cette méthode est essentielle pour réussir l'épreuve de questions sur un texte argumenté.
