I. Situation d'Énonciation

Situation d'énonciation : Contexte dans lequel un énoncé est produit. Elle se définit par quatre questions : qui parle ? À qui ? Quand ? Où ? Dans quel but ? Les indices dans le texte permettent de la repérer.
Qui parle ? (Énonciateur) :
  • Identité : Identité du locuteur
  • Statut : Statut du locuteur (auteur, narrateur, personnage...)
  • Rôle : Rôle dans le texte
  • Position : Position par rapport au sujet
  • Engagement : Degré d'engagement
À qui ? (Destinataire) :
  • Identité : Identité du destinataire
  • Type : Destinataire individuel ou collectif
  • Statut : Statut du destinataire
  • Relation : Relation entre énonciateur et destinataire
  • Influence : Influence sur le ton et le style
Quand ? (Moment) :
  • Moment : Moment de l'énonciation
  • Date : Date de production du texte
  • Époque : Époque de production
  • Contexte historique : Contexte historique
  • Actualité : Rapport à l'actualité
Où ? (Lieu) :
  • Lieu : Lieu de l'énonciation
  • Espace : Espace de production
  • Contexte géographique : Contexte géographique
  • Environnement : Environnement de production
  • Distance : Distance avec le sujet
Dans quel but ? (Intention) :
  • Intention : Intention de l'énonciateur
  • Objectif : Objectif du texte
  • Fonction : Fonction du texte (informer, convaincre, raconter...)
  • Effet : Effet recherché sur le destinataire
  • Stratégie : Stratégie de communication

II. Énonciateur et Destinataire

Énonciateur et destinataire : Identification du locuteur (énonciateur) et de l'interlocuteur (destinataire). La relation entre les deux est essentielle pour comprendre le texte.
Identification du locuteur :
  • Énonciateur : Celui qui produit l'énoncé
  • Auteur : Peut être l'auteur réel
  • Narrateur : Peut être le narrateur
  • Personnage : Peut être un personnage
  • Voix : Voix qui parle dans le texte
Identification du destinataire :
  • Destinataire : Celui à qui l'énoncé est adressé
  • Lecteur : Lecteur du texte
  • Auditeur : Auditeur (si texte oral)
  • Personnage : Peut être un personnage
  • Public : Public visé
Relation entre les deux :
  • Hiérarchie : Rapport de hiérarchie
  • Proximité : Proximité ou distance
  • Familiarité : Degré de familiarité
  • Respect : Degré de respect
  • Influence : Influence sur le ton

III. Indices d'Énonciation

Indices d'énonciation : Marques dans le texte qui permettent d'identifier la situation d'énonciation. Les principaux indices sont les pronoms personnels, les temps verbaux, les marques de subjectivité et les déictiques.
Pronoms personnels :
  • Je : Marque la première personne (énonciateur)
  • Tu : Marque la deuxième personne (destinataire)
  • Il/Elle : Marque la troisième personne (extériorité)
  • Nous : Marque l'inclusion
  • Vous : Marque le pluriel ou le vouvoiement
Temps verbaux :
  • Présent : Présent d'énonciation (moment de la parole)
  • Passé composé : Passé lié au présent
  • Futur : Futur lié au présent
  • Imparfait : Peut marquer la simultanéité
  • Valeur : Valeur d'énonciation des temps
Marques de subjectivité :
  • Verbes d'opinion : Je pense, je crois, je considère
  • Adverbes : Sans doute, certainement, probablement
  • Termes appréciatifs : Bien, mal, heureusement
  • Modalisation : Indices de la subjectivité
  • Émotion : Marques d'émotion
Déictiques :
  • Définition : Mots dont le sens dépend du contexte
  • Adverbes de lieu : Ici, là-bas
  • Adverbes de temps : Maintenant, aujourd'hui
  • Démonstratifs : Ce, cette, celui-ci
  • Référence : Référence à la situation d'énonciation

IV. Types d'Énoncés

Types d'énoncés : Deux grands types d'énoncés selon leur rapport à la situation d'énonciation : l'énoncé ancré (présent, je, ici) et l'énoncé coupé (passé, il, là-bas).
Énoncé ancré :
  • Définition : Énoncé lié à la situation d'énonciation
  • Présent : Utilisation du présent d'énonciation
  • Je : Utilisation de la première personne
  • Ici : Utilisation de déictiques de lieu
  • Exemple : Dialogue, lettre, journal intime
Énoncé coupé :
  • Définition : Énoncé détaché de la situation d'énonciation
  • Passé : Utilisation du passé simple ou composé
  • Il : Utilisation de la troisième personne
  • Là-bas : Utilisation de déictiques de lieu éloignés
  • Exemple : Récit, roman, article de presse
Comparaison :
  • Ancrage : Énoncé ancré vs coupé
  • Subjectivité : Subjectivité vs objectivité
  • Immédiateté : Immédiateté vs distance
  • Intimité : Intimité vs extériorité
  • Genre : Genre littéraire concerné

V. Conclusion

L'énonciation est l'acte de produire un énoncé. La situation d'énonciation se définit par quatre questions : qui parle ? À qui ? Quand ? Où ? Dans quel but ? L'énonciateur est celui qui parle, le destinataire est celui à qui l'énoncé est adressé. Les indices d'énonciation sont les pronoms personnels, les temps verbaux, les marques de subjectivité et les déictiques. Les types d'énoncés sont l'énoncé ancré (présent, je, ici) et l'énoncé coupé (passé, il, là-bas). La maîtrise de l'énonciation est essentielle pour analyser et comprendre les textes.
