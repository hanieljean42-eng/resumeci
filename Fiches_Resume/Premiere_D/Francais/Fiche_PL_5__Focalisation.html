Première D Français Focalisation

I. Focalisation Interne

Focalisation interne : Point de vue d'un personnage. Le narrateur adopte le point de vue d'un personnage et le lecteur voit ce que le personnage voit et ressent.
Point de vue d'un personnage :
  • Subjectivité : Vision subjective du personnage
  • Limitation : Vision limitée à ce que le personnage perçoit
  • Pensées : Accès aux pensées du personnage
  • Sentiments : Accès aux sentiments du personnage
  • Perception : Perception filtrée par le personnage
Caractéristiques :
  • Première personne : Utilisation du "je"
  • Subjectivité : Marque de la subjectivité
  • Intériorité : Focus sur l'intériorité
  • Limitation : Limitation de l'information
  • Identification : Identification du lecteur au personnage
Effets :
  • Identification : Identification du lecteur au personnage
  • Immersion : Immersion dans l'histoire
  • Subjectivité : Subjectivité du récit
  • Mystère : Création de mystère
  • Intimité : Intimité avec le personnage

II. Focalisation Externe

Focalisation externe : Point de vue d'un observateur extérieur. Le narrateur observe les personnages de l'extérieur et ne connaît pas leurs pensées.
Point de vue d'un observateur extérieur :
  • Objectivité : Vision objective des événements
  • Observation : Observation des comportements
  • Extériorité : Focus sur l'extériorité
  • Actions : Description des actions
  • Paroles : Rapport des paroles
Caractéristiques :
  • Troisième personne : Utilisation du "il" ou "elle"
  • Objectivité : Marque de l'objectivité
  • Distance : Distance par rapport aux personnages
  • Limitation : Limitation de l'information
  • Neutre : Ton neutre
Effets :
  • Distance : Distance critique
  • Mystère : Création de mystère
  • Suspense : Création de suspense
  • Objectivité : Impartialité du récit
  • Réalisme : Réalisme de la description

III. Focalisation Zéro

Focalisation zéro : Point de vue omniscient. Le narrateur sait tout des personnages et de l'histoire. Il a une vision globale et complète.
Point de vue omniscient :
  • Omniscience : Connaissance totale de l'histoire
  • Pensées : Accès aux pensées de tous les personnages
  • Passé : Connaissance du passé
  • Futur : Connaissance du futur
  • Contexte : Connaissance du contexte
Caractéristiques :
  • Troisième personne : Utilisation du "il" ou "elle"
  • Omniscience : Marque de l'omniscience
  • Universalité : Vision universelle
  • Complétude : Information complète
  • Souveraineté : Souveraineté du narrateur
Effets :
  • Information : Informations complètes
  • Clarté : Clarté du récit
  • Compréhension : Facilite la compréhension
  • Distance : Distance par rapport aux personnages
  • Contrôle : Contrôle total du narrateur

IV. Effets

Effets de la focalisation : Conséquences du choix de la focalisation sur le récit et sur le lecteur : mise en scène, suspense, identification, distance critique, informations complètes.
Mise en scène :
  • Scène : Mise en scène des événements
  • Perspective : Perspective choisie
  • Angle : Angle de vue
  • Cadrage : Cadrage de l'action
  • Réalisme : Réalisme de la scène
Suspense :
  • Mystère : Création de mystère
  • Tension : Création de tension
  • Attente : Création d'attente
  • Surprise : Effet de surprise
  • Intérêt : Maintien de l'intérêt
Identification :
  • Empathie : Empathie avec le personnage
  • Immersion : Immersion dans l'histoire
  • Projection : Projection du lecteur
  • Attachement : Attachement au personnage
  • Émotion : Émotion ressentie
Distance critique :
  • Objectivité : Objectivité du récit
  • Critique : Distance critique
  • Réflexion : Réflexion sur les événements
  • Jugement : Jugement du lecteur
  • Analyse : Analyse de la situation

V. Conclusion

La focalisation est le point de vue adopté par le narrateur dans un récit. La focalisation interne adopte le point de vue d'un personnage, le lecteur voit ce que le personnage voit et ressent. La focalisation externe adopte le point de vue d'un observateur extérieur, le narrateur ne connaît pas les pensées des personnages. La focalisation zéro est un point de vue omniscient, le narrateur sait tout des personnages et de l'histoire. Les effets de la focalisation sont la mise en scène, le suspense, l'identification, la distance critique et les informations complètes. La maîtrise de la focalisation est essentielle pour analyser et écrire des récits.
