Première D Français Implicite

I. Définition

Implicite : Ce qui est dit sans être dit explicitement. L'implicite est le sens sous-entendu, le non-dit que le lecteur doit déduire du texte.
Ce qui est dit sans être dit explicitement :
  • Non-dit : Information non exprimée directement
  • Sous-entendu : Sens caché du message
  • Déduction : Nécessite une déduction du lecteur
  • Inférence : Inférence à partir du contexte
  • Compréhension : Compréhension fine du texte
Sens sous-entendu :
  • Double sens : Possibilité de double sens
  • Allusion : Allusion à quelque chose
  • Suggestion : Suggestion plutôt qu'affirmation
  • Nuance : Nuance dans le message
  • Subtilité : Subtilité de l'expression
Non-dit :
  • Information : Information implicite
  • Silence : Ce qui n'est pas dit
  • Omission : Omission volontaire
  • Stratégie : Stratégie de communication
  • Interprétation : Nécessite l'interprétation

II. Types d'Implicite

Types d'implicite : Différentes formes d'implicite : le sous-entendu (ironie), le présupposé (information admise) et la connotation (sens associé).
Sous-entendu :
  • Définition : Sens caché que l'on veut faire comprendre
  • Ironie : Souvent lié à l'ironie
  • Moquerie : Peut être moqueur
  • Critique : Critique indirecte
  • Dénonciation : Dénonciation implicite
Présupposé :
  • Définition : Information admise comme vraie
  • Admission : Admise sans être démontrée
  • Postulat : Postulat de départ
  • Croyance : Croyance partagée
  • Contexte : Dépend du contexte culturel
Connotation :
  • Définition : Sens associé à un mot
  • Affectif : Charge affective
  • Subjectif : Sens subjectif
  • Culturel : Dépend de la culture
  • Imaginaire : Fait appel à l'imaginaire

III. Indices

Indices de l'implicite : Éléments qui permettent de repérer l'implicite dans un texte : le contexte, le ton, le choix des mots, la situation d'énonciation et la culture partagée.
Contexte :
  • Situation : Situation de communication
  • Environnement : Environnement du texte
  • Historique : Contexte historique
  • Culturel : Contexte culturel
  • Social : Contexte social
Ton :
  • Ironique : Ton ironique
  • Sarcastique : Ton sarcastique
  • Moqueur : Ton moqueur
  • Sérieux : Ton sérieux
  • Humoristique : Ton humoristique
Choix des mots :
  • Vocabulaire : Choix du vocabulaire
  • Connotations : Connotations des mots
  • Images : Images utilisées
  • Expressions : Expressions idiomatiques
  • Figures de style : Figures de style
Situation d'énonciation et culture partagée :
  • Locuteur : Identité du locuteur
  • Destinataire : Identité du destinataire
  • Lieu : Lieu de l'énonciation
  • Moment : Moment de l'énonciation
  • Culture : Culture partagée

IV. Interprétation

Interprétation de l'implicite : Méthode pour interpréter l'implicite dans un texte. Il faut repérer les implicites, les analyser et comprendre leur rôle dans le texte.
Repérer les implicites :
  • Identification : Identifier les passages implicites
  • Marques : Repérer les marques d'implicite
  • Indices : Repérer les indices
  • Anomalies : Repérer les anomalies
  • Contradictions : Repérer les contradictions
Les analyser :
  • Type : Identifier le type d'implicite
  • Sens : Déterminer le sens implicite
  • Intention : Comprendre l'intention
  • Effet : Analyser l'effet recherché
  • Justification : Justifier l'interprétation
Comprendre leur rôle dans le texte :
  • Fonction : Déterminer la fonction de l'implicite
  • Argumentation : Rôle dans l'argumentation
  • Expressivité : Rôle expressif
  • Ironie : Rôle ironique
  • Stratégie : Stratégie de communication

V. Conclusion

L'implicite est ce qui est dit sans être dit explicitement. C'est le sens sous-entendu, le non-dit que le lecteur doit déduire. Les types d'implicite sont le sous-entendu (ironie), le présupposé (information admise) et la connotation (sens associé). Les indices de l'implicite sont le contexte, le ton, le choix des mots, la situation d'énonciation et la culture partagée. L'interprétation de l'implicite consiste à repérer les implicites, les analyser et comprendre leur rôle dans le texte. La maîtrise de l'implicite est essentielle pour analyser et comprendre les textes littéraires et argumentatifs.
