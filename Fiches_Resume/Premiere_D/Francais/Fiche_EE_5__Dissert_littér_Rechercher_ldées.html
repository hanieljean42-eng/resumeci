I. Brainstorming

Brainstorming : Technique de recherche d'idées qui consiste à noter toutes les idées qui viennent à l'esprit sans filtrer, afin d'explorer différentes pistes de réflexion pour la dissertation.
Principes du brainstorming :
  • Liberté : Noter toutes les idées sans jugement
  • Quantité : Chercher le plus grand nombre d'idées possible
  • Originalité : Chercher des idées originales et créatives
  • Association : Laisser les idées s'associer librement
  • Sans censure : Ne pas censurer les idées qui semblent farfelues
Méthodes de brainstorming :
  • Liste : Faire une liste d'idées
  • Carte mentale : Organiser les idées visuellement
  • Associations libres : Laisser les idées venir librement
  • Questions : Se poser des questions sur le sujet
  • Analogies : Chercher des analogies avec d'autres domaines
Exploration de pistes de réflexion :
  • Pistes littéraires : œuvres, auteurs, genres
  • Pistes thématiques : thèmes, motifs, symboles
  • Pistes formelles : formes, styles, procédés
  • Pistes culturelles : contexte historique, culturel
  • Pistes personnelles : réflexions personnelles

II. Classement des Idées

Classement des idées : Organisation des idées issues du brainstorming en regroupant celles qui sont liées, en identifiant les arguments et en trouvant des exemples littéraires.
Regroupement par thèmes :
  • Identification des thèmes : Repérer les thèmes communs
  • Classification : Classer les idées par catégories
  • Sous-thèmes : Distinguer les sous-thèmes
  • Hiérarchie : Établir une hiérarchie entre les idées
  • Regroupement : Regrouper les idées similaires
Identification des arguments :
  • Thèse : Idée principale à défendre
  • Arguments : Idées qui soutiennent la thèse
  • Preuves : Exemples qui illustrent les arguments
  • Nuances : Distinctions et précisions
  • Contre-arguments : Arguments opposés à anticiper
Recherche d'exemples littéraires :
  • Œuvres étudiées : Œuvres du programme
  • Œuvres lues : Autres œuvres connues
  • Citations : Citations pertinentes
  • Personnages : Personnages significatifs
  • Scènes : Scènes marquantes

III. Sélection

Sélection des idées : Choix des idées les plus pertinentes pour la dissertation, en éliminant les redondances et en assurant la cohérence de l'ensemble.
Choix des idées les plus pertinentes :
  • Pertinence : Choisir les idées en lien avec le sujet
  • Originalité : Privilégier les idées originales
  • Force : Sélectionner les arguments les plus solides
  • Clarté : Choisir les idées claires et compréhensibles
  • Variété : Assurer la variété des arguments
Élimination des redondances :
  • Recherche des doublons : Repérer les idées répétées
  • Fusion : Fusionner les idées similaires
  • Simplification : Simplifier les arguments redondants
  • Épuration : Éliminer les idées inutiles
  • Concision : Aller à l'essentiel
Assurance de la cohérence :
  • Unité : Vérifier l'unité des idées
  • Logique : Vérifier l'enchaînement logique
  • Progression : Assurer une progression des idées
  • Équilibre : Équilibrer les différents arguments
  • Fidélité : Rester fidèle à la problématique

IV. Organisation

Organisation des idées : Structuration des idées sélectionnées en axes de réflexion pour préparer le plan détaillé de la dissertation.
Structuration en axes de réflexion :
  • Axe 1 : Premier axe de réflexion
  • Axe 2 : Deuxième axe de réflexion
  • Axe 3 : Troisième axe de réflexion
  • Progression : Progression logique entre les axes
  • Équilibre : Équilibre entre les axes
Types de plans :
  • Plan dialectique : Thèse, antithèse, synthèse
  • Plan thématique : Trois thèmes différents
  • Plan progressif : Du plus simple au plus complexe
  • Plan analytique : Analyse d'un problème
  • Plan mixte : Combinaison de plusieurs approches
Préparation du plan détaillé :
  • Intitulé des parties : Titre de chaque partie
  • Arguments : Arguments de chaque partie
  • Exemples : Exemples pour chaque argument
  • Transitions : Transitions entre les parties
  • Conclusion : Conclusion de chaque partie

V. Conclusion

La recherche d'idées pour la dissertation littéraire suit plusieurs étapes méthodiques. Le brainstorming consiste à noter toutes les idées qui viennent à l'esprit sans filtrer, en explorant différentes pistes de réflexion. Le classement des idées regroupe les idées par thèmes, identifie les arguments et trouve des exemples littéraires. La sélection choisit les idées les plus pertinentes, élimine les redondances et assure la cohérence. L'organisation structure les idées en axes de réflexion et prépare le plan détaillé de la dissertation. La maîtrise de cette méthode est essentielle pour construire une dissertation riche et structurée.
