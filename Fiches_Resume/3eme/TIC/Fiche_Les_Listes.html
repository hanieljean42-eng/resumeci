📖 TIC🏫 3èmeLes listes (Scratch)

I. Définition

Liste : Structure de données permettant de stocker plusieurs valeurs dans une seule variable. Les éléments sont ordonnés et accessibles par leur position (indice).

II. Caractéristiques d'une liste

  • Contient plusieurs éléments de même type (nombres, textes...)
  • Chaque élément a une position (indice)
  • Le premier élément est à la position 1 (dans Scratch)
  • La taille de la liste peut varier

III. Blocs de liste dans Scratch

BlocFonction
Ajouter ... à ...Ajoute un élément à la fin de la liste
Supprimer l'élément ... de ...Efface l'élément à la position donnée
Insérer ... à la position ... de ...Ajoute un élément à une position précise
Remplacer l'élément ... de ... par ...Modifie la valeur d'un élément
Élément ... de ...Récupère la valeur d'un élément
Longueur de ...Donne le nombre d'éléments
... contient ... ?Vérifie si un élément existe

IV. Exemple : Calcul de moyenne

  1. Créer une liste "Notes"
  2. Ajouter les notes une par une (15, 12, 18...)
  3. Calculer la somme de tous les éléments
  4. Diviser par la longueur de la liste
  5. Afficher la moyenne

V. Applications des listes

  • Stocker des notes pour calculer une moyenne
  • Gérer un inventaire dans un jeu
  • Mémoriser des positions pour un dessin
  • Créer un questionnaire à choix multiples
