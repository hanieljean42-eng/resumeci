📖 TIC🏫 3èmeLes variables (Scratch)

I. Définition

Variable : Espace de stockage dans la mémoire de l'ordinateur qui conserve une valeur pouvant changer au cours du programme. Chaque variable a un nom.

II. Caractéristiques

  • Nom : Identifiant unique (ex: "score", "age", "nom_joueur")
  • Valeur : Contenu actuel de la variable
  • Type : Nombre, texte (chaîne de caractères), booléen (vrai/faux)
  • La valeur peut être modifiée pendant l'exécution

III. Créer une variable dans Scratch

  1. Cliquer sur "Créer une variable" (données)
  2. Donner un nom explicite
  3. Choisir la portée : pour tous les lutins ou pour ce lutin seulement
  4. La variable apparaît sur la scène (peut être masquée)

IV. Affectation et opérations

BlocActionExemple
Mettre ... à ...Donner une valeurMettre "age" à 15
Ajouter ... à ...IncrémenterAjouter 1 à "score"
Soustraire ... de ...DécrémenterSoustraire 5 de "vie"
Montrer / Cacher variableAffichageMontrer "score"

V. Exemple pratique

Calculer l'âge du père :
  1. Créer variable "mon_age" et mettre à 12
  2. Créer variable "age_pere"
  3. Mettre "age_pere" à ("mon_age" + 25)
  4. Montrer "age_pere" → affiche 37

VI. Applications

  • Score : dans un jeu
  • Vies : compteur de vies restantes
  • Chronomètre : temps écoulé
  • Résultat : stocker un calcul
  • État : mémoriser une situation
