📖 SVT🏫 3èmeLeçon 3 : Le sang

I. Composition du sang

Le sang = plasma (55%) + éléments figurés (45%)

II. Le plasma

Plasma : Liquide dans lequel baignent les cellules sanguines. Composition :
  • Eau (90%)
  • Glucose, lipides, protides
  • Sels minéraux
  • Déchets (urée)
  • Hormones
  • Fibrinogène (protéine de coagulation)

III. Les éléments figurés

CelluleCaractéristiquesFonctions
Globules rouges (hématies)Sans noyau, contiennent hémoglobine, couleur rougeTransport de l'oxygène (grâce à l'hémoglobine)
Globules blancs (leucocytes)Avec noyau, plusieurs typesDéfense immunitaire (combattre microbes)
PlaquettesFragments de cellulesCoagulation sanguine

IV. L'hémoglobine

Hémoglobine : Protéine contenue dans les globules rouges qui donne la couleur rouge au sang.
Rôle : Fixer l'oxygène dans les poumons et le libérer dans les tissus.
Formule : Hb + O₂ → HbO₂ (oxyhémoglobine)

V. Fonctions du sang

  • Transport : O₂, CO₂, nutriments, hormones, déchets
  • Défense : Globules blancs + anticorps
  • Coagulation : Prévention des hémorragies
  • Régulation : Température corporelle (circulation)
