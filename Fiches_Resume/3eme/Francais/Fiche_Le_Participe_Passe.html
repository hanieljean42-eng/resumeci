📖 Français🏫 3èmeLe participe passé

I. Formation du participe passé

Forme du verbe utilisée avec les auxiliaires avoir et être pour former les temps composés (passé composé, plus-que-parfait...).
GroupeRègleExemples
1er (-er)-er → -éparler → parlé, manger → mangé
2e (-ir)-ir → -ifinir → fini, choisir → choisi
3eFormes irrégulièresvoir → vu, faire → fait, prendre → pris

II. Accord avec l'auxiliaire ÊTRE

Règle : Le participe passé s'accorde toujours avec le sujet du verbe.
Ex : « Elle est allée au marché » (accord avec "elle")
« Les enfants sont partis » (accord avec "enfants")

III. Accord avec l'auxiliaire AVOIR

Règle générale : Le participe passé avec AVOIR est invariable...
EXCEPTION : Accord avec le COD placé avant le verbe.

Application de la règle

SituationAccordExemple
COD après le verbeInvariable« Il a mangé une pomme » (pas d'accord)
COD avant le verbeS'accorde avec le COD« La pomme qu'il a mangée » (COD "pomme" = féminin)
COD avec êtreS'accorde toujours avec le sujet« Elles sont venues »

IV. Participe passé des verbes pronominaux

Règle générale : Accord avec le sujet (comme avec être).
Ex : « Elle s'est lavée » (COD = elle, placé avant)

Exception : Si le COI est placé après, pas d'accord :
« Elle s'est lavé les mains » (COI "mains" placé après)
