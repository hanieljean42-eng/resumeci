I. Équations du 1er degré

Types simples

TypeSolution
x + a = bx = b − a
ax = b (a ≠ 0)x = b/a

Type général : ax + b = cx + d

Méthode :
  1. Regrouper les termes en x d'un côté : ax − cx = d − b
  2. Factoriser : (a − c)x = d − b
  3. Diviser : x = (d − b) / (a − c) si a ≠ c
Cas particuliers :
  • 0x = 0 → infinité de solutions (tout ℝ)
  • 0x = b (b ≠ 0) → aucune solution

II. Inéquations du 1er degré

Inéquation : ax + b < cx + d (ou ≤, >, ≥)
Règle fondamentale : en multipliant ou divisant par un nombre NÉGATIF, on INVERSE le sens de l'inégalité.

Résolution

Exemple : 3x − 5 < 7
3x < 12 → x < 4
Ensemble solution : ]←; 4[

III. Équation produit

A × B = 0 ⟺ A = 0 ou B = 0
Exemple : (2x − 6)(x + 3) = 0
2x − 6 = 0 → x = 3
x + 3 = 0 → x = −3
Solutions : {−3 ; 3}
