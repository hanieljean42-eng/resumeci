I. Propriété de Thalès

Dans un triangle ABC, si M ∈ (AB) et N ∈ (AC) et si (MN) // (BC), alors :
AM/AB = AN/AC = MN/BC
Utilité : Calculer des longueurs inconnues lorsqu'on a des droites parallèles.

II. Configurations de Thalès

ConfigurationDescription
TriangleM sur [AB], N sur [AC], (MN) // (BC)
PapillonDeux droites sécantes en A, (BC) // (MN), M et N de l'autre côté de A
Dans les deux cas : AM/AB = AN/AC

III. Réciproque de Thalès

Si M ∈ (AB), N ∈ (AC) et si AM/AB = AN/AC avec M et N du même côté de A, alors (MN) // (BC).
Thalès : droites // → égalité de rapports
Réciproque : égalité de rapports → droites //
