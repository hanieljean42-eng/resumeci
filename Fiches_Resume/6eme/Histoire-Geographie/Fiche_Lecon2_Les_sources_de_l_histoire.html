📚 Histoire-Géographie🏫 6èmeLeçon 2 – Les sources de l’histoire
Objectifs de la leçon :
  • Définir ce qu’est une source de l’histoire.
  • Identifier les principaux types de sources.
  • Comprendre leur utilité et leurs limites.

I. Définition

Les sources de l’histoire sont l’ensemble des éléments qui permettent de reconstituer les faits passés.

II. Les principaux types de sources historiques

1. Les sources écrites

Ce sont tous les documents écrits :

  • manuscrits, archives, lettres anciennes ;
  • livres d’histoire, récits, mémoires ;
  • textes religieux (Bible, Coran…) ;
  • textes gravés sur des supports (tablettes, papyrus, parchemins…).

2. Les sources orales

Elles sont constituées des témoignages parlés :

  • récits des anciens ;
  • paroles des griots ;
  • traditions et légendes transmises de génération en génération.

3. Les sources archéologiques (ou muettes)

Ce sont les objets matériels découverts lors des fouilles :

  • outils, poteries, armes, bijoux ;
  • ruines de bâtiments, tombes, fossiles…

4. Les sources audio‑visuelles

Ce sont les documents modernes :

  • photographies, films, enregistrements audio ou vidéo ;
  • émissions de radio et de télévision.
Pour écrire l’histoire, l’historien croise plusieurs types de sources pour vérifier les informations.

III. Intérêt et difficultés des sources

  • Les sources permettent de connaître le passé même très ancien.
  • Mais elles peuvent être :
    • incomplètes (documents manquants ou détruits) ;
    • partiales (points de vue déformés, exagérations, oublis) ;
    • difficiles à interpréter (tradition orale, vestiges abîmés…).
  • L’historien doit donc les critiquer et les comparer.
À retenir : aucune source n’est parfaite ; l’objectivité vient de la multiplication et de la critique des sources.

IV. Synthèse pour le contrôle

  • Les sources de l’histoire peuvent être écrites, orales, archéologiques ou audio‑visuelles.
  • Elles sont indispensables pour reconstituer le passé, mais doivent être utilisées avec prudence.
  • L’historien croise les sources et les critique pour approcher la vérité historique.
