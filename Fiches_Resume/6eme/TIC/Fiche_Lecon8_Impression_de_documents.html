📝 FICHE DE RÉSUMÉ

📚 TIC🏫 6èmeLeçon 8 – Impression de documents
Objectifs de la leçon :
  • Prévisualiser un document pour vérifier la présentation avant impression.
  • Choisir une imprimante et une configuration adaptée.
  • Gérer l’impression sans gaspiller de papier (deux exemplaires, recto verso si possible).

I. Préparation avant impression

  • Lire le document attentivement pour détecter les fautes de frappe ou de mise en page.
  • Utiliser l’aperçu avant impression pour vérifier les marges, l’en-tête, les sauts de page.
  • Choisir une imprimante disponible.

II. Étapes de l’impression

  1. Cliquer sur Fichier > Imprimer (ou Ctrl+P).
  2. Sélectionner l’imprimante.
  3. Choisir le nombre d’exemplaires (ex. : 2 pour le directeur et l’élève) et le format (A4).
  4. Activer le recto verso si l’imprimante propose l’option, pour économiser du papier.
  5. Démarrer l’impression.
Prévisualisation → sélection imprimante → configuration (ex. recto verso) → impression.

III. Après l’impression

  • Vérifier chaque page pour s’assurer que le texte n’est pas tronqué.
  • Classer les exemplaires imprimés, en conserver un et donner l’autre à la personne concernée.
  • Éteindre l’imprimante ou la remettre en veille pour économiser l’énergie.
À retenir : imprimer un document propre exige de contrôler sa mise en forme, de choisir une bonne configuration et de conserver les exemplaires nécessaires.

IV. Synthèse pour le contrôle

  • Prévisualiser avant d’imprimer évite les erreurs.
  • Choisir le bon nombre de pages et activer le recto verso si possible.
  • Ranger les documents imprimés dans un dossier ou une chemise.
