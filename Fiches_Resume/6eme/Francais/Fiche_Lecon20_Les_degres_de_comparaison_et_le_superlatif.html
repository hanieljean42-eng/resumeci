📚 Français🏫 6èmeLeçon 20 – Les degrés de comparaison et le superlatif
Objectifs de la leçon :
  • Connaître les degrés de comparaison de l’adjectif qualificatif.
  • Distinguer comparatif et superlatif.
  • Savoir les utiliser correctement.

I. Les degrés de comparaison de l’adjectif

On utilise la comparaison pour rapprocher deux éléments et apprécier une qualité (grand, beau, rapide…).

On distingue trois comparatifs :

  • Comparatif d’infériorité :
    • structure : moins + adjectif + que
    • exemple : La candidate 3 est moins grande que la candidate 1.
  • Comparatif d’égalité :
    • structure : aussi + adjectif + que
    • exemple : La candidate 1 est aussi grande que la candidate 2.
  • Comparatif de supériorité :
    • structure : plus + adjectif + que
    • exemple : La candidate 2 est plus grande que la candidate 3.
Comparatif : on compare deux éléments pour dire qui a « plus / moins / autant » d’une qualité.

II. Le superlatif

Le superlatif exprime le degré le plus haut ou le plus bas d’une qualité, dans un groupe.

1. Superlatif relatif

Il indique la qualité par rapport à un ensemble.

  • Forme : article défini (le, la, les) + comparatif de supériorité ou d’infériorité

Exemples :

  • La classe de 6ᵉ 2 est la plus propre.
  • Claude est le moins bavard de tous mes enfants.

2. Superlatif absolu

Il exprime une qualité à un très haut degré, sans comparaison directe avec un groupe.

  • Forme : adverbe d’intensité + adjectif : très, fort, bien, tout à fait, infiniment, extrêmement, super…

Exemples :

  • La classe de 6ᵉ 2 est très propre.
  • Cet élève est super intelligent.
  • Il est merveilleusement beau, ce collier.
À retenir : le comparatif compare deux éléments, le superlatif met en avant un élément parmi tous les autres ou insiste fortement sur une qualité.

III. Synthèse pour le contrôle

  • Trois comparatifs : moins…que, aussi…que, plus…que.
  • Superlatif relatif : le / la / les plus… ou le / la / les moins….
  • Superlatif absolu : adverbe d’intensité + adjectif (très, extrêmement, super…).
