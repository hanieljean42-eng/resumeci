📚 Français🏫 6èmeLeçon 19 – Les déterminants du nom : démonstratifs et possessifs
Objectifs de la leçon :
  • Identifier le déterminant dans le groupe nominal.
  • Connaître les adjectifs démonstratifs et possessifs.
  • Savoir les accorder en genre et en nombre.

I. Le déterminant du nom

Le déterminant est un mot placé devant le nom. Il :

  • fait partie des constituants obligatoires du groupe nominal ;
  • s’accorde en genre (masculin / féminin) et en nombre (singulier / pluriel) avec le nom.
GN = Déterminant + Nom (+ expansions)

II. Les adjectifs démonstratifs

1. Emploi

Ils servent à montrer, à désigner un être ou une chose dont on parle.

Exemples :

  • Ce monsieur est mon père.
  • Cette école est belle.

2. Formes

  • Masculin singulier :
    • ce devant consonne : ce garçon ;
    • cet devant voyelle ou h muet : cet arbre, cet homme.
  • Féminin singulier :
    • cette : cette statue, cette école.
  • Masculin ou féminin pluriel :
    • ces : ces garçons, ces filles.

III. Les adjectifs possessifs

1. Emploi

Ils marquent une relation de possession ou d’appartenance :

  • ma maison (maison qui m’appartient) ;
  • mais aussi d’autres liens : mon professeur de français (lien professionnel).

2. Formes

Ils varient selon :

  • la personne du possesseur (1ʳᵉ, 2ᵉ, 3ᵉ personne) ;
  • le genre et le nombre de l’objet possédé.
  • Masculin singulier : mon, ton, son, notre, votre, leur
  • Féminin singulier : ma, ta, sa, notre, votre, leur
  • Masculin ou féminin pluriel : mes, tes, ses, nos, vos, leurs

Exemples :

  • Son véhicule est encore neuf.
  • Ma maison a été détruite.
  • Notre maison a été détruite.

Cas particulier :

  • devant un nom féminin commençant par une voyelle ou un h muet, on emploie mon, ton, son :
    • mon école, mon histoire, son habitation.
À retenir : les adjectifs démonstratifs et possessifs s’accordent toujours avec le nom qu’ils accompagnent.

IV. Synthèse pour le contrôle

  • Le déterminant est obligatoire dans le groupe nominal (sauf nom propre/pronom).
  • Les démonstratifs (ce, cet, cette, ces) servent à montrer.
  • Les possessifs (mon, ma, mes…) marquent une appartenance.
