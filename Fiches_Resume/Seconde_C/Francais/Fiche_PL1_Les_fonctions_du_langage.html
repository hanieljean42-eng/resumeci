I. Rappels sur la communication

1. Situation de communication

  • Communiquer, c’est transmettre un message d’un émetteur à un destinataire dans une situation donnée.
  • Tout acte de communication met en jeu plusieurs facteurs :
    • Émetteur (ou destinateur) : celui qui parle / écrit.
    • Destinataire (ou récepteur) : celui qui reçoit le message.
    • Message : ce qui est dit / écrit.
    • Code : langue, signes utilisés (français, symboles, images…).
    • Canal : support de transmission (voix, téléphone, télévision, livre…).
    • Référent : sujet dont on parle (thème, situation, objet…).

II. Les principales fonctions du langage

1. Définition générale

À chaque facteur de la communication correspond une fonction du langage, c’est‑à‑dire une manière particulière d’utiliser la langue.

FacteurFonctionRôle principal
ÉmetteurFonction expressive / émotiveExprimer sentiments, émotions, jugement personnel.
DestinataireFonction conativeAgir sur l’autre (ordre, conseil, demande…).
CanalFonction phatiqueÉtablir, maintenir ou interrompre le contact.
MessageFonction poétiqueMettre l’accent sur la forme du message (rythme, images…).
CodeFonction métalinguistiqueParler de la langue elle‑même (définitions, explications de mots…).
RéférentFonction référentielleInformer sur la réalité (faits, événements, lieux, temps…).

III. Caractéristiques et exemples

1. Fonction expressive (émotive)

  • Centrée sur l’émetteur et ses sentiments.
  • Marques fréquentes :
    • interjections : « Oh ! », « Ah ! », « Hélas ! »
    • ponctuation expressive : « ! », « ?! »
    • adverbes d’intensité, jugement : « tellement », « vraiment », « trop ».
  • Exemple : « Quelle belle voiture ! »

2. Fonction conative

  • Centrée sur le destinataire, vise à influencer son comportement.
  • Marques fréquentes :
    • impératif : « Écoutez‑moi », « Venez » ;
    • interpellations : « Peuples ! », « Mes chers amis… ».
  • Exemple : « Seigneur, garde ta puissante main sur moi. »

3. Fonction phatique

  • Centrée sur le canal (établir ou vérifier le contact).
  • Marques fréquentes :
    • formules d’appel : « Allô ? », « Vous m’entendez ? », « Me suivez‑vous ? »
    • répétitions pour garder l’attention.
  • Exemple : « Je n’accepterai plus de retard, vous m’entendez ? »

4. Fonction poétique

  • Centrée sur la forme du message (sonorités, images, rythme).
  • Marques fréquentes : figures de style (métaphores, comparaisons, allitérations…).
  • Exemple : « Cette femme est une vipère. »

5. Fonction métalinguistique

  • Centrée sur le code, la langue elle‑même.
  • Marques fréquentes : définitions, reformulations, explications de mots.
  • Exemple : « De nos jours, le sexe est omniprésent ; en d’autres termes, on parle de sexualité… »

6. Fonction référentielle

  • Centrée sur le référent (information sur le monde).
  • Marques fréquentes : indications de temps, de lieu, de faits.
  • Exemple : « Le fleuve Sassandra passe par la ville de Soubré. »

IV. À retenir

  • Un même énoncé réalise souvent plusieurs fonctions du langage à la fois, mais l’une est généralement dominante.
  • Les 6 fonctions classiques sont : expressive, conative, phatique, poétique, métalinguistique et référentielle.
  • Les reconnaître permet d’analyser finement un texte et de mieux maîtriser ses propres productions orales et écrites.
